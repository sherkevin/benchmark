**PR-62 的意义要单独说**：goal §2b 的

$$\text{open\_score} = \mathbb{1}[\text{hit}(G_B)] \times \mathbb{1}[\text{grounding\_pass}]$$

其中：
- $\mathbb{1}[\cdot]$：指示函数，条件成立取 1、不成立取 0；
- $\text{hit}(G_B)$：提交的分子属于该 case 落盘的 B 侧合格集 $G_B$；
- $\text{grounding\_pass}$：产物落地验证通过（anchor ∈ A、引用值与工具返回一致、`edit_op(anchor)` 规范化后 == 提交分子）；

**这个公式在你上一轮跑的时候一次都没执行过**（被路由劫走了）。本轮是它第一次真正上场——所以 **open 那道题的判分结果这次才有意义**。
