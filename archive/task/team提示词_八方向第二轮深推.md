## 【共同背景】——以下每份提示词都已内含，复制时不用单独粘

（此段仅供你自己参考，八份里都已包含）

项目：造制药领域 agent benchmark，最终目的**不是评测，而是让模型在制药任务上真的变强**。
故事线：多个计算工具对同一分子给出矛盾预测，agent 判断该信谁并恢复决策。

**五条硬约束**：① 禁蒸馏（不用更强模型当老师）② 禁 LLM-as-judge ③ 单 agent ④ 判分机械可判 ⑤ 已收敛到制药，不扩模态。

**已有真实数据**：血脑屏障通透性冲突普查——4 个真实模型（ADMET-AI 1.4.0 + DeepPurpose 的 cnn/morgan/mpnn）× 730 分子，400 行可复现跨体系冲突，每行带实验真值，复测漂移 0。BBB 是二分类。

**已实测的六个数字（勿重复验证，直接用）**：恒答基线 66.3%（真值偏斜 265:135）｜固定选 morgan = **80.5%**、admet_ai = 79.2%｜理想选择器 = 100%｜四工具**全错仅 12 行**｜DeepPurpose-cnn 高置信 247 行**错 153**（置信度是反指标）｜跑间噪声底 0.18–0.29。

**第一轮已确立的六条结论（勿推翻，除非有新证据）**：
1. **方差分解二难**：误差 = 分子主效应 + 工具主效应 + 交互项。"选最准的工具"靠交互项 ⇒ 换工具失效；"判断这组能不能用"靠分子主效应 ⇒ 可迁移。二者不可兼得。
2. **势函数塑形定理**：形如 $r_t = [\log p_t - \log p_{t-1}] - \lambda c_t$ 的逐步奖励，其求和只依赖端点 ⇒ 保最优策略不变（Ng 1999）⇒ **数学上不可能抬上限**，只能降方差、给可读诊断。真正改变最优策略的只有成本项 $-\lambda c_t$。
3. **抬上限靠标签空间重构**：二分类真值的残余信息仅 19.5 个百分点（80.5→100），约 0.3 bit/行；而"工具可靠性向量"每行最多 4 bit。差一个数量级。
4. **静态判断不与经典方法竞争**："给分子和预测值判断可信度"是适用域判定，四十年文献，随机森林几分钟零 GPU 可训。agent 的唯一优势是**能主动决定去查什么**。
5. **纯 outcome RL 抬不了上限**（arXiv:2504.13837 NeurIPS 口头 + 2507.14843 + 2510.15990 三篇独立证否）；且**纯采样不训练即可匹配 RL**（arXiv:2510.14901）⇒ 任何 RL 提升必须对照等算力采样基线。
6. **拐杖与工具的分界线**：是否被告知何时用它。做成平凡命名、无使用说明、有成本的检查器 = 工具（合规）；写进提示词告诉它何时用 = 拐杖（变成测指令遵循）。

**已砍掉的两项（别再提）**：① "错误共识"子目标——全库只有 12 行四工具全错，统计上做不了；② 原文里"蛋白家族"这一维——BBB 没有靶点，这一维在本数据上不存在。

**工程现实**：训练栈未装（无 trl/peft/vllm）；1 块 H20；测试集若只有 80 行，1 行 = 1.25 个百分点，只能检出 ≥8 个点的差异。

# 方向 2｜预算感知的主动复核

## 共同背景
（同方向 1，此处照抄）项目：造制药 agent benchmark，最终目的让模型在制药任务上真的变强。故事线：多个工具对同一分子给矛盾预测，agent 判断该信谁。

**五条硬约束**：① 禁蒸馏 ② 禁 LLM-as-judge ③ 单 agent ④ 判分机械可判 ⑤ 已收敛到制药。

**已有真实数据**：4 个真实模型（ADMET-AI + DeepPurpose 的 cnn/morgan/mpnn）× 730 分子，400 行可复现跨体系冲突，每行带实验真值。BBB 二分类。

**已实测数字**：恒答 66.3%｜固定选 morgan = 80.5%｜理想选择器 100%｜四工具全错仅 12 行｜cnn 高置信 247 行错 153｜噪声底 0.18–0.29。

**已确立结论**：① 静态判断不与经典方法竞争，**agent 的唯一优势是能主动决定去查什么**——本方向正是这个优势位；② **势函数塑形定理**：$r_t = [\log p_t - \log p_{t-1}] - \lambda c_t$ 的求和只依赖端点 ⇒ 保策略不变 ⇒ 不可能抬上限，只能降方差；真正改变最优策略的只有 $-\lambda c_t$；③ 纯采样即可匹配 RL，任何提升须对照等算力采样基线。

**工程现实**：1 块 H20；训练栈未装。

## 方向原文
将工具调用视为有成本的信息获取问题，让 Agent 学会选择预期信息增益最高的同功能或正交工具，并研究准确率、时延和算力之间的 Pareto 前沿。

## 第一轮已得出的结论（别重做）
- 信息增益的可计算定义已给：$\text{EIG}(a|s) = H(Y|s) - \mathbb{E}_o H(Y|s,o)$，收益密度 = EIG/成本，停止条件 $\max_a \text{EIG}/c < \lambda$。
- **诚实自认：目标函数与经典最优实验设计完全没区别。** 区别只在两点——① 动作是异质、不可枚举的（读工具元数据、扰动重问、查文献），写不出 $P(o|Y,a)$；② agent 用化学先验**零样本**给似然。**这两点必须写进设计，否则应当认输。**
- 叙述定为"零样本的信息价值——当设计空间无法枚举、似然无法写出时，先验知识本身就是实验设计能力"。
- **生死判据（已预注册为 kill check）**：若单个廉价探针（很可能是训练集近邻相似度）就拿到 >80% 的可得信息，前沿塌成一步规则 ⇒ 整条方向判死。

## 这轮要往深推的四个问题
1. **把那 12 个探针具体列出来**，每个写：它测什么、返回什么形状、成本怎么定、**预判它能贡献多少 bit**。并标出你认为哪个最可能导致"探针退化"。
2. **"开放/不可枚举的探针空间"怎么落成可判分的实验？** 如果动作空间不可枚举，判分器怎么知道 agent 选的动作是好的？给出机械可判的方案。
3. **成本表怎么定才不被质疑是"人为设定"？** 给出可辩护的定价方式（实测时延？归一到一次模型推理？）。
4. **在 $H(Y) \le 1$ bit、n=400 的条件下，Pareto 前沿的动态范围够不够？** 若不够，怎么办（换 bit 指标？扩 endpoint？配对 bootstrap？）。

# 方向 3｜跨性质约束推理

## 共同背景
项目：造制药 agent benchmark，目的让模型在制药任务上真的变强。故事线：多个工具对同一分子给矛盾预测，agent 判断该信谁。

**五条硬约束**：① 禁蒸馏 ② 禁 LLM-as-judge ③ 单 agent ④ 判分机械可判 ⑤ 已收敛到制药。

**已有真实数据**：4 个真实模型 × 730 分子（BBB 二分类），400 行可复现跨体系冲突，每行带实验真值。另有本地实测：AqSolDB 溶解度约 9983 条、TDC 脂水分配数据。

**已实测数字**：恒答 66.3%｜固定选 morgan 80.5%｜理想 100%｜四工具全错仅 12 行｜噪声底 0.18–0.29。

**已确立结论**：**拐杖与工具的分界线 = 是否被告知何时用它**。做成平凡命名、无使用说明、有成本的检查器 = 工具（合规）；写进提示词告诉它何时用 = 拐杖（变成测指令遵循）。

## 方向原文
建立制药知识图谱或可执行约束层，把结构、亲和力、物化性质、ADMET、稳定性和成药性联系起来，帮助 Agent 区分真实矛盾、单位/定义差异和合理的条件依赖。

## 第一轮已得出的结论（别重做）
- 内核：把"该信谁"这个主观仲裁降维成"**这组赋值是否存在可行解**"的可判定问题。
- 七条约束已给（含硬/软标注）：logD–logP–pKa 的 Henderson-Hasselbalch 恒等式（硬）、pH–溶解度单调（硬）、永久阳离子不可被动跨 BBB（硬）、溶解度经验式 GSE（软 ±1 log）、TPSA>140 或 HBD>6 渗透极低（有例外）、InChIKey 分段比对判定义差异（硬）、单位恒等换算（硬）。
- 三关顺序判据已给：关一单位/定义差异 → 关二解方程看有无正解（条件依赖）→ 关三硬约束不可满足且跨决策阈值（真实矛盾）。**容差只许取自实验重复误差，不许手调。**
- **不配当独立题型**——"能被约束一步判死的题就该删掉"（那是测完即答案型）。
- **最有价值的用法是第三种：约束层当筛题器 + 数据生成器**——给冲突打"约束可判定/约束沉默"两标，前者当校准哨兵、后者当主测试集；再反向合成受控假冲突把 730 扩到数千。

# 方向 4｜规划—执行—审计分工

## 共同背景
项目：造制药 agent benchmark，目的让模型在制药任务上真的变强。故事线：多个工具对同一分子给矛盾预测，agent 判断该信谁。

**五条硬约束**：① 禁蒸馏 ② 禁 LLM-as-judge ③ **单 agent（立项硬边界）** ④ 判分机械可判 ⑤ 已收敛到制药。

**已有真实数据**：4 个真实模型 × 730 分子（BBB 二分类），400 行可复现跨体系冲突，每行带实验真值，每个 run 有完整轨迹（工具调用账本）。

**已实测数字**：恒答 66.3%｜固定选 morgan 80.5%｜理想 100%｜四工具全错仅 12 行｜cnn 高置信 247 行错 153。

**已确立结论**：纯 outcome RL 抬不了上限；纯采样即可匹配 RL；势函数塑形形式的逐步奖励保策略不变、不能抬上限。

## 方向原文
探索 planner、tool executor 和 scientific auditor 的多角色架构；审计角色专门检查证据来源、参数一致性、未验证假设和替代解释，降低过早停止和工具盲从。

## 第一轮已得出的结论（别重做）
- **作为独立的"多角色架构"方向不值得做**：合规化后（同权重、同上下文、确定性阶段切换）只剩提示词调度，无科研分量；不合规化则撞单 agent 硬边界。
- **但两块价值必须被主线吸收**：
  ① **环境侧确定性过程检查器**（非 LLM，机械可判）——查引用的工具输出是否真在轨迹里、质子化态是否一致、是否在关键证据缺失时提前提交；
  ② **"agent 会假装自己验证过"这个指标**——声称做过的检查 vs 实际做过的检查之间的落差（claimed-vs-actual verification gap）。
- 已知风险：清单不完备导致 Goodhart（刷满检查项仍判错）；阶段化收益可能只是格式/长度效应，对照必须控 token 预算。

## 这轮要往深推的四个问题
1. **那个"落差"指标怎么精确定义？** 给出数学形式：声称向量、实际向量、落差怎么算（汉明距离？分方向的假声称率/漏声称率？），以及为什么这个定义不可被刷。
2. **"实际做过的检查"怎么从轨迹里机械提取？** 现有轨迹是工具调用账本（tool / args / result）。请给出具体的提取规则，并指出哪些检查在现有轨迹格式下**提取不出来**（需要加什么字段）。
3. **确定性检查器的检查项清单**：列出 K 个机械可判的检查项，每项写判据。并诚实标出哪些是"必要不充分"（可被刷）。

# 方向 5｜面向恢复过程的训练（本轮最关键）

## 共同背景

**已有真实数据**：4 个真实模型（ADMET-AI 1.4.0 + DeepPurpose 的 cnn/morgan/mpnn）× 730 分子，400 行可复现跨体系冲突，每行带实验真值，复测漂移 0。BBB 二分类。

## 方向原文

## 第一轮已得出的结论（别重做，这些是本轮的地基）
1. **势函数塑形定理**：形如 $r_t = [\log p_t(y) - \log p_{t-1}(y)] - \lambda c_t$ 的逐步奖励，其求和只依赖端点 ⇒ 保最优策略不变（Ng 1999）⇒ **数学上不可能抬上限**。它是**方差手段与可解释性工具**，不是能力手段。真正改变最优策略的只有成本项 $-\lambda c_t$。
2. **抬上限靠标签空间重构**：二分类真值的残余信息仅 19.5 个百分点（80.5→100），约 **0.3 bit/行**；换成"工具可靠性向量"（4 个工具各对不对）则每行最多 **4 bit**。差一个数量级。
3. **训练方式裁决**：GRPO **否**（400 prompt + 二元奖励 + 动作空间只有"4 工具 + 弃答"，必然收敛到恒跟 morgan = 80.5%，这就是锐化）；teacher-SFT 禁；DPO 仅作辅助且只用同策略自采样对；**推荐拒绝采样微调（RFT）为主 + 同策略 DPO 收尾**。
4. **两个实现细节已定**：$\lambda$ 在不相交校准子集上测基座每次调用的 $\Delta\log p$ 中位数，令 $\lambda$ 等于它（"一次调用必须挣回本"），不事后调；$p_0$ **必须由冻结的初始模型给出**，否则被训练策略会压低 $p_0$ 刷增益（sandbagging）。置信度一律不进奖励。
5. **冷启动三招**（都不违反禁蒸馏）：后见之明合理化（已知标签下生成复核叙述 + 泄漏检查过滤）+ 奖励基数课程 + k 采样兜底（k=32 时单条 5% 通过率也有约 80% 的 prompt 出至少一个正样本）。
6. **抬上限的判据是 pass@k（k=1…64）**：锐化 = k=1 赢而 k=64 被基座追平；抬上限 = k=64 仍赢。必报等推理算力的 best-of-n 基线。
7. **功效限制**：80 行测试集，1 行 = 1.25 个百分点，只能检出 ≥8 个点差异，须扩到 ≥300 行。
8. 叙述定为**有反结论的论文**："过程奖励是方差手段，不是能力手段"。

1. **"标签空间重构"怎么落成具体的训练目标？** 从 0.3 bit 到 4 bit 是理论上界，但**模型输出什么格式才能真的取到这 4 bit**？给出输入输出规格（agent 该被要求预测什么），以及对应的损失/奖励定义。
