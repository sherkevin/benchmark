## 1. 上游诉求（owner 原话）

> "先把背书过的数据集拉下来，所谓背书的数据集指的是这些数据集被其他论文构建 benchmark 的时候用过，我们可以直接拿对应 benchmark data，也可以拉 raw 的原数据集 data，都是可以的，看哪个更好用用哪个（这个任务产出的是数据集的调研报告，包括谁引用过该数据集，该数据集的权威性）"

## 2. 与 GOAL 的对齐

- **最终目标**（§1）：造评过程的 long-horizon agent benchmark。
- **本 task 服务于**：GT-first 反查法**第 1 步的数据底座**——真值必须锚定权威数据库（§4 可信度支柱 1）。**数据集的"被背书"属性是我们论文里数据可信度的直接论据**：能证明"该数据集已被其他论文造 benchmark 时采用"，就等于借用了同行评议的背书。
- **红线关联**（§5）：不得引用无出处的数据当真值；判分零联网，权威库只在造题阶段用。

## 3. 什么叫"被背书"（判定口径，避免各人理解不同）

一个数据集算被背书，须**同时**满足：

1. **被至少一篇已发表论文用于构建 benchmark**（不是仅被引用讨论，而是真的拿它的数据造了题或做了真值）；
2. 该论文**可查证**：有 venue（会议/期刊）+ DOI 或 arXiv 号；
3. 数据集本身有**可访问的公开来源 URL**。

> 三条缺一条即标注为"未达背书标准"，如实记录，**不凑数**。

## 4. 子目标与验收（三要素）

| # | 子目标 | 打勾通过标准 | 验证方式 | 红线 |
|---|---|---|---|---|
| 1 | 候选数据集清单 | 覆盖药物线与材料线，每个数据集四要素齐备（名称/URL/被引论文+venue+DOI/服务方向） | 逐条可点开核对 | 只写库名不写出处 |
| 2 | 背书证据落实 | 每个数据集写明**被哪篇论文用于造 benchmark**、该论文 venue 与 DOI | 抽查 ≥5 条能在原文找到对应描述 | 把"被引用过"当成"被用于造benchmark" |
| 3 | 可达性实测 | 每个 URL **当场 curl 实测**并记 HTTP 码与时间戳，**不沿用历史结论** | 报告中有实测表 | 抄历史文档的可达性结论 |
| 4 | 取 benchmark 成品还是 raw 的选择 | 每个数据集给出选择与**理由**（哪个更好用） | 报告中每条有一句结论 | 不做选择、两个都不说 |
| 5 | License 标注 | 标明许可，特别标出 ShareAlike 类（不可 bulk dump） | 报告有 License 列 | 漏标 SA 类导致全集被传染 |
| 6 | 落盘与留痕 | 拉下来的数据存 `dag_poc/data/sources/<db>/` + `MANIFEST.json`（url/时间/字节/行数/md5/完整性） | MANIFEST 齐备 | 只下载不留校验痕迹 |

## 6. 已知坑（前人踩过，别再踩）

1. **历史可达性结论会失效**：task12 实测发现 OQMD 从"可达"变为"不可达"、BindingDB 从"被墙"恢复为可达。**必须当场重测**。
2. **PubChem API 字段名与请求名不一致**：请求 `CanonicalSMILES`，实际返回 `ConnectivitySMILES`。
3. **大文件会被静默截断**：3DSC 9.4MB 实测需 3 轮断点续传才拉全；**zip 类必须额外做结构校验**（UCI 的 zip 曾下到 2.4MB 且 EOCD 校验失败）。
4. **Materials Project / OQMD 本环境不可达**（403 / 000），材料线已改锚 3DSC。
5. **ChEMBL 是 CC-BY-SA 3.0**：只存 ID + 查询配方，**不可 bulk dump**，否则整个数据集被 SA 传染。

## 7. 不做的事（边界）

- ❌ 不构造 mock 后端库（那是 `E1-后端数据库构造`／步 4）；
- ❌ 不定 tools 数量（E3）；
- ❌ 不写 query / template（E2、E5）；
- ❌ 不修 mock_db 的既有数据（SMILES 错配是 T-55，若顺路处理须另立 task）；
- ❌ 不引 DFT 预测值当真值（如 JARVIS 的预测列，只可用其实验锚点子集）。
