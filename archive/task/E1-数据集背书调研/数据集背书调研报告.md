## 〇、核心结论（先总后分）

**总结论**：16 行数据集（15 库口径全覆盖，SuperCon 衍生快照 UCI #464 单列一行）中，**8 个达背书标准、8 个未达背书标准**；可达性实测发生两处与 task12 不一致的结论（OQMD 由"000 不可达"翻转为"不稳定可达"，ChEMBL 旧式 API 端点已迁移返回 404）。**材料线最大风险确认**：材料线 7 行中仅 Materials Project 一家有 benchmark 背书（MADE），我方锚点 3DSC 本身无第三方 benchmark 背书、其权威性只能靠 Scientific Data 同行评议 + MP/SuperCon 双上游 provenance 支撑，论文表述必须区分这两类证据。

分述（三点）：

1. **背书判定**：达标 8 个——TDC ADMET、AqSolDB（经 TDC logS 任务间接背书）、PubChem、ChEMBL（SA 类）、BindingDB（弱背书）、PDB、ZINC、Materials Project（MADE venue 待官方 proceedings 复核）；未达标 8 个——UniProt、PDBbind、3DSC、SuperCon via UCI #464、SuperCon (NIMS 原始库)、OQMD、MPDS、JARVIS。未达标原因全部是口径①（无"被已发表论文用于构建 benchmark"的在案记录），SuperCon 原始库另叠加口径③主站不可达。
2. **可达性**：13/16 可达；Materials Project 403（预期内）、SuperCon NIMS 000（交互站拦脚本，预期内）；OQMD 间歇性 200/000 判为"不稳定可达"。
3. **落盘完成度**（1d 收口审校新增）：`dag_poc/data/sources/` 下 **11 库** MANIFEST 六要素齐全、`complete` 全 true，完整性自检脚本全绿（见 §六）。
4. **A/B 分层**：7 库完全支持（TDC、AqSolDB、BindingDB、PDB、UniProt、3DSC、UCI #464）；2 库有条件支持（PubChem、ZINC 为身份/候选池库，无目标性质列，第三条件不适用）；1 库暂缓判定（PDBbind，注册制数据未落盘）；ChEMBL 因 SA 约束只存 ID **不可分层**；MP/OQMD/MPDS/SuperCon NIMS 因可达性或许可受限当前不支持，JARVIS 弱支持。

## 五、A/B 分层判定（open 类任务物理分层可行性）

> 判据：open 类任务要求库可物理分层——A 侧 agent 可查、B 侧完全不可查、agent 须从 A 内线索推理出 A 中不存在的目标。三条件：a) 同分布（A/B 来自同一总体，随机或按属性分层切分）；b) 可分层（数据落盘后可按 ID/行切分并冻结）；c) B 侧目标性质无缺失（B 侧 held-out 条目具备判分所需的目标性质列）。
