# Task5 Ground Truth — 分阶段 vs 不分阶段(v1, 6 道 pipeline)

> 分开存,便于盲测。每题两层 GT:**实验值 GT**(sanity 锚)+ **派生/一致性 GT**(主分)。
> 派生 GT 须用「该模式自己 transcript 里工具/步骤返回的真实数值」重算来判——而非用下表的实验值重算
> (平台预测值可能与实验值有差;判"自洽"看的是它有没有用错/算错/漏掉自己得到的数)。
> 实验值容差:Tc ±20% 或 ±10K(取宽);带隙 ±0.2 eV 或 ±15%(取宽);logS/logD ±0.5;BBB/hERG/直接间接为类别精确匹配。

## 一、超导材料发现

### SC-P1（MgB2 vs Nb3Sn 对比分析）
- 实验值 GT:MgB2 Tc≈**39 K**;Nb3Sn Tc≈**18.3 K**。(形成能无统一实验 GT,按"两个都给出且为负值/热力学稳定"判合理性。)
- 派生 GT:
  - (a) Tc 比值 = MgB2_Tc ÷ Nb3Sn_Tc。用实验值 ≈ 39/18.3 ≈ **2.13**;判分时用该模式自己第 1、2 步报出的 Tc 重算,核对它报的比值是否与自己的数一致(两位小数)。
  - (b) 形成能之差 = MgB2 − Nb3Sn,核对方向与数值与自己的中间值自洽。
- 结论 GT:高场超导磁体 → **Nb3Sn**(更高 Hc2≈30 T,ITER/高场 NMR 主力;MgB2 主要用于低场/MRI)。
- 步骤覆盖:1–5 全做;报告里 Tc/形成能/比值/差值/结论齐全。

### SC-P2（4 材料筛选排序选型）
- 实验值 GT(常压 Tc):Nb **9.25 K**、MgB2 **39 K**、YBa2Cu3O7 **92–93 K**、Bi2Sr2Ca2Cu3O10(Bi-2223) **~110 K**。
- 派生 GT:
  - 第 2 步排序(高→低)= **Bi-2223 > YBCO > MgB2 > Nb**。
  - 第 3 步 >77 K 的 = **YBCO、Bi-2223**(MgB2 39、Nb 9.25 不过线)。
- 结论 GT:只能液氮(77 K)冷却的应用 → 选 **YBCO 或 Bi-2223**(唯二超过 77 K;实用 HTS 线材常用)。
- 一致性:排序、筛选、推荐三者与第 1 步报出的 Tc 自洽。

## 二、半导体材料性能预测

### SE-P1（GaN/GaAs/Si 能带分析选 LED）
- 实验值 GT(300 K):GaN **3.39–3.44 eV,直接**;GaAs **1.42 eV,直接**;Si **1.12 eV,间接**。
- 派生 GT:
  - 第 2 步排序(大→小)= **GaN > GaAs > Si**。
  - 第 3 步 GaN−Si 带隙差 ≈ 3.4 − 1.12 = **2.28 eV**(用模式自己报的值重算核对)。
- 结论 GT:高效蓝光 LED → **GaN**(带隙宽,落在蓝光区 ~3.4 eV,且为**直接**带隙,发光效率高;Si 间接带隙不能高效发光,GaAs 直接但带隙太窄发红外)。
- 一致性:排序/差值/结论与第 1 步自洽,直接-间接标注正确。

### SE-P2（5 材料光电选材筛选）
- 实验值 GT(300 K, eV / 类型):Si **1.12 / 间接**、GaAs **1.42 / 直接**、GaN **3.4 / 直接**、InAs **0.354 / 直接**、diamond(C) **5.47 / 间接**。
- 派生 GT:
  - 第 2 步排序(大→小)= **diamond > GaN > GaAs > Si > InAs**。
  - 第 3 步 >3 eV 宽禁带 = **diamond、GaN**。
  - 第 4 步 1.0–1.6 eV 中最接近 1.34 eV 的 = **GaAs(1.42)**(|1.42−1.34|=0.08 < |1.12−1.34|=0.22)。
- 结论 GT:(a) 紫外/功率器件 → **GaN(或 diamond)**;(b) 单结光伏 → **GaAs**。
- 一致性:排序/筛选/挑选与第 1 步自洽。

## 打分口径(results.md / CONCLUSION.md 用)

对每题 × 每模式(A 分阶段 / B 不分阶段)记 5 个维度:
1. **子步覆盖**:1–N 步是否都执行(漏几步)。
2. **工具调用**:是否逐候选真的调了平台预测工具(还是只"深度思考")。
3. **实验值 GT 命中数**:各项预测/分类落在容差/正确类别的个数。
4. **派生一致性**:排序 / 比值 / 差值 / 筛选 / 最终推荐 是否正确且与本模式中间数值自洽。
5. **综合质量**:是否整合成正确结论。

- **主分** = 维度 3 + 4 的命中率,A vs B 对比。
- **差异判定** = A、B 主分之差;同时记录每题"是否弹出选择框、是否调真工具"——未弹/未调工具的题标注为"该题不可区分两模式"并从主分剔除。
