# Task 5 — 「分阶段」 vs 「不分阶段」 两种回答模式的质量差异

## 背景

被测对象是科学对话网站 NobelClaw（DAMO Nobel AI4S 平台)。对一个**足够复杂的问题**,平台会弹出选择:
- **A · 分阶段(stage by stage)**:把任务拆成多个子阶段,逐阶段/并行执行,最后汇总。
- **B · 不分阶段(直接)**:不拆解,一口气给出结果。

**目标:测出这两种回答模式的质量差异。**

## 关键设计约束(本版的核心修正)

1. **问题必须是一条完整的 whole question**——所有步骤写在**一条**消息里,一次性整条粘贴发送。**不**像 task1 的 B 条件那样分段、一段段喂(那是 user-side 投递方式,不是本任务要测的)。
2. **问题必须足够深,能触发平台的「分阶段/不分阶段」选择框。** 已实测:单句事实题/简单比较题(如"MgB2 vs YBCO 谁 Tc 高")平台直接「深度思考」答掉,**不弹选择框** → 测不了。只有**多阶段流程任务**(列出 1/2/3/4/5 步、要串真实工具、最后出整合交付物)才会触发分解——这一点借鉴 task1 的 pipeline 形状(task1 的 A 全量提问确实触发了"逐阶段执行")。
3. **必须有 ground truth,可判分。** 这是 task5 区别于 task1 的根本:task1 跑在 mock 技能上、没有 GT、只能测过程量;task5 要用 GT 测质量对错。

## 方法:GT 锚定的多阶段 pipeline

每道题是一个 whole question 形式的多阶段流程,内嵌**两层 GT**:

- **第一层 · 实验值 GT(sanity 锚)**:Tc / 带隙 / ADMET 性质的公认实验真值已知 → 抓某模式有没有漏值、瞎编、报出离谱的数、答错类别。
- **第二层 · 派生 / 一致性 GT(主分,也是两模式最可能分化处)**:每道题都含一步"**仅根据前面工具/步骤得到的数值,自己算出 X / 排序 / 下结论**"。GT = 用该模式自己 transcript 里的真实数值**重算一遍**——看最终报告里的比值/差值/排序/推荐对不对、N 个子步齐不齐、报告数值与中间结果是否自洽。这正是「分阶段 vs 直接」拉开差距的地方(精度保持、漏步、算错、综合质量)。

## 题集(v1:每域 2 题,共 6;确认能触发后再扩到每域 5 题)

见 `questions.md`,GT 与判分口径见 `ground_truth.md`。

- **超导材料发现**:SC-P1(MgB2/Nb3Sn 对比分析)、SC-P2(4 材料筛选排序选型)
- **半导体材料性能预测**:SE-P1(GaN/GaAs/Si 能带分析选 LED)、SE-P2(5 材料光电选材筛选)
- **药物 ADMET 模拟**:AD-P1(4 分子 CNS 成药性筛选)、AD-P2(5 分子溶解度排序)

GT 来源:`search/{superconductor,semiconductor,admet}_gt_findings.md`(均一手论文/公认数据集,已核验)。药物题只给 SMILES、不给药名(抗记忆污染)。

## 打分维度(沿用 task1 已验证的过程量框架 + GT 锚定,A/B 各打一份)

每道题对 A(分阶段)/ B(不分阶段)分别评:
1. **子步覆盖**:N 个步骤是否都真正执行/回答(漏步=扣分)。
2. **工具调用**:是否对每个候选真的调了平台预测工具(还是只"深度思考"硬答)。
3. **实验值 GT 命中**:各项预测/分类是否落在实验真值的容差/正确类别内。
4. **派生一致性 GT**:比值/差值/排序/最终推荐是否正确,且与本模式中间数值自洽。
5. **最终综合质量**:是否产出整合结论(而非碎片),结论是否正确。

主分 = 维度 3+4 的命中;维度 1+2+5 解释差异来源。**A、B 得分之差即两模式质量差异。**

## 关键风险与控制

- **canned-output(实测过)**:平台部分药物工具(如 `generate_drug_report`)不论输入返回相同输出 → 这类题两模式无法区分。需在浏览器确认:**药物题是否真的逐分子调到 input-sensitive 的 ADMET 工具**;若是 canned,则 ADMET 域只能测"编排完整性"(维度 1),不能测输出质量。材料技能(crystal_predict/compare_materials)已知是**真工具**(~1% 噪声),材料域最可能测出真实差异。
- **半导体工具未知**:需浏览器确认平台是否有真实带隙预测工具;若只是 LLM 推理,仍可触发分解、仍可对 GT 判分,但"工具调用"维度记为无。
- **DFT 低估带隙**:半导体一律对**实验带隙**判分(PBE 系统性低估 30–50%)。
- **污染**:经典材料/名药多被 LLM 背过 → 用 SMILES 输入、用排序/派生计算/带条件的综合结论(而非单值)来降低纯记忆能蒙对的比例。

## 实验流程(浏览器跑,user 操作)

对每道题:
1. **A · 分阶段**:新建 session → 整条粘贴 whole question → 弹出选择框点「分阶段/并行执行」→ 等跑完 → 记录完整回答(含工具调用与中间数值)。
2. **B · 不分阶段**:新建 session → 粘贴同一条 → 点「不分阶段/直接」→ 等跑完 → 记录。
3. 两模式独立 session、相同题面,可重复 ≥1 次取稳定值。
4. 对照 `ground_truth.md` 给 A/B 各维度打分。

> 先决探针:发题后必须确认 **① 弹没弹选择框 ② 有没有逐项调真工具**。不弹/不调工具的题须淘汰或加深。
