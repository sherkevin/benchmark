## 一、超导材料发现

### SC-P1 ｜对比分析 pipeline
```
请对两种超导材料做完整的定量对比分析并生成报告,按以下步骤执行:
1. 预测 MgB2 的超导临界温度 Tc 与形成能;
2. 预测 Nb3Sn 的超导临界温度 Tc 与形成能;
3. 仅根据第 1、2 步得到的预测数值,自己计算:(a) 两者 Tc 的比值 MgB2÷Nb3Sn(保留两位小数);(b) 形成能之差 MgB2−Nb3Sn;
4. 将你的预测与已知实验值交叉验证;
5. 整合以上全部结果生成一份对比报告,并明确指出:做高场超导磁体更适合哪一个,为什么。
```

### SC-P2 ｜筛选排序选型 pipeline
```
我有一组候选超导材料,请完成一个完整的筛选与选型流程:
1. 逐一预测下列每个材料在常压下的超导临界温度 Tc:Nb、MgB2、YBa2Cu3O7、Bi2Sr2Ca2Cu3O10;
2. 按预测 Tc 从高到低排序;
3. 筛选出所有能在液氮温度(77 K)以上工作的材料;
4. 将你的排序与已知实验 Tc 交叉验证,指出预测与实验是否一致;
5. 综合给出:若某应用只能用液氮(77 K)冷却,这批材料里应优先选哪一个,为什么。
```

## 二、半导体材料性能预测

### SE-P1 ｜能带分析选型 pipeline
```
请对一组半导体做完整的能带性质分析并生成选型报告,按以下步骤执行:
1. 预测/给出 GaN、GaAs、Si 在 300 K 的电子带隙(eV),并分别标明是直接带隙还是间接带隙;
2. 按带隙从大到小排序;
3. 仅根据第 1 步结果,计算 GaN 与 Si 的带隙差(eV);
4. 将你的结果与已知实验值交叉验证;
5. 整合给出:制作高效蓝光 LED 应选哪一个,为什么(必须同时结合带隙宽度与直接/间接性质)。
```

### SE-P2 ｜光电选材筛选 pipeline
```
我要为光电器件选材,请完成一个完整的半导体筛选流程:
1. 逐一给出下列材料在 300 K 的电子带隙(eV)与直接/间接类型:Si、GaAs、GaN、InAs、diamond(C);
2. 按带隙从大到小排序;
3. 筛选出带隙大于 3 eV 的宽禁带材料;
4. 在带隙处于 1.0–1.6 eV 的材料中,挑出最接近单结太阳能电池理论最优带隙(约 1.34 eV)的那一个;
5. 将以上与已知实验值交叉验证,生成选型报告,并给出两类应用各自的推荐材料:(a) 需要宽禁带的紫外/功率器件,(b) 单结光伏。
```

## 三、药物 ADMET 模拟（只给 SMILES）

### AD-P1 ｜CNS 成药性筛选 pipeline
```
请对一组候选小分子做完整的中枢神经系统(CNS)成药性评估并生成报告,按以下步骤执行:
1. 逐一预测下列每个分子的:脂水分配系数 logD(pH 7.4)、能否穿过血脑屏障(BBB+ / BBB−)、是否阻断 hERG 钾通道:
   M1: Cn1c(=O)c2[nH]cnc2n(C)c1=O
   M2: O=C(CCCN1CCC(O)(c2ccc(Cl)cc2)CC1)c1ccc(F)cc1
   M3: CN(C)CCCN1c2ccccc2CCc2ccccc21
   M4: Cc1nc2n(c(=O)c1CCN1CCC(c3noc4cc(F)ccc34)CC1)CCCC2
2. 筛选出能穿过血脑屏障(BBB+)的分子(CNS 药物的前提);
3. 在 BBB+ 的分子中,排除有 hERG 心脏毒性风险的;
4. 将你对每个分子的每一项预测与已知实验数据交叉验证;
5. 综合给出结论:这批分子里有没有"既能入脑、又无 hERG 风险"的理想 CNS 候选?若没有,指出根本矛盾在哪。
```

### AD-P2 ｜溶解度评估排序 pipeline
```
请对一组小分子做完整的水溶性评估与排序,按以下步骤执行:
1. 逐一预测下列每个分子的水溶性 logS(log mol/L):
   M1: CN1C=NC2=C1C(=O)N(C(=O)N2C)C
   M2: Cc1cc(NS(=O)(=O)c2ccc(N)cc2)no1
   M3: CC(C)NCC(O)COc1cccc2ccccc12
   M4: CN(C)CCCN1c2ccccc2CCc2ccccc21
   M5: CC(=O)CC(c1ccccc1)C2=C(O)c3ccccc3OC2=O
2. 按 logS 从高到低(最易溶 → 最难溶)排序;
3. 仅根据第 1 步的预测值,计算最易溶与最难溶分子之间的 logS 差值;
4. 将你的预测与已知实验值交叉验证;
5. 综合给出:若要开发口服溶液剂型(需要高水溶性),这批里最适合的分子是哪个,为什么。
```
