## 一、结论先行

1. **调研结论（出题侧）**：一道 query 要合理专业，已核验样本里用到四类检查——**约束不矛盾（题有解）／答案唯一无歧义／术语地道／确是真实工作流**。四类内容各有论文逐字原文支撑，但**"合成四道关清单"是我的归纳，非论文原话**。
2. **量化标准极稀缺**：6 篇深读样本中**只有 InfoMosaic** 报了出题质量的一致性系数（120 题×3 人独立按 Factual Alignment/Coherence/Difficulty 三维 5-3-1 打分，Cohen κ=0.92）。ScienceAgentBench 只有过程计数（改 41 条/删 3 题），NewtonBench 的 98.3% 是**判分器**一致性（易误读）。
3. **代码级发现（本 task 唯一真增量）**：实拉 3 家仓库——**InfoMosaic 与 ScienceAgentBench 均未开源造题代码**（前者 470 文件中 425 是工具后端；后者全仓 31 文件皆 harness）；**MLE-bench 是唯一一家**，且把出题正确性写成 **83 份 `prepare.py` 的可执行 `assert` + 82 份 `checksums.yaml` 的 md5 冻结**。
4. **一个反直觉规律**：论文里描述最花哨的造题 pipeline（InfoMosaic-Flow 双 agent）恰恰**没有代码**；写得最朴素的（MLE-bench 重切数据集）**每题都有可执行校验**。**"出题质量"的工程化程度普遍远低于"判分质量"。**
5. **本 task 发生并已纠正一次任务偏离**（详见 §三）——议题与 task14 重复、账本重号、重复建议已有能力、小样本越推。
