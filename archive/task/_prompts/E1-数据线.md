## 一、30 秒了解项目

- **项目**：为**材料发现 + 药物发现**造一套 long-horizon agent benchmark。核心卖点是**评过程**——不只看 agent 最终给的分子对不对，更看它寻找的过程对不对，每个关键步骤都有可机器判定的检查点。
- **工作区**：`/Users/jingwu/work/benchmark`
- **题集分两类**（你必须都支持）：
  - **fixed 推理类**：gt 就在 agent 能查到的库里，考"能不能把活干对"；
  - **open 发现探索类**：数据库分 **A（agent 可查）/ B（agent 完全不可查）**，agent 要从 A 内线索**推理出一个 A 中不存在的分子**，用存在性接口验证。**这一类要求你的库必须能物理分层。**
- **你在链路里的位置**：`goal.md` §6 的**步 1**（数据集背书调研）与**步 4**（后端 mock 库构造）。你是关键路径的上游，E5 造题、E3 建工具都等你的数据。

## 三、你要交付什么

### 阶段一：数据集背书调研（目标第 1–2 周）

**"被背书"的判定口径**（三条同时满足，缺一条即标注"未达标准"、**不凑数**）：
1. 被**至少一篇已发表论文用于构建 benchmark**（不是仅被引用讨论）；

3. 数据集有可访问的公开来源 URL。

**产出** → `task/E1-数据集背书调研/数据集背书调研报告.md`，主表每行一个数据集，列出：
- URL / **被哪篇论文用于造 benchmark** / venue + DOI / 权威性判定
- **可达性当场实测**（HTTP 码 + 时间戳，**禁止沿用历史结论**）
- License（**特别标出 ShareAlike 类**，那类不可 bulk dump）
- 取 benchmark 成品还是 raw 原始数据（**给出选择与理由**）
- **该数据集能否支持 A/B 分层**（同分布、可分层、B 侧目标性质无缺失）——这是 open 类成立的前提

**数据落盘** → `dag_poc/data/sources/<db>/` + 每库一份 `MANIFEST.json`（url / 抓取时间 / 字节数 / 行数 / md5 / 完整性）。**该目录已在 `.gitignore`，原始库不入库。**

## 五、已知坑（前人踩过，别再踩）

1. **历史可达性结论会失效**：实测发现 OQMD 从"可达"变"不可达"、BindingDB 从"被墙"恢复可达。**必须当场重测**。
2. **PubChem API 字段名与请求名不一致**：请求 `CanonicalSMILES`，**实际返回 `ConnectivitySMILES`**。
3. **大文件会被静默截断**：3DSC 9.4MB 实测需 **3 轮断点续传**才拉全；**zip 类必须额外做结构校验**（UCI 的 zip 曾下到 2.4MB 且 EOCD 校验失败）。用 `fetch_authoritative_sources.py` 的续传 + Content-Length 校验逻辑。
4. **Materials Project / OQMD 本环境不可达**（403 / 000），材料线已改锚 3DSC。
5. **3DSC 首行是生成注释**，读取须 `comment='#'`，否则表头解析为 1 列。
6. **3DSC 不含"常压/高压"列**——`condition` 字段**必须人工按文献标注**，不能从数据推导。这是 open 类陷阱题的核心字段（LaH10 的 Tc=250K 只在 ~170GPa 成立）。**标注来源必须写入 provenance**。
7. **现有 9 个 tool 是硬编码假实现**（`predict_binding` 恒返 −8.5、`generate_molecules` 返非法 SMILES `C0CC`、`preview_structure_file` 恒返 P6/mmm），这些 tool 的后端库要从零建。
8. **`crystal_generate` 的 tc/bandgap 全 0 需改为"未知/待评估"**，否则 agent 会把 0 当真值。
