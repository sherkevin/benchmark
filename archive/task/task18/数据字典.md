## 1. 3DSC（材料线主数据源）

**出处**：Sommer et al., *3DSC — a dataset of superconductors including crystal structures*, **Scientific Data** 10:816 (2023), DOI `10.1038/s41597-023-02721-y`。它是 **NIMS SuperCon 的 Tc × Materials Project 的晶体结构**匹配产物——这是它能同时补"Tc 真值"与"真实结构"两个缺口的原因，也是 provenance 必须双标上游的原因。

**注意读取方式**：CSV **首行是生成注释**（`# "The 3DSC_MP without SOAP and MAGPIE columns..."`），须 `comment='#'` 跳过，否则表头解析为 1 列。

### 关键字段

| 字段 | 含义 | 量纲/取值 | 缺失 | 可映射到 mock |
|---|---|---|---|---|
| `tc` | 超导临界温度 | K，**实测范围 0.0–132.9** | **0 缺失**（5,771 全非空） | `crystals[].tc` ← 直接取 |
| `formula_sc` | 超导体化学式（SuperCon 侧） | 字符串 | 少量缺 | 材料标识/真名映射 |
| `pretty_formula_2` | MP 侧规范化学式 | 字符串 | — | 与 `formula_sc` 交叉校验身份 |
| `material_id_2` | **Materials Project ID**（如 mp-xxxx） | 字符串 | — | provenance 溯源锚（可回查 MP） |
| `cif` | **完整 CIF 晶体结构文本** | 多行字符串 | — | `structures[].cif` ← **补空壳的关键** |
| `sc_class` | 超导体族标签（cuprate/pnictide/其他） | 分类 | — | 题目分层/防污染（按族抽样） |
| `latc_2` | 晶格常数（非数值列，需解析） | — | — | `structures[]` 晶格参数 |
| `orig_formula_cif` | CIF 原始化学式 | 字符串 | — | 身份三方校验 |

> 92 列中其余多为特征工程列（SOAP/MAGPIE 已被该版本剔除）与匹配质量指标（`formula_similarity`、`correct_formula_frac`），**造题只需上表 8 列**。

### 对我方的直接价值

- **补 `structures` 空壳**：当前 17 条 structures 无 CIF 内容、`preview_structure_file` 恒返 P6/mmm；3DSC 的 `cif` 列可直接填真结构。
- **晶体池 17 → 5,771**：题量上限与防污染素材同时解决（大量不知名组分）。
- **`condition` 字段需自行标注**：3DSC 未直接给"常压/高压"列，高压相（如 LaH10）需按 `sc_class`/文献另行标记——**这是我方 open 类陷阱题的关键字段，不能从 3DSC 直接取**。

## 2. AqSolDB（药物线 logS 事实标准）

**出处**：Sorkun et al., *AqSolDB: A curated reference set of aqueous solubility*, **Scientific Data** 6:143 (2019), DOI `10.1038/s41597-019-0151-1`。

### 全部 26 列分三组

| 组 | 字段 | 含义 | 可映射 |
|---|---|---|---|
| **身份（5）** | `ID`, `Name`, `InChI`, `InChIKey`, `SMILES` | 分子标识 | 与 PubChem 交叉校验；**但身份统一取 PubChem**（指南 §4.1 规则 3） |
| **目标性质（3）** | **`Solubility`**, `SD`, `Occurrences` | **logS（水溶解度对数）**、标准差、来源出现次数 | **`admet[].logS` ← 直接取 `Solubility`** |
| **RDKit 描述符（18）** | `MolWt`, `MolLogP`, `MolMR`, `TPSA`, `HeavyAtomCount`, `NumHAcceptors/HDonors/Heteroatoms/RotatableBonds/ValenceElectrons`, `NumAromaticRings/SaturatedRings/AliphaticRings`, `RingCount`, `LabuteASA`, `BalabanJ`, `BertzCT`, `Group` | 由 SMILES 算出的分子描述符 | **可选**：`MolLogP` 可作 `logD` 的近似参考，但**属计算值非实测，不宜当真值** |

### 关键实测

- **`Solubility` 范围 -13.17 ~ 2.14，9,982 条全非空**——覆盖面足以补齐 mock 现有 11 个 logS 空格。
- `SD` 与 `Occurrences` 提供**数据可信度**：同一分子多来源时可优先取 `Occurrences` 高、`SD` 小的记录。
- **`Group` 列是数据质量分组标签**（如 A/B/C 表示不同 curation 严格度），取值时应记录以备论文说明。

## 3. PubChem（身份唯一权威源）

**出处**：NIH 官方库，PUG REST API。指南 §4.1 规则 3 明定：**身份（SMILES/InChIKey/CID）一律取 PubChem**（公共领域、最干净），性质取 TDC/AqSolDB/BindingDB——两者分离取源，正是为避免 mock 现有的 15 条错配。

### 字段与一个必须记录的 API 变更

拉取 URL 形如：
```
https://pubchem.ncbi.nlm.nih.gov/rest/pug/compound/name/<NAME>/property/CanonicalSMILES,InChIKey,MolecularFormula,MolecularWeight/JSON
```

**⚠️ 实测发现 API 已改名**：请求 `CanonicalSMILES` 但**返回字段是 `ConnectivitySMILES`**。写脚本时不能假设字段名与请求名一致。

| 返回字段 | 含义 | 可映射 |
|---|---|---|
| `CID` | PubChem 化合物 ID | **`molecule_search[].pubchem_cid`（新增字段，身份锚）** |
| `ConnectivitySMILES` | 连接性 SMILES（无立体） | **`molecule_search[].smiles` ← 替换现有** |
| `InChIKey` | 27 位标准哈希 | **`molecule_search[].inchikey`（新增，比 SMILES 更稳）** |
| `MolecularFormula` | 分子式 | 入库门校验用（与 RDKit 算出的比对） |
| `MolecularWeight` | 分子量 | 可选补充 |

### 40 分子身份核验结论（RDKit 规范化后精确比对）

| 类别 | 数量 | 说明 |
|---|---|---|
| 规范化后完全一致 | **18** | 仅书写风格差异（mock 用芳香小写 `c1ccc`，PubChem 用 Kekulé `C1=CC=C`），**无错** |
| 分子式相同但写法不同 | **7** | 立体化学/互变异构差异（af/cb/dc/dd/df/dh/eh），需逐个判断是否算错 |
| **分子式确实不同＝真错配** | **15** | 与 task11 查出的"15/40 SMILES 错配"**精确吻合** |
| mock SMILES 非法 | 0 | 现有 SMILES 均可被 RDKit 解析 |

**真错配典型例**（mock 算出的分子式 vs 权威）：

| ID | 分子 | mock 分子式 | 权威分子式 | 判断 |
|---|---|---|---|---|
| `aa` | Metoprolol | C16H21NO2 | **C15H25NO3** | mock 给的是萘环骨架（实为 Propranolol），**真错** |
| `ah` | Digoxin | C18H16O10 | **C41H64O14** | 差距巨大，真错 |
| `bf` | Astemizole | C22H21ClN2O | **C28H31FN4O** | 真错 |
| `ei` | Mirtazapine | C18H13N | **C17H19N3** | 真错 |

**`aa`/`bh` 重复问题**：PubChem 给出 `aa`(Metoprolol)=`CC(C)NCC(COC1=CC=C(C=C1)CCOC)O`、`bh`(Propranolol)=`CC(C)NCC(COC1=CC=CC2=CC=CC=C21)O`，**两者不同，重复已可解除**。
