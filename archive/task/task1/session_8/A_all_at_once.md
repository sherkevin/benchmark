# 任务 1：MgB₂ 超导机制科普（面向本科生）

MgB₂ 是一种金属间化合物，其超导转变温度约为 39 K。它属于**传统 BCS 超导体**，超导机制由声子媒介的电子配对驱动：晶格中的硼原子振动（声子）吸引两个自旋相反的电子形成"库珀对"，库珀对在晶格中无阻力流动，产生超导电性。MgB₂ 的特殊之处在于它拥有**两个超导能隙**（σ 带和 π 带），这使其 Tc 远高于普通金属超导体，但仍低于铜氧化物高温超导体。

MgB₂ 是一种在极低温（约 39 K，即零下 234 °C）下才能超导的金属化合物——这个温度虽比铅、铝等普通金属超导体高，但**远未达到"高温超导"的标准**，请不要把它与铜氧化物高温超导体混为一谈。

它的超导原理是：**硼原子**（不是镁原子）在晶格中的振动像"媒人"一样，把两个电子撮合成库珀对，库珀对无阻力流动便产生超导。镁的作用主要是提供电子、稳定结构，声子贡献以硼为主。

# 任务 3：面向高中生的准确解释短文

MgB₂ 在约 39 K 时进入超导态，但请注意：这并不意味着它是"高温超导体"——物理学家所说的高温超导特指铜氧化物等完全不同机制的材料，MgB₂ 本质上仍是传统超导体。

# 任务 3：面向高中生的准确解释短文
