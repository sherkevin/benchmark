# Session 7 评估 · 混合链（自由解读 → 自由选材 → 调工具 → 综合简报）

**目的**：测试在 NobelClaw 上当 agent 自由生成的内容（选哪个材料）被后续步骤（调工具搜索 + 简报）真实依赖时，分步是否会出现"忘记/篡改"自己选过的化学式。

**4 步任务**：① 介绍 MgB2 并指出最突出特点；② 基于该特点自由选一个对比材料（化学式）；③ 用 literature_search 搜该化学式；④ 综合写简报。

## 客观一致性核验（每行一个 run）

| Run | 第 2 步选的材料 | 第 3 步搜索 query 是否含该化学式 | 第 4 步简报是否提到 MgB2 + 该化学式 |
|---|---|---|---|
| A_r1 (全量) | NbSe₂ | ✅ | ✅ ✅ |
| A_r2 (全量) | NbN | ✅ | ✅ ✅ |
| A_r3 (全量) | NbN | ✅ | ✅ ✅ |
| B_r1 (分步) | Nb3Sn | ✅ | ✅ ✅ |
| B_r2 (分步) | Nb3Ge | ✅ | ✅ ✅ |
| B_r3 (分步) | FeSe | ✅ | ✅ ✅ |

**6/6 全部一致。** 分步即使经过 3 个独立轮次，第 3、4 步仍精确记得第 2 步自由选的化学式。**没有"忘记/混淆"现象。**

## 盲评（顺序对调防偏置，子 agent 不知谁是 A 谁是 B）

简报质量 1-5 分：

| Run | 真实身份 | 盲评分数 |
|---|---|---|
| A_r1 | 全量 | 5/5 |
| A_r2 | 全量 | 3/5 |
| A_r3 | 全量 | 4/5 |
| B_r1 | 分步 | 3/5 |
| B_r2 | 分步 | 2/5 |
| B_r3 | 分步 | 5/5 |

**A 平均 4.0，B 平均 3.33。** 但 B_r3 单次也拿到了最高分 5/5；A_r2 与 B_r1 同为 3 分。
**质量差异主因不是提问方式**，而是 agent 自由选材（FeSe/NbSe₂ 能撑起机制级对比，Nb3Sn/Nb3Ge 撑不起，文献搜索还易落空）——A、B 都受这个方差影响。

## 判定

- **传播错误：未观察到**（6/6 完美传承自由选择）。
- **质量差异：非系统性**（最高分 5/5 在 A、B 两边都出现；分差来自材料选择运气，不是 query 模式）。
