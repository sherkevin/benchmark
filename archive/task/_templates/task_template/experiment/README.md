# {{Task N}} · Experiment 记录

> 本目录记录本 task **过程中做过的每一项实验**——一次实验一篇 .md。
> 新文档:复制 `TEMPLATE.md` → `NNNN-<slug>.md`(`NNNN` 顺序编号、`<slug>` 用 kebab-case)。

## 命名规约

```
0001-baseline-on-ms3.md
0002-add-noise-sweep.md
0003-real-llm-pilot.md
runs/                # (可选)原始数据 / 工具输出 / SSE 流
```

- `NNNN` 让目录按时间顺序自动排好,**不用纠结日期**。
- `<slug>` 描述这次测什么,**一眼看懂**。
- 失败的实验**也写**(失败本身就是结果)。
- 跨实验的原始数据放 `runs/`,正文不重复粘贴。

## 写作纪律(每篇都遵守)

1. **一次实验测一个可证伪命题**——不要把 3 件事捆一起测。
2. **先放结论,再放支撑数据**(每节的第一行就是该节的结论)。
3. **卡点显式列**——没有卡点写"无",**不能略过**。
4. **细节链向 `runs/` 或上一篇实验**,正文不重复粘贴 transcript 或大段日志。

## 与其他文件的关系

- 本目录的实验在 `../result.md` 的"§2 关键产出"里**被引用作证据**(用路径指针)。
- 跨实验的总结**不写在 experiment/**——写到 `../result.md`(内部账本)或 `../block.md`(对外定调)。
