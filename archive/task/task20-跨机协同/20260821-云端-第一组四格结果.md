# 第一组套卷：六格矩阵已完成 4 格，工具替代量首次量出来了

> **一句话：同一道题、同一份真值、同一套判据，只把工具从 basic 换成 some，分数从 0.53 抬到 0.78–0.81（Δ_tool ≈ +0.25），而且逐模型的 Δ 从 +0.002 到 +0.408——这条"工具替代了多少推理"的纵向轴第一次真正量出来了。**
> 2026-08-21。第一组 = 一道母题 × 六配置（ADR-0026），本轮完成 4 格。

| | basic（1–2 个工具） | some（+2 个便捷工具） | enough |
|---|---|---|---|
| **fixed**（题面给候选池） | ✅ n=77 **0.529** | ✅ n=28 **0.775** | ⬜ |

| **Δ_tool** | — | **fixed +0.246 / open +0.277** | — |

**4/6 格完成。** 四格严格同题同真值同判据——some 档的判分器一行逻辑都没新写，
整套转发 basic 档 fixed 的 `judge.py`，并带 golden + lead_conditions 双重同源断言。

## 二、便捷工具是由实测失败模式导出的，不是拍脑袋

按 ADR-0026 §3，先跑 basic、看模型实际栽在哪，再配工具：

| basic 档实测失败模式 | 占比 | 配的工具 | some 档结果 |
|---|---|---|---|
| 外推偏高（低估下降速度） | **76%** (58/77) | `fit_trend(xs, ys, x_query, degree)` | `cp_extrap` 0.300 → **0.621** |
| 违反免费硬条件（没核对 psa 就选） | **21%** (16/77) | `screen_candidates()` | 21% → **4%**（1/28） |

三条预登记预测全部命中：S1 cp_extrap 明显抬升 ✅、S2 违反率从 21% 降到 4% ✅、
S3 工具被真实调用（**30/30 个 run 都调了 `fit_trend`**）✅。

## 三、最有价值的发现：工具替代了算术，没替代判断

逐模型的 Δ_tool 差了 200 倍：

| 模型 | basic | some | Δ_tool |
|---|---|---|---|
| qwen3-coder-plus | 0.517 | 0.925 | **+0.408** |
| bailian/glm-5.2 | 0.584 | 0.955 | **+0.372** |
| DeepSeek-V3-671B | 0.106 | 0.452 | **+0.346** |
| qwen3.7-max | 0.812 | 0.955 | +0.142 |
| deepseek-v3.2 | 0.561 | 0.609 | +0.048 |
| qwen3.5-plus | 0.623 | 0.625 | **+0.002** |

**所有模型都调用了工具，但收益天差地别。** 原因在于 `fit_trend` 让调用者自己选拟合阶数：
用 `degree=2`（曲线）的拿到接近真值的外推，用 `degree=1`（直线）的原样复现了 basic 档
那个 76% 的错误。degree 使用分布：2 用了 32 次、1 用了 18 次、3 用了 2 次。

⇒ **工具把"拟合并外推"这个算术步骤变成了一次调用，但"这关系是直的还是弯的"这个科学判断
仍然留在 agent 身上。** 这正是 ADR-0026 想量的东西：Δ_tool 大说明该步骤是真瓶颈；
Δ 小的两个模型（deepseek-v3.2 / qwen3.5-plus）不是不会用工具，是**用错了参数**——
它们的瓶颈不在算术，在建模判断。

（一个反例要如实标注：qwen3.7-max 也多次用 degree=1，Δ 却有 +0.142、cp_extrap 到 0.910。
说明"最后一次调用的 degree"不足以完全解释收益，机制不能只归到参数选择上。）

## 四、顺带修掉的一个结构性错误

此前 open 格被我改成了**另一道题**（纯外推、无先导选型），违反"同题只换配置"，
分数差就无法归因到配置。根因是发现原语选错：`search_pool(query, page)` 按 SMILES 子串
搜索，实际考的是"会不会猜中结构片段"（实测模型连试四个子串零命中、题目做不成），
而 fixed/open 这条轴**按定义只区分候选可不可见**。

已改为 `list_pool(page)` 纯分页枚举：一定看得到全部候选，代价是翻页扣预算
（判据④仍成立），但不用猜任何东西。open 预算按项目公式从 12 提到 17
（= fixed 12 + ⌈33/4→9 页/2⌉）。改完后两侧 `ground_truth.json` **只差
`measurement_budget` 一个字段**。

**修完的效果**：open·basic 0.532 与 fixed·basic 0.529 几乎持平——两侧终于是同一道题了。
