# 低方差确定性任务：药物侧撑不起，材料侧能撑（闸2 实测对比）

> **一句话**：owner 08-24 定了路线 B（改做"答案由推理唯一确定"的低方差任务）。
> 闸2 实测的结论是：**这类任务需要"族内一致、族间分离"的数据结构，
> 药物侧 logS 没有这个性质（族内一致的骨架族只有 2 个、整族全合格的 0 个），
> 而材料侧 tc 天然有（低温族族内 SD 仅 2–7K、族间差几十 K）。**

## 一、为什么低方差任务需要"族结构"

`triage_01` 的方差诊断（见 `20260824-triage01方差诊断.md`）查明：方差来自
**"20 个候选只能测 8 个、测哪 8 个每次都不一样"** 这个抽签过程。

要消掉抽签，池子就得**有结构**：分成几个族，**族内成员性质一致**。
这样 agent 只需测每族 1–2 个代表就能判定整族，预算不再是抽签，而变成
**"选对族"这个离散判断** —— 推理对了答案就唯一，单 run 自然稳定。

材料侧已跑通的三道题（`chain_01` / `constraint_02` / `satisfy_02`）都是这个结构。

## 二、药物侧 logS：撑不起（闸2 不通过）

在 601 个冷僻类药分子（≥2 环、MW 180–520、有 logS 真值）上按 Murcko 骨架分族，
≥5 成员的族共 **17 个**，逐族看 logS 的族内一致性：

| 族内 SD | 族数 | 例 |
|---|---|---|
| < 0.7（够一致） | **2** | 苯二氮类 n=5 SD 0.56；甾体 n=13 SD 0.68 |
| 0.7 ~ 1.5 | 10 | 二苯胺 SD 0.71、喹啉 SD 0.82、蒽醌 SD 1.44 |
| > 1.5 | 5 | 联苯 SD 1.89、二苯甲酮 SD 1.89、萘 SD 1.98、二苯甲烷 SD 2.00 |

再用 logS 窗口去切那 2 个一致族，看能否分出"整族全合格 / 整族全不合格"：

| 窗口 | 整族全合格 | 整族全不合格 |
|---|---|---|
| [−3, −2] | **0** | 1 |
| [−4, −3] | **0** | 0 |
| [−2, −1] | **0** | 2 |
| [−4, −2] | **0** | 0 |

⇒ **"整族全合格"一个都没有**。测代表判不了整族，"选对族"这个机制在这份数据上立不起来。
**这是数据事实，不是选料没选好。**

## 五、闸2 追加：action #4（晶系/层型变）数据够，且规律跨体系一致

owner 08-24 定了走甲（材料侧），前置检查是"#4 的数据够不够"。**实测：够，
而且推翻了 `action_归位表` 原来"#4 缺数据"的记载。**

**原判断错在哪**：原依据是"`Tl-Ba2` 有 4 种层型但 n=3 只 1 个样本"——那是**按具体化学式**数的，
而化学式里带掺杂微调（`Cu2.98Fe0.02` 之类），一个真实层型被拆成了几十个"变体"。
改**按元素体系分组、以 Cu 的整数计量当层型**（排除 |Cu−round(Cu)|>0.02 的掺杂微调）后：

**满足"≥3 种层型 × 每层型 ≥3 样本"的元素体系有 15 个。**

更关键的是**层型-tc 规律跨体系一致**（每层型取 max tc，因 tc 问的是"能达到多高"）：

| 峰在哪个 Cu 层型 | 体系数 |
|---|---|
| **Cu=3（三层相）** | **13** |
| Cu=4 | 2 |

逐体系（节选）：

| 体系 | 逐层型 max tc | 峰位 |
|---|---|---|
| Ba-Ca-Cu-Hg-O | Cu2:134 → **Cu3:136** → Cu4:127 | 3 |
| Ba-Ca-Cu-O-Tl | Cu2:114 → **Cu3:134** → Cu4:128 | 3 |
| Ba-Cu-O-Y | Cu1:96 → **Cu3:130** → Cu4:90 → Cu7:95 | 3 |
| Ba-Ca-Cu-F-O | Cu2:108 → **Cu3:120** → Cu4:105 | 3 |
| Bi-Ca-Cu-O-Pb-Sr | Cu2:111 → Cu3:116 → **Cu4:130** | 4（例外） |

⇒ **"三层相 tc 最高"是一条跨体系可归纳的真规律**（也符合铜氧化物的已知物理）。
这正是确定性推理任务要的：**归纳出规律就能定位答案，不靠抽样撞**。

**与已有三道题不重复**：`chain_01`/`constraint_02`/`satisfy_02` 覆盖的是
#5 趋势外推 + #6 约束推理 + #8 family 归类；**#4 是结构改动轴（层型），是新的一个 action**。
