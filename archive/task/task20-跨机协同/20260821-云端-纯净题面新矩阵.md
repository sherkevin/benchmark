# 纯净题面下重跑：Δ_tool 更大了，而且工具打在了真痛点上

> **一句话：题面删掉全部解题指引后，basic 掉到 0.503/0.516，加上按新基线重导的两个工具后升到 0.847/0.804——Δ_tool 从旧题面的 +0.246 涨到 +0.344，说明旧题面的提示原本就替工具干了一部分活。**
> 2026-08-21。owner 裁定：解题指引不加回；some / enough 按新基线重新导出。

## 一、新矩阵（纯净题面）

| | basic | some | Δ_tool |
|---|---|---|---|
| **fixed** | 0.503 (n=24) | **0.847 (n=27)** | **+0.344** |
| **open** | 0.516 (n=23) | **0.804 (n=26)** | **+0.288** |

对照旧题面：Δ 分别是 +0.246 / +0.279。**去掉提示后 Δ 变大**——合理，因为旧题面的
提示原本就在替工具干活，工具的边际价值被压低了。

## 二、主判别关的变化最说明问题

| | basic | some |
|---|---|---|
| fixed `cp_extrap` | 0.180 | **0.783** |
| open `cp_extrap` | 0.208 | **0.809** |

外推归因（fixed）：

| | basic | some |
|---|---|---|
| 外推准 | 1 / 23 (4%) | **22 / 26 (85%)** |
| 外推偏高 | 19 / 23 (83%) | 3 / 26 (12%) |

**从 4% 准到 85% 准。** 这一关原来就是这道题的主要难点，工具一给就解开。

## 三、两个工具都是从实测失败导出的，且都被 100% 调用

| 工具 | 打的失败模式（新基线实测） | 调用率 |
|---|---|---|
| `fit_trend` | 外推偏高 **85%** | **26/26、24/24** |
| `group_by_scaffold` | 测量花在非目标系列 **53%**（435 次里 231 次） | **26/26、24/24** |

**`screen_candidates` 被换下**：它打的"违反免费硬条件"在新基线上只剩 11%、退出前二，
下放为 enough 档候选。这就是 ADR-0026 §3 "由错误分析导出档位"的实际运作——
基线一变，工具清单跟着变，而不是沿用旧的。

## 四、一个没有完全奏效的地方（如实标注）

`group_by_scaffold` 100% 被调用，但 **`cp_focus` 只从 0.391 升到 0.501**（fixed）、
0.593 → 0.612（open）——**测量投放的改善远小于预期（预测 N1 只算部分命中）**。

也就是说：模型拿到了正确的分组，却仍有一半测量花在非目标系列上。可能的解释是它们
在做 Task 2（挑非同系列的化合物）时本来就需要测别的系列——**这部分"浪费"其实是任务
要求的**。这说明 `cp_focus` 这个诊断量对本题的两任务结构而言定义得不够精确，
**下一轮应把它拆成"Task 1 相关测量"与"Task 2 相关测量"分别看**。

## 五、下一步

按 ADR-0026 §3 的顺序：**先分析 some 档的剩余失败，再配 enough 档的工具**。
候选（不预先承诺）：`describe_structure`（链长解析）、`screen_candidates`（psa 簿记）。
