## 读前须知：这道题在考什么

一句话：**给 agent 一个 200 个分子的库和一台"化验机"，化验次数上限 16 次，让它交出
5 个符合要求的分子；其中至少 3 个必须是它没化验过、靠推理断定的。**

| | 内容 |
|---|---|
| 给它什么 | 200 个候选分子的清单（只有编号和结构信息，没有活性数据）；一个 `measure` 工具，输入一个分子编号，返回它的实测活性 |
| 限制 | `measure` 最多用 16 次（`BUDGET=16`）。200 个分子里只有 19 个真合格（9.5%） |
| 要它交什么 | 一个 5 个编号的名单（`DELIVER_K=5`） |
| 怎么算过 | 三个条件**全部**满足才得 1 分，否则 0 分：<br>① 名单里 5 个全在库内、且全是真合格者（一个假阳性都不许有）<br>② 交够 5 个<br>③ 这 5 个里 **≥3 个是它压根没化验过的**（`N_EXTRAP=3`） |
| 分数 | 只有 0 或 1，没有中间分 |

**为什么要求"≥3 个没化验过"**：16 次化验换 5 个答案，靠穷举是不够的——它必须从化验到的
少数几个里**看出规律**，再把规律推到没化验的分子上。这一条是这道题的题眼。

**为什么这道题叫 SAR-flip**：SAR 是"构效关系"（分子结构怎么影响药效）。这个库是刻意
造成**反直觉**的——按教科书经验去挑，会系统性挑错。所以死记硬背的领域知识在这里没用，
只有真去化验、真从数据里读规律才行。§2.2 第一次拿到了这个设计意图成立的实测证据。

**这次跑的两组对照**：

| 组（本文叫"臂"） | 有没有 `measure` 工具 | 用来干什么 |
|---|---|---|
| **工具臂** | 有 | 正式成绩 |
| **无工具臂** | 没有（其余完全相同） | 地板线。它拿不到任何实测数据，只能靠背知识猜 |

两臂分差 Δ 就是"给它化验工具值多少分"。本批的任务是把两臂各补到 ≥10 个 run，
看之前用 6+6 算出来的效应量 `d=1.291` 还站不站得住。

## §2 结论

**一句话：`d=1.291` 守住了（现为 `d=1.477`），但这个"守住"不配当硬结论 —— 它是噪声上
的一线之差，而且这道题的 d 结构上几乎不可能塌。本批真正挣到的硬结果是另一件事：
无工具臂那个 0 分是它自己答错挣来的，不是判分闸送的。**

| # | 结论 | 数字 | 硬度 |
|---|---|---|---|
| 1 | 效应量守住了 | d 从 1.291 → **1.477**（11+11 重算） | ⚠️ **不硬**，见下 |
| 2 | 预登记的精确检验第一次过了 0.05 | 非配对置换 **p=0.012** | 硬 |
| 3 | 无工具臂的 0 分是挣来的，不是闸门送的 | 交出 60 个名额、42 个不同分子，**命中合格集 0 个**；合格集基础率 9.5% | 硬 |
| 4 | 但按"单次重跑看不看得出来"这把尺，差距只超噪声底 22% | Δ=0.545，噪声底 0.447，**Δ/SD=1.22** | 硬（这是坏消息） |
| 5 | 同一道题换一批重跑，5 个模型里 **2 个翻了答案** | bailian 0→1、qwen3.7-max 1→0 | 硬 |

### 2.1 为什么"d 守住了"不硬：这道题的 d 几乎不可能塌

无工具臂全是 0 分、方差为 0。把这个代进 Cohen's d 的定义，d 就退化成一个
**只含三个变量的闭式**（已与探针实算逐位对过，六组取值全部吻合）：

```
d = sqrt(  p · (n_工具 + n_无工具 − 2)  /  ( n_工具 · (1 − p) )  )

    p = 工具臂通过率，n = 各臂样本数
    两臂等大时化简为 d = sqrt( 2(n−1)·p / (n·(1−p)) )
```

| n_工具 | 通过数 | p | n_无工具 | d | 对比旧值 1.291 |
|---|---|---|---|---|---|
| 6 | 3 | 0.500 | 6 | 1.291 | ← 旧值本身 |
| 11 | **6** | **0.545** | **11** | **1.477** | **守住（本批实测）** |
| 11 | 6 | 0.545 | 12 | 1.514 | 反事实，见下 |
| 11 | 5 | 0.455 | 11 | 1.231 | 塌了 |
| 12 | 6 | 0.500 | 12 | 1.354 | 守住 |
| 40 | 20 | 0.500 | 40 | 1.396 | 守住 |

三件事因此成立：

1. **通过率不变时，光加样本就会把 d 抬高**（p=0.5 时 n 从 6 到 40，d 从 1.291 涨到 1.396）。
   ⇒ "补样本看 d 守不守得住"这个设计，**方向上偏向守住**。
2. **本批撞上了一个现成的例子**。无工具臂第 12 个 run（`bailian-glm-5.2__t1`）超时被剔，
   见 §3。假设它跑完 —— 它的分数**结构上必然是 0**（§2.2 已证），一个字节的新信息都不带 ——
   光把它加进分母，d 就从 1.477 涨到 **1.514**，置换 p 从 0.0124 降到 0.0046。
   **一个零信息的 run 能把效应量和显著性同时推好看**，这个指标在本题上就不能当证据用。
   （顺带说明一件反直觉的事：那次基础设施故障其实**压住**了一个更好看的数字，见 §6。）
3. **本批的判定挂在一个 run 上**：11 个里通过 6 个 → d=1.477 守住；通过 5 个 → d=1.231 塌。
   而结论 5 实测到同一模型换批重跑有 2/5 会翻分 ⇒ **一个 run 的翻转完全在噪声之内**。

⇒ 「d 守不守得住」这个问法，等价于「工具臂通过率还是不是 ~50%」，它没有比通过率本身
多带任何信息。指令 §4 第 2 项写的"这批的唯一目的就是看 d=1.291 守不守得住"，
**这个目的本身选错了指标**，不是执行走偏。同理，`n_per_arm_for_power_0.8 = 10`
也是由同一个闭式反解出来的，用它来定"需要多少 run"是循环论证。

**1.291 这条线是哪来的**：它不是任何标准或阈值，就是 **6+6 那批实测算出来的 d 本身**
（工具臂 3/6 通过、无工具臂 0/6）。所以"守住"的字面意思只是"补样本之后这个数没变小"。
它没有对应"d>0.8 算大效应"那类外部判据——本项目的规矩是执行方不设阈值，故此处也不设。

**这个批评只打 d，不打 p。** 两者性质不同，不能连坐：

| | 随 n 变大会怎样 | 应该吗 |
|---|---|---|
| **p 值** | 单调变小（同样的通过率，样本越多越难说是巧合） | **应该**。证据变多、结论变硬，这是 p 的本职 |
| **Cohen's d** | 本题也单调变大 | **不应该**。d 的设计初衷是"无量纲、与样本量无关"，它在这里被 n 带着走，说明这个量在本题退化了 |

⇒ §2 表里 p=0.012 那条**仍然算硬**（结论 2），塌掉的只有 d（结论 1）。

**替代指标提案（不自主采用，供 owner 裁）**。d 在这道 0/1 题上退化的根因是：一条臂
方差恒为 0，Cohen's d 的分母就没有独立信息了。直接报下面三个数即可，都不需要新 run：

| 报什么 | 本批值 | 为什么这么选 |
|---|---|---|
| 工具臂通过率 + 区间 | 6/11 = 0.545（Wilson 95% 区间 0.28–0.79） | 这是唯一的原始信息量，且区间随 n 收窄的方向是对的 |
| 噪声底（同模型换批重跑 SD） | 0.447 | 回答"这个通过率本身抖多少" |
| 非配对精确置换 p | 0.012 | 回答"跟地板臂的差距是不是巧合" |

三个数各答一个不同的问题，且没有一个会因为"多跑几个 run"就自动变好看。

### 2.2 本批真正挣到的东西：那个 0 分不是闸门送的

原先有个说不清的疑点：`judge.py:136` 写着 `grounding = 1.0 if measured else 0.0`，
而无工具臂结构上拿不到化验账本 ⇒ 它的 0 分可能**纯粹是这道闸判死的**，跟它答得对不对
无关。若真如此，Δ=0.545 量的就只是"有没有给它测量工具"，不是"能不能找出答案"。

**已查清：不是。** 判分器的另外两扇门与 grounding 闸各自独立计算，无工具臂在这两扇门上
也是全灭：

| 子门 | 判据（`judge.py:128-133`） | 工具臂 | 无工具臂 |
|---|---|---|---|
| 零假阳性 | 交上来的分子全在池内、且全是真合格者 | 6/11 | **0/11** |
| 交够个数 | ≥ 5 个 | 11/11 | 11/11 |
| 外推 | 交上来的真合格者里，≥3 个是没测过的 | 6/11 | **0/11** |
| grounding（闸） | 账本里至少有一次成功 `measure` | 10/11 | 0/11 |

`cp_delivery = 零假阳性 × 交够 × 外推`，无工具臂这一项恒为 0 ⇒ **就算把 grounding 闸
整个删掉，无工具臂还是 0 分。**

而且它错得比瞎猜还厉害。逐个核过 11 份答卷：

```
无工具臂交出 60 个名额，涉及 42 个不同分子
合格集 19 个 / 池子 200 个 ⇒ 基础率 9.5%
若纯随机猜，60 个名额期望命中 5.7 个；实测命中 0 个
```

**不附 p 值**：各模型的猜法高度相关（52% 的名额落在被 ≥2 个 run 反复交的分子上，
`z013740` 被交 4 次），独立性不成立，算出来的 p 会虚高。

⇒ 但方向明确：**领域直觉在这道题上是负资产，它系统性地把 agent 引向不合格的分子。**
这正是 SAR-flip（构效关系翻转）这个题型的设计意图 —— 凭经验外推必然踩空，只有实测能救。
本批第一次拿到了这个意图**成立**的实测证据。

### 2.3 一个必须一起报的坏消息

按 ADR-0026 §9.2 的字面尺子（档间差须超过跑间方差），sarflip 的分离度**弱于**
qed_01 那个唯一过关的档间跳：

| 档间差 | Δ | 噪声底 SD | Δ/SD |
|---|---|---|---|
| qed fixed basic→some | +0.345 | 0.228 | **1.51** |
| **sarflip 有工具 − 无工具** | **+0.545** | **0.447** | **1.22** |
| qed open basic→some | +0.111 | 0.186 | 0.60 |

原因是分数只有 {0, 1} 两档，单个 run 的离散度天然就大（0.447）。

**换 SE 那把尺结论相反，但 SE 有同一个坑，必须三个读法一起报。** 公式：

```
SE = sqrt( SD_工具² / n_工具  +  SD_无工具² / n_无工具 )
```

无工具臂 SD=0 ⇒ 它在 SE 里**一点方差都不贡献** ⇒ SE 变小 ⇒ Δ/SE 变大。
这与 §4.1 揪出的是同一个缺陷，只是换到了 SE 上（本轮一并补齐，commit `a6bf5f7`）：

| SD 取哪个 | 值 | SE | **Δ/SE** | 这一读法的意思 |
|---|---|---|---|---|
| 跑间噪声，各臂用自己的 | 0.447 / 0.000 | 0.135 | **4.05** | 模型身份算固定效应，只把重跑噪声当误差 |
| 两臂都按工具臂的噪声算 | 0.447 / 0.447 | 0.191 | **2.86** | 保守读法：不拿判分器退化当"低噪声" |
| 各臂的**总** SD | 0.522 / 0.000 | 0.157 | **3.46** | 教科书两样本 SE，模型身份也算进噪声 |

**手算复核请对最后一行。** 我自己独立验算时先算出 3.46，与探针的 4.05 差一截，
查下来不是谁错了——**是两个不同的量**：探针把"模型之间本来就有强弱"当固定效应扣掉了，
教科书公式把它算进噪声。三个都落进 `run_variance.json`，就不会再出现"报告一个数、
手算另一个数"这种最容易被当成动过数据的情况。

三个读法都 > 2，所以"攒够 run 后均值差稳定非零"这个结论**不依赖选哪个读法**。
两把尺（SD / SE）答的是不同问题：

- **SD**：这个差距，能不能从一次重跑里看出来？ → 勉强（个别 run 会翻）
- **SE**：攒够 run 之后，这个均值差是不是稳定非零？ → 是，很清楚

选哪把是口径问题，仍在 ADR-0026 §9.2 / 决议_20260831 §6.1 待裁，**执行方不替业主定**。

## §4 指令 §4 的四个必报项

### 4.1 跑间标准差（本配置下现算）

**先说一个坑：这道题的噪声底原本算不出来。** 取样规矩是"条件 = 模型 × 批次"
（`probe_run_variance.py`，批次不混算，防批次漂移被算进重跑噪声）。而 sarflip 每个模型
在每个批次里**只有 1 个 run** ⇒ 自由度 df=0，除不出来。

**改用与 Δ 口径匹配的那把尺。** Δ=0.545 本身就是把 s1 与 t1 **两批合起来**算的
（两条臂都是），所以与它匹配的噪声底，就该是"同一个模型、同一套配置、换一批重跑"的
离散度。这把尺 df=5，现成可算，且**不需要任何新 run**：

```
无工具臂：5 个模型有重复，0 个翻了答案     ⇒ SD = 0.000（结构性，见下）
工具臂：  5 个模型有重复，2 个翻了答案     ⇒ SD = 0.447（df=5）
    DeepSeek-V3-671B   [0, 0]
    bailian-glm-5.2    [0, 1]   ← 翻了
    deepseek-v3.2      [1, 1]
    qwen3.5-plus       [1, 1]
    qwen3.7-max        [1, 0]   ← 翻了
```

**顺手揪出一个会把结论抬高一倍的算法缺陷。** 脚本原先把两臂 SD 直接取算术平均当噪声底。
在 qed 上没问题（两格离散度相当），但 sarflip 无工具臂的 SD=0 **不是"测得稳"，是
grounding 闸结构性锁死**。把这个 0 平均进去等于拿判分器的退化当低噪声用：

| 取法 | 噪声底 | Δ/SD |
|---|---|---|
| 两臂 SD 取算术平均（旧算法） | 0.224 | 2.44 ← **虚高一倍** |
| 按自由度合并方差 | 0.316 | 1.72 |
| **只看会动的那条臂（本报告采用）** | **0.447** | **1.22** |

已改脚本三种取法并列报，并对"一条臂 SD=0"的行显式打警告。旧列一位没动：qed 六格
同批 SD 仍是 0.177 / 0.230 / 0.176 / 0.187 / 0.193 / 0.219，cns 两臂仍是 0.289 / 0.250，
与 T-271 记录逐位一致（commit `04d147b`）。

**一处措辞对不上，先说明，免得看成偷换。** ADR-0026 §9.2 的原话是"档间差值须超过跑间
**方差**"，而本节报的全是**标准差**（SD）。这不是换尺子，是因为按字面读没法比：

| 量 | 本批值 | 单位 |
|---|---|---|
| 差距 Δ | 0.545 | 分 |
| 跑间**方差** | 0.200 | 分² |
| 跑间**标准差**（= 方差开根） | 0.447 | 分 |

"分"和"分²"之间比大小没有意义（就像不能拿长度比面积）。要跟 Δ 同单位，必须开根 ⇒
比的是 SD。顺带一句：若真按字面拿 0.545 去比 0.200，会得出"轻松跨过"的结论——
**比按 SD 比更宽松**，所以本报告选的是更严的那种读法，不是更宽松的。
建议 owner 在 ADR-0026 §9.2 里把"方差"改成"标准差"，措辞与算法对齐。

### 4.2 效应量 d 与精确检验 p（11+11 重算，未沿用 6+6 旧值）

| 量 | 6+6 旧值 | 11+11 新值 |
|---|---|---|
| 工具臂均分 | 0.500 (n=6) | **0.545 (n=11)** |
| 无工具臂均分 | 0.000 (n=6) | **0.000 (n=11)** |
| Δ | +0.500 | **+0.545** |
| 非配对精确置换 p | 0.1818 | **0.012** |
| Cohen's d | 1.2909944 | **1.4771** |
| 配对符号翻转 p | — | 0.125（枚举 64 种；正 4 零 2 负 0） |

两个 p 差这么远，是因为配对检验只有 6 个模型级均值，其中 2 个模型两臂同分（都是 0）
⇒ 只剩 4 个有信息的配对。**64 怎么变成 16**：

```
6 个模型 ⇒ 每个的差值可正可负 ⇒ 2^6 = 64 种符号组合（脚本确实枚举了 64 种）
但 2 个模型的差值是 0 ⇒ 给 0 变号还是 0 ⇒ 这 2 位翻不翻，总和一模一样
⇒ 真正不同的总和只有 2^4 = 16 个，每个各出现 4 次
```

双侧 p 的最小可能值 = "总和绝对值达到最大"的那些组合占比。16 个不同总和里，
达到最大的恰有 2 个（全正、全负）⇒ **最小可能双侧 p = 2/16 = 0.125**。
**这把尺结构上到不了 0.05**，与效应大小无关；要它能到，至少需要 6 个不同分的模型
（2/64 = 0.031 < 0.05）。
⇒ 报它是为了守"配对与非配对并列报"的纪律，但**不能因为它没过 0.05 就说结论不成立**。

d 的解读见 §2.1：它守住了，但这个指标在本题上近乎无法被证伪。

### 5.1 一条值得单独看的证据：无工具臂"想测但没工具"
