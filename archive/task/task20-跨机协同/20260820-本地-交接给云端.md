## 6. 判分体系的几条硬约定（改判分器前必读）

| 约定 | 为什么 |
|---|---|
| 一个 query 一个判分器 | owner 定的硬规范。判分器只吃两个文件路径，与 workspace 在哪、跑第几次、哪台机无关 |
| 柯西平滑 loss `1/(1+(Δ/s)²)` | 不用阶梯（容差处硬截断）、不用高斯（尾部退化 3.2%） |
| 尺度换算必须除 2 | 旧 `tol` 是"衰减到 0 分的误差"，柯西 `scale` 是"衰减到 0.5 分的误差"。直接用会让均值虚高（census_02 曾 0.468→0.784） |
| 尺度从真值导出 | 计数用 √该量真值（**不是**全库 N）、分布中心用 σ/√预算 |
| 平滑 loss 只用于"要估计的量" | "抄测量值"的量（如 `peak_tc`）要精确比对——401 个答案里 392 个误差恰好 0，没一个落在 0~0.5 之间 |
| 判别性关只记录、不进总分 | 用 `NOT_IN_MEAN` 声明。preflight 靠它识别，不要改成扫源码（open 侧薄壳无源码可扫） |
