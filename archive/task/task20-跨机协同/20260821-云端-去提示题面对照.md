# 去掉解题指引后的对照结果：总分几乎不变，但主判别关腰斩

> **一句话：题面删掉全部解题指引后，总分只从 0.529 掉到 0.503（fixed），但主判别关 cp_extrap 从 0.300 腰斩到 0.180、"外推准"的比例从 21% 掉到 4%——那些提示原来主要是在托主判别关，而且托得比总分显示的多。**
> 2026-08-21。owner 定的规矩：题面只讲"问题是什么"和"答案交成什么格式"，凡涉及"怎么解"的都算泄题。

## 一、删了什么

按新标准审旧题面，泄题的不止"别用直线"一处：

| 删掉的话 | 为什么算泄题 |
|---|---|
| "每个骨架有自己的曲线，形状和水平都不同" | **直接把要发现的规律给了** |
| "QED 沿系列系统性变化" | 同上 |
| Job 1 的三步（先找同系列 → 测它 → 拟合） | **一份完整解题步骤** |
| "池子里只有短链成员，所以你是在往外推、不是内插" | 点明问题结构 |
| "别默认是直线、别抄最近邻" | 提示了关系的形状 |
| "约束 2、3 查起来不花钱，先查它们再花测量" | 策略指导 |
| `answer.json` 的 `congener_ids` 字段 | **字段本身在暗示"同系列分子是关键"** |

**保留**："同系列"的定义（约束③引用了这个词，不定义则要求不明确——那是结果规范）、
预算与什么扣预算（问题约束）、交付格式、"实测值必须来自真实调用"（有效性规则）。

`congener_ids` 删掉后，同样的诊断改**从账本推**（实测花在了哪些分子上），
判分器 `cp_congeners` → `cp_focus`，仍是记录关、不进总分。

## 二、对照结果

| | 带提示（旧） | 纯净（新） | 变化 |
|---|---|---|---|
| **fixed 总分** | 0.529 (n=77) | **0.503 (n=24)** | −0.026 |
| **fixed cp_extrap** | 0.300 | **0.180** | **−0.120（腰斩）** |
| **open 总分** | 0.530 (n=30) | **0.520 (n=22)** | −0.010 |
| **open cp_extrap** | 0.285 | **0.210** | −0.075 |

外推归因（fixed，纯净题面）：

| | 带提示 | 纯净 |
|---|---|---|
| 外推准 | 21% | **4%（1/23）** |
| 外推偏高 | 76% | **83%（19/23）** |

## 三、三条读法

1. **总分掩盖了真实变化。** 总分只掉 0.026，但那是因为总分里还有选型关（cp_conditions
   仍有 20/23 拿满分——那部分要求本来就写得很明确）。**主判别关腰斩才是真相**：
   "外推准"的比例从 21% 掉到 4%，说明**原来那些提示主要在托外推这一关**。

2. **提示值多少分，量出来了**：cp_extrap 0.300 → 0.180，权重 0.5 ⇒ 约 **0.06 分**是提示
   直接送的。这个数以后可以引用为"题面泄题的代价"。

3. **一个新观察：`cp_focus` 只有 0.391**（fixed）——模型把测量花在目标同系列上的比例
   不到四成。带提示的旧题面直接告诉它"先找出同系列再测"，现在不说了，**它们大量测量
   花在了无关系列上**。这是"发现该测什么"这个能力第一次被暴露出来（旧题面把它掩盖了）。
   open 侧 0.591 略高，因为枚举目录时顺带看清了结构。

## 四、连带影响（要处理）

**some / enough 两档的工具是从"带提示题面"的失败模式导出的，现在基线变了，须重新导出。**

新基线的失败模式已经不同：
- 旧 basic：76% 外推偏高、21% 违反免费硬条件
- 新 basic：**83% 外推偏高、13% 违反免费硬条件、而且新增一个"测量花错系列"（cp_focus 0.39）**

⇒ 按 ADR-0026 §3，some 档的工具应当针对**新**的失败模式重新配，不能直接沿用。
