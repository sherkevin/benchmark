# 交付物 A — 端到端任务样例:从 MolBench 种子到「自主性度量」任务规格

**种子来源(真实)**:下载数据 `prd/molbench_repo/data_full/molbench-ms-3/molbench-ms-3.csv`,`index=1`。
靶点 **CK2α(Casein kinase II subunit alpha,CHEMBL3629)**;该行含 60 个候选分子、10 个真实活性分子及其实验 pChEMBL(6.0–8.0)。
**脚手架来源**:`prd/molbench_repo/skills/L2_workflows/{00,01,02,05,08}.md`、`L3_methodology/`。

> **真实性标注**:`▣ 真实` = 直接来自下载数据/ChEMBL;`▽ 作者撰写` = 为本原型撰写的模板/阈值/路径,评测时由专家审核或工具实算替换。
> 本文件不臆造任何工具运行的具体数值;凡需实算者标注「由确定性工具在评测时计算」。

---

## A.0 为什么选这个种子

- ▣ 真实:CK2α 是 ATP 竞争性激酶靶点,数据里给了**一条 congeneric/同靶活性谱**(pChEMBL 6.0→8.0),
  天然适合改写成**结构基础的先导优化(lead optimization)**——一个长程、需多工具编排、能拉开自主性差距的任务类型
  (正是 MS-1/MO 那种"单步可解"题缺的)。
- 这类任务正好命中 MolClaw `L2-05 iterative-molecular-optimization` 模板,使"金标准轨迹/介入卡"可由现成脚手架填空而非从零创作。

**种子分子(▣ 真实,来自该行 actives)**

| 角色 | SMILES | 实验 pChEMBL |
|---|---|---|
| 起点 hit `H0` | `CCCC(=O)Nc1n[nH]c2ccc(-c3cn(Cc4ccccc4)nn3)cc12` | 6.5 |
| 同靶最强参考 `R*` | `O=C(O)c1ccccc1Nc1ccnc(Nc2ccc3cn[nH]c3c2)n1` | 8.0 |

(说明:R* 仅作为"该靶可达到的活性上限"参考量,不作为答案泄露给 agent。)

## A.1 任务规格(Task Spec)

| 字段 | 值 |
|---|---|
| `task_id` | `CK2A-OPT-01` |
| 类型 | 结构基础先导优化(single-target affinity lead-opt) |
| 靶点 | CK2α / CHEMBL3629 ▣ |
| 起点分子 `H0` | 见上 ▣ |
| **成功标准(可被工具判定)** | ① 设计出新类似物,**对接分较 H0 改善 ≥ 1.5 kcal/mol**(同一锁定 box)▽;② QED ≥ QED(H0) ▽;③ Lipinski 违反 ≤ 1 ▽;④ 与 H0 的 Tanimoto ∈ [0.40, 0.95] ▽;⑤ 新颖性:不得等同于该行 60 个候选或任何已知 CK2α 活性 ▽ |
| 终止 | 达标即停;否则最多 8 轮(▽,对照 E2E-Q3 的 15 轮) |
| 评分对象 | **过程量为主**:阶段 checkpoint 通过率 + 介入(深度加权)次数 + autonomy@0;最终量(是否达标)为辅 |
| ground-truth 形态 | **金标准"路径"**(非唯一金标准分子);终点由工具实算判定 + 对照裁判按 checkpoint 比对 |

> 设计要点(对齐 PRD §2.3):**目标明确性拉满且四档恒定**(靶点、起点、成功度量、约束完全一致);**只让"路径指导性"在 L0–L3 间递增**。

## A.2 分级 prompt(L0–L3)

**L0 — 仅给明确目标(测自主性主条件)** ▽
> 以分子 `H0 = CCCC(=O)Nc1n[nH]c2ccc(-c3cn(Cc4ccccc4)nn3)cc12`(对 CK2α / CHEMBL3629 的已知抑制剂,实验 pChEMBL≈6.5)为起点,设计一个**对 CK2α 预测结合更强**的新类似物:要求在同一锁定对接 box 下**对接分较 H0 改善 ≥ 1.5 kcal/mol**,同时 **QED 不低于 H0、符合 Lipinski(违反 ≤1)、与 H0 的 Tanimoto 在 0.40–0.95**。给出最终分子 SMILES 及"为何更强"的依据(须基于计算证据)。

**L1 — 目标 + 关键约束** ▽(在 L0 上追加)
> 须保留与铰链区(hinge)形成关键氢键的母核片段;每轮只改 1–2 个位点;合成步数估计 ≤ 5;不得引入 PAINS/已知毒性药效团。

**L2 — 目标 + 高层阶段(每阶段怎么做仍由 agent 决定)** ▽(在 L1 上追加)
> (1) 准备 CK2α 结构并在 ATP 位点锁定对接 box;(2) 对 H0 做基线对接与相互作用分析,定位可优化位点;(3) 迭代设计-评估-验证若干轮;(4) 选出最优并给出计算依据与轨迹。

**L3 — 目标 + 详细步骤(近乎按图施工,主要测执行)** ▽(在 L2 上追加,示例)
> 1 取一个含 ATP 位点配体的 CK2α 催化域结构,去水去杂、加氢(pH 7.0)、转 PDBQT;以共晶配体质心定义并**锁定** box(全程复用)。
> 2 对 H0 做 QuickVina 对接记录基线分,跑相互作用分析,标注铰链 H 键与催化 Lys 等锚点、以及低相互作用可改造位点。
> 3 每轮在可改造位点枚举 ≥3 个修饰(生物电子等排/取代),校验 SMILES 有效性与骨架保留,用**锁定 box**重对接并算 QED/Lipinski/Tanimoto,记录 ΔDock。
> 4 取全局最优,核对达标与 ADMET 未恶化,输出带来源文件的优化轨迹表。

> ★ 主指标 autonomy@0 基于 **L0** 报告;L2/L3 作对照,用以验证"agent 间差距随 prompt 详细度收窄"(PRD §2.3),反向论证 L0 设定未人为加难。

## A.3 金标准轨迹 + 阶段 checkpoint

四个阶段对应 PRD §2.1 的(任务分解 / 实验设计 / 执行 / 结果分析),并映射到下载的 L2 工作流。
**金标准是"路径与门控条件",不是唯一分子**(L0 下合理路径不唯一,由对照裁判判"是否走在合理且通向正确结论的路径上",PRD §2.6 注)。

### Stage 1 — 任务分解与规划 ‹映射 L2-00 triage›
- 期望子目标:识别任务为"结构基础先导优化";规划覆盖 准备→基线→迭代→选择 四相;明确成功度量与终止条件。
- **CP1 通过条件**:产出的计划包含上述四相且锁定了"对接 box 全程不变"这一关键约束;复述了成功标准(ΔDock≥1.5、QED、Lipinski、Tanimoto、新颖性)。
- 典型偏离:直接开始改分子而无规划;漏掉"box 锁定";误把目标当成单步编辑。

### Stage 2 — 实验设计与基线 ‹映射 L2-01 / L2-02 / L2-08›
- 期望动作(动作空间见 `skills/L1_tools`):取 CK2α 结构 → 准备(去水/加氢/PDBQT)→ 在 ATP 位点定义并**锁定 box** → 对 H0 基线对接(记录分)→ 相互作用分析(标注铰链 H 键、催化 Lys 等**锚点**与可改造位点)。
- **CP2 通过条件**:① 得到合法的已准备结构;② box 已锁定且来源明确(共晶配体质心/口袋检测);③ 记录了 H0 基线对接分(数值由工具实算);④ 标出 ≥1 个锚点相互作用 + ≥1 个可改造位点。
- 典型偏离:跳过基线直接设计;每轮重新检测口袋导致 box 漂移(使 ΔDock 不可比);凭训练知识编造 H0 的活性数值(违反 L3 Principle 13 Computation-first)。
- **对照裁判可用锚**:可用本行真实 pChEMBL 谱(▣)对 agent 的"基线/口袋合理性"做 sanity check;筛选类子步可调用**交付物 B**的指标判定。

### Stage 3 — 迭代设计执行 ‹映射 L2-05 Evaluate→Diagnose→Design→Verify›
- 期望:每轮 评估→诊断→设计(每轮改 1–2 位点,保留锚点,不重复已失败策略)→ 验证(SMILES 有效、骨架保留、用**锁定 box**重对接、算 QED/Lipinski/Tanimoto);维护优化轨迹表;连续无改进则换策略或早停。
- **CP3 通过条件**(逐轮):① 每个上报数值可溯源到工具返回(非记忆);② 未破坏 Stage 2 锚点;③ 候选 SMILES 有效率达标;④ 卡住时策略发生改变(L2-05 决策逻辑)。
- 典型偏离:一次改太多位点无法归因;破坏铰链锚点导致掉分;数值与工具返回不一致(违反 L3 Principle 11 Count-Before-Report)。

### Stage 4 — 结果分析与选择 ‹映射 L2-05 final / L2-08›
- 期望:取全局最优分子;核对是否达成 ΔDock≥1.5 且 QED/Lipinski/Tanimoto/新颖性满足;检查 ADMET 未恶化;输出带来源文件的轨迹表与结论;**若未达标则如实说明**(诚实性也计入)。
- **CP4 通过条件**:最终分子的每个关键数值可溯源;成功标准逐条核对;结论与数据自洽(达标即报达标,未达标不谎报)。

> **介入守恒视角**:Stage 1/2 的正确行为几乎完全由 L2-00/01/05 模板规定——把这些模板前置进 harness(技能),运行期介入即可大幅下降。这正是我们对 agent 系统的核心建议的可度量化身。

## A.4 分级介入卡(每阶段 × D0–D3 四档深度)

按 PRD §2.5:触发介入时,系统从该阶段预制库取**最低必要深度**喂回。取材自 `L2-05` 的 "Common Failures & Recovery" 与 "Quality Gates"。▽(内容为模板,专家审核)

| 阶段 | D0 极轻推 | D1 指向 | D2 方向性 | D3 显式内容 |
|---|---|---|---|---|
| **S1 规划** | "先想清楚这是什么类型的任务、要分几步。" | "你的计划里缺了一个全程不变的关键约束。" | "这是结构基础先导优化:请按 准备→基线→迭代→选择 规划,并明确对接 box 全程锁定。" | 直接给出四相计划骨架与成功标准复述。 |
| **S2 基线** | "动手设计前,先确认基线。" | "你还没有可比较的基线锚点。" | "请先准备 CK2α 结构、在 ATP 位点锁定 box、对 H0 基线对接并做相互作用分析,再进入设计。" | 给出"取结构→去水加氢→PDBQT→以共晶配体质心锁 box→对接 H0→标注铰链锚点/可改造位点"的具体步骤。 |
| **S3 迭代** | "回看上一轮结果再决定下一步。" | "这一轮的改动可能动了不该动的地方 / 改太多了。" | "保留 Stage2 的锚点相互作用,每轮只改 1–2 个位点,并用锁定 box 重对接后再比较 ΔDock。" | 指出具体破坏的锚点/具体应改的低相互作用位点,并给一个合规修饰示例。 |
| **S4 选择** | "把所有轮次放一起再下结论。" | "你的结论和记录的数值不完全一致。" | "请用各轮工具返回值核对全局最优是否满足全部成功标准,并检查 ADMET 未恶化。" | 给出带来源列的轨迹汇总表模板与逐条达标核对清单。 |

- **介入计数(PRD §2.5)**:仅"能力性求助/被动偏离触发"计入;有副作用操作的"许可性中断"统一 auto-approve、不计;"许可校准度"单列。
- **深度加权**:D0..D3 给递增权重(如 1/2/4/8),用于"达标介入数"指标。

## A.5 反事实变体(抗污染,PRD §2.2)

在保持任务结构与可解性下做受控改造,使具体实例"从未在文献出现":

1. **CF-1 换起点** ▽:起点改为本行 pChEMBL 6.3 的活性分子 `CN(C)c1cc2sncc2cc1NC(=O)C(=O)O`,目标/约束不变 → 最优修饰路径不同于 H0。
2. **CF-2 改目标(转为选择性)** ▽:由"纯提升 CK2α 亲和力"改为"在维持 CK2α 对接分不变差于 H0 的前提下,使对近缘激酶(如 CLK2/DYRK1A 之一)的预测结合**变弱**(选择性)"。→ 触发多目标,映射 `L2-11 multi-target-selectivity`(Scene C/D)。
3. **CF-3 换靶点变体** ▽:把口袋换成一个**未被研究的 CK2α 守门/铰链点突变体**(在准备阶段对结构做指定点突变),其最优解不存在于任何训练语料 → 对任意新模型零记忆污染。

反事实金标准:可确定性计算者(对接/ADMET)用工具实算;否则由专家基于原 seed 科学原理推演(PRD §2.2)。

## A.6 这个样例证明了什么

- ▣ 用**真实下载数据**(CK2α 活性谱)当种子;▽ 用**下载的 L2/L3 脚手架**把"金标准轨迹/checkpoint/介入卡"填成型——
  说明 PRD §5.1 的头号瓶颈(专家从零标注)确实可降为"在模板上审核"。
- 产出了 PRD 要求而 MolBench 完全没有的全部**过程量结构**:L0–L3 分级、4 阶段金标准路径与门控、分级介入卡、反事实变体、可接入对照裁判的锚点。
- 可直接复制此模板到其余 24 个 MS-3 靶点 / MS-2 的 33 靶点 / MO 源分子,扩成 30–50 题核心集。

> 配套:本样例 Stage 2 的"筛选/排序"子步,其评分由 **交付物 B**(`B_ms3_screening_prototype/`)提供可运行的数值锚实现。
