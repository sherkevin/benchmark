# 重建路线到底可行吗 —— 诚实评估(附可运行例子)

> 针对质疑"重建路线你真的认为可行吗"。这里**不堆文档**,而是把"已证明 / 仅模板化 / 真正难"三类分开,
> 并用一个**能跑的例子**(`intervention_loop_demo.py`)给你看核心机制,再坦白它**还没**证明什么。

## 0. 一句话诚实回答

**部分可行,且可行的那部分我已经跑给你看了;不可行/最难的那部分我不假装解决了。**
- ✅ **测量仪器**(分级评分 + 偏离检测 + 分级介入回路 + 介入-成功率曲线 + autonomy@0 + 达标介入数):**已在真实数据上跑通、且数值正确、能区分 agent**。
- 🟡 **长程开放任务的金标准轨迹/介入卡**:目前是**有依据的模板(Deliverable A)**,尚未对真实 agent 跑过 —— 是设计,不是证据。
- 🔴 **开放式 L0 设计路径的"偏离 vs 合理的不同路径"判定**:真正的难点,文档解决不了,需要真实验 + 人工校准。PRD §5.2 自己也把它列为头号技术风险。

## 1. 已经证明的(可运行、真实数据)—— 这就是你要的例子

运行 `python3 intervention_loop_demo.py`,在真实 MS-3(25 靶点 + 实验 pChEMBL)上得到:

### 1a. 签名输出:介入-成功率曲线(整体通过率 vs 介入预算)
| agent (sigma) | b=0 | b=1 | b=2 | b=3 | autonomy@0 | 达标介入数(≥80%) |
|---|---|---|---|---|---|---|
| strong (0.4) | 100% | 100% | 100% | 100% | **100%** | **0** |
| medium (1.2) | 92% | 100% | 100% | 100% | **92%** | **0** |
| weak (3.0) | 64% | 84% | 96% | 100% | **64%** | **1** |

三个 agent 的 autonomy@0 与达标介入数**显著不同** → 该机制确实能区分自主性、并定位"差多少介入能救回"。这正是 PRD 要的"曲线而非标量"。

### 1b. 单实例 trace(CK2α,弱 agent)—— 回路真的在跑,不是叙述
```
[autonomy@0(零介入)] top5=['C24·非活','C51✓活性','C23✓活性','C58·非活','C16·非活']
        hits@3=2 ef@10%=2.0 auroc=0.584 → 裁判: FAIL ❌ auroc=0.584<0.6
        ↪ 触发最低必要介入: D1 指向:你的 top 里没有像样的结合分子,重新评估。
[介入#1] top5=['C51✓活性','C23✓活性','C24·非活','C58·非活','C16·非活']
        hits@3=2 ef@10%=3.0 auroc=0.742 → 裁判: PASS ✅
→ autonomy@0=未通过;达标介入数=1。
```
**裁判为什么便宜且可靠**:它手握 ground truth(真实活性 pChEMBL),只做"当前排序是否偏离已知正确"的低难度比对——可靠性来自外部真值,**不要求裁判比 agent 更聪明**。这是整套设计能成立的关键,这里被真实地执行了。

### 1c. 正确性自检(防止"自说自话")
Deliverable B 的指标在参考排序器上:`random` 的 `hits@3≈0.40`(=3×n_active/60 的解析期望)、`auroc≈0.49`(≈0.5),`oracle→random→reversed` 单调。两项与理论值吻合 → 实现正确,不是凑出来的。

## 2. 仅模板化的(Deliverable A,尚未证据化)

`A_worked_example_CK2alpha.md` 的 L0–L3、4 阶段金标准轨迹、分级介入卡:**有依据**(种子真实、脚手架来自下载的 L2-05),但**还没让真实 agent 跑过**。它证明"可以写出来",**不**证明"真实 agent 跑起来会产生有用的曲线"。诚实地说:这是合理的设计,不是实验结果。

## 3. 真正难、我不假装解决的

**开放式 L0 设计任务的被动偏离判定。** 在"设计一个更强的分子"这种开放任务里,合理路径不唯一,"跑偏"与"正确但不同的走法"难以廉价区分——便宜裁判的前提(手握唯一正确路径)在这里不成立。

诚实的边界与 PRD 既有缓解(§5.2):
- **把被动偏离触发限制在收敛型/可判定任务**(筛选、过滤、确定性编辑、带锁定 box 的对接分)——上面 §1 演示的正是这一类,可靠。
- **开放任务只统计"主动求助" + 过程 rubric**(借 E2E 的 5 维),并**公开裁判与人工的一致率(Cohen's κ)**,把裁判可靠性变成一个数字而非隐含假设。
- 因此:**一个严谨但有适用边界的版本现在就可行**;"对任意开放任务都能自动判偏离"是开放研究,不应过度承诺。

## 4. 把"声称"变成"证明"的最小实验(可证伪)

下一步真正该做的、成本可控的真实验:
1. 取 CK2α 这一个任务,用**真实 agent**(如 Claude Code 技能版 vs 一个 vanilla agent)各跑 L0,k 次重复;
2. 看 autonomy@0 与介入-成功率曲线**是否真的把两者分开**(§1 用模拟 agent 证明了仪器能分;这一步验证真实 agent 也分得开);
3. 在**收敛 checkpoint** 上,核对便宜裁判与人工标注的一致率(目标 κ>0.6);
4. 成本:单任务 × 2 agent × k 次,几十次工具调用量级——是 PRD §5.3 说的"先小后密"。

**这步通过 → 重建路线从"已造出仪器"升级为"仪器在真实 agent 上有区分力";不通过 → 暴露的就是要修的地方。** 这正是该有的态度:用可证伪的小实验推进,而不是靠文档自证。
