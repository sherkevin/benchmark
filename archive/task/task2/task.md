# Task 2 — 评估 MolBench(AI Lab) 数据集能否改造成我们的自主性度量 benchmark

## 1. 背景

- **被参考工作**：上海AI实验室 + 北京大学的药物发现智能体 **MolClaw** 及其配套评测基准 **MolBench**。
  - 微信报道：https://mp.weixin.qq.com/s/6ws_KWxTdJnGvmV59ArBQw （已抓取至 `prd/wechat_article.md`）
  - 论文：https://arxiv.org/pdf/2604.21937
  - 开源：https://github.com/InternScience/MolClaw
  - MolBench 覆盖：分子筛选(MS)、分子优化(MO)、端到端发现(E2E) 三类任务。
  - **关键局限**：MolBench 只用「最终结果」打分（标量成功率），不关注**中间过程量**（推理/操作轨迹、阶段 checkpoint、自主决策、人类介入）。

- **我们的目标基准**（初步 PRD：`prd/AI4S_agent_autonomy_metrics.md`）：
  面向 AI4S 长程任务的 **Agent 自主性度量基准**，核心轴是「人类介入程度」。
  需要从任务里能提取/标注出**过程量**：带阶段 checkpoint 的金标准轨迹、分级介入卡(L0–L3)、
  中断分类（能力性求助/许可性中断/许可校准度）、介入-成功率曲线、autonomy@0 等。

## 2. 本任务目标（GOAL）

> **核心问题**：MolBench 这个 AI Lab 的 dataset，能不能改造成我们需要的（带过程量的自主性度量）benchmark？
>
> **重点**：去看论文与开源数据集**到底提供了哪些字段/产物**，判断
> **「能否从中提取出过程量」**（而不仅是最终答案），并据此给出可行性结论与改造方案。

## 3. 需要回答的子问题

1. **数据集到底是什么样子**：MolBench 的任务格式、字段、规模、是否开源、是否含中间轨迹？
2. **过程量可提取性**：是否含/可推导出——阶段分解、金标准轨迹、checkpoint、工具调用序列、
   中间数值（对接分、ADMET、QED…）、失败/重试信号？
3. **与我们 PRD 的对齐度**：MolBench 的 seed/任务能否支撑我们的
   反事实扩展、L0–L3 prompt 分级、分级介入卡、对照裁判、纯过程评分？
4. **改造可行性结论**：直接可用 / 部分可用(需补标注) / 不可用(只能借思路)，并给出**具体改造路径**与工作量估计。
