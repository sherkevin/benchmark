## 2. 最终键方案

```

    （真实身份 Ag0.02Ge2Pd1.98Sr1，I 4/m m m = SG 139，仅 judge 侧可知）
```

### 2.1 pymatgen 可用性声明

环境实测 `import pymatgen` 成功（**可用**），但只用于空间群符号→号转换。reduced_formula **不走 pymatgen**，三处实测障碍：

| 障碍 | 实测 |
|---|---|
| 无法解析 dummy 记法 | `Composition('[1*]2[2*]1')` → `ValueError: 1* is an invalid formula`；`{'X1':2}` dict 构造被误解为电荷态 |
| 小数计量不整数化 | `Composition('Ba2Ca1Cu2Hg1O6.13').reduced_formula` 原样返回（3DSC 中 **3,482/5,771** 条含小数计量） |
| 排序依赖真实元素电负性 | 匿名域无元素身份，排序不可用 |

### 2.2 实现路径：纯 Python Fraction 归约 + pymatgen 空间群转换

- **reduced_formula（纯 Python，`src/data_build/material_identity.py::reduced_formula_anon`）**：口径＝元素分数向量归一化到最小整数比（Fraction 精确、通分整数化、全体 gcd 归约、标签数字升序规范序）。输入顺序无关、输出确定性，可直接 `==` 比对。
- **空间群号（`sg_symbol_to_number`）**：pymatgen `SpaceGroup` 直解 134/135 符号；唯一例外 `'C m c a'`（24 条，SG 64 旧记法，现代标准符号 Cmce）走显式别名表——归属经三源核验（UCL 空间群图集 064az1、Wikipedia List of space groups、Grenier 2012 文献），且 24 条全部为正交晶系铜氧化物/稀土铜酸盐，自洽。
- **等价性自检**：整数计量子集 2,288/2,289 条与 pymatgen `reduced_composition` 逐一语义等价；唯一例外 c05146（O2 分子晶体）为 pymatgen 对分子单质的内置特殊处理（不除 gcd），纯 Python 口径取经验式、全库更齐，已定名入白名单（不得静默扩大）。
