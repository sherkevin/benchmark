## 2. A/B 隔离测试执行记录（`test_ab_isolation.py`，退出码 0）

### 2.1 断言① 键集隔离：A 侧键集 ∩ B 侧键集 = ∅ —— **通过 ✓**

按子库实测键集规模与交集（真实库）：

| 子库 | A 侧键数 | B 侧键数 | 交集 |
|---|---:|---:|---:|
| literature_search | 321 | 0 | 0 |
| search_candidates | 80,712 | 0 | 0 |
| get_entity | 80,712 | 0 | 0 |
| get_property | 9,198（实体粒度去重；E1-04 清理后为 9,186，见 task-04-report §2.3） | 0 | 0 |
| check_molecule_exists | 0（仅 B 侧库） | 0 | 0 |

**B 非空后自动生效的显式验证（沙箱负向自检）**：在临时沙箱库中注入与 A 键重叠的 B 记录（键 `aa`）+ 不重叠记录（键 `zz`），同一断言函数**立即抓住重叠**（violations=[search_candidates/aa]）——证明断言不依赖「B 为空」前提，E5 冻结 gt 集入库后无需改测试代码即自动生效。沙箱即用即毁，不触真实数据。

### 2.2 断言② 句柄隔离：agent 读取路径不触 `*_B.jsonl` —— **通过 ✓**

方法：monkeypatch `builtins.open` 做接口级句柄追踪，驱动 `backend_reader.BackendReader` 全载 + 五个契约查询接口各跑一次（覆盖契约 §6 全部 agent 可达读取路径）。实测打开的 backend 文件句柄共 5 个：

| 句柄 | 判定 |
|---|---|
| `literature_search/literature_search_A.jsonl` | A 白名单 ✓ |
| `search_candidates/search_candidates_A.jsonl` | A 白名单 ✓ |
| `get_entity/get_entity_A.jsonl` | A 白名单 ✓ |
| `get_property/get_property_A.jsonl` | A 白名单 ✓ |
| `check_molecule_exists/check_molecule_exists_B.jsonl` | 契约 §6.5 声明的**唯一触 B 白名单例外** ✓（只读 inchikey/canonical_smiles 两列身份键） |

非法 `_B` 句柄：**0**。另读取层内置白名单守门（非白名单路径运行期直接 `PermissionError`），隔离靠机制不靠自觉。

### 2.3 断言③ `check_molecule_exists` 语义 —— **通过 ✓**

B 侧空占位时 `m ∈ B` 恒为假——对 A 内分子与库外分子一律返「不存在」是正确行为（goal §2b⑤，若对 A 内分子返 true 则 agent 直接交 A 中分子即过、整个设计崩塌）。实测：

- 抽样 A 内分子身份键 **50 个**（get_entity_A 的 InChIKey，随机种子 20260806）+ 库外入参 3 个，**全部返 `exists=false`**；
- `exists` 字段全部为纯 bool 类型；
- 返回结构严格为 `{exists, attempt, attempts_remaining}` 三键，无任何性质/相似度/距离字段（单 bool 语义）。
