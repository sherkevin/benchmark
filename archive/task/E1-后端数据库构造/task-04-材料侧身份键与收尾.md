## 1. 材料侧身份键（主任务）

分子侧的匿名与身份判定已经解决（dummy atom + RDKit canonical）。**材料侧还没有**：5,771 条晶体没有 SMILES 表示，canonical SMILES 与 InChIKey 对周期性晶体无定义。

按 [ADR-0017](../../governance/adr/0017-匿名命名空间用dummy-atom载体.md) §4，材料侧口径是 `pymatgen` 的 `Composition.reduced_formula` + 空间群，**在匿名域计算**。

| 要求 | 说明 |
|---|---|
| 身份键形态 | 与分子侧的 InChIKey 位置对等——E3 能用同一个接口取到 |
| 匿名域 | 键必须在匿名化之后计算（元素符号已换成 dummy atom 标签），不得用真实元素算完再匿名 |
| 覆盖率 | 5,771 条全覆盖，或**如实报告覆盖率与缺口原因** |
| 交接说明 | 写清 E3 怎么取、键的格式是什么、边界情况（如空间群取不到时怎么办） |

**你在 E1-02 已报"3DSC 的 cif 列只是路径引用、`atom_count` 全 null"**。若空间群从现有快照拿不到，**如实报并给替代键**（例如 `reduced_formula` + tc 分档 + 元素种类数），不要硬凑一个看起来完整但实际无判别力的键。
