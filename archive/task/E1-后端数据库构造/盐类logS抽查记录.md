## 一、核心结论（先总）

**抽查不通过：存在系统性偏差，须报监工重新裁定。** 三点概要：

1. **偏差方向单向且机制化**——最大片段 canonical SMILES 匹配必然剥离反离子，因此凡是 AqSolDB 侧为盐、实体侧为中性游离碱的配对，盐的 logS 一律赋给游离碱；反向（游离碱 logS 赋给盐实体）在结构上不可能发生（全库 6,812 个多组分盐实体 0 条获得 logS，已全量核验）。
2. **影响面可精确量化**——2,311 条 logS 行中 74 条（3.2%）选自多组分 AqSolDB 记录：其中 20 条为明确的"药物盐→中性游离碱/中性分子"，29 条为"盐→裸离子实体"（语义退化），25 条为"混合物/共晶→单一组分"。
3. **偏差量级有库内对照实证**——AqSolDB 内部同一 canonical 同时有盐记录与游离记录时，两者 logS 差 1.6～4.1 个单位（特比萘芬 Δ2.75、肾上腺素 Δ3.01、苯胺 Δ1.58、十八烷归属错误 Δ4.10）；且现有 Occurrences/SD 选择规则**不感知化学形式**，15/74 条本可换成同分子单组分记录却选中了盐/混合物记录。

## 二、检查方法（只读）

1. 从 `get_property_A.jsonl` 的 2,311 条 logS 行解析 provenance note 中的"所选记录 ID"（2,311 个唯一 AqSolDB 记录）。
2. 与 `AqSolDB/data_curated.csv`（9,982 条）按 ID 交叉，筛出 SMILES 含"."（多组分）的被选记录 → 74 条。
3. 用 RDKit（2025.09.2）对 74 条做片段形式电荷分析，结合 `_build_state/entity_registry.jsonl`（74,941 个分子实体）的实体 canonical SMILES / InChIKey，逐条判定"AqSolDB 测定化学形式 vs 实体化学形式"。
4. 反向核验：全量扫描 2,311 条 logS 行的实体 canonical SMILES，确认 0 条为多组分（即盐实体从未拿到 logS）。
5. 库内对照：统计 AqSolDB 全库中"同一最大片段 canonical 既有单组分记录又有多组分记录"的分子（共 94 个），直接度量盐 vs 游离碱的 logS 差异。

匹配机制事实（`src/data_build/build_get_property.py`，`canon_largest_fragment` + AqSolDB 段）：
- 源侧与被匹配侧都取**最大片段** canonical SMILES 作键，反离子（Cl⁻/Na⁺/H⁺/K⁺/酒石酸等）在成键时被丢弃；
- 同一 canonical 多条记录时按 (Occurrences 高, SD 小) 择优，**平局时保留先出现者**（严格大于比较）；该规则对"盐记录 vs 游离碱记录"无感知。

## 五、不一致的影响量级评估

**方向**：A 类（盐→游离碱）几乎一律**高估**游离碱溶解度——成盐使可电离药物溶解度典型提高 1～3 个数量级（药剂学常识：盐酸盐/钠盐成盐是增溶的标准手段）。例外出现在 C 类混合物与难溶无机盐（如 #9、#10 反而偏低）。

**量级（三重证据）**：
1. **库内对照（最硬）**：特比萘芬 Δ2.75、肾上腺素 Δ3.01、苯胺 Δ1.58、十八烷 Δ4.10——同一数据库、同一分子、仅化学形式不同。
2. **选择规则放大效应**：74 条中 15 条存在同分子单组分替代记录，全部被 Occurrences/SD 规则弃用（如 #1 盐 Occ=2 压过游离碱 Occ=1；#2 平局按行序）；全库层面这种"盐 vs 游离碱"竞争对共 94 个分子。
3. **文献常识**：可电离药物盐型 vs 游离型溶解度比 10～1000 倍（Δ1～3 log）与库内对照吻合；极易溶小分子（二甲双胍、氨基酸、肼）Δ<1。

**对造题的实际风险**：logS 是药物侧主目标性质（容量判据裁定），若题面以 entity（游离碱身份）出题、以入库 logS 作真值，特比萘芬类题目的"真值"偏离同库游离碱记录近 3 个 log 单位——足以把"微溶"判成"可溶"，属科学正确性错误而非噪声。

## 六、系统性判定与建议（供监工重新裁定）

**判定：系统性偏差成立。** 理由：
1. 偏差源于匹配键设计本身（最大片段键必然丢弃盐型信息），非个别脏数据——只要"实体为游离碱 + AqSolDB 存在其盐记录"即必现；
2. 择优规则（Occurrences/SD）对化学形式无感知，甚至系统性偏好盐记录（盐记录常因多来源而 Occurrences 更高，如 #1、#9、#10）；
3. 平局按行序取先者，行为不可预期（#2）。

**候选处置方案（按侵入性递增）**：
- **方案 A（最小改动，推荐先做）**：匹配候选过滤——同一 canonical 存在单组分记录时，只在单组分记录间按 Occurrences/SD 择优；仅当无任何单组分记录时才允许多组分记录，并在 provenance note 追加 `salt_form=true` 标记。影响面：改 20+15 条左右，匹配率几乎无损。
- **方案 B**：多组分 AqSolDB 记录一律不参与 logS 匹配（剔除 74 条，匹配率 2,311→2,237，−3.2%，对 150 题容量无实质影响）。
- **方案 C**：保留现状，仅在 provenance 标注盐型供下游自担——不满足 §7.1 科学正确性要求，不建议。
- 附带建议（与方案正交）：B 类"裸离子实体"（[Na+]、[OH-]、[H+]、H₂O 等 29+2 条）是实体侧退化问题，建议另立小项清理或同样排除；A-1819 的 Name/SMILES 源内矛盾建议登记到 AqSolDB MANIFEST。

**复测锚点**：修复后可用本文 §四 的 14 条样本作回归——预期 #1～#12、#14 的入库值变化或剔除，#13 保持不变。
