## 2. 造什么：切分参数已由监工实测确定，直接用

**不要自己重新设计约束组合**——监工已在真实后端库上实测出可行的切分维度（完整依据见 [`task/_prompts/裁定-题量容量判据修订.md`](../_prompts/裁定-题量容量判据修订.md)）。

### 2.1 药物侧（15 道：类型1 八道 + 类型2 七道）

| 项 | 值 |
|---|---|
| 目标性质 | **`logS`**（2,311 个分子有值） |
| 结构约束 | **`atom_count`**（92 种取值，取自 `get_entity_A.jsonl`） |
| 切分 | `(atom_count // 5, round(logS))` → 实测 **156 个非空格** |
| 容量 | 类型1 可用 **154 格**、类型2 可用 **91 格**（远超本批需求） |

**明令禁止**：不要用 `bbb + herg + caco2` 这类多性质交集——实测三者同时有值的只有 **14 个分子**（caco2 仅 235、herg 仅 104），撑不起配额。该题型已被降为"第二版候选"，待 ADMET 覆盖补齐后再启用。

### 2.2 材料侧（15 道：类型1 八道 + 类型2 七道）

| 项 | 值 |
|---|---|
| 切分 | **`family` × `tc` 五档 × 元素种类数** → 实测 **73 个非空格** |
| 容量 | 类型1 可用 **69 格**、类型2 可用 **59 格** |
| tc 五档 | `<10 / 10–30 / 30–60 / 60–100 / ≥100` |
| 元素种类数 | 从 `formula` 正则提取（如 `Ag0.02Ge2Pd1.98Sr1` → 4 种） |

**两条硬性断言，必须写进造题脚本**：

1. **排除 `tc == 0`** —— 占 **1,764 / 5,771 = 30.6%**（3DSC 含非超导样本）。不排除会把非超导样本塞进"最大化 Tc"的排序题。
2. **题面不得出现"常压 / ambient / ambient pressure"** —— 实测 `condition` 分布：`未知` **5,755** / `ambient` **15** / `high_pressure` **1**，**仅 16 条有人工标注**。限定常压则可用池只剩 15 个。
   **替代写法**：题面用 `in the candidate database` 限定范围，**不声称常压**。

### 2.3 `|G|=1` 的正确语义（这条最容易搞错）

**`|G|=1` 指"满足约束的候选中，目标量最优者唯一"**，不是"候选池只有一个成员"。

格子里可以有 100 个候选，只要目标量（tc / logS）最优的那个不并列，答案就唯一。**按错误理解会把材料侧容量从 69 格误算成 10 格**——监工第一次计算时就犯了这个错，已纠正。

**每个 case 必须落盘穷举证明**：记录该格全部成员及其目标量，证明最优者唯一。

## 3. 怎么造：三条硬约束

### 3.1 字段以 `answer_schema.json` 为唯一来源（ADR-0014）

| 类别 | 题面必点字段 |
|---|---|
| fixed（类型1/2） | `candidates`、`ranking`、`answer` |
| open（类型4，本批不做） | 上述三个 + `anchor_molecules`、`cited_values`、`edit_op` |

**旧字段 `screened_pool` / `ranked_candidates` 已降为派生字段，题面不得点名**（`query_lint.py` 的 M7 会断言这一点，现有 37 case 在此项上有 41 条违规）。

### 3.2 每道题必须落合格 `provenance`（ADR-0016）

必须指向**一篇真实论文/报告**（标题 + DOI 或 URL）。**"mock_db.admet"这类数据来源不算背书**——现有 37 case 的 `provenance` 全属此类，**37/37 不合格**。

后端库的 `provenance` 字段（如 `TDC_ADMET:BBB_Martins` + Harvard Dataverse URL）可作为**数据溯源**，但**不能替代题目背书**。两者是不同的东西。

### 3.3 每造一题立即跑 lint，不要攒到最后

```
python dag_poc/query_lint.py --cases "<你的新 case 路径>" --strict
```

**通过标准：退出码 0**。E2 已把 11 条机器可判规则落成断言（M1 无 CJK / M4 末句含字段名 / M5 约束外置 / M6 type2 含 Scoring 句 / M7 字段全集 / M8 分档词数 / M9 变体率 ≥0.3 + gt 全库唯一 / M11 / M12 / M13 / R4）。

**注意 M9 是库级断言**：开头两词模式种类 ÷ 该类题数 **≥ 0.3**，且**同一 gt 全库出现 ≤1 次**。这意味着**不能用同一个句式套 30 道题**，也不能复用 gt。
