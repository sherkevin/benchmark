## 1. 为什么要重做：脚本的三个毛病（全部实测）

| 毛病 | 实证 |
|---|---|
| **造出化学上不可能的题** | `cs_drug_01` 要求"原子数 ≤ 4 且几乎完全不溶"——比水还小的分子不可能不溶。那个 `[0,4]` 是 `原子数 // 5 == 0` 机械反推的 |
| **挑格只看数学条件** | 选格条件是"格内最优唯一 + 格干净 + 未占用"，**没有一条是"这题对化学家有意义"**。14 道落在库内占比 <1% 的极端角落 |
| **题面没有专业含义** | 150 道题面**一字不差**，都是 "Identify a small-molecule drug candidate that satisfies all required aqueous-solubility and molecular-size criteria"，只有数值区间不同 |

**审稿人一眼能看出的差别就在这里。**

## 2. 怎么做：读规程，按规程走

**唯一标准是 [`手写case操作规程-v1.md`](../../governance/手写case操作规程-v1.md)**，不要凭印象做。规程里已经写清：

| 规程章节 | 内容 |
|---|---|
| §1 | 你要填的四栏（领域 / 约束 / 说明 / 题面），每栏的合格判据与不合格示例 |
| §2 | 机器核的四栏（答案 / 候选池 / 可解性 / 格位）——**不要手填** |
| §3 | 化学合理性三条硬线（原子数下限 ≥10、约束相容性、材料不用「未知」族） |
| §4 | 候选池下限（类型1 ≥3、类型2 ≥5、上限 100） |
| §5 | 文献怎么挂（针对本题科学问题选，不按性质类型套模板，**不许编造**） |
| §6 | 提交前六条自检 + 两条自动查 |
| §7 | **库的实测分布** —— 选约束前先查这里"有没有货" |
| §8 | **四条红线无例外 / 四项默认值可带理由偏离** |

### 2.1 特别注意 §8 的分类（这条 owner 专门讨论过）

**四条红线无例外**（碰到必须改题，不用问监工）：约束不矛盾、答案唯一、格位不撞车、文献不编造。

**四项默认值可偏离**（原子数 ≥10、候选池 ≥3/≥5、不用「未知」族）：**不用停下来问监工**，把理由写进 case 的 `deviation_note` 字段，随题一起交审查。

`deviation_note` 写三件：偏离哪条 / 实际取值 / **为什么这道题必须这样**。

**这么设计的原因**：150 道题若每道遇冲突都来问，监工就是瓶颈；而偏离理由留痕，对论文反而是加分项（审稿人看到"该科学问题在库内天然只有 2 个候选，已记录"，比盲目套规则更显专业）。

### 2.2 `element_count` 的用法有变（owner 已拍定）

| 侧 | 用不用 | 理由（是科学含义，不是统计分布） |
|---|---|---|
| **药物** | **禁用** | 有机分子基本都是 C/H/O/N + 少量 S/P/卤素，"用了几种元素"不携带独立信息——没有药物化学家会拿这个说事。agent 面对"元素种类数=4"做不出任何化学推理 |
| **材料** | **推荐** | 就是二元/三元/四元化合物的分类，材料学基本维度；合成难度、相稳定性、掺杂策略都跟它相关。**你现有 45 道用了它的材料题是对的，不该改** |

### 3.1 一条要注意的事实

**材料侧最大的族叫「未知」，占 11,481 条（66.5%）**，是 UCI 没有族标注的部分。你现有材料题都避开了它，做法正确。但这意味着**材料侧可用库只有 5,771 条（33.5%）**，出题空间比药物侧窄。

**若材料侧凑不够 75 道，如实报，不要退回用「未知」族。**
