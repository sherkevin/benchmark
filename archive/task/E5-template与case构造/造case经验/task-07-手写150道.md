# task-07 造题经验 — 手写 150 道（五批流水线方法论沉淀）

> 批次：task-07（Task #41~#52），2026-08-09 ~ 2026-08-10。150 道全部工程师手写（owner 裁定：脚本只算答案与验可解性，不生成约束或题面），五批 ×30 各自完成"复检→三维评审→修复→定向复检"四层闭环。本文沉淀方法论，供后续批次与论文方法节援引。

## 1. 四步节奏：每批固定工序，不可跳步

1. **设计意图文档先行**：`batchN_设计意图.md` 逐道写领域名 + 约束组合 + §3.2 相容性自答 + 题面草案 + 文献——先回答"这题对化学家/材料学家有意义吗"，再落盘；
2. **逐道落盘**：约束/题面手写进 case JSON，顶层带 `lineage: handwritten-batchN`；
3. **机器核**：`task07_solve.py` 逐道独立复算 gt/s_feasible/grid_key/objectives，30/30 一致才过（人不填机器栏）；
4. **质检冻结**：逐道 lint strict violations==0 → freeze-batch → corpus 守卫 → 账本落盘 → builder 上禁重跑硬闸。

教训：**第 1 步的"相容性自答"是返工率最高的工序**——批① case 01"原子数≤4 且几乎不溶"这类化学上不可能的组合，全部应该在自答阶段被自己拦下，而不是等评审来抓。

## 2. 三教训的防护演进（批②立规、批③④⑤逐批加层）

批②踩出的三个坑，演化为后续批的设计期强制对照表（批④设计意图 §6 逐条自查）：

1. **场景温窗**：题面叙事里引用的温度点必须落在约束窗口内（批④逐道核：case 27 用 65K 过冷氮落于 [60,80)、case 28 用 77K 落于 [76,99.3)）；
2. **文献匹配**：文献按"族标签 + element_count + 温区"三重核对挂接，弱对应降"语境参考"措辞（批④ 11 道降级）；批③ masked 实体无真实化合物身份时，文献挂科学问题本身（机制上规避批②挂错化合物类别的坑）；
3. **术语消歧**：Ferrite 等易混族名全道带消歧注（"five-element iron-based (Ferrite-family)"）。
4. **批④补第 4 条：gt 化学自答核验**——自答必须对照 gt 真实化学解码核验（d97b3f1 修了 6 处 gt 化学误认：O₂/纯 U/Hf₀.₆Zr₀.₄V₂/La₂CuO₄₊δ/NdFeAsO₀.₇/铋系铜氧）。**教训：人写的设计意图也会认错 gt，落盘前用库数据解码 gt 组成反向核自答。**

## 3. 枚举器缺陷与硬闸纪律（批⑤重选事故）

批⑤药物初选 13/15 道作废，两处确定性缺陷：① config_pool 枚举器**未按变元计数去重**（同计数同分异构体当不同梯度点，段内计数重复退化）——镜像 task-03 try_build 修复重刷池；② **d 口径误用位置索引距离**，真实口径=计数轴绝对差，初判可保留的 d12/d13 实算 d=3 超界。

处置与纪律：reselect_drug.py 在修复后池内确定性重选（backbone+var 互异/批内 gt 互异/排除集实扫/旧 gt 零沿用四重硬约束）；**所有 builder 完成后上入口硬闸**（账本/产物已存在即 raise 拒跑），修复轮补账本一律走"先解冻→改生成器→重跑验产物零 diff→重新上闸"。教训：**枚举器的去重口径与距离口径必须在首批使用前用已知样例标定，不能等 33 道造完再发现。**

## 4. 混提防御四条（五次事故换来的）

task-07 期间共享仓发生五次混提（faa436c/8f78419/ab7a2db/ba0f645/fa130f4），裹挟 E5 资产从 37 件到 1 件不等。方向还有反转：前三次是 E5 宽 add 卷入他线或多线混提，ba0f645 是他线宽 add 卷入 E5 未提交产物（E5 无过错但裸奔窗口过长是可控因素）。防御四条：①提交前 git status 逐文件核对归属；②显式 add 路径清单；③禁止 git add -A；④**落盘后立即提交，缩短未提交裸奔窗口**。leader 裁定不重写共享仓历史（rewriting 风险大于收益），逐次登记留痕。

## 5. xfail 转正的曲折（批③裁定 B → 批⑤转正）

批③把 corpus 守卫 b)（18 禁入格）转正时，曾按字面把 c)（lineage）一起删 xfail——实测 c) 对全 150 道生效而非仅已手写批次，60 道未手写旧题缺 lineage 致 pytest 红。裁定 B：恢复 c) xfail（strict=True，批⑤补齐后 xpass-fail 自动提醒转正）。**教训：断言的作用域（当前批 vs 全语料）在转正前必须实测确认，字面口径不等于实际作用域；CI 红数日阻塞五条并行线的代价大于字面合规的收益。** 批⑤ 150 道全带 lineage 后 c) 如期转正，3 passed 终态。

## 6. 容量探针先行（批④批⑤的开工第一课）

批④开工即三重探针全量穷举（terrain_probe/swap_windows/full_terrain + 跨 ec 拼池），得出池≥5 可行格上限 28 < 30——**先证明容量上限再决定偏离策略**（28+2 的 +2 走 deviation_note 三要素，不硬凑不降池下限），比"造到一半发现凑不够"省一整轮返工。批⑤沿用：容量探针先行（材料 280 配置/药物 7,576 配置，均充裕）后才开造。批②的反例（五族白名单可行空格 23<30 凑不满）触发的是批级族口径裁定——**容量不足时要么换口径（报备）、要么如实偏离（留痕），没有第三条路**。另记两处探针自身缺陷留痕：Other(1,3) 双窗重复计数（29→28 更正）、三重探针漏查禁入格表（落盘自检兜底拦下 2 新格后 replacement_probe 补位）——**探针的结论也要被独立自检复核。**

## 7. 其他可援引要点

- **题面互异的承载维度**：跨类型靠题型骨架本质不同；同类型靠 opener 动词 + 场景叙事 + 族/性质/窗口。open 发现题骨架同构是题型固有（差异维度 = opener/领域/目标量，M9a 0.533 达标），不为互异核虚构骨架多样性。
- **owner 三裁定（批次①期间）**：query 英文骨架（M1 无 CJK）；E6 样本作废重采排全量窗口（不逐批零敲，samples 隔离归 E6）；gt 查重活跃口径（分母=现役活跃语料，spare/_deprecated 不入排除集，排除仅作用于新题 gt 位）。
- **文献纪律**：DOI 全部 api.crossref.org 核实、不写作者名；弱对应降语境措辞；禁编造（红线 4）。
- **判废如实口径延续**：预筛/无解/判废分列不混账（批① 8 无解、批③ 10 无解、批⑤预筛 2,047 单列），"0 判废"必须附数据学原因。
