## 0. 总结论（先总）

**做一个 100–150 题、材料+药物双领域、单 agent、过程可判的 long-horizon 科学发现 benchmark，统一在 VIS-DAG（可验证中间状态图）形式化之下，落两个正交实例：fixed（查库找分子，过程判"做对了吗"）与 open（长上下文埋线索找分子，过程判"知道对了吗"），并把 checkpoint 奖励顺带用于一个最小 RL 验证实验。**

四条支撑：

1. **量级**：**100–150 题**（fixed ~100 + open ~30–50），配"模板可批量生成 N 万实例"的可扩展性论证——这是 ICLR 科学 agent benchmark 的实际合格线（ScienceAgentBench 102、Toolathlon 108、AstaBench 端到端子集仅 40+40）。
2. **特征优势**：唯一做到**中间产物级 + 数值真值比对 + 可执行**过程判分的科学发现 benchmark（18 篇里无一做到），叠加 GT-first 反查真值 + 分子匿名化防污染 + 过程奖励天然可喂 RL。
3. **两类都能做也都适合**：fixed 已有 dag_poc 实跑验证（三模型命中 4/15、过程分 0.03–0.87，区分度成立）；open 有 InfoMosaic 的 testcase 作为已发表同构证据。
4. **dag_poc 现状**：**方向对、机器可判、区分度成立**，但**未达标**——量级差 20 倍、horizon 偏短、open 类未落地、四个判分缺口未补、且实跑暴露 2 个必修 bug。

## 1. Q1：我们要做什么量级的 benchmark

**结论：精选 100–150 题，不靠题海，靠"每题真值硬 + 过程可判 + 管线可扩展"取胜。**

### 1.1 量级由"真值获取成本"决定，不由会议门槛决定（横评规律 1）

| 真值来源 | 典型量级 | 实例 |
|---|---|---|
| 自动可得（测试/排行榜/工具输出） | 10³–10⁵ | SWE-bench 2294、RoboVQA 82.9 万 |
| 半自动（模板 + 程序化改写） | 10²–10³ | NewtonBench 324、GAIA 466、InfoMosaic 621 |
| 需专家逐题把关 | **10²** | ScienceAgentBench 102、Toolathlon 108、ColorBench 175、AstaBench 端到端 40 |

我们属于"半自动 + 需领域把关"之间：GT-first 反查可自动化取真值，但题面设计 + 陷阱组 + 质量门需人工。**故 10² 量级是对的定位。**

### 1.2 目标数字（决策）

| 任务类型 | 精选题数 | 可扩展性论证 |
|---|---|---|
| **fixed（查库找分子）** | **~100**（药物 ~60 + 材料 ~40） | 模板 + slots，一个模板可实例化数百题 |
| **open（埋线索找分子）** | **~30–50**（先药物，够则加材料） | haystack 生成器按 (L, 跨度, 干扰密度) 参数批量生成 |
| **合计** | **~130–150** | 写法照抄 SWE-bench：正式集 N + 管线可生成 M 万 |

**降级顺序**（时间不够时从后往前砍，`投稿策略` §4.3）：先砍 1M token 档 → 砍材料线 → 砍 open 题量到 20，**过程判分/质量门/防污染一件不砍**。

## 2. Q2：我们的 benchmark 本身要有什么特征和优势

**结论：一句话卖点——"第一个把长程科学发现的中间过程做成可执行、数值真值比对、免 LLM judge 的硬判分 benchmark"。**

### 2.1 五个特征（每个都对标一个已发表缺口）

| # | 特征 | 对标缺口（来自真实样本/阅读报告） |
|---|---|---|
| F1 | **过程 checkpoint 硬判**（中间产物 vs 数据库真值，可执行断言，无 LLM judge） | Toolathlon 判分脚本证实 SOTA 仍是"终态二元"；NewtonBench 想看过程只能上 LLM 事后标注；ColorBench 里程碑只判"到达屏幕"不判内容；ScienceAgentBench rubric 掺 GPT-4o judge |
| F2 | **GT-first 反查真值** | 与 SWE-bench(测试即真值)、NewtonBench(代码即真值)同一"真值先于题目"哲学，可自动化、可复核 |
| F3 | **分子匿名化防污染** | SWE-bench 已被实证训练集泄漏；GAIA/ScienceAgentBench 未处理污染。我方 mock 数据库抹名 + 受控反事实 |
| F4 | **过程奖励天然可喂 RL**（checkpoint reward 是判分器的免费副产品） | WebRL 要自训 ORM、AgentGym-RL 只能限 horizon、AgentPRM 要学 promise/progress——都缺"原生过程奖励的 benchmark" |
| F5 | **双领域 + 双任务类型统一形式化（VIS-DAG）** | 现有科学 benchmark 要么单领域(NewtonBench 物理)、要么无过程(AstaBench)、要么通用域(Toolathlon) |

### 2.2 相对最像的三家，差异化必须写死（横评 §2.2 R-撞车）

- **vs NewtonBench**：它发现**方程**、交互 ≤10 轮、过程靠 LLM 标注；我们发现**分子**、上下文可达 1M、过程硬判。
- **vs InfoMosaic**：它有 testcase 证据链但**只用于生成题面、不判过程**；我们把证据链**升格为逐条判分的 checkpoint**。
- **vs ColorBench**：它的里程碑是**界面位置**（到达某屏幕）；我们的 checkpoint 是**科学内容**（性质值/候选池是否与数据库真值一致）。

## 3. Q3：两大类（fixed 找数据库 + open 埋线索）是否可以做、是否适合做

**结论：两类都能做、都适合、且互补——它们是同一形式化（VIS-DAG）的两个正交实例，这个"统一"本身就是论文最强的新颖点。**

### 3.1 fixed（查库找分子）：✅ 能做，已有实跑验证

- **可行性**：dag_poc 已跑通 5 个 fixed case × 3 个真实模型（qwen/kimi/glm），机器判分产出逐 checkpoint 分数（见 §5）。**不是设想，是已运行的系统。**
- **适合性**：直接坐实 F1–F4，且真值来自科学数据库（药物 ADMET / 材料带隙、Tc），可复核。
- **"长"来源**：工具调用轮数（实跑 9–54 次）+ 依赖链深度（6 个有序 checkpoint）。

### 3.2 open（长上下文埋线索找分子）：✅ 能做，有已发表同构证据

- **可行性**：InfoMosaic 的 `testcase`（答案实体 + 一组工具可验证的条件线索）已经是"证据闭包"的现成实例，且它证明了"用工具真值反向合成 + 跨源依赖 + 捷径过滤"这条路 ICLR 2026 认可。我们的增量 = 把线索**埋进可控长度的 haystack**（大海捞针）+ 把线索**升级为判分对象**。
- **适合性**：坐实 F1（过程判"知道对了吗"）+ F3（合成 haystack 承载真实数值，天然防污染）+ 一条新"长"来源（上下文长度）。
- **构造法已设计完整**：证据闭包(MSS) + haystack 四旋钮 + 四类干扰 + 四道门判分，其中"结论对但证据覆盖不过半 → 0 分"是"猜对不算发现"的机器化表达（详见 [`发现类任务构造方案.md`](发现类任务构造方案.md)）。

### 3.3 为什么两类要一起做（而非二选一）

| | fixed（procedural） | open（epistemic） |
|---|---|---|
| 节点语义 | "做了什么"（流程产物） | "知道了什么"（原子事实） |
| 边语义 | 执行依赖（不可逆） | 蕴含依赖（凑齐才成立） |
| 主"长"来源 | 轮数 + 依赖深度 | 上下文长度 + 推理深度 |
| 失败模式 | 跳步/逆序/缺节点 | 大海捞针失败/被诱导/蒙对 |

**统一句（可进 Abstract）**：把长程 agent 评测统一为"在可验证中间状态图（VIS-DAG）上的行进"，给出它的两个正交实例——过程型（做对了吗）与认知型（知道对了吗）。18 篇里没有任何一篇做过这个统一。

## 4. Q4：整个技术难点在哪里

**结论：难点不在"造题"，在"让过程判分既硬又不脆、既防作弊又不误杀"。按难度排序有 6 个。**

| # | 难点 | 本质 | 现有对策/状态 |
|---|---|---|---|
| **D1** | **过程 checkpoint 既要 hard 又要路径无关** | 判"知道对了吗"而非"用没用某工具"；等价路径不能罚 | 已定"验证器查产物不认动作"（ADR-0008）；dag_poc 已实现产物 vs 真值比对 |
| **D2** | **未执行到 vs 执行了但错，必须分开** | 级联失败会污染能力诊断（前面挂了后面没机会跑） | ⬜ 缺口 G1：报**条件通过率** `P(cp_i✓\|pre✓)`，照抄 ColorBench 的 AC 条件化分母 |
| **D3** | **防"蒙对"与"倒推补 trace"** | agent 靠记忆直接给答案再编证据 | open 类用"覆盖不过半即 0"+ 落地门（引用须被真实读取记录支撑）；fixed 类用匿名化 + 工具落地检查 |
| **D4** | **防"捷径解"** | 一次全表查询+排序就能解掉 = 不是长程题 | ⬜ 缺口 G2：trivial baseline 跑全题集，被解掉的淘汰/升难度（照抄 InfoMosaic 捷径过滤） |
| **D5** | **难度可控且可复现** | 长程任务方差极大，且要能拧难度 | fixed 靠宇宙规模+查证预算；open 靠 haystack 四旋钮；报 pass@k 与方差（照抄 MLE-bench） |
| **D6** | **合成 haystack 的外部效度** | 审稿人必问"合成的太假" | 数值全用真实数据库值(只有承载文本是模板)+ 做 20 题真实文献子集对照报 Spearman ρ |

**最硬的是 D3+D4**：它们决定 benchmark 到底测的是"发现能力"还是"检索/记忆能力"。这也是我们区别于所有现有工作的地方。

## 5. Q5：目前 dag_poc 的这些 case 是不是符合要求的

**结论：方向完全正确、机器可判、区分度已被真实模型跑出来——但作为投稿资产还不达标，差在"量级/horizon/open 缺失/判分缺口/2 个 bug"五处。**

### 5.1 已达标的部分（真实证据）

dag_poc 三个真实模型（qwen3.7-max / moonshot-kimi-k3 / bailian-glm-5.2）实跑 5 个 fixed case（`dag_poc/traces/_all_results.json`）：

| 指标 | 实测 | 说明 |
|---|---|---|
| 命中率 | **4/15** | 不太易不太难，**区分度成立** |
| 过程分范围 | **0.03 ~ 0.87** | 跨度大，能拉开模型差距 |
| 逐 checkpoint 分 | cp1–cp6 各有分 | 过程真的被机器逐节点判了（F1 成立） |
| GT 反查 + 匿名化 | ✅ | `gt.id='aa'` 真名仅评分侧 |
| reward∈[0,1] + gate | ✅ | ADR-0009 的 6-cp 真 DAG + 门控打分 |

**这证明了最难的一步（过程 hard 判分 + 真实模型区分度）是可行的、已运行的**，不是 PPT。

### 5.2 未达标的部分（必须补）

| # | 差距 | 证据 | 对应 Todo |
|---|---|---|---|
| G-1 | **量级差 20 倍**：只有 5 fixed + 1 open，目标 130–150 | 目录清点 | T-33 起 |
| G-2 | **open 类未落地**：现有 open_discovery 是"超导体目标判优"，**不是**长上下文埋线索型 | `dag_poc/templates/open_discovery/` | T-33 |
| G-3 | **horizon 偏短**：6 个 cp 单次提交；虽工具调用 9–54 次，但依赖链只有 6 层 | template checkpoint_dag | 造题时加深依赖 |
| G-4 | **四个判分缺口未补**：条件通过率 / 捷径闸 / no_regression / 开放类分位标尺 | 横评 §5 | T-32 |
| G-5 | **实跑暴露 2 个必修问题** | 见下 | 新增 T-36 |

### 5.3 实跑暴露的 2 个必修问题（新发现，之前未记录）

1. **cns_metoprolol 三模型全命中（process 0.85–0.87）** —— 这个 case 可能**过易或存在记忆泄漏**（metoprolol 是超热门 CNS 药）。**动作**：核查其匿名化是否被穿透，或提高其陷阱密度。
2. **打分表达式边界 bug**：多条记录出现 `best=None`（没交出答案）但 `cp5=1.0`（排序满分）——例如 bailian 在 4 个 case 上 `best=null, cp2=0, cp5=1.0`。排序 checkpoint 在候选池为空/无答案时不应给满分。**动作**：修 cp5 的 reward 表达式，空池/空答案时置 0。

### 5.4 判定

> **dag_poc 是一个"已验证可行的最小内核"，不是"可投稿的成品"。** 它证明了方法论能落地（过程判分 + 真实模型区分度），但要成为 ICLR 资产，须：扩到 130–150 题、补 open 埋线索类、加深 horizon、补四个判分缺口、修 2 个 bug。这些已全部进入 TODO（T-31~T-36）。

## 6. 一页纸给 owner 的答复

- **Q1 量级**：100–150 题（fixed ~100 + open ~30–50）+ 可扩展性论证；对标 ICLR 科学 benchmark 的 10² 合格线，不做题海。
- **Q2 特征优势**：唯一"中间产物级 + 数值真值 + 可执行 + 免 LLM judge"的科学发现过程 benchmark，叠加 GT-first 真值 + 匿名化防污染 + 过程奖励可喂 RL。
- **Q3 两类**：都能做、都适合、且互补——统一在 VIS-DAG 下（fixed 判"做对了吗"，open 判"知道对了吗"），这个统一是最强卖点。fixed 已实跑验证，open 有 InfoMosaic 同构先例。
- **Q4 难点**：核心是 D3 防蒙对 + D4 防捷径（决定测的是发现力还是记忆/检索力）；其次 D1 路径无关的硬判、D2 未执行/执行错分离、D5 难度可控、D6 合成外部效度。
- **Q5 dag_poc**：内核已验证（过程硬判 + 真实模型区分度 4/15、过程分 0.03–0.87），但未达标——差量级(20×)、缺 open 类、horizon 偏短、缺 4 个判分口径、且实跑暴露 2 个 bug（cns 疑似过易/泄漏、cp5 空答案给满分）。
