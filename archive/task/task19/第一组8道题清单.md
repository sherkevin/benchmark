## tools 提供量的档位说明（先讲清，免得误读）

**现在 8 道题的 tools 量全是 `basic`，没有 some / enough。** 这不是漏标——

按 ADR-0026 §3：便捷工具档（some / enough）**不预设**，必须从 basic 档跑出来的
失败模式里**导出**。也就是说，得先看 basic 档下模型卡在哪、缺哪个工具，
才知道 some 档该补什么。所以 some/enough 是第二阶段的事，现在全部是 basic。

| 档位 | 含义 | 现状 |
|---|---|---|
| **basic** | 只给最小必要工具（measure_tc + 该题特有的 1 个） | ✅ 8 道题全在此档 |
| some | basic + 从失败模式导出的便捷工具 | ⛔ 未开，待 basic 档跑完导出 |
| enough | 给足工具 | ⛔ 未开 |

## 逐题详情

### 题 1 / 2：chain_01（fixed / open）

- **测什么**：四步依赖链。A 找掺杂序列 Tc 峰（#5）→ B 用峰值派生阈值筛第二族（#6）
  → C 对测不到的材料归纳规律外推（#5+#8）→ D 从预测为高的里按元素数最少选终答（#6）。
- **为何强**：每步输出是下一步输入，早错沿链拖垮，"卡在哪一步"天然分档。
- **tools**：fixed 只给 `measure_tc`；open 多给 `search_db`（查库目录、只返组成不返 Tc）。
- **数据**：两侧各 283 / 282 个当前题面 run，是四道题里最充足、最稳的（批间极差最小）。

### 题 3 / 4：constraint_02（fixed / open）

- **测什么**：恰好 4 元素约束下找 Tc 最高（#6）。真最优（4 元素 Hg-1201，98K）被工具拒答，
  必须从可测的汞系归纳"Hg-Ba-Cu-O 体系 Tc 高"（#8）再外推过去（#5）。
- **tools**：`measure_tc` +`get_element_count`（数元素种类，免预算，让"筛 4 元素"留痕可核）。
  open 侧加 `search_db`。
- **数据**：fixed 93 / open 255。fixed 侧批间极差偏大，需第二独立批次确认（runner 已写好）。

### 题 5 / 6：satisfy_02（fixed / open）

- **测什么**：报出完整满足双约束（恰好 4 元素 且 Tc∈[90,100]K）的集合。9 个满足者全在
  "不可测"集，须先实测排除 La 系、再归纳外推才敢提交（#6+#8+#5）。
- **tools**：待写 runner 时定（至少 `measure_tc`；元素约束可复用 `get_element_count`）。
- **数据**：fixed **仅 9 个**（严重不足）/ open 221。是数据缺口最大的一道。

### 题 7 / 8：dopant_01（fixed / open）

- **测什么**：给 Er（抑制最慢）+ Nd（最快）两条边界曲线，推中间未合成的 Gd 系。
  **覆盖最宽**——RE 元素轴（#1 同族替换）× Pr 比例轴（#2 比例调整）× 掺杂（#3）× 外推（#5）。
- **为何最纯**：目标曲线整条没样品，`measure_tc` 如实返回 `sample_available:false`，
  没有绕过推理的捷径。
- **tools**：fixed `measure_tc`；open 加 `search_db`。
- **数据**：fixed 64 / open **仅 8 个**（单批次，尺子②目前反向但样本太少不能定论）。
