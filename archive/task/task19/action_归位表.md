## 逐题依据

### `dopant_01` ✅ 四个 infer，覆盖最宽（此处纠正过一次漏归）

给两条已合成的边界曲线（Er 系抑制最慢、Nd 系最快），推中间那条**未合成**的 Gd 系。

| action | 证据 |
|---|---|
| **#1** 元素替换 | `truth` 有 `re` 字段，取值 `Er/Gd/Nd` **全是镧系（同族）**；`golden.law` 明写"抑制速率取决于 RE 是哪个元素"。效应量级实在：同一 Pr=0.30 处 Er 61.1K vs Nd 5.6K，**差 55.5K** |
| **#2** 比例调整 | Pr 含量有 **13 个比例点**（0.03→0.90），agent 要沿这条比例轴外推 |
| **#3** 掺杂 | Pr 替位 RE 抑制超导（引入第三元素少量掺杂） |
| **#5** 趋势外推 | 从两条边界曲线插出第三条 |

**为何最纯**：`measure_tc` 对未合成材料如实返回 `sample_available: false`——
科学上唯一站得住的"测不到"理由是没有实物。没有任何绕过推理的捷径。

**漏归的教训**：我初次只归了 #3 + #5，把 #1 和 #2 算到"缺数据"里去了。
实际上这道题有**两个变化轴**（RE 元素轴 × Pr 比例轴），各对应一个 action。
归位时要看**真值里有几个变化维度**，不能只看题面一句话概括。

### `chain_01` ✅ 三个 infer，稳定性最好

四步依赖链，每步对应一个明确的 infer action：

| 步 | 做什么 | action |
|---|---|---|
| A | 找掺杂序列的 Tc 峰 | #5 趋势外推 |
| B | 用峰值派生阈值筛第二族 | #6 约束推理 |
| C | 对**测不到**的材料归纳规律做外推 | #5 + #8 family 归类 |
| D | 从预测为高的里按元素数最少选终答 | #6 约束推理 |

**为何是最好的**：早错则沿链拖垮，"卡在哪一步"天然分档——这正是逐检查点能分出
≥3 档的机制（实测 cpB 置换 p<0.001、cpD Fisher p=0.008）。

### `constraint_02` / `satisfy_02` ✅ 三个 infer，机制相同

两题共用同一个杀手机制：**真最优被工具拒答**（"暂未探测到"）。

- 可测的合法候选 Tc 只到 39.25K，真最优（4 元素 Hg-1201，98K）测不到
- 必须从可测的 5 元素 Hg-1223 系（121–127K）**归纳出"Hg-Ba-Cu-O 体系 Tc 高"**（#8 family 归类）
- 再**外推**到不可测的 4 元素成员（#5）
- 全程受"恰好 4 元素"硬约束（#6）

**关键**：工具拒答逼出纯 infer——这是 owner 认可的防可背设计（不靠匿名，靠任务设计）。

### `census_02` ⚠️ 只一个弱 infer，降级不判死

产物是分组统计量（每组 count / mean / median）。

- **有 infer**：#8 family 归类——必须先按化学组成正确分类，错分一个材料会**同时**拉偏两个组的数字
- **但归类很浅**：看化学式里有没有 Hg / La 即可，不需要机理推理

**判定**：留作辅助题，不作第一组主力。

### `census_01` ❌ 判死

产物是全库统计量（库规模、高温计数、均值、中位数）。

**对不上任何 infer action**：

| 它要做的 | 是什么 |
|---|---|
| 数库里有多少个 | 数行数（题面已把 70 个全列出） |
| 数 Tc≥阈值 的有多少 | 查性质后计数 |
| 算均值 / 中位数 | 查性质后算术平均 |

全部是 acquire #29（查性质）+ 算术，**没有一步需要科学推理**。
它测的是"会不会用工具遍历、会不会算平均数"，不是"会不会做科学发现"。

**这解释了一个长期困惑**：我一直觉得 census 浅但说不出为什么——因为它测的东西
根本不在我们的能力清单里。

**判死的是"进第一组"资格，不是删数据**：3391 个 run（fixed 1284 + open 1113 + 未交卷 941 等）
留档，通用判分器已能全部判出（均值 fixed 0.627 / open 0.583）。
它可以作为**"acquire 能力基线"**引用——证明工具链本身通畅、模型会用工具，
但不能当作过程推理能力的证据。
