# 阶段 B 前置：真值数据盘点与阻塞判定

> 用数据回答一个问题：**现有真值库能否支撑材料侧缺的 4 个 infer action？**
> 结论：**不能**。这不是"我不会造题"，是候选池已被榨干。
> 盘点脚本产出，非推测。

---

## 一、盘点结果

现有 10 个真值库，合并去重后共 **187 个真名材料**，字段只有
`{tc, element_count, family}`（`dopant_01` 另有 `{pr, re}`）。

| 缺的 action | 需要什么数据 | 现有库 | 判定 |
|---|---|---|---|
| **#2 比例调整** | 同结构、单一元素计量连续变化的 Tc 序列 | 有 **2 条优质序列** | ⚠️ **数据有，但已被占用** |
| **#1 元素替换** | 同结构、单一位置换元素的 Tc 对照 | 150 组"只差一元素"的对，但**大多跨体系** | ❌ 需筛且量不足 |
| **#4 晶系/层型** | 同族不同层型，且待预测组 ≥3 个点 | `Tl-Ba2` 有 4 种层型，但 **n=3 只有 1 个样本** | ❌ 单点预测无区分度 |
| **#7 制备条件** | 压力字段 | **无** | ❌ 缺字段 |

### 关于 #4：我中途纠正过一次自己的错判

初次盘点我写"层数全为 Ca=1（同一层型）"——**那是错的**：
我只查了同时含 Hg 和 Ca 的材料，而 Hg-1201（n=1）不含 Ca，被漏掉了。

重查后的实情：

| 族 | 层型取值 | 各层峰值 Tc |
|---|---|---|
| **`Tl-Ba2`** | **n=1 / 2 / 2.2 / 3** | 95K ×4 / 98K ×3 / 104K ×1 / **119K ×1** |
| `Hg-Ba2` | n=1 / 2 | 98K ×17 / 127K ×12 |
| `Bi-Sr2` | n=1 / 2 | 14K ×2 / 91K ×6 |

`Tl-Ba2` 确实有 4 种层型且 Tc 随层数单调上升（真实物理）。
**但它仍造不了题**，两个硬障碍：

1. **待预测组 n=3 只有 1 个样本**（`O10Ca2Cu3Ba2Tl2`）。
   单点预测题的判分退化成一次命中——抛硬币，没有区分度。
   对照 `dopant_01`：它的目标组有 **11 个点**，cp2 是逐点精度的均值。
   （这正是 `dopant_01` 早期 cp3/cp4 二值判分的老毛病，已知会伪造区分度。）
2. **层型效应被氧含量效应盖住**：n=1 组的 Tc 是 `[0, 0, 40, 88, 95]`——
   同一层型内差异比层型间差异还大，agent 无法从中归纳出层型规律。

另外这 10 个候选已散落在 5 道现有题的池子里（constraint_02 占 5 个）。

## 二、#2 的数据很好，但已被榨干

找到两条**同结构氧含量序列**（除 O 外计量完全相同），都是教科书级的真实物理：

### `Ba2Ca1Cu2Hg1` 系（12 点）—— 倒抛物线，最优掺杂

| O 含量 | Tc (K) | |
|---|---|---|
| 6.080 | 92.0 | 欠氧 |
| 6.130 | 102.0 | |
| 6.160 | 121.0 | |
| **6.210** | **127.0** | **峰（最优掺杂）** |
| 6.240 | 123.0 | |
| 6.310 | 98.0 | 过氧 |

这正是铜氧化物超导的核心机理：Tc 随载流子浓度呈倒抛物线。

### `Ba2Cu1Hg1` 系（17 点）—— 平台 + 陡降

峰在 O=4.081（98.0K），到 O=4.370 陡降到 37.5K。

### 但它们已经是现有题的候选池

| case | 用了 O4.x-Hg 系 | 用了 O6.x-HgCa 系 |
|---|---|---|
| `chain_01` | 14 个 | **12 个（全部）** |
| `census_02` | 11 个 | 8 个 |
| `satisfy_02` | 10 个 | 6 个 |
| `constraint_02` | 9 个 | 5 个 |

尤其致命：**`chain_01` 的 stepA 峰就是 O6.210/O6.220 @ 127K**——
那正是 #2 这条序列的峰值点。

**所以造 #2 新题若复用同一批材料，答案与 `chain_01` 高度重叠，等于同一道题换个问法。**
这违反"一道 query 一个目录"的实质（表面是两道题，实际测同一件事、答案还相同）。

## 三、#7 另有一层更硬的障碍

即使补上压力字段，#7（制备条件-超导关联）的真实数据恰恰是**最出名的那几个**：

| 材料 | Tc | 压力 | 出处 |
|---|---|---|---|
| H3S | ~203K | 155 GPa | Nature 2015 |
| LaH10 | ~250K | 170 GPa | PRL 2019 |
| YH9 | ~243K | 200 GPa | Nat Commun 2021 |

这些是超导领域的标志性成果，强模型必然背过。直接问它们的 Tc 就是纯记忆题——
**会重犯 `explore_01` 的错**（那道题正因"汞系最高"是教科书常识而退役）。

要造 #7，必须先有**大量非明星的高压超导数据**，才能让"归纳压力-Tc 关系"这件事
无法靠记忆绕过。这不是造题技巧能解决的，是数据规模问题。

## 四、阻塞判定与解法

**阶段 B 的前置条件是扩后端真值库**，这属于 `goal.md` §6 的步 1（拉被背书的数据集）
与步 4（后端库调研与构造），是 E1 工程师的活。

需要补的字段与规模：

| 维度 | 需要 | 用途 |
|---|---|---|
| 压力 / 制备条件 | 同一材料在不同压力下的 Tc，≥30 个体系 | #7 |
| 层型序列 | 同族 n=1/2/3/4 各 **≥3 个样本**（现在 n=3 只有 1 个），且同层型内氧含量可控 | #4 |
| A 位元素序列 | 同结构换 RE / 碱土的 Tc 对照，≥5 元素 × 3 体系 | #1 |
| **新的比例序列** | 与现有 Hg 系**不重叠**的体系（如 Bi-2212、Tl 系、Y-123 的氧含量序列） | #2 |

**一条通用量级要求**：任何"藏一组让 agent 外推"的题，待预测组必须 **≥5 个点**。
依据：`dopant_01` 的目标组 11 个点才能把 cp2（逐点精度均值）做成连续量；
点数太少时判分退化成二值命中，已实测会伪造区分度。

数据源候选：SuperCon（NIMS）、Materials Project、以及各 benchmark 已提供的后端库。
**必须是真实数据**——真值编造是项目红线。
