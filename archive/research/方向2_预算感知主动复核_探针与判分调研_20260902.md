# 方向2「预算感知的主动复核」怎么落成可判分实验——12 探针、成本表、动态范围与判死检验

日期：2026-09-02 ｜ 类型：八方向第二轮深推 · 方向2 调研报告

证据范围：本报告只依据项目内部材料——提案（`governance/提案_20260901_制药科学预测冲突诊断与恢复Benchmark.md`）、八方向提示词方向2节（`task/team提示词_八方向第二轮深推.md` L99-117）、BBB（血脑屏障通透性，blood–brain barrier）冲突误差表（`cases/_methodology/bbb_authoritative_v2/`）、工具注册表（`dag_poc/tools_schema.json`）、成本量级记录（`governance/讨论_20260901_工具冲突诊断题型的三条前置检验.md` L106），以及第一轮已确立的六条结论。未做外部文献系统检索（见「没查到的」一节）。

## 调研问题原文

提示词 L106-109 的四问：① 把那 12 个探针具体列出来，每个写它测什么、返回什么形状、成本怎么定、预判贡献多少 bit，并标出哪个最可能导致探针退化；② 开放/不可枚举的探针空间怎么落成可判分的实验；③ 成本表怎么定才不被质疑是人为设定；④ 在 H(Y) ≤ 1 bit、n=400 的条件下，Pareto 前沿的动态范围够不够，若不够怎么办。

括注：H(Y) 是终端答案的熵（不确定性的度量），二分类时最多 1 bit；n=400 指评测集 400 行。

## 一句话答案

能落地：12 根探针全部能在现有误差表加公开参照集上机械实现，判分只收「终端答案 + 计量成本」两个机器量；但这条方向的生死不取决于 agent 怎么设计，而取决于两根预注册主嫌疑探针（②训练集近邻距离、③带标签邻居检索——单次检索即出观测的廉价探针）能否单独吃掉八成可得信息——先花约两天零 GPU 跑判死检验，活着才建 agent。

## 速读区

- 「12 个探针」此前从未落盘（全库检索确认，唯一出处是提示词的任务要求本身），本报告是首次成文；12 根全部可机械实现，探针实现与判分器均无需 LLM 参与（硬约束②③下安全）。
- 信息上界是硬的：二分类标签残余 19.5 个百分点（80.5→100，约 0.3 bit/行）；4 维工具可靠性向量每行最多 4 bit。判分面必须扩到后者，否则没有可测的头部空间。
- 准确率指标在 n=80 下检出限（统计上能可靠分辨的最小差异）为 8 个百分点，大于预期效应量 ⇒ 主指标换成信息效率（bit/成本），评测面用全 400 行加分子级配对 bootstrap，检出限量级估计压到 2-4 个百分点（推断，待实测）。
- 成本表辩护三条：Pareto 前沿（准确率与成本之间「改进一边必牺牲另一边」的最优点集）对成本表正单调变换不变（只需保序）、三口径并列（归一单位/墙钟/美元）、±50% 扰动下前沿排序不变才收货。
- 判死线：单根廉价探针（单次检索或单次前向以内）准确率 > 96.1%（= 80.5 + 80% × 19.5，严格大于）⇒ 方向判死。预注册主嫌疑是近邻相似度类探针。
- 最可能触发退化的是「带标签邻居检索」：kNN 一步规则就可能逼近上界——它就是主动找来推翻本方向的证据。
- 现行运行面（dag_poc 9 工具）与方向2所依据的 4 模型误差表是两套系统，误差表尚未接进工具面（提案 L258）；方向2 实验先在误差表上离线做，运行面改造是判死检验通过之后的事。

## 读前必备的区分

- **探针 ≠ 现行 benchmark 工具**。探针指方向2实验环境里向 agent 开放的、有成本的信息获取动作（查相似度、查文献、扰动重问等），返回观测；dag_poc 注册的 9 个工具是单真值表运行面，两者不是一套东西。
- **工具还是拐杖（硬约束⑥）**：12 根探针全部平凡命名、无使用说明、有成本，何时查由 agent 自己决定——这是工具，合规；任何一根若写进提示词告诉 agent 何时用，就变成测指令遵循，越线。
- **预判 bit 与实测 bit**：探针表里的 bit 全部是推断档量级先验；实测值以留一交叉验证（每行用其余行估计，防止自证）的 EIG（expected information gain，预期信息增益）回填。报告里的实答数字只有：六个基线数字（恒答 66.3%、固定 morgan（DeepPurpose 的分子指纹模型）80.5%、admet_ai 79.2%、理想选择器 100%、四工具全错仅 12 行、cnn 高置信 247 行错 153，出处：误差表普查）与成本量级（一轮 12 个 run 计 3.74 美元、26 分钟，讨论_20260901 L106）。
- **预判 bit 的计账信道是 4 维可靠性向量（上界 4 bit/行），不是二分类答案（上界 0.3 bit/行）**：各探针信息互相重叠，逐根预判加总超过 0.3 属正常；判死检验用准确率份额度量，度量的是标签信道。
- **三个样本量的关系**：730 是普查的全部分子；400 是其中四工具跨体系冲突、带实验真值的行——方向2 的评测全集；80 只是「若切小测试集」的假设规模，仅用于算检出限（1 行 = 1/80 = 1.25 个百分点）。

## 证据组 1：12 根探针全部可机械实现

一句话：每一根都能用「现有 4 模型误差表 + 公开参照集」确定性实现；成本单位统一为归一单位——一次本地模型前向的实测中位时延（同机、n≥100、取中位数）。

| 探针 | 测什么 | 返回形状 | 成本定价依据 | 预判 bit | 退化风险 |
|---|---|---|---|---|---|
| ① 连续打分读出 | 四个工具的决策边际与方向（置信度本身是反指标） | 4 浮点 | 读表，实测≈0 | ≤0.1（cnn 置信反向） | 高：一步规则「反用置信」 |
| ② 训练集近邻距离 | 分子到各工具训练集的最近邻 Tanimoto 相似度（分子指纹重合度，0 到 1；即适用域位置——分子落在模型可靠范围的内外） | 4×k 浮点 | 指纹 + 近邻检索实测 | 0.1–0.2 | 高（判死检验预注册主嫌疑） |
| ③ 带标签邻居检索 | 外部参照集 top-k 相似分子及其公开标签 | k×(id, 相似度, 标签) | 同② + 返回 token | 0.2–0.3 | 最高：kNN 一步规则即近上界 |
| ④ 理化描述符 | MW、LogP、TPSA、HBD、可旋转键、电荷等 | 约 10 浮点 | RDKit 实测 | 0.05–0.1 | 中：静态随机森林即可复现 |
| ⑤ CNS-MPO 与结构警示 | 规则化制药先验（Wager CNS MPO、P-gp 底物警示） | 标量 + 布尔集 | 规则计算实测 | 约 0.05 | 低 |
| ⑥ SMILES 扰动稳定性 | 非规范重序列化 × K 次重跑同一工具的预测翻转率 | 每工具翻转计数 | K 次前向 | 0.05–0.15 | 中：「翻转即弃」一步规则 |
| ⑦ 规则型第二意见 | swissADME BBB score 一类规则评分（Daina & Zoete 2016） | 布尔 + 整数分 | 纯计算实测 | 0.05–0.1 | 低 |
| ⑧ 外部 ML 第二意见 | BBBP 训练集自训的独立模型打分 | 布尔 + 概率 | 一次前向 + 不相交审计 | 0.1–0.2 | 低；训练集须与 730 行审计不相交 |

| ⑩ 文献命中检索 | 截止日前该分子 BBB 实验文献是否命中 | 文档 ID 列表 | API 调用 + 阅读 token 实测 | 0.1–0.2（命中子集内近 1） | 须排除真值来源记录防泄漏 |

| ⑫ 现场抽检 | agent 自选参照分子现场测某工具局部错误率 | 每工具 k 个对错 | k 次前向 + 检索 | 0.1–0.2 | 中：可被预计算局部精度图替代 |

实现前提三条：

- ②③需要各工具训练集的指纹库（DeepPurpose 内置 BBBP；ADMET-AI 用 TDC 系数据集）。训练集与 730 行评测分子可能同源，重叠率必须先审计——重叠未审，②③的信息量解释不可信（见「没查到的」）。
- ⑧的外部模型训练集与 730 行做不相交审计，未过审不得上线。
- ⑩复用现行 literature_search 的接口形态（只返元信息，tools_schema.json），但必须把真值来源记录从可检索面排除，防标签直接泄漏。

退化判断（问题①的末问）：**③带标签邻居检索最可能导致退化，②次之**。适用域判定是四十年的成熟方向（第一轮结论④），如果「训练集近邻相似度 + 标签」一步规则就能判定信谁，前沿塌成一步规则，agent 的顺序与时机决策就失去主要价值。⑪工具元数据不退化但逐行信息≈0——它的价值是工具级先验（开局一次），不在逐行。

## 证据组 2：开放空间收窄成三个自由度，判分只收两个机械量

一句话：判分器不评价动作好坏，只收终端答案与计量成本——「不可枚举」的诚实落点是探针空间开放、信息入口封闭。

- 判分量一：终端答案，对照真值表机械判分；
- 判分量二：计量成本 = 成本表 × 调用日志逐项求和，由环境计量，不靠 agent 自报。

环境只对 12 根注册探针返回观测，第 13 种动作拿不到新信息。agent 的自由度收在三个维度：调用顺序、调用时机（何时停）、调用参数（③的 k、⑫的自选参照集）。这保住了第一轮承认的两点——动作异质、写不出 P(o|Y,a)（给定答案，某个查询会返回什么的概率）——同时让判分满足硬约束④。

信息增益定义沿用第一轮：

$$\text{EIG}(a|s) = H(Y|s) - \mathbb{E}_o H(Y|s,o)，\quad \text{收益密度} = \text{EIG}/\text{成本}，\quad \text{停止条件} \ \max_a \text{EIG}/c < \lambda$$

其中：a 是一个探针调用；s 是调用前状态（免费信息 + 已有观测）；Y 是 4 维工具可靠性向量（广义信道）；H(·) 是熵，衡量不确定性大小；E_o 表示对该动作各种可能返回观测 o 取平均；收益密度是单位成本的预期信息增益；λ 是停止阈值，扫描 λ 取值画出整条前沿。

EIG 只做事后诊断：判分器重放轨迹计算，不进 reward。依据是势函数塑形定理（第一轮结论②：过程奖励若形如「状态势能差 − 成本」，加总只依赖端点，不改变最优策略）——把 EIG 加进逐步奖励改变不了最优策略，只多一层可读诊断。

agent 是否值得存在，由三条对照判：等算力随机调用（第一轮结论⑤：纯采样即可匹配 RL，任何提升先过这条线）；预计算最优固定序列（连顺序价值也归零，单测时机）；反向单探针规则（agent 打不赢它 = 该探针已吃掉大头）。打赢第一条和第三条，才有资格画 Pareto 前沿（准确率与成本之间「没法在不牺牲一边的情况下改进另一边」的最优点集）。

## 证据组 3：成本表的可辩护定价——保序不变性 + 实测三口径 + 扰动稳健

一句话：成本表不需要「正确」，只需要「保序且稳健」——前者是数学性质，后两者是实测纪律。

- 第一层（数学）：Pareto 前沿对成本表的正单调变换不变——所有成本同乘一个正常数，前沿每一点仍在前沿上，变的只是 λ 阈值的位置。所以「定价是人为的」这个质疑攻击不到前沿形状，只能攻击 λ 位置；而 λ 本来就要扫描取值画整条曲线。
- 第二层（实测）：三口径并列——归一单位（主口径）、墙钟秒、美元；时延与算力（GPU·s）双列，防「时延优化只是并行化」的混淆。美元口径有现成锚点：现行一轮 12 个 run 计 3.74 美元、26 分钟（纯 API + 本地 RDKit，讨论_20260901 L106）。
- 第三层（稳健）：发布前做 ±50% 成本扰动，前沿排序不变才收货；哪一根成本敏感就如实报敏感性。原始时延分布（不止中位数一个数）随成本表一起发布。

各探针定价依据已在表内：读表类（①⑪）实测≈0；指纹检索类（②③）按指纹计算加近邻检索实测；扰动类（⑥）按 K 次前向；纯计算类（④⑤⑦⑨）按计算实测；外部模型（⑧）按一次前向；文献（⑩）按 API 调用加返回 token；现场抽检（⑫）按 k 次前向加检索。

## 证据组 4：动态范围不够，按序四招

一句话：够不够取决于指标选什么——准确率不够，信息效率够。

先算账：标签信道总容量 19.5 个百分点（80.5→100），约 0.3 bit/行；n=80 时 1 行 = 1/80 = 1.25 个百分点，检出限 8 个百分点，大于「agent 比一步规则好」的预期效应量。四招按「先便宜后贵」排序：

1. 主指标换成信息效率 bit/成本：分母是连续量，方差小，且直接对齐「预算感知」的叙事。
2. 判分面扩到 4 维可靠性向量：逐工具预测对错、逐项对照真值表，机械可判；可测空间从 0.3 抬到 4 bit/行，是第一轮结论③（二分类残余仅 0.3 bit/行、可靠性向量 4 bit/行）的落点，不动数据就能改。
3. 全 400 行评测 + 分子级配对 bootstrap（同一批分子逐对相减再重抽样，消掉分子间差异的方差）：检出限量级估计压到 2-4 个百分点（推断，待实测）。
4. 仍不够再扩 endpoint：Caco-2、logD 等已入库（get_property 可查 12 项性质），探针全批复用，只需重校成本表。

## 证据组 5：判死检验（kill check）的执行步骤——先于一切 agent 建设

一句话：每根探针单独能吃掉多少可得信息，规则先落盘、后跑数。

1. 预落盘：分类器族（logistic 回归与深度 3 决策树取高者）、5 折交叉验证、固定随机种子、判死阈值 80%——全部写进 governance 再动手，防止事后挑口径。
2. 判死判据只评②③（预注册主嫌疑，提示词 L103）：在 400 行上，用「免费状态 + 该探针观测」训练浅分类器直接预测终端答案，得单独准确率 A_i。①的开局打分就是免费状态本身（已被基线 80.5 吸收）、⑪逐行信息≈0——两根近零成本但不构成新信息威胁，不进判死名单；⑥⑫需多次前向，不属「廉价」定义。
3. 份额计算：

$$\text{份额}_i = (A_i - 80.5) / 19.5$$

   其中：A_i 是只用第 i 根探针（加免费状态）时的终端答案准确率，5 折交叉验证均值；80.5 是最佳固定工具 morgan 的基线，代表「什么都不查」的起点；19.5 是 morgan 到理想选择器（100%）之间的全部可得空间；份额_i 即该探针单独吃掉的可得信息比例。
4. 判定：存在单根廉价探针（成本不超过一次前向或一次检索）份额 > 80%，等价于 A_i > 96.1%（严格大于）⇒ 方向2判死：降级为一条对照规则并入基线集，资源转方向1。
5. 显著性：分子级配对 bootstrap（探针策略 vs 固定 morgan 的逐分子对差）。
6. 附带产出：若②③未触发判死，12 根全部跑同口径份额，得到第一张实测 EIG 表，回填探针表的「预判 bit」列——它是后续探针取舍与成本表设计的输入；若判死则到此为止，其余探针不再跑，算力转方向1。

成本估计：约两天，纯 CPU（sklearn 级），零 GPU，不依赖未装的训练栈（无 trl/peft/vllm 也不影响）。

## 反面证据

主动找过推翻本方向的材料，找到的：

- 三篇独立证否（arXiv:2504.13837、2507.14843、2510.15990）已吸收进设计——对照组含等算力随机调用，任何 RL 提升先过这条线（第一轮结论⑤）。
- 势函数塑形定理已吸收——EIG 不进 reward，只做诊断（第一轮结论②）。
- 真实威胁来自数据本身：适用域判定四十年文献（结论④），且相似度式适用域正是 ADMET 工具的标配思路（推断档）——「一步相似度规则吃掉大头」不是稻草人，这正是判死检验押注②③的原因。
- 四工具全错仅 12 行（实答）⇒「全错才需要复核」的强假设不成立：复核的价值必须来自「谁对」，不是「都不对」。
