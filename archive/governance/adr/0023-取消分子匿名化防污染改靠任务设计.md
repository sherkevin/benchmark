# ADR-0023 · 取消分子/材料匿名化，防污染改靠任务设计

- 状态：已裁定（Owner 2026-08-09）
- 决策者：Owner
- 起因：只改元素名、保留结构的匿名化能被 agent 立即反推，等于没做
- 关联：**Supersedes [[0017]]**（dummy atom 匿名载体）· 修订 [[0012]] 的"分子 mock 等价变换防知识泄漏"一句 · 承接 [[0022]] §6 已暴露的泄漏面事实

---

## 1. 决定

**取消实体匿名化（不再做元素替换 / dummy atom 变换 / 抹身份），agent 可见真实化学身份（formula、InChIKey、真名）。防污染不再靠匿名，改靠任务设计。**

一句话分清取消什么、保留什么：

| | 取消（B 层：身份匿名） | 保留（A 层：离线库当 oracle） |
|---|---|---|
| 是什么 | 元素级/dummy-atom 替换、A 侧删 formula/inchikey、case_id 去真名 | 性质预存进库、查库返真值、答案侧隔离 |
| 为什么 | 防不住，且掐死结构推理 | 判分的真值来源，删了 benchmark 就塌 |

**A 层必留**——没它工具返不了值、判分没真值可对。本 ADR 只取消 B 层。

## 2. 为什么取消：三条理由

**理由一：结构就是分子的指纹，留结构 = 留身份，只改元素名是假匿名。**

分子式 + 连接方式在化学里与分子身份一一对应（`C₉H₈O₄` + 特定拓扑 = 阿司匹林，全世界唯一）。把 C 换成 `[16*]` 只是换层皮，指纹没动——agent 拿匿名结构去比对训练时见过的分子，一对一就认出来了。这跟"给人脸打码却保留全部五官轮廓"一样无效。

**理由二：[[0022]] 自己已实测证明匿名名存实亡。**

为了让 agent 能做结构推理，0022 已开通拓扑可见性，并在 §6 承认：全库 92,153 实体的标签频率有明显指纹（`[19*]` 占 43.5%、`[16*]` 占 36.0%），按有机分子常识可直接对应到氢碳氧氮；**元素表被破解后再叠加拓扑，即得完整结构，反推真实分子难度显著下降**。也就是说，从开通结构可见性那一刻起，匿名已实质失效——继续维持它只是徒增成本、给出"防了污染"的错觉。

**理由三：防背答案与测结构推理本质冲突，二选一。**

$$\text{测结构推理} \Rightarrow \text{必须给真结构} \Rightarrow \text{能认出分子} \Rightarrow \text{防不住背答案}$$

其中：

- **测结构推理**——我们要测的核心 infer 能力（加一个原子、看性质怎么变）；
- **必须给真结构**——没有真实拓扑，agent 无从推"改了会怎样"；
- **能认出分子**——真结构即指纹，等于交出身份；
- **防不住背答案**——身份一交出，记忆型模型可直接命中。

四步是硬链，中间断不开。留结构和防背答案不可兼得，"改元素名留结构"是个两头落空的假折中。既然要测结构推理（项目核心），就必须放弃靠匿名防污染。

## 3. 防污染改靠什么（诚实声明）

匿名取消后，防污染改由两层承担：

1. **任务设计层（主）**：答案不写在题面、必须靠多步推理+工具探索才能到达（对应正在推进的"删 search_candidates + 顺藤探索"方向）。答案不在题面时，背一个分子名也没用——因为不知道要背哪个。
2. **陌生结构（未来可选）**：用训练集未见的分子（改造衍生物 / 冷门采样），结构真、身份陌生、背不出。此项本 ADR 不落地，列为后续选项。

**时间差如实标注**：任务设计层（第 1 条）尚未落地。**在它落地前，本 benchmark 不对外声称"抗记忆污染"**——不能取消了旧机制、新机制没上，还宣称防住了。这是本 ADR 必须写明的诚实边界。

## 5. 本 ADR 不裁定的事

- **任务设计层怎么落**（删 search_candidates、顺藤探索、seed 怎么定）——属正在进行的 query/world 方案讨论，另行立项，不在此拍。
- **判分不动**——取消匿名不改任何 checkpoint 口径。
- **既有矩阵结果**——匿名取消前跑的结果，与取消后不可直接对比（agent 可见信息变了）。

## 6. 备案

本 ADR 由 owner 直接决议（监工客观陈述"改元素名留结构防不住、且与结构推理冲突"，owner 裁定直接取消匿名）。ADR-0017 的 PR-31 相应转为 OBSOLETE。
