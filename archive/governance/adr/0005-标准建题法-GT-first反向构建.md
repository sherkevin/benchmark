# ADR 0005 · 标准建题法:GT-first 反向构建(选根 → 拉真值链 → 反向出题 → 注入负例)

- **状态**:Active
- **日期**:2026-06-13
- **领域**:benchmark 建题方法学(操作级)
- **关联**:操作化 [[0002]] 的 5 步法(取代其 Step 2/5 的松散表述)· 沿用 [[0003]] 的 Σ 规模公式 · 遵 [[0004]] 应然设计 · 模具 `longhorizon/定义_长程任务与桩点.md` · 配料表 `longhorizon/ckpt_gt_binding.md`

## 背景

0002 定了"造 trace"+ 5 步法,但其 **Step 2(抽象→实例)和 Step 5(∏mᵢ 组合)是松散/错误的**——红队证明 ∏mᵢ 不成立,且"自由拼检查点"会造出"前面晶体 A、后面晶体 B 串不起来"的无意义 trace。2026-06-12~13 与 owner 多轮对齐,收敛出一套**可操作、可保证连贯、可走量、零编造**的标准建题法。本 ADR 钉死它。

## 决策:一条 trace 这样造(GT-first 反向构建)

> **核心:不先有问题再找答案,而是先锚定一个"已知答案的真实实体",再倒着把题搭出来。**

7 步(以 caseD / Ba-Ti-O 为例):

1. **选根 = 定答案**:挑一个真实实体(化学体系 / 靶点 / 靶点-病对 / 药物 / 目标分子),其全套性质在公开源里有。选了它即定了这道题的答案。
2. **拉真值链**:拿根去源里**一次关联(JOIN)查询**,把「每个科学检查点的真值」+「最终答案」一起拉出——皆为该根的不同侧面,**天生自洽**。
3. **配过程检查点**:写脚本判路(预算 / 单调 / 覆盖 / 连通 / 无环),不拉值。
4. **反向出题**:用 6 种自然题型模板,给这套真值配一个**自然**的 query。
5. **写金标准 trace**:把真值串成"理想 agent 该怎么走"的轨迹;**补的是连接叙述,不是数**。
6. **注入造负例**:在金标准里**故意注入 1 个已知错误(D1–D7)**、其余保持真 → 硬负例;对错与错处建题时即知,对应检查点亮红。
7. **换根走量**:换实体重跑全流程。

## 检查点三类

- **科学类**(数值 / 集合 / 排序):按根 JOIN 拉真值。
- **过程类**(守恒 / 工具落地 / 内部一致):脚本判 agent 录像,不拉值。
- **语义类**(策略 / 报告诚实):人编细则 + LLM 判 + κ 校准;少量、非承重。

## 三条铁律

1. **一个数不编**:真值必从真实来源拉(库 / 论文 / 规则)。只有"连接叙述"是写的,且写错检查点会亮红。
2. **一根到底**:一条 trace 的所有科学检查点都从**同一个根** JOIN 拉 → 天生连贯;**绝不跨实体拼值**。
3. **正例靠构造、负例靠注入**:两者建题时即知对错,**不做"全组合 + LLM 填描述 + 置信度分"**。

## 答案两条来源(A / B,互补)

- **A 期刊/实验**:真·新发现 + 常带实验验证,**且给出真实中间全过程**。稀少(几十篇级),含金量最高 → 少量 premium 金标准 + 验证整套判分法。
- **B 数据库反向**:已知事实,海量 → **量产主力**。
- 关键:**B 不弱**——agent 要走的多步过程与 A 一样难,测"过程质量"一样有力;B 只少"新颖发现"那层。**A 考"能否发现新东西",B 考"能否正确走完多步流程到已知正确答案"。**"答案在库里" ≠ 题简单(agent 不许查库,只能自己推/算;库只是我方"答案本")。

## 走量公式(替代 ∏mᵢ)

题量 ≈ **真锚数 × 介入档(L0–L3)× 反事实变体 × 重复跑**。规模来自"换多少个根"。

## 反向构建 4 纪律(否则造出垃圾题)

① query 自然(套模板)② 必须长程(多步,非单值)③ 防记忆泄漏(挑冷门 / 扰动 / 用模型 cutoff 后数据)④ 答案可发现(能从起点推出,非孤立死记)。

## 我们到底测什么

**过程质量**——只看终答看不出走偏,检查点能定位"第几步、哪种偏(D1–D7)"。这是与"只判终答"的 benchmark 的根本区别,也是 paper 命门。

## 后果

- ✅ "模板 → 几千条真题"路径明确、可工程化:每个模板配一个**实例化脚本**(根类型 + JOIN 查询链),写一次、换 N 个根出 N 条连贯真题。
- ✅ **连贯性、无编造、正负例标签** 三件事都由构造方式保证,不靠事后判别。
- ⚠️ A 路稀缺是天花板(真发现题靠少量论文);B 路要做防泄漏。
- ⚠️ 唯一非结构化、需人工的是"逐题文献对照"类(已隔离为可选加分项,不挂 trace 仍完整)。
