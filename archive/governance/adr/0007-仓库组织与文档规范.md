## 上下文

仓库经三轮"结构不够清晰"反馈,owner 明确了组织的第一性原理:**仓库最终为调研服务**。此前尝试过"按文档性质分六类序号子目录",被否——分类轴本身不是目的,服务调研与最终写作才是。

## 决策(组织规范七条)

1. **`datasets/` = 纯数据资产,不存文档**。一数据集一文件夹,只放采样数据 + 官方判分脚本 + `README_采样说明.md`(采样血缘元数据,随数据走)。自造题集也是 dataset 资产(`datasets/NobelClaw/`)。
2. **`research/` = 调研文档,平铺,不设分类子目录**。一次深度调研的报告 = 一个平铺 `.md`;benchmark 解释文档与 benchmark 同名(`research/tau-bench.md` ↔ `datasets/tau-bench/`)。
3. **调研文件夹例外**:若一次调研同时产出报告与中间材料(搜索原始输出、参考论文、核查笔记),并成一个文件夹,文件夹名 = 调研名。
4. **待办唯一**:全项目只有根 `TODO.md` 一份待办,分散的 todo_* 一律合并,不再新立。
5. **项目级文档居根**:`goal.md`(权威)/ `PROJECT_RESULT.md` / `TODO.md` / `construction_methodology.md` / `README.md`。
6. **`决议/` 扩容定位**:ADR + 对话商讨的及时性经验规范;**作为最后写文档的参考资料,不作为呈阅文档**。
7. **`task/` 冻结**:业务方历史任务存档,暂不维护、不删除。
