# ADR-0026 · 三档套卷：同题同真值，只变工具供给

- 状态：已裁定（Owner 2026-08-12）
- 决策者：Owner
- 关联：承接 [[0025]]（科学家代入判据判出的「不给」工具，正是本 ADR 的便捷工具候选池）
- 起因：ADR-0025 把工具收到 3 个后，需要一个办法量化「工具替代了多少推理」，而非只报一个绝对分

---

## 1. 决议（三句）

**一、三档套卷用同一个 query、同一份判定真值，只有工具供给不同。** 不是造三套题，而是**一套题跑三种工具配置**。

**二、便捷性工具的定义：把一个推理过程变成一次工具调用。** 一个工具是不是便捷工具，只看它是否替代了 agent 本该自己完成的推理步骤。

**三、构建顺序是先难后易，不预先设计档位。** 先用最基本工具（当前 3 个）跑困难档，分析结构与出错点，**再针对实测出的失败模式提供对应便捷工具**，由此构成中等档与简单档。

## 2. 为什么必须同题同真值

对比的有效性完全依赖这一条。

$$\Delta_{\text{tool}} = S(\text{题 } q,\ \text{工具集 } T_{\text{易}}) - S(\text{题 } q,\ \text{工具集 } T_{\text{难}})$$

其中：

- $q$ —— **同一道题**：题面、约束、判定真值、合格集全部不变；
- $T_{\text{难}}$ —— 基本工具集（[[0025]] 的 3 个：查文献、做实验、交卷）；
- $T_{\text{易}}$ —— 基本工具集 **加上**若干便捷工具；
- $S(\cdot)$ —— **同一套 checkpoint 判据**算出的分；
- $\Delta_{\text{tool}}$ —— 该便捷工具替代掉的推理量。

**只有 $q$ 与判据都不变，$\Delta$ 才能归因到工具供给。** 若三档换了题或换了判据，差值就混入了题目难度差异与判据差异，归因失效。

**工程含义**：case 文件（query、gt、constraints、合格集）一份不动；变的只是运行时的**工具集档位配置**。

## 3. 构建顺序：困难档先行，档位由错误分析导出

| 阶段 | 做什么 | 产出 |
|---|---|---|
| 一 | 全量 150 题跑**困难档**（3 个基本工具） | 基线成绩 + 完整轨迹 |
| 二 | 分析轨迹结构与**出错点分布** | 失败模式清单（各模式占比） |
| 三 | 针对占比高的失败模式，各配一个便捷工具 | 便捷工具清单，**每个工具对应一个实测失败模式** |
| 四 | 同题重跑中等档与简单档 | 三档对比曲线 |

**为什么不预先设计档位**：预设的便捷工具可能替代的是 agent 本来就不出错的环节，那么 $\Delta \approx 0$，这一档白跑。**由错误分析导出，能保证每个便捷工具都打在真实痛点上**，每一档的分数抬升都有明确来源。

**便捷工具的候选池已现成**：[[0025]] 按科学家代入判据判为「不给」的那批——分子编辑（单原子增删）、变体枚举、候选检索、邻居检索、排序。它们之所以在困难档被排除，正因为它们替代推理；这个性质使它们成为低难度档的天然素材。

## 4. 两种对比，两类结论

| 方向 | 比什么 | 得到的结论 |
|---|---|---|
| **横向** | 同一档内，不同模型 | 谁做科学家更强（能力排名）|
| **纵向** | 同一模型，跨三档 | 工具替代了多少推理（能力构成）|

纵向对比顺带解决 [[0025]] §9 登记的未验证前提——**模型写 SMILES 的语法能力是否构成瓶颈**：

- 给了结构编辑工具后分数大涨 → 瓶颈在**结构构造**（语法与操作），不在化学推理；
- 给了不涨 → 瓶颈确在**推理**。

这比单独测「50 个 SMILES 的合法率」更可信，因为它在真实任务上测量。

## 5. 定位：主测困难档，低难度档是消融对照

**必须按此表述，不得含混。**

| 说法 | 判定 |
|---|---|
| ✅ 「主测是困难档；中等/简单档为消融对照，用于量化工具替代的推理量」 | 正确 |
| ❌ 「我们有三档难度的题目」 | **错**。这等于承认我们也在测搜索能力，与 [[0025]] 冲突 |

**低难度档的作用是标出「靠搜索能拿到的天花板」，从而证明困难档的分数来自推理。** 它是论证工具，不是评测主体。

## 6. 分数不可合成（硬约束）

**三档分数绝对不得平均成一个总分。** 工具集不同即任务定义不同，跨档平均无意义。

对外只报：三档各自的分 + 档间差值 $\Delta$。**此条须落成机器断言**，防止后续汇总脚本擅自合成。

## 7. 判分口径三档一致（本 ADR 裁定）

**低难度档不改 checkpoint 判据，沿用同一套。**

理由：我们要测量的正是「agent 靠搜索能拿多少分」。若为低难度档调整判据，两档即不可比，$\Delta$ 失去意义。

**代价如实记录**：简单档分数可能显著偏高（爬山搜索确实能解一部分题）。**这正是要报告的结论，不是缺陷**。

## 8. 本 ADR 不裁定的事

- **便捷工具的具体清单与分档边界**——须待阶段二错误分析完成后确定，不预设（§3）。
- **对照档的抽样规模**——困难档为全量 150 题；中等/简单档是否全量重跑或抽子集，待阶段三定，取决于失败模式的分布集中度。

## 9. 待验证

1. **困难档可解性**：3 个基本工具下，三类题是否都存在可行解法路径（尤其外推题的可见集须由题面给定，见 [[0025]] §8）。**若某类题在困难档无解，该类题的三档设计不成立。**
2. **$\Delta$ 的显著性**：档间差值须超过跑间方差才有意义。项目已登记「跑间方差未实测」，此项须先补。
