## §1 裁定一：旧范式作废，新范式重立

### 1.1 旧范式是什么，错在哪

**旧范式（现役 150 道题、15 份判分器、全部手写题，无一例外）**：

```
判分 = 比对(产物, 我们藏起来的标准答案) → 命中 / 不命中
```

**错在哪——不是"题造得不好"，是这个式子本身有一个死结**：
只要存在一个固定答案，就一定存在一条不经过能力、也能到达那个答案的路。
全库每一次判死都是这条路的一个实例：

| 题 | 那条便宜的路 | 实测 |
|---|---|---|
| `layer_01` | 闭眼背书（零数据） | **0.952** vs 123 个真跑 run 的 **0.602** |
| logS/#12 | 纯记忆报数值 | 裸答 **0.680** ≈ 诚实做完的天花板 **0.877** |
| `sarflip_01` | 花 1 次预算 + 免费列做算术 | 免能力天花板 **21.89%**（判死线 5%） |
| Job 2 第二/三版 | 一律猜某个链长 | 猜 n=6 → **0.934** |
| `qed_01` 两关 | 同一个二值协议门 | 54/54 run **完全共线** |

我们的应对一直是**把答案藏得更深**（挖洞、抹除、隐藏规律、匿名化）。
**但"藏答案"这件事没有下限**——藏得越深，题越脆、越依赖我们自己没漏，
而每一次"藏"都要新造一份真值。**这就是 08-19 以来打转的机械原因。**

⇒ **owner 的裁定把病灶从"题"提到了"式子"这一层。这是本轮最重要的一句话。**

### 1.2 新范式：三条性质（owner 认可的口径）

```
分数 = 打分函数(产物) − 打分函数(题面钉死的起点)
```

| # | 性质 | 为什么这一条要紧 |
|---|---|---|
| **①** | **没有标准答案** | 无答案可背、可抄、可蒙。旧范式的整条攻击路径**直接不存在** |
| **②** | **判分是跑一个函数，不查真值库** | 判分不再依赖"我们先造好一份真值" ⇒ **造题成本与判分成本脱钩**（这一条是 §2.2 的关键） |
| **③** | **输出是连续量，不是单值** | 有大小、可排序、可求差 ⇒ 天然是**训练信号**，不只是及格线 |

**owner 的"这本质上是查它最后的结果"要按字面执行**：判的是**交上来的产物本身好不好**，
不判它路上做了什么、也不判它是不是我们心里那一个。

### 1.3 先说坏消息：攻击面没有消失，是**搬家**了

⚠️ **这一条必须写在最前面，不许当作已解决**（否则就是坑①：臆想一个"必须"就往前冲）。

| | 旧范式 | 新范式 |
|---|---|---|
| 唯一攻击面 | **答案泄漏**（被背到 / 被查到 / 被蒙到） | **打分函数被爬穿**（不做实验、只用免费信息就能把分推上去） |
| 出事的后果 | 那道题作废 | **那个函数管的所有题一起作废** |

**已有的不利证据（不是猜测）**：QED 是若干免费描述符压成的平滑函数——
T-223 实测 4-烷氧基苯甲醛那整条断崖，**完全由 rdkit 的 ALERTS 计数一个开关决定**；
T-220 实测 QED 曲线顶部六档只差 0.015、比判分容差还窄。
⇒ **拿 QED 直接当打分函数，极可能就是一条免费梯子。**

**⇒ 落为硬前置**：任何打分函数在用之前，必须**先离线算免能力天花板**
（只用免费信息、不花实验预算，能把分推高多少），沿用 `BENCH_SPEC.md §4.1` 闸4 第二必答，
**>5% 就换函数，不许调分差阈值**（调阈值是坑⑨）。

### 1.4 与新范式配套的两条约束（其中一条是本决议自己引入的风险）

1. **必须有多目标张力**。单轴爬坡不是药物优化：活性↑ 常伴脂溶性↑ ⇒ 溶解度↓、毒性↑。
   只有一个量可推，"改进"就退化成把一个数往一个方向顶。
2. ⚠️ **起点必须由题面钉死，不许 agent 自选**。
   起点若可选，**故意挑个烂起点、随便改一下就"进步很大"** ⇒ 分差变成"选起点的技巧"，
   这正是坑⑨的形状。**这是新范式自带的新旋钮，当场堵掉。**

### 1.5 裁定

1. **"比对藏起来的标准答案"这个判分范式作废**，不再据它造任何新题。
2. **新范式 = §1.2 三条性质**，判的是产物本身、分数是连续量、判分靠跑函数。
3. **打分函数在用之前必须先过免能力天花板**（§1.3），不过就换函数。
4. **起点由题面钉死、必须有多目标张力**（§1.4）。

## §2 裁定二：RSI 必须含模型训练

### 2.1 四级阶梯：owner 要的是第几级

| 级 | 做法 | 权重变不变 | owner 判定 |
|---|---|---|---|
| **L0** | 只调提示词 / 改 system prompt | 不变 | ❌ **"最低级别的"，不算 RSI** |
| **L1** | agent 在一条链里多轮改进产物（改→验→修正→再改） | 不变 | ◐ 有回路，但只是 agent 行为，不是自我迭代 |
| **L2** | 用跑批产生的轨迹 + 连续分数**训练模型** | **变** | ✅ **owner 要的层** |
| **L3** | 训练后的模型再去跑、再产分数、再训练（闭环） | 变，且循环 | ✅ 真正的 RSI 终态 |

**owner 原话"尽量还是要做模型训练"⇒ 目标层是 L2，终态是 L3。L0 明确排除。**

### 2.2 本决议的核心论证：两条裁定不是两件事，是一件事

**这是本文最要紧的一段。**

- **在旧范式下，L2 根本起不来**：每一条训练样本都需要一份**人工造的标准答案**
  ⇒ **造训练数据的成本 = 造题的成本**。我们花了 9 天造出的活着的题是 **0 道**
  （`决议_20260828_原子问题定义与长程组装.md §5.3`），按这个速度攒训练集是无望的。
  而且旧范式的分是**命中/不命中**，是个二值 ⇒ **没有梯度、没有排序，天生不是训练信号。**

- **新范式恰好把这两个障碍同时拆掉**（正是 §1.2 的性质 ② 和 ③）：
  - 性质②（判分是跑函数、不查真值库）⇒ **给任意起点、任意产物都能立刻打分**
    ⇒ **训练数据可以自动、无限地生成，不需要人先造答案。**
  - 性质③（输出连续）⇒ **分数本身就是奖励信号**，可排序、可求差、可做偏好对。

⇒ **owner 的两条裁定咬合成一条**：

> **换掉"藏答案"范式，不只是为了让 benchmark 更难作弊——
> 它是让"有模型训练的 RSI"从不可能变成可能的前提条件。
> 打分函数同时是判分器和奖励函数；产物优化的链同时是考卷和训练环境。**

### 2.3 随之而来的一条硬风险（必须与 §1.3 一起读）

⚠️ **打分函数一旦可被爬穿，在训练场景下危害是放大的**：

| | benchmark 场景 | 训练场景 |
|---|---|---|
| 函数被爬穿的后果 | 那道题作废，我们发现了、判死它 | **模型被强化去钻这个空子**，而且越训越会钻 |

⇒ **免能力天花板从"造题的一道闸"升级为"训练开工的前置"**：
天花板没算过、或算出来 >5%，**不许进 L2**。

## §6 必须说清、不许当已解决的六条

1. **新范式没有消灭作弊，只是把攻击面从"答案"搬到"函数"**（§1.3）。而且**后果更重**：
   旧范式漏一次废一道题，新范式漏一次废掉那个函数管的所有题。
2. **QED 大概率不能当打分函数**。已有两条不利实测：断崖完全由 rdkit 一个警报开关决定（T-223）、
   曲线顶部比判分容差还窄（T-220）。⇒ P4′ 很可能直接把它判掉，**这是预期，不是失败**。
3. **"起点钉死"是本决议自己引入的新旋钮风险**，已在 §1.4-2 当场堵掉。往后凡改起点选取方式，
   必须回来核这一条。
4. **L2 的可行性一个字都还没核**。1 块 H20 是**事实**，"够不够"是**待查项**（§5 P6）。
   ⚠️ 现在无论说"够"还是说"不够"，都是坑⑪。
5. **存量 150 道题的命运还没定**。范式作废是**造新题的禁令**，不是存量的死刑；
   逐族重判是 P5 之后的事，**不得在此之前宣布它们全废**——上一轮正因为这类过度概括
   把活着的资产判死过（坑②+坑⑪）。
6. **本轮零代码、零数据改动**，只落决议与台账。P4′ 之前不动任何判分逻辑。

## §7 一句话总结

**owner 把病灶从"题造得不好"提到了"判分的式子本身有死结"这一层**——
只要藏着一个标准答案，就一定有一条不经过能力也能到达它的路，而藏答案没有下限。
换成"跑一个函数看产物比起点好多少、分数是连续的"，那条路直接不存在；
**而这同一个改动，恰好也是"有模型训练的 RSI"能起来的前提**——
因为判分不再需要人先造答案，训练数据就能自己生成；因为分数是连续的，它本身就是奖励信号。
**代价是攻击面搬了家**：打分函数就是奖励函数，它一被爬穿，训练会主动去钻那个空子。
所以第一步不是训练，是**先离线证明这个函数不是一条免费梯子**——零机时，一天能出结论。
