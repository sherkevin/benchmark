# 决议（2026-08-31）：两类题都留 + 验收标准三条 + 三档分数反读题目难度

> **这份文档回答什么**：owner 在一轮回话里下了四条裁定——
> ① **cns_01 与 sarflip_01 这两类题都有价值，都留**，负结果本身就是「工具不一定都有效」的证据；

> ③ 工具供给是 **basic / some / enough 三档**（不是我此前一直在测的两条臂）；

## §1 速读区

**一句话**：判一道题好不好，看的是它测得严不严谨、问得对不对、能不能喂 RSI，**不看分差大不小**；
分差小本身是一条读数——它说明这道题的坎不在工具能买到的地方。

| # | 事实 | 数字 |
|---|---|---|
| 1 | cns_01（测量只是诊断）工具臂对无工具臂 | 差 **+0.056**（0.333 对 0.278，**n=12 / 9**），精确秩和 p=**0.859**，d=**0.185**，要每臂 **462** run 才有 0.8 功效 |
| 2 | sarflip_01（测量即答案）工具臂对无工具臂 | 差 **+0.500**（0.500 对 0.000，**n=6 / 6**），d=**1.291**，只要每臂 **10** run；现有 run 太少故精确置换 p=**0.182**（**效应大而 p 不小，纯粹因为 run 少，不是效应弱**） |
| 3 | cns_01 的差距为什么小：逐轴拆开，**全题只卡 clogp 一条**（**n=13 / 9**） | mw **13/13 对 9/9**（都 100%）、hbd 10/13=77% 对 8/9=89%、tpsa 10/13=77% 对 6/9=67%、**clogp 2/13=15% 对 0/9=0%** |
| 4 | 换尺子救不救得了：换了三把 | `(n−2)/2` 与 `n/4` 的 p 和 d **逐位相同**（单调线性变换，秩不变）；真正更细的 mpo 尺子反而**无工具臂反超 −0.034** |
| 5 | owner 的「三档差不多 ⇒ 反读难度」**已经在 qed_01 上应验过一次** | fixed 档 some→enough 只涨 **+0.047**（前一跳是 +0.344）⇒ 当时据此定出不可再分内核。**⚠️ 但 open 档第二跳是 +0.091、比它大一倍**，见 §5.2 |
| 6 | ⚠️ **但 cns_01 和 sarflip_01 至今都只测了两条臂，不是三档** | 有 basic 档 + 一条「零领域工具」地板对照；**some / enough 两档一个 run 都没跑** |

**三个分母必须分清（上表里的 n 不是同一批 run）**：cns_01 一共跑了 **27 个 run（工具臂 15 + 无工具臂 12）**。

| 用途 | 筛法 | 剩下多少 |
|---|---|---|
| 总分与换尺子对比（第 1、4 条） | 三道门（SMILES 可解析 + 骨架没砸 + 走过化验）全过 | **12 / 9** |
| 逐轴过关率（第 3 条） | 只要求 SMILES 可解析 + 骨架没砸（不要求走过化验，否则无工具臂全灭、没法逐轴比） | **13 / 9** |
| 原始批次 | 不筛 | **15 / 12** |

⇒ 13 + 9 = 22 ≠ 27，差的 5 条是被门筛掉的（SMILES 读不出来或骨架砸了）。
**本文所有百分数一律按上表的分母读，不得跨行混用。**

**第 6 条是本文最重要的自曝**：owner 说的三档，在这两道新题上还没有被实例化。
现有的 cns_01 数字**不是**三档比较的结果，不得当三档结论引用。

### 1.1 本文用到的词，一次讲清（只列本文论证依赖的）

| 词 | 意思 |
|---|---|
| **RSI** | recursive self-improvement，自我迭代。本项目的第二半目标：**拿 benchmark 跑出来的数据去训模型**，让它变强（08-28 已裁定必须含模型训练，只调提示词不算） |
| **一条臂 / arm** | 一组只差一个变量的实验条件。本文的两条臂只差"有没有领域工具"，题面、预算、判分器全同 |
| **地板对照** | 一条**什么领域工具都不给**的臂，用来回答"不给任何仪器能拿多少分"。它标出的是分数的地板，不是一个难度档 |
| **尺子 / 判分函数** | 把 agent 交的答卷折成一个分数的那个函数。本文换过三把：`(过关条数−2)/2`、`过关条数/4`、连续合意度 mpo |
| **四条轴** | cns_01 这道题要同时满足的四个化学条件：`mw`（分子量 ≤360，纯算术）、`hbd`（氢键给体数 =0，数个数）、`tpsa`（极性表面积 40–90，把极性片段加起来）、**`clogp`（脂水分配系数 ≤3，要 Crippen 加和模型，脑子里算不出来）** |
| **Δ_tool（档间差）** | 高档分数减低档分数。ADR-0026 用它量"这个便捷工具替代掉了多少推理" |
| **fixed / open** | 同一道题的两种题面：**给**含答案的候选集（fixed）/ **不给**候选集（open）。只这一处差别 |
| **口径 B** | 失败怎么记：**基建**失败（接口报错、工具泄漏）把这个 run 撤出统计；**能力**失败记 0 分、留在分布里 |
| **improve 类题** | 08-28 立的新范式下的题：不藏标准答案，**给一个东西，看它改得比原来好多少**，跑一个打分函数取连续分。cns_01 就是第一道 |

## §2 裁定一：两类题都留，负结果就是结果

### 2.1 这"两类题"具体指什么

不是两道题的区别，是**两种机理**的区别。判别问题只有一句话：

> **测完之后还要不要再想一步？**

**这一句在跑之前、只读题面就能答**（下表前两行）；后两行是跑完才有的**验证**，不是判别条件：

| | `case_dr_sarflip_01` | `case_dr_cns_01` |
|---|---|---|
| ↓ 跑之前读题面就能答 | | |
| 工具给什么 | 测一个候选，返回它合不合格 | 化验一个分子，返回四条轴的取值 |
| 测完之后 | **不用再想**——测出来合格的那几个，交上去就是答卷 | **还得再想一轮**——知道自己 clogp 3.62、超了，怎么改回 3.0 以下是另一件事 |
| ↓ 跑完才有，用来验证上面答得对不对 | | |
| 工具在分数里可见吗 | **可见**：差 +0.500、d=1.291 | **几乎不可见**：差 +0.056、p=0.859 |
| 预算够不够买到解 | 够（列表有限，测得完） | 不够（8 次化验买不到一次成功的化学再设计） |

**这条判别问题是从实测反推出来的，不是先想好的**（推导过程见 `TODO.md` T-268 ④ → T-269 ②，
第一版解释错了，逐轴拆开后才改对）。

### 2.2 我错在哪，owner 纠了两次

- **第一次**：我把「尺子太粗、判别力不够」读成「这道题该废」。
  owner：「cns01 为什么要废弃,用新尺子再量一遍不得了呗」。
  ⇒ 换判分函数、题面一个字不动，那 27 个 run 全部可以重判，不用重跑；
  这也不犯 `judge_contract` 那条「一道 query 一个目录、绝不原地改」——
  census_01 当年是**问法**变了、老 run 答的是另一道题，这里问法没动。
- **第二次（本轮）**：我把「换尺子也救不回来」又读成「那还是得重造」。
  owner：**两类题都有价值，都留。**

### 2.3 为什么负结果有价值——这不是给自己找台阶

一道题测出「工具没用」，有两种可能，**它们的价值完全不同**：

| 情形 | 是不是缺陷 | 怎么分辨 |
|---|---|---|
| 题造坏了：判分器读不到工具影响的量，或工具压根没接上 | **是缺陷，必须修** | 逐轴/逐关拆开，看有没有一条轴根本没被工具触及 |
| 题是好的：工具真的买不到这道题的坎 | **不是缺陷，这是结论** | 逐轴拆开后能指出**卡在哪一条**，且能说清工具为什么买不到它 |

cns_01 属第二种，证据是第 3 条那张逐轴表：四条轴里三条**白给**（纯算术、数个数、纸上加和），
全题实际只卡 `clogp ≤ 3` 一条——那条要 Crippen 加和模型，脑子里算不出来；
**而连有工具那条臂也只有 2/13 = 15% 过得去**。差距小不是因为工具没给信息，
是因为**两条臂倒在同一条轴上**。

⇒ 这条负结果是可发表的读数：**在"按已发表要求单改一个分子"这件事上，给测量工具不改善产物。**
它回答的是"工具能替代多少推理"这个正题，只是答案是"这里替代不了"。

## §3 裁定二：验收标准三条，「结果符合预期」不在其中

### 3.1 三条是什么

| 条 | owner 原话 | 现在能怎么查 |
|---|---|---|
| **严谨** | "要保证结果是严谨的" | 已有机器闸：精确检验（不抽样不设种子）、口径 B（基建失败退场 / 能力失败计 0 留在分布里）、判别力必须走判分实际给分路（视图自检 A9） |
| **问题恰当** | "问题是恰当的" | **暂无机器判据**。现有的只是人读：这道题问的是不是一件真事、坎在不在该在的地方、题面有没有把答案漏出去 |
| **能为 RSI 服务** | "是可以为后面 rsi 服务的" | **只有一半可查**。可查的：分数是**连续可比**的量（判分范式决议 §1.2 性质③）、轨迹落盘可回判。**不可查的**：这个分数是不是真的**能当训练信号用**——那要等真训起来才知道（现在只有约 23 条判过分的轨迹，训练栈 trl/peft 等还没装） |

### 3.2 为什么"不保证符合预期"这句话要单独落盘

这句话把项目一直在守的那条规矩，写到了**验收层**：

> **执行方不定阈值，不为了达到某个结果去调旋钮。**

如果验收标准里含一条"结果要符合预期"，那么每出一个负结果，
就自动变成一份"把旋钮调到能出正结果为止"的压力单。
本轮的 cns_01 就是活标本——尺子换到第三把（真的更细，19 个不同取值）时**无工具臂反超**，
如果当时按"必须出正结果"办，剩下的动作就只有继续换尺子直到差值转正，
那是拿判分函数去凑结论。**owner 这句话事前掐断了这条路。**

### 3.3 三条里有两条查不全，如实登记

**缺口一：「问题恰当」完全没有机器判据。** 本轮唯一一条够格的，是 §2.1 那个判别问题
（测完还要不要再想一步），但它只能说明**工具会不会在分数里可见**，
不能说明**问题本身恰不恰当**——一道题可以工具可见、同时问得很蠢。

**缺口二：「能为 RSI 服务」只验了形式，没验实效。** 现在能查的是分数的**形状**
（连续、可比、可回判），查不了它的**效用**（拿这批分数去训，模型是不是真变强）。
后者要等 RSI 那条线真跑起来才有答案。

⇒ 两条都登记为缺口，不假装有。

## §4 裁定三：三档是 basic / some / enough——我此前只测了两条臂

### 4.1 ADR-0026 的三档定义（照抄，本文不改）

- 同一个 query、同一份真值、**同一套判分口径**，只有工具供给不同（§1、§7）；
- Δ_tool = S(题 q, 易档工具集) − S(题 q, 难档工具集)，量的是"该便捷工具替代掉的推理量"（§2）；
- 便捷工具清单**由上一档的实测失败模式导出，不预设**（§3）；
- 三档分数**不得合成总分**（§6）；
- 对外只能说"主测困难档 + 低难度档是消融对照"，**不得说成"三档难度的题目"**（§5）。

### 4.2 我实际测的是什么——两条臂，而且下面那条不是任何一档

| 我叫它 | 暴露给 agent 的工具 | 对应 ADR-0026 的哪一档 |
|---|---|---|
| 工具臂 | 5 个内置文件工具（`Read/Write/Edit/Grep/Glob`，**无 Bash**）+ 领域工具 `assay()` | **basic 档**（cns_01 就放在 `improve_basic_tools/`） |
| 无工具臂（"裸跑"） | 只有那 5 个内置文件工具，**零领域工具** | **不是任何一档。它在 basic 之下。** |

**这一条必须说清**：`ws_mcp_server_notools.py` 注册的工具数是 0，
agent 眼里"根本没有化验这回事"。它是**地板对照**（免能力天花板探针），
用来回答"不给任何仪器能拿多少分"；三档 basic/some/enough **全部位于它之上**。

⇒ 所以 cns_01 和 sarflip_01 现在的形态是 **1 档 + 1 条地板**，不是三档。
**some / enough 两档在这两道题上一个 run 都没跑，机件也没写**
（对比：`ws_mcp_server_qed01_some.py` / `_enough.py`、`ws_mcp_server_aedit01_some.py` / `_enough.py` 都是现成的）。

### 4.3 已经跑完三档的是 qed_01（但在旧范式下）

`case_dr_qed_01` 六格各 60 个 run 目录都在，三档分数是真测出来的：

| 总分 | basic | some | enough |
|---|---|---|---|
| fixed | 0.503 (n=24) | 0.847 (n=27) | 0.894 (n=29) |
| open | 0.291 (n=21) | 0.449 (n=27) | 0.540 (n=27) |

Δ_tool：fixed **+0.344 / +0.047**、open **+0.158 / +0.091**。

**但这批数字挂在"藏一个答案看模型能不能猜对"的旧判分范式上**，
该范式经 08-28 裁定作废（[判分范式作废决议](决议_20260828_判分范式作废与RSI含训练.md)）。
⇒ 三档**机件**已验证可用；三档在**新范式（improve 类题）**上一次都没跑过。

## §5 裁定四：三档分数差不多 ⇒ 反读这道题的难度

### 5.1 规则本身

ADR-0026 只写了正向读法：**Δ 大 ⇒ 这个便捷工具替代掉了很多推理。**
owner 补的是反向读法：**三档分数差不多 ⇒ 这道题的坎不在工具能买到的地方，这本身就是难度读数。**

### 5.2 这不是新猜测——它已经在 qed_01 上应验过一次（但有两处必须交代）

qed_01 fixed 档的两跳是 **+0.344 → +0.047**：第二跳几乎平了。当时据此下的结论是
「**工具梯子到头了**」，并进一步指出剩余推理不可再被工具替代的两条硬证据——
① 统计学工具帮倒忙（LOO-CV 推荐了错的 degree=1）；② 真正的坎是领域知识
（ALOGP 项在 n=6 后机制反转崩塌），**任何供给它的工具都会泄答案**。
⇒ 那次就是"分数差不多"反读出了这道题的不可再分内核：「识别出外推段会发生机制反转」。

**owner 这条裁定，是把当时一次性的读法立成通则。**

**交代一：只有 fixed 那一侧平了，open 那侧没平。** open 的两跳是 **+0.158 → +0.091**，
第二跳比 fixed 的 +0.047 **大一倍**。同一道母题、同一套判分器，两侧对"梯子到哪儿到头"给出不同答案。
当年记录的机制是：open·basic 有 18/21 个 run 把目录全翻完、只剩 3 次测量，
给了便捷工具后反而学会少翻页 ⇒ **open 的 Δ 里混了"省发现成本"这一项，不是纯的"替代推理"**，
故当时就写明**不可与 fixed 的 Δ 直接比较归因**。⇒ 引这条规则时**必须说清是哪一侧的梯子**。

**交代二：这批数字挂在已作废的范式上，能转移的只是读法，不是数值。** 08-28 作废的是
"藏一个答案看模型能不能猜对"这个**判分范式**，它决定那些绝对分**代表什么**；
而"三档之间的 Δ 塌下来 ⇒ 剩余推理买不到"这个**读法**只依赖一件事——三档共用同一套判分口径
（ADR-0026 §7），这一条在那批数据里是成立的。
⇒ **可以说**：这条读法有过一次成功应用，不是凭空立的规则。
**不可以说**：这条规则在新范式下已被验证。**新范式（improve 类题）上的三档，一次都没跑过。**
⚠️ 「作废范式下的测量还能不能当证据引用、边界写在哪」本身是治理问题，**已列入 §6.4 待 owner 裁**。

**交代三（同日补测，是测量不是裁定，见 T-271）：这两跳第一次有噪声地板可比，结论朝加强的方向走。**
ADR-0026 §9.2 一直要求「档间差值须超过跑间方差才有意义」，而跑间方差挂了 19 天没实测；
现已实测（qed_01 六格 **0.176–0.230**）。套上去：**fixed 第二跳 Δ/SD=0.18、Δ/SE=0.94，
两把候选尺子下都不过关** ⇒「梯子到头」这个读法**不依赖选哪把尺**，比当年只说"几乎平了"硬。
但同一张表也给出一条**反方向**的账：**open 整条梯子都在单次重跑噪声以内**
（Δ/SD 仅 0.58 / 0.38），即交代一那句"open 没平"本身可能只是噪声 —— 换 SE 那把尺它又过（2.91 / 1.95），
**两把尺在此处结论相反**，故选哪把已列入 §7 待裁，本文不判定。
另：按**全部**已落盘 run（每格 60 条，goal.md 当年只用了约一半）重算，fixed 两跳为 **+0.345 → +0.037**、
open 为 **+0.111 → +0.078**，**梯子形状不变**。`goal.md` 未改动——哪一批算权威仍归 §6.4。

### 5.3 cns_01 是这条**读法**的第二次使用——但它不是一个三档实例

cns_01 的 basic 对地板差 +0.056、p=0.859 ⇒ 反读，得到的是同一形状的结论：
坎是 `clogp ≤ 3`，它要一个 Crippen 加和模型，**而现有那个 `assay()` 只诊断不修**。

**必须与 §1 第 6 条对齐，不许含混**：这里被复用的是"分差小 ⇒ 去找那条买不到的坎"这个**读法**；
被比的两端是 **basic 档对零工具地板**，**不是档对档**。
⇒ 它**不构成**裁定④的三档实例，**不得**写成"cns_01 三档差不多"。

### 5.4 读这条规则必须附一句限定：平在什么高度，意思相反

这一条是我从 owner 那句话推出来的，**不是 owner 的原话**，标为推断：

| 三档的形状 | 反读出什么 | 现成实例 |
|---|---|---|
| **三档都低且平** | 难——坎在工具买不到的地方，能指出是哪一条 | cns_01（卡 clogp，两侧 15% / 0%）。⚠️ 但那是 basic 对地板、不是档对档 |
| **三档都高且平** | 易——工具无所谓，这一关已经饱和 | **档级实例还没有**。只有轴级的类比：cns_01 的 mw 两侧都 100%；轴级饱和的处置沿用实验规范 §11.4 三分法（饱和关降为记录关、不计分） |

⇒ 报"三档差不多"时**必须连分数高度一起报**，只报差值会把这两种相反的情形写成同一句话。

### 5.5 与 ADR-0026 §5 不冲突（备查）

ADR-0026 §5 禁止的是把三档**说成**"三档难度的题目"（那等于承认我们也在测搜索能力）。
owner 这条裁定读的是"三档分数的形状 ⇒ **这道题**的难度"，主语是题、不是档。
⇒ 两条并存，§5 的对外表述规矩不变。

## §6 四件不由我定的事（待 owner 裁）

### 6.1 「差不多」怎么算——我不设阈值

按"执行方不定阈值"，我不给"差不多"划线。可选的两条路：

| 选项 | 做法 | 代价 |
|---|---|---|
| **A（我倾向）不设线，一律原样报** | 三档分数 + 逐跳 Δ + 精确检验 p + 达 0.8 功效所需每臂 run 数，四个数一起打印，让读者自己看 | "差不多"不是一个可自动触发的判定，得人读 |
| B 挂在跑间方差上 | ADR-0026 §9.2 已要求「Δ 须超过跑间方差」；把跑间方差实测出来当参照量 | 跑间方差本身还没实测（该 ADR 的待验证项 2 至今未清），且它也是一个会被当旋钮拧的量 |

### 6.2 cns_01 要不要补 some / enough 两档

补了才算真三档。按 ADR-0026 §3，这两档的工具**必须由实测失败模式导出**——
失败模式已经查清（只卡 clogp），所以候选工具很明确：**一个能算 clogp 的工具**。
**已知的坑**：qed_01 那次的结论正是"真正的坎是领域知识，任何供给它的工具都会泄答案"。
直接给一个 clogp 计算器，等于把那条唯一起作用的轴送掉，Δ 会很大但什么也没测出来。

三个选项，代价都写出来（**我不选，请 owner 定**）：

| 选项 | 做法 | 代价 |
|---|---|---|
| **甲 不补** | cns_01 就以「1 档 + 1 条地板」的形态留档，作为负结果案例 | 裁定④在这道题上永远没有档级实例；三档要另找题实例化 |
| **乙 补全量 clogp 工具** | some/enough 档给一个能算任意分子 clogp 的工具 | **等于把答案送掉**：那条轴从"要推理"变成"查一下"，Δ 大但不测量任何东西，重演 qed_01 的泄答案 |
| **丙 只给能力、不给答案** | 工具只对**题面已给的参考分子**返回 clogp（模型能从中学到 Crippen 加和怎么算），**对 agent 自己设计的新分子不返回** | 更接近"给知识而非给评分器"，但**这是我设计的、没实测过**：它究竟算 some 还是 enough、能不能真的把能力传过去，都得跑了才知道；且"哪些算参考分子"是一条新的、需要有人拍的边界 |

### 6.3 preflight 要不要加那句纯打印（上轮遗留）

在 preflight 里加印两个数：**这把尺子可达的取值个数** + **达 0.8 功效所需每臂 run 数**。
纯打印、不设门、不改判分。本轮的教训正是它能提前拦住："尺子只有 3 个取值、要 462 run"
这件事，是跑完 27 个 run 之后才算出来的——现有 preflight 只查量程、不查分辨率。

### 6.4 作废范式下的测量，还能不能当证据引用

**这条是写这份决议时新暴露出来的，之前没人问过。** 08-28 作废了"藏答案"判分范式，
但那批数据没有被删——qed_01 六格 360 个 run 目录都还在，本文 §5.2 就引了它的 Δ。
我在 §5.2 划了一条界（**读法可转移、数值不可当新范式的验证**），但**那是我划的，不是裁定**。
需要 owner 定的是：**作废一个范式，是否连同作废它下面所有测量的证据资格？**
若是，本文 §5.2 与 §1 第 5 条都得删；若否，引用边界写在哪一份文档里。
