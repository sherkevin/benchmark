## §0 一句话总账

## §4 资产④ 实测结论：花机时买的，不可再生

这一节是家底里**最贵**的部分——每条都由真 run 或全量离线穷举钉住，换题依然成立。

| 结论 | 证据 |
|---|---|
| **"问规律"型检查点在构造上不可考**：可背（真实规律）或彩票（自编规律），无第三种 | `cp_layer` 裸答 0.952；`cp_rule` 撞见→答对 143/145=98.6%。两条用相反理由分别判死，其实是同一种关 |
| **裸答能反超真跑**：给了数据反而更差 | layer_01 裸答 0.952 vs 123 run 实跑 0.602 |
| **常数答案基线打不下去，补数据也不行** | "恒答 Cu=3" 白拿 0.867（13/15 峰在 Cu=3）；Stanev 16,414 条只 +1 个垃圾体系，基线 0.867→0.812；样本门槛放宽到 1，Cu=3 仍占 30/48 |
| **采样型任务单 run 方差是固有属性** | triage_01 组内 SD **0.151** > 模型间 SD **0.086**；多 run 聚合是假解（k=1~20 差值恒在 +0.087~+0.111）；调预算/池大小两端互斥 |
| **判分公式零超参 ≠ 判据零超参** | sarflip_01 判分器零常数、闸6 三条全过，判据仍塌缩成 `logS_pred ≥ −3.83`，免能力天花板 **21.89%**（判死线 5% 的 4 倍） |
| **单关形态是全库历史最好** | 删 `rule` 字段后 8 行存活且读数一致：捷径天花板 **0.000**、差距 **1.000**（旧两关是 0.500/0.500） |
| **m 道关时 `max(总分)` 在 `1/m` 饱和** ⇒ 一道关的题不存在"运气买一半分"的盲区 | 由此判死⑧ 不需要复活 |
| **厂商-定位身份先验被否证**；首份可用先验是 refbench BFCL 三档分层 | 671B(标强)垫底、qwen3.5-plus(标弱)并列第一 |
| **三题唯一与独立能力排序显著对齐的检查点是零超参的那个** | `cp_layer` rho=+0.812 p=0.050；失效的全挂 tol/scale/权重 |
| **零工具门失效是系统性的** | 回填 7 道跑过的题，**无一当初该开批**；4/7 没有挂在账本上的门，纯背答案者 `total=1.000` |
| **合成裸答基线本身就是旋钮** | 给 dopant_01 合成的先验把 `cp2_numeric` 打到 0.825，真跑实测最高只 0.436 ⇒ 裸答只认逐条落盘答卷重判 |
| **全库作废原因分布** | 55% 调参 / 24% 代码 bug / 11% 真值设计缺陷（`sweep_ws.py:17-22`）；预算扫描那 799 个作废 run，用 3 run 探方向只需 ~80 个 |
| **三档工具可作判别轴，但 basic 档头部已饱和** | A-Edit basic 裸答 qwen/glm 满分、deepseek 93% ⇒ 只认闭卷等于永远开不了批 |
| **agent 会猜错自己的 cwd** | sarflip 首批协议失败根因，读不到 TASK.md（已修，`ws_runner` 里写死绝对路径） |
| **模型用逐基团排除法，会系统性欠采样多基团分子（4 倍）** | 读 4 条真 trace 得出 |
