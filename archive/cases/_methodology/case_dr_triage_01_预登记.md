## 四、可否证的方向预测（P1–P5）

| # | 预测 | 否证条件 |
|---|---|---|
| **P1** | **精确率恒 1.0 而召回明显低于它**（模型不乱报、瓶颈在预算分配） | 若出现召回 ≥ 精确的 run，或精确率出现 <1.0 的多数，P1 被否 |
| **P2** | 总分（= 召回）**不饱和不地板**：强档均值落在 **0.25–0.75** | 落到 >0.85（饱和）或 <0.10（地板）即否。（v1 的 0.45–0.85 是含精确率那 0.4 的口径，R1 已按纯召回重设） |
| **P3** | **强档显著高于弱档**（判据⑥ 区分度成立），差 ≥ +0.10 且置换 p<0.05 | 差 <0.10 或不显著即否 |
| **P4** | 实际测量次数中位 **= 8**（用满预算） | 中位 <6 说明模型不肯花预算，P4 被否（则区分度来自别处，须重新归因） |
| **P5** | 所有 run 的 `_unmeasured_claims` **= 0**（没人报没测过的分子） | 出现 >0 说明存在猜答行为，须在报告里单列 |

## 六、检验方案（事先定好，防事后挑口径）

- 主指标：`total` 的强档 vs 弱档差，**置换检验**（10,000 次重排），报 p 值。
- 逐检查点：`cp_recall` / `cp_precision` 分别报，不只报总分（`§11.2`）。
- 噪声门：均值差必须大于组内离散度，否则不声称差异（`goal.md §7.5`）。
- 每格必报：n、均值、离散度、剔除数与剔除原因。
