## 下一步：pivot 到 dopant_01（第一组真正的种子）

dopant 外推题**天生符合新原则**：真实元素（Er/Nd/Gd/Pr），要预测一条**没被合成过的 Gd 曲线**——材料直觉用得上，但具体 11 点曲线背不出来。它的问题不是污染，是**判分噪声**（cp3/cp4 二值抛硬币）。

### 进展（2026-08-14 晚）
1. ✅ **dopant "答案不可背" 已验**：裸答基线（gpt-4.1/qwen-plus/deepseek，无工具无边界）cp2 数值最高仅 0.436、多数 ~0.10 → Gd 曲线背不出，必须实测外推。（记 README）
2. ✅ **with-tools 4×5 已跑并诊断**：with-tools 0.50–0.64 > 裸答（✓工具加值）；但未过信号门。零成本再判（去cp4/只看cp2）证实：**模型间极差始终 0.12–0.15、被轮间波动 0.33–0.54 淹没** → 根因是模型池（四同档强模型太接近）、非 judge。

### d3 已跑完：加弱模型仍不分（重要反面发现）
已建 OpenAI 端点 harness（`openai_dopant_runner.py` + `sweep_openai_dopant.py`），接入弱模型 qwen-turbo 跑 3模型×5轮：
- turbo 0.503 / coder 0.436 / max 0.542（max 仅1轮、其余 OpenAI 端点生成超时），极差 0.106、**turbo>coder 反序**。
- 所有模型 cp1=6/9、cp2~0.45。**根因比模型池更深**：“测两条边界再插值”弱模型也会，任务对全池一样难→无梯度。

### 两条线索汇总（重要）
explore：能分，但区分来自**记忆**（不合法，已退役）。dopant：**无记忆但也无梯度**（核心动作全池都会）。两条路从不同方向撞到同一堵墙：**要同时满足“答案不可背 + 核心动作在池内真有强弱之分”，很难。**

### owner 定向=改判过程（2026-08-14）；但 trace 证据显示 dopant 过程也平
为设计过程检查点，先扈了 15 个 run 的 tool_calls：**所有能跑通的 run（turbo×5、coder r4/r5、max r1）都是“测满 19 个 Er/Nd 边界点 → 提交”，一模一样**；唯一过程差异是失败模式（coder r1 没测就瀞交、max r2-r5 超时未交）——那是可靠性噪声、非能力梯度。**→ 判过程原则对，但 dopant 太浅（一步：测边界→插值），承载不了。**

**结论：把“判过程”用到深任务 chain 上**（A找峰→B派生阈值→C外推→D终选，多步依赖，弱模型在编排上会崩）。这才是 owner #1（判过程）+ 深任务的正解。

### 原三候选（供参考）
1. **改判过程而非终值**：dopant 无梯度是因为只判终值精度；改成判过程（是否测全 Er/Nd 边界、顺序、不去测不可测的 Gd）——回到 goal.md “评过程”本意，弱强模型在过程上可能真有差。
2. **换一个核心动作真有强弱之分的任务**：如多步依赖链（chain_01）——弱模型在多步编排上坐崩。
3. **拉宽模型池能力跨度**：当前 turbo/coder/max 在材料任务上本就接近；需更弱的模型或更难的任务。
