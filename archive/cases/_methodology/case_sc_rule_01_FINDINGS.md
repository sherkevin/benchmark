# case_sc_rule_01 · 规则归纳 case 调查（突破 + 一个基础设施阻塞）

## 突破：规则归纳是第一个能把分数压到 0.9 以下的题型
给训练样本让 agent **归纳隐含高 Tc 规律**、再对隐藏真值的新材料分类。数据里有真正反直觉的多因子交互：

- 单因子"含 Hg→高"只有 49%；但 **Hg+5 元素→92% 高**、**Hg+4 元素→仅 32% 高**
- **Bi+5 元素→仅 17% 高**（"5 元素→高"也错）
- **含 La→0% 高**（强否决）
- 甚至 Hg+4 元素内部还有 dome（O4.08~4.16 少数为高）→ 无任何简单规则能 100%

单因子启发式在测试集上只有 55~64% 准，逼模型抓交互，天然把上限压到满分以下。

## 实测（train 9 / test 7，纯推理、数据全在 prompt、无 get_property 杜绝测量泄漏）
| 模型 | 准确率 | correct |
|---|---|---|
| qwen-turbo | 0.714 | 5/7 |
| gpt-4.1 | 0.571 | 4/7 |
| qwen-plus | 0.286 | 2/7 |
| qwen3.7-max / glm-5.2 / kimi-k3 | **无法完成** | 504 网关超时 |

- 完成的 3 个模型：分布 min 0.286 / max 0.714 / **极差 0.428**（标准1 ✓），且**全部 <0.9**（含强模型 gpt-4.1 0.571）——**目标"强模型不满分"首次达成**。

## 阻塞：3 个重推理模型在单次开放式归纳上必 504
qwen3.7-max / glm-5.2 / kimi-k3 会吐海量思维链，超过 idealab 网关墙钟限制：
- 普通 chat（300s / 600s）：504 Gateway Time-out
- max_tokens=2000：qwen3.7 仍 504；glm/kimi 把 token 全耗在推理、没吐 JSON（parsed=0）
- 强制 tool_choice：qwen3.7/kimi 报 400，glm 空

对比：**同 3 个模型在链式 tool-calling 任务里完全正常**（各做 40~55 轮，每轮只出个短 tool_call）。
→ 差别在"单次长响应" vs "多轮短响应"。

## 下一步（未试的杠杆）
把规则归纳改成**多轮 tool-calling**：每轮只分类 1 个测试项 / 或先出规则再逐项判，
每轮响应短 → 绕开单次长响应的 504。这是让那 3 个模型也能测完的最可能路径。

## 结论
规则归纳这条路**方向正确**（完成的模型全部 <0.9、有梯度），只差一个 harness 形态改造
（多轮短响应）来把 3 个重推理模型纳入测量。这是把 case 做合格的明确下一步。
