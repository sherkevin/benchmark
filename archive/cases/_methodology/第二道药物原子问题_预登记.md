> **一句话：给一个亲脂过高的先导物和 23 个单点改造候选，agent 要在预算内挑出真正提升成药性的改造——而"加极性基团改善成药性"这条教科书直觉在这道题上会全军覆没（8 个极性改造无一达标），真正有效的是缩短烷基链。**
> 登记日期 2026-08-21。跑批前登记，遵实验规范 §8 / §11.4 / §6.0。

## 一、母体与它的毛病

母体 = 联苯酰胺 + C8 正烷基链：`c1ccc(cc1)-c1ccc(cc1)C(=O)NCCCCCCCC`

| QED | MW | ALOGP | PSA | ROTB | ALERTS |
|---|---|---|---|---|---|
| 0.6136 | 309.5 | **5.44** | 29.1 | **9** | 1 |

毛病很明确：**亲脂性过高（ALOGP 5.44）、分子量偏大、柔性过大（9 个可旋转键）**，
而极性表面积并不低（29.1 已在合理区）。所以正确的改造方向是**减小体积与亲脂性**，
不是继续往上加极性基团。

## 二、23 个候选改造，以及那个陷阱

| 改造类 | 数量 | 最高 QED | 达标(≥0.80)数 |
|---|---|---|---|
| **A 改链长**（C1–C10） | 10 | **0.8690**（C3） | **4** |
| B 链上加极性（OH/COOH/NH₂/NMe₂/醚/酰胺） | 6 | 0.7016 | **0** |
| C 环上取代（OH/F/Cl/OMe/NO₂/换吡啶） | 6 | 0.6734 | **0** |
| D 去掉一个苯环 | 1 | 0.6802 | **0** |

关键数字（相对母体 0.6136 的变化）：

| 改造 | QED | Δ |
|---|---|---|
| 链长 C3 | **0.8690** | +0.2554 |
| 链长 C2 | 0.8540 | +0.2404 |
| 链长 C1 | 0.8126 | +0.1990 |
| 链长 C4 | 0.8048 | +0.1912 |
| 链中插醚 O | 0.7016 | +0.0880 |
| 链末加 OH | 0.6355 | +0.0219 |
| 环上加 NH₂ | 0.5021 | −0.1115 |
| 环上加 NO₂ | 0.3549 | −0.2587 |

**陷阱成立**：往分子上加极性基团（B 类）确实降了 ALOGP，但同时抬高 MW、ROTB、
有时还引入结构警报，QED 净增很小甚至为负。**照教科书直觉做的 agent 一个都拿不到达标改造。**

**前四名差距很小**（0.8690 / 0.8540 / 0.8126 / 0.8048），所以"谁最高"**靠免费描述符猜不准，
必须实测**。

## 三、任务与 answer.json 契约

沿用已定稿的交付方式（规范 §6.0）：`answer.json` 由 runner **预放进 workspace**、
字段齐全值留空，模型只填值；判分只按 key 取值。

```json
{
  "best_edit_id": null,          // 池内 QED 最高的改造
  "best_qed_measured": null,     // 你为它实测到的 QED
  "pick_edit_id": null,          // 满足三条约束的改造（中间值那关判它）
  "failed_direction": null       // 你实测确认"无效"的改造方向（诊断用，记录关）
}
```

## 四、三条约束（中间值那关），以及为什么实测不可绕过

query 要求 `pick_edit_id` 同时满足：

| 条件 | 判据 | 需账本证据 |
|---|---|---|
| c1 实测 QED ≥ **0.80** | 查真值 | **是**（依赖工具确认，猜对不给分） |
| c2 `psa` ≤ **40** | 池内免费描述符 | 否 |
| c3 `rotb` ≤ **9** | 池内免费描述符 | 否 |

**关键校验（这是第一道题踩过的坑，必须先算清）**：两条免费条件**过关 12 个**，
其中真正达标的只有 **4 个**（C1–C4），**另 8 个必须实测才能排除**
（chain_C5–C8、drop_ring、mid_ether、ring_Cl、ring_F）。
⇒ 免费条件只做粗筛、不代替实测，QED 门承担真正的筛选工作。
（第一版把 rotb 卡到 ≤5，免费条件直接筛出 4 个合法解、实测变成白设，已弃。）

合法解 4 个（不脆）：`chain_C1` `chain_C2` `chain_C3` `chain_C4`。

## 五、判分（按 §11.4 三分法预先声明归属）

    total = 0.6*cp_best + 0.4*cp_conditions

| 关 | 判什么 | 形式 | 归属 | 零工具基线 |
|---|---|---|---|---|
| `cp_best` | 报的最高改造：拿它的真值 QED 与真最大值比（柯西平滑，**不做二值判 id**） | 柯西 | 计分 0.6 | 待实测，预期低 |
| `cp_conditions` | `pick_edit_id` 逐条对照三约束：免费硬条件违反即 0，两条都过 0.5，再满足实测门 1.0 | 两段式 | 计分 0.4 | **预期 0.5** |
| `cp_best_value` | `best_qed_measured` 与真值一致性 | 柯西 | **待定**：若与 cp_best 重复计分则降记录关 | ≈0 |
| `failed_direction` | 是否识别出"加极性无效"这个方向 | 命中判定 | **记录关**（不计分） | 可能免费 |
| grounding | 无成功实测 ⇒ 总分归零 | 门 | 门 | — |

`cp_best` 用"报的那个的真值 QED vs 真最大值"而非"id 对不对"，是为避免二值门
（规范 §6.2 禁 0/1 关卡）：报 C2（0.8540）比报 ring_NO2（0.3549）明显更接近，应当有分差。

## 六、预算

**8 次**（候选 23 个）。理由：看懂"该缩短链"的 agent 只需测 C1–C5 附近 4–5 个点就能定最高；
盲目遍历 23 个候选必然预算耗尽。预算数由题目结构定，非试出来的。

## 七、跑批前要核的四条可否证预测

| # | 预测 | 否证后怎么处置 |
|---|---|---|
| P1 | 两侧交卷、零 tool_leak、零格式类失败（预放模板已生效） | 修工程，不动题目参数 |
| P2 | `cp_conditions` 零工具基线 = 0.5（免费两条过、实测门不给） | 若为 1.0 说明条件又白设，回到 §四重调阈值 |
| P3 | 至少有 run 落入"教科书陷阱"（挑了 B/C 类改造）⇒ cp_conditions = 0 | 若无一落入，说明陷阱太明显、判别力不足 |
| P4 | `cp_best` 非恒定（不同模型报不同改造） | 若全场同值，说明"谁最高"其实免费，需收紧免费描述符 |

**不预测分数**（n 小不构成证据，不得据冒烟调容差或给分公式）。
