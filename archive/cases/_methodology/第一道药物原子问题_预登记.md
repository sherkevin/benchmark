# 第一道药物原子问题：预登记

> **一句话：药物领域 × 趋势外推，考"先认出目标属于哪个同系列，再在该系列内把趋势拟对"。真值由 rdkit 确定性算出，不是编的，也不是教科书能默算的。**
> 登记日期 2026-08-20。跑批前登记，遵 实验规范 §11.3。

## 速读区

| 项 | 结论 |
|---|---|
| 领域 / 类型 | 药物 / 趋势外推（对应 agent_action 全量枚举 #12 的药物版） |
| 主判别性质 | **QED**（成药性综合评分，0–1） |
| 真值来源 | rdkit 2026.03.5 `QED.qed()`，确定性可复现 |
| 母题一句话 | 池子里有 4 个同系列（不同骨架类），目标分子的 QED 测不到，必须从**同系列**可测成员的趋势外推 |
| 判别力（实测，落地后跑 judge） | 认对系列+二次拟合 **0.937**；线性 0.355；抄最近邻 0.333；过拟合 0.300；认错系列 0.320–0.344；空账本 **0.000** |
| 为什么不可背 | 目标分子是枚举生成的同系物，QED 值不在任何训练语料里；QED 是 8 个描述符的加权 ADS 函数，人和模型都不能默算 |

## 一、为什么走这条路：原方案被数据否掉了

owner 原本的设想是"药物性质天然正交，可多角度验证"（qed 主判别，logs 因是教科书公式而排除）。我把 backend 真实翻了一遍，**这个设想在现有数据上做不出来**：

`dag_poc/data/backend/get_property/get_property_A.jsonl` 共 240467 条，long-format 三元组 `{entity_id, prop, value}`，12 种 prop：

| prop | 条数 | 备注 |
|---|---|---|
| element_count | 92153 | 材料侧 |
| atom_count | 74901 | 材料侧 |
| tc / family / structure_in_db / condition | 各 17252 | 材料侧 |
| logS | 2272 | 药物侧 |
| bbb | 730 | 药物侧，二值 |
| logD | 582 | 药物侧 |
| half_life | 503 | 药物侧 |
| caco2 | 220 | 药物侧 |
| herg | 98 | 药物侧，二值 |

三个硬事实：

1. **qed / tpsa / mw / logp / hbd / hba / rotatable_bonds 在库里根本不存在**。owner 点名要的主判别性质无数据。
2. **药物侧太薄，撑不起多角度**。3378 个实体带至少一个 ADMET 性质，但带 ≥3 个的只有 245 个，带 ≥4 个的只有 99 个。多角度验证需要同一分子上多个正交性质同时有值，样本量不够。
3. **结构被 mask，算不出描述符**。`get_entity_A.jsonl` 只给 `formula` + `masked_structure`（形如 `FORMULA:C3F3N3;ATOMS:9`）+ `inchikey`。InChIKey 是单向哈希，反不出结构，所以无法用 rdkit 补算描述符。

而唯一算得出的强相关，恰好是 owner 要排除的那个：

```
logS vs logD       n=163  r=-0.556      ← 脂溶性-溶解度，教科书关系
logS vs half_life  n=144  r=-0.063
logS vs caco2      n= 91  r=-0.101
logD vs half_life  n=143  r=+0.011
logD vs caco2      n= 52  r=+0.154
half_life vs caco2 n= 69  r=+0.099
```

除 logS~logD 外全是噪声（|r|<0.16）。**在原库上做药物趋势外推，要么用教科书关系，要么用噪声。两条都不能要。**

`dag_poc/data/mock_db.json` 里有 40 条真 SMILES，但它自己标着"mock 数据库（手工逐条构造）"，40 条也撑不起系列外推。

## 二、解法：rdkit 当真值 oracle，同系物枚举当数据层

既然库里没有 qed，就自己造一个**确定性可复现**的数据层：枚举同系物 SMILES，用 rdkit 算 QED 和描述符。

这仍然满足 owner 的设计原则"可推关系需数据真实存在但非教科书公式"：

- **数据真实存在**：QED 由标准化学信息学库确定性算出，同一 SMILES 任何机器上算出同一个值，可第三方复核。不是我编的数。
- **非教科书公式**：QED 是 8 个描述符（MW / ALOGP / HBA / HBD / PSA / ROTB / AROM / ALERTS）各过一条非对称 sigmoid 期望函数后取几何加权平均。模型背不下来，也算不出来，只能从测到的点上归纳。

## 三、母题设计

### 3.1 候选池：4 个骨架类 × 各若干链长

四个系列共用"苯环 + 酰胺 + N-正烷基链"母版，只换骨架类，链长 n 为系列内变量：

| 系列 | SMILES 模板（n = 烷基碳数） | 骨架特征 |
|---|---|---|
| A | `COc1ccc(cc1)C(=O)N` + `C`×n | 甲氧基苯甲酰胺，干净骨架 |
| B | `O=[N+]([O-])c1ccc(cc1)C(=O)N` + `C`×n | 带硝基，触发结构警报 |
| C | `OCC(O)C(O)C(O)C(=O)N` + `C`×n | 多羟基，无芳环，强极性 |
| D | `c1ccc(cc1)-c1ccc(cc1)C(=O)N` + `C`×n | 联苯，大体积强亲脂 |

四条系列的 QED 走势**形状和水平都不同**（实测，n=2/5/8/11）：

| n | A | B | C | D |
|---|---|---|---|---|
| 2 | 0.7621 | 0.5826 | 0.3237 | 0.8540 |
| 5 | 0.7498 | 0.4683 | 0.3244 | 0.7778 |
| 8 | 0.6884 | 0.4252 | 0.3282 | 0.6136 |
| 11 | 0.5545 | 0.3396 | 0.3029 | 0.4280 |

A/B/D 是"先升后降"（A 峰在 n=3），C 几乎平（0.30–0.33 全程）。**没有统一形状，必须在正确系列内实测才能拟对。**

上表 n=11 一行只是展示四条系列**各自的形状**。实际池子里 B/C/D 只到 n=10；
n=11 只有目标系列 A 的那一个分子，而它恰恰是不可测的目标。

### 3.2 目标、候选池的不对称、工具分档

- **目标分子**：A 系列 n=11，真值 QED = **0.5545**（池内 id `m05`）。
- 该分子的 QED **测不到**（工具返回 `probe_unavailable`），与 dopant 母题同架构。
- **候选池故意不对称**（33 个分子）：

  | | 池内链长 | 数量 |
  |---|---|---|
  | 目标系列 A | 只有短链 **n=2..6** | 5 个可测 + 目标 n=11 |
  | 干扰系列 B/C/D | 做全了 **n=2..10** | 各 9 个可测 |

  **这个不对称是判别力的来源**。第一版让 A 也给到 n=10，结果目标 n=11 只差一格，
  两点线性外推就拿 0.970 分、二次拟合 0.967——系列内推理质量完全没有梯度，
  等于白送。改成只给短链后须外推 5 格，梯度才出来（见 3.4）。

- basic 档工具（fixed 侧**只有一个**）：
  - `measure_qed(mol_id)` — 测 QED，受预算 8 限制，目标分子返回 probe_unavailable。
  - 五个免费描述符（mw / alogp / psa / rotb / arom）**直接随候选池写在题面
    `data/pool.tsv` 里**，不单独设 `get_descriptors` 工具——描述符是"catalogue 附带的
    便宜数据"，做成工具反而多一层无考点的调用。**故意不给 hba / hbd / alerts**
    （QED 要 8 个，只给 5 个），防止描述符全给退化成机械回归。
  - open 侧多一个 `search_pool(query, page)`：分页 4 个/页、**每页扣 1 预算**、
    与 measure_qed 共用预算 8（方案 Y，不做翻页补偿，否则两侧难度不可比）。
- 便捷工具（some/enough 档）按 ADR-0026 §3，**由 basic 档实测失败模式导出，此刻不预设**。

### 3.3 为什么这道题考的是科学推理不是曲线拟合

agent 必须依次做对三件事，错一件就掉分：

1. **认系列**：从 SMILES 看出池子分四类骨架、目标属 A 类（psa / arom / alogp 也能辅证）。
2. **花预算测对系列**：预算 8，测错系列等于白花。
3. **在系列内归纳并外推**：A 系列有峰（n=3）、后段加速下降，且**目标落在测量范围之外
   5 格**——抄最近邻、两点线性都不够，三次过拟合更会飞掉。

open 侧还多一层：**33 个分子盲目翻页要 9 页、预算必然耗尽**（实测第 9 页耗尽、
一次测量都做不了）；用目标骨架子串 `COc1ccc(cc1)` 去搜只命中 6 个 = 2 页，
剩 6 次足够测完 5 个同系物（实测正好找齐、用掉 7/8）。**会用结构去搜的做得成、
盲目翻页的做不成**——这是判据④"发现有后果"的落点。

### 3.4 对抗基线实测分（跑落地后的 judge，尺度由真值导出 = **0.041**）

尺度不是拍的：`QED_SCALE` = 跨系列同链长平均 QED 差距 / 2，再经 `scale_from_tol`
换成柯西"0.5 分点"口径——推导同 dopant 的 `TC_SCALE`。

| 基线 | 预测值 | total | cp_qed | cp_series |
|---|---|---|---|---|
| 完美（golden） | 0.5545 | **1.000** | 1.000 | 1.000 |
| 认对系列 + 二次拟合外推（正解） | 0.5416 | **0.937** | 0.910 | 1.000 |
| 认对系列 + 线性拟合 | 0.6950 | 0.355 | 0.078 | 1.000 |
| 认对系列 + 两点线性 | 0.6772 | 0.370 | 0.100 | 1.000 |
| 认对系列 + 抄最近邻 n=6 | 0.7377 | 0.333 | 0.048 | 1.000 |
| 认对系列 + 三次过拟合 | 2.1323 | 0.300 | 0.001 | 1.000 |
| 认错系列 B（硝基）拟合外推 | 0.3772 | 0.336 | 0.051 | 1.000 |
| 认错系列 D（联苯） | 0.3956 | 0.344 | 0.062 | 1.000 |
| 认错系列 C（多羟基） | 0.3138 | 0.320 | 0.028 | 1.000 |
| QED 硬填上限 1.0 | 1.0000 | 0.306 | 0.008 | 1.000 |
| 填池中位数 | 0.4776 | 0.455 | 0.221 | 1.000 |
| 撒网：全池都报成同系列 | 0.5545 | 0.781 | 1.000 | 0.270 |
| 只报 1 个同系列 | 0.5545 | 0.800 | 1.000 | 0.333 |
| **空账本 + 满分答案（G1）** | 0.5545 | **0.000** | — | — |

三条结论：

1. **主判别有梯度**：正解 0.910，线性 0.078–0.100，抄最近邻 0.048，过拟合 0.001。
   只有"认对系列 + 拟对曲率"才拿得到高分。
2. **认错系列被罚到底**：cp_qed 0.028–0.062，与抄最近邻同档。
3. **grounding 生效**：一次成功 measure_qed 都没有就交满分答案 → **总分 0**
   （补 satisfy_02 审计里的 G1 漏洞）。撒网报全池 → cp_series 掉到 0.270（补 G3 无精度罚）。

注：所有"方法错"的基线都有 0.30 的地板，因为 cp_series 权重 0.3 且它们系列认对了。
这是加权设计的必然，与正解 0.937 仍拉开 0.57–0.64。

## 五、结论

数据把原方案否了：库里没有 qed，药物侧多角度样本不够，结构 mask 掉算不出描述符，
唯一强相关是教科书关系。改用 rdkit 当确定性 oracle + 同系物枚举当数据层，既保住
"数据真实存在、非教科书公式"，又实测出干净的判别力梯度。

落地中还自己抓到并修掉一个会让整道题白送的设计缺陷：**目标离测量范围只差一格时，
两点线性外推就能拿 0.97 分**——把目标系列稀疏化成只给短链后，正解 0.937 与线性
0.355 / 抄最近邻 0.333 才真正分开。四件套与三道闸门都过了，下一步按规范跑 `--probe`
冒烟核对上面四条预测。

### 6.1 关键数据证据：一个 psa 门就能堵死"靠常识猜"

池内 QED 最高的三个分子**全是联苯系列**（m11 0.869 / m13 0.854 / m04 0.805）。
任何模型看免费描述符都会往那儿猜——两个芳环、psa 只有 29.1、最"像药"。
**但一旦 query 要求 `psa ≥ 40`，联苯全军覆没。**

`psa ≥ 40` 的可测分子有 18 个（硝基 psa=72.24 九个、多羟基 psa=110.02 九个），
其中过 `QED ≥ 0.60` 的**只有 1 个**：

| 系列 | psa | 各链长 QED |
|---|---|---|
| 硝基苯甲酰胺 | 72.24 | n2 **0.5826** / n3 **0.6046** / n4 0.4709 / n5 0.4683 / … / n10 0.3724 |
| 多羟基酰胺 | 110.02 | 全程 0.315–0.333，无一过门 |

唯一解 **m02**（硝基，n=3，QED=0.6046）。它只比门槛高 **0.0046**——这个余量猜不出来，
只能测。而"峰在 n=3"这条规律 agent 做外推时会在自己系列上先学到，再迁到硝基系列
——这正是枚举表 **#28 类比迁移**，不是撞运气。

### 6.2 v2 的 query 与 answer.json 契约

题面给三个小要求，由**同一个分子**联合满足，外加一个外推量。**判分只读 key，不读文字**
（规范 §6.0 规则二）：

```json
{
  "target_qed": <number>,
  "lead_mol_id": "<mol_id>",
  "lead_qed_measured": <number>,
  "congener_ids": ["<mol_id>", "..."]
}
```

| key | 对应 query 里哪条要求 |
|---|---|
| `target_qed` | 预测目标分子 `m05` 的 QED（它测不到，须从同系列外推） |
| `lead_mol_id` | 挑一个备选先导化合物，须**同时**满足：实测 QED ≥ 0.60、psa ≥ 40、不属于 `m05` 所在系列 |
| `lead_qed_measured` | 你为上一条实测到的 QED 数值 |
| `congener_ids` | 你用来外推的同系列成员 |

### 6.3 新增规则：需工具确认的条件，必须有账本证据才算满足

**这是对 owner 第 3 点的直接回应。** 光"对照检查"不够——猜对的人也能拿满分。
所以中间值逐条判定时，**凡是依赖工具才能确认的条件（此处 c1 的 QED 门），
账本里必须有对该分子的成功 `measure_qed` 记录，否则该条判不满足**。

零工具基线因此被压住（这是 §11.4 要求的实测，不是估计）：

| 条件 | 零工具能不能满足 |
|---|---|
| c1 实测 QED ≥ 0.60 | ✗ 没有账本证据 ⇒ 判不满足 |
| c2 psa ≥ 40 | ✓ 描述符表里免费 |
| c3 不属于目标系列 | ✓ 看 SMILES 免费 |

⇒ 零工具基线 `cp_conditions = 2/3 = 0.667 < 0.9`，通过 §11.4 的计分门槛。
`lead_qed_measured` 那一关零工具基线拿不出 0.6046，也过。

### 6.4 四个关的归属与权重

| 关 | 判什么 | 权重 | 零工具基线 |
|---|---|---|---|
| `cp_extrap` | `target_qed` 精度（主判别，柯西） | 0.5 | ≈0 ✓ |
| `cp_conditions` | 挑出的分子逐条对照三条件，满足数/3（**中间值**） | 0.3 | 0.667 ✓ |
| `cp_lead_value` | `lead_qed_measured` 与该分子真值的精度（堵背答案） | 0.2 | ≈0 ✓ |
| `cp_congeners` | 同系列成员 F1 | 记录关 | 1.0（已按 §11.4 降级） |

### 6.5 代价

改题面属于"必须重跑"（规范 §11.4 成本分级）：**6 个冒烟 run 作废**（本就是冒烟）。
预算从 8 提到 **12**（自己系列 5 个 + 跨系列探 3–5 次），因为 v2 多了一个需要
跨系列测量的目标。真值文件需新增 `lead_conditions` 段（阈值、psa 门、合法解集合）。

## 七、some 档预登记（2026-08-21，按 ADR-0026 §3 由 basic 实测失败模式导出）

### 7.1 先摆失败模式（阶段二产出，不是设计时拍的）

fixed·basic 三批共 **76 个入分布 run** 的实测归因：

| 子任务 | 失败模式 | 占比 |
|---|---|---|
| 外推 | **低估下降速度、外推偏高** | **58 / 76 = 76%** |
| 外推 | 拟合正确 | 16 / 76 = 21% |
| 选型 | 违反免费硬条件（没核对 psa / rotb 就选） | 16 / 76 = 21% |
| 选型 | 选了但没实测验证 | 6 / 76 = 8% |

测量次数中位数 12、**65/76 用满预算** ⇒ 预算是紧的，但瓶颈不在预算（basic 冒烟已确认）。

### 7.2 据此配的两个便捷工具（每个对应一个实测失败模式）

| 工具 | 打的失败模式 | 替代了什么推理 |
|---|---|---|
| `fit_trend(xs, ys, x_query, degree=2)` | 外推偏高 **76%** | "把测到的点归纳成趋势、再外推到测量范围之外"——basic 档下四分之三的模型在这一步用了直线 |
| `screen_candidates()` | 违反免费硬条件 **21%** | "逐条核对 psa / rotb 两个免费门槛"——纯簿记，返回满足两条免费硬条件的 mol_id 列表 |

**两个工具都不发放 QED**：`screen_candidates` 只用免费描述符筛，QED 门仍必须靠
`measure_qed` 实测确认（grounding 与账本证据规则不变）。`fit_trend` 只做数值拟合，
**喂哪些点仍由 agent 决定**——喂错系列就得到错误答案，系列辨识仍是 agent 的活。

### 7.3 严格守"同题同真值同判据"

| 项 | some 档 |
|---|---|
| 题面 query / 目标 / 三条约束 | **与 basic 完全相同** |
| `ground_truth.json` | **同一份**（open 侧仅 `measurement_budget` 因枚举成本不同） |
| 判分器 | **转发 basic 档 fixed 的 `judge.py`**，一行判分逻辑都不新写 |
| 预算 | **与 basic 相同**（fixed 12 / open 17）——变量只能是工具供给，加预算会混淆归因 |
| 唯一变化 | 工具集：basic 的基础上 **+2 个便捷工具** |

### 7.4 要算的量

    Δ_tool = S(某模型, some 档) − S(同模型, basic 档)

- Δ 大 ⇒ 该推理步骤是真瓶颈，工具替代掉了它；
- Δ ≈ 0 ⇒ 这个便捷工具打在了模型本来就不出错的环节（ADR-0026 §3 警告的"白跑一档"）。

### 7.5 三条可否证预测

| # | 预测 | 否证后怎么处置 |
|---|---|---|
| S1 | `fit_trend` 使 `cp_extrap` 明显抬升（basic 侧 76% 偏高的那批应大幅改善） | Δ≈0 则说明模型不会用工具、或瓶颈不在拟合，需看账本里工具调用率再判 |
| S2 | `cp_conditions` 的"违反免费硬条件"比例下降（21% → 显著更低） | 若不降，说明失败不是簿记疏忽而是没读懂约束 |
| S3 | 工具**被真实调用**（账本里有 fit_trend / screen_candidates 记录） | 若调用率极低，Δ 无意义，须先查题面是否讲清工具用途 |

**不预测分数绝对值。** 判据、容差、给分公式一律不动（参数冻结承诺继续有效）。

## 八、enough 档预登记（2026-08-21，由 some 档剩余失败模式导出）

### 8.1 some 档之后剩下什么失败（阶段二再做一次）

some 档两侧合计 **57 个入分布 run**，`cp_extrap` 呈**双峰**：37 个 >0.9、19 个 <0.3、
中间只有 1 个。逐个查这 19 个低分 run：

| 核查项 | 结果 |
|---|---|
| 喂给 `fit_trend` 的点来自哪个系列 | **19/19 全部喂对了同系列**（不是选错数据） |
| 喂的点数 | 4–5 个（够拟合） |
| 拟合阶数 | degree 1/2/3 都有（不是单纯的阶数问题） |
| **查询的链长 `x_query`** | **12 用了 12 次、13 用了 6 次、11 只有 1 次** |

对照高分组：**35/38 查询的是 11**。目标分子 `m05` 的真实链长就是 **11**
（`COc1ccc(cc1)C(=O)NCCCCCCCCCCC`，N 之后 11 个 C）。

⇒ **some 档的主要剩余失败不是推理错，是把 SMILES 里的碳数数错了。**
这正好回答 ADR-0025 §9 登记的那个未验证前提——**模型的结构读写能力确实构成瓶颈**，
而且在算术被工具接管之后，它成了首要瓶颈。

### 8.2 据此配的便捷工具

| 工具 | 打的失败模式 | 替代了什么 |
|---|---|---|
| `describe_structure(mol_id)` | 数错链长 **33%**（19/57） | "把 SMILES 解析成骨架 + 取代基链长"这一步纯结构读写 |

返回 `{mol_id, scaffold, chain_len}`。**仍然不发放 QED**，QED 门依旧要 `measure_qed`
实测确认；拟合、选点、选阶数、核约束仍是 agent 的活。

### 8.3 严格守"同题同真值同判据"

题面 query / 目标 / 三条约束 / `ground_truth.json` / 判分器 / 预算 **全部与 basic、some 相同**，
判分器同样整套转发 basic 档 fixed 的 `judge.py`。唯一变化：工具集 = some 档 **+1 个**。

### 8.4 三条可否证预测

| # | 预测 | 否证后怎么处置 |
|---|---|---|
| E1 | `cp_extrap` 的双峰消失、低分簇（<0.3）大幅收缩 | 若低分簇仍在，查它们的 `x_query` 是否仍错——那说明模型连工具给的数字都不用 |
| E2 | Δ(enough − some) > 0，但**小于** Δ(some − basic) 的 +0.25（越往后剩下的推理越少） | 若反而更大，说明结构读写比趋势拟合更卡人，需回写 ADR-0025 §9 |
| E3 | 工具被真实调用（账本里有 `describe_structure`） | 调用率低则 Δ 无意义，先查题面是否讲清 |

**不预测分数绝对值。** 判据、容差、给分公式一律不动。

## 十、enough 档（纯净题面基线，2026-08-21）

### 10.1 some 档剩下什么失败

两侧合计 n=51，总分 ≈0.877，**损失几乎全在外推关**：

| 关 | 均值 | 权重 | 损失 |
|---|---|---|---|
| `cp_extrap` | 0.798 | 0.5 | **0.101** |
| `cp_conditions` | 0.941 | 0.3 | 0.018 |
| `cp_lead_value` | 0.980 | 0.2 | 0.004 |

逐个查 7 个低分 run，**这次和旧基线完全不同**：

| 核查 | 结果 |
|---|---|
| 喂的点来自哪个系列 | 7/7 全对 |
| 查询的链长 `x_query` | **7/7 全是 11（正确）**——不再是数错碳数 |
| 报的值是否来自工具输出 | **51/51 全部对得上某次工具输出**，没人自己编数 |
| 真正的问题 | `deepseek-v3.2` 同时拿到了 0.5416（degree 2）和 0.695（degree 1），**报了 0.695** |

⇒ **剩余失败 = 在自己跑出的几个拟合结果里挑错了**。

### 10.2 一个反直觉的证据：统计学工具会帮倒忙

本想配一个"用交叉验证自动选阶数"的工具，先在真值上验了一遍：

| degree | LOO-CV 误差 | 外推 x=11 | 柯西分 |
|---|---|---|---|
| 1 | **0.0231（最小）** | 0.6950 | **0.078** |
| 2 | 0.0401 | 0.5416 | **0.910** |
| 3 | 0.1025 | 2.1323 | 0.001 |

**交叉验证会推荐 degree=1，也就是错的那个。** 因为测量范围 n=2..6 内关系本来就近似直线，
曲率只在外推段才显现。⇒ **纯统计的模型选择工具在这道题上是有害的，不能配。**

### 10.3 真正的坎是领域知识（分项数据实证）

把 QED 的 8 个分项拆开看（同系列 n=2→6→11）：

| 分项 | n2→n6 | n6→n11 |
|---|---|---|
| MW | +0.352 | +0.316 |
| **ALOGP** | **+0.124（还在变好）** | **−0.509（反转崩塌）** |
| ROTB | −0.460 | −0.426 |
| 其余 5 项 | 基本不变 | 基本不变 |

**在测量窗口内 ALOGP 这一项还在往好里走，越过窗口才掉头。** 这个拐点从 5 个 QED 数值里
看不出来——要知道亲脂性有最优区、目标的 alogp 已到 4.96（题面免费给了）越过了最优。

### 10.4 据此配的工具

| 工具 | 打的失败模式 | 替代了什么 |
|---|---|---|
| `qed_components(mol_id)` | 挑错拟合结果 / 看不出拐点 | 把"QED 为什么在跌、哪一项在主导"从领域知识变成可查数据 |

**只对已实测的分子可用**（目标测不到，所以拿不到它的分项 ⇒ 不泄答案）。
agent 仍要自己看出 ALOGP 项已见顶、结合题面给的目标 alogp 判断会反转。

### 10.5 预测（含"梯子到头"这个可能）

| # | 预测 | 含义 |
|---|---|---|
| G1 | Δ(enough − some) > 0 但明显小于 +0.34 | 边际递减继续 |
| G2 | 若 **Δ ≈ 0**，则说明**工具梯子到头了**——剩下的推理无法在不泄答案的前提下被工具替代，那是这道题不可再分的科学内核 | **G2 成立也是有价值的结论，不算失败** |
| G3 | 工具被真实调用 | 否则 Δ 无意义 |
