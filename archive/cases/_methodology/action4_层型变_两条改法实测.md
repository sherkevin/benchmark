## 1. 加数据为什么无效：不是没下够，是自由源只有一条谱系

**先纠正一个我自己上一轮的错误**：我曾把 NIMS MDR（26321 行）当作补数据首选推荐给 owner，
但 `task-05-扩数据源调研.md §2.1` 早已明确否掉它作主入库源（化学式含占位符、102 种 token 需清洗规则、
元素集超出 88 元素映射、同式多行需另定去重口径），定位是"族级文献溯源 + Tc 交叉验证"。
没读已有积累就推荐——正是 `DECISIONS.md §6 坑⑤`。

**库存现状（实测）**：材料侧晶体 17252 条 = 3DSC 5771 + UCI SuperCon 11481
（`task-05-扩数据入库记录.md` §0，Task #31 已入库）。也就是说调研列为"✅ 首选主扩源"的 UCI **已经用掉了**。

**剩下的自由源全是同一条 SuperCon 谱系**（`task-05-扩数据源调研.md §2` 八源横评）：

| 源 | 与现库关系 | 实测增量 |
|---|---|---|
| Stanev 2018（16414 条） | 随 3DSC 仓库分发 | 唯一成分 16079，其中库里没有的 **2492**；合格体系 15 → 16（+1 且垃圾） |
| JARVIS supercon_chem | 与 Stanev 逐条同源（16414 条，同一文件） | 同上，无独立增量 |
| NIMS MDR（26321 行） | 上述所有源的**共同上游** | 未实测；需清洗，且见下一段的结构性上限 |
| ICSD 子集 / MP / SuperMat / 高压氢化物 | 许可屏障 / 无实验 Tc / 抽取噪声高 / 压力混淆 | 已排除 |

**结构性上限（这一条才是决定性的）**：把每层型样本门槛从 3 放宽到 **1**——等价于"用尽全库每一条记录、
再多的数据也不过如此"——合格体系从 15 涨到 48，而 Cu=3 仍占 **30/48 = 0.625**。
因为"铜氧化物同系列 n=3 最优"是**物理规律、教科书事实**，补数据只会让它更稳，不会让它变得不可背诵。

⇒ 补数据能提高的是**实例数**，压不下**背诵基线**。而实测连实例数也没提上去（+1）。

## 2. 改题面为什么不达标：低背诵上界是噪声造出来的

问"哪个层型 Tc 最高"可被背诵（常数答案 0.867）。改问**完整排序**（整个排列完全一致才算对，
离散零超参，满足 `BENCH_SPEC.md` §4 闸4），背诵上界确实降了——但要看清降在哪。

`tools/gate5_layer_ordering_gap.py` 扫 2 种实例池 × 3 种聚合口径，每组再报**真值留一稳健**子池
（去掉任意单条记录后整个排列不变才算真值稳；零阈值、离散，替代"相邻差 > k×sd"那种超参判据）：

| 实例池 | 聚合 | 全池 n / 背诵上界 / 收益差 | 留一稳健 n / 背诵上界 / 收益差 |
|---|---|---|---|
| 恰好 3 层型 | max | 12 / 0.667 / 0.333 | 8 / 0.750 / **0.250** |
| 恰好 3 层型 | mean | 12 / 0.500 / 0.500 | 4 / 1.000 / **0.000** |
| 恰好 3 层型 | median | 12 / 0.583 / 0.417 | 9 / 0.778 / **0.222** |
| ≥3 层型变长 | max | 15 / 0.600 / 0.400 | 8 / 0.750 / **0.250** |
| ≥3 层型变长 | mean | 15 / 0.467 / 0.533 | 5 / 1.000 / **0.000** |
| ≥3 层型变长 | median | 15 / 0.533 / 0.467 | 10 / 0.700 / **0.300** |

读法（三点，按重要性排）：

1. **mean 口径那个最漂亮的 0.533 是假的**。它背诵上界最低（0.467），但明细里
   `Ba-Cu-O-Pr-Y` 三个层型的 mean 是 50.7 / 50.9 / 51.1 K，而层型内 tc 标准差中位 **15.2 K**——
   真值排序由噪声决定，所以任何固定先验都猜不中。加稳健筛后该口径只剩 4~5 个体系、
   背诵上界升到 **1.000**、收益差归 **0.000**。**"背诵基线低"必须先排除"真值不稳"这个成因。**
2. 唯一压到闸5 下限的是 `≥3 层型变长 × median × 留一稳健`：n=10、背诵上界 0.700、收益差 0.300。
   而 `gate5_strategy_gap.py` 文档字符串写明 **0.30 是下限不是达标线**——`triage_01` 收益差 0.333
   仍被 run 间方差 0.172 摊平。10 个实例、整体匹配判分，分辨率 0.1/实例，比 triage_01 更薄。
3. **预算受限版更糟**：该组合下正确策略在预算 6/9/12/20 时只有 0.446/0.513/0.568/0.674，
   **全部低于背诵上界 0.700**——即"老老实实查库测量"不如"直接背文献"，题面一加预算就反向激励。
   只有预算 30 时（0.839）才超过背诵，收益差却掉到 0.139。

## 3. 本轮产出的两条可复用零超参判据（真正的沉淀）

`layer_01` 之所以跑完 123 run 才发现问题，是因为闸5（`gate5_strategy_gap.py`）**有随机基线、
没有背诵基线**。本轮把两条补上，都只用真值、零 API、零阈值：

1. **背诵基线**（`gate2_data_census.constant_answer_baseline` / `gate5_layer_ordering_gap.fixed_prior_rules`）：
   不查库、只凭固定先验能拿多少分。判据是严格不等式「正确策略可达命中率 > 背诵基线」。
   固定先验要含一条**作弊上界**（直接从真值挑最优固定序），它等价于一个把文献读透的模型。
2. **真值留一稳健**（`gate5_layer_ordering_gap.loo_stable`）：去掉任意单条记录后真值不变，才准进池。
   这条同时兼掉坑⑥（报聚合数字不核原始样本）——稳健子池的脆弱峰体系数为 0/10。

两条已登记进 `BENCH_SPEC.md §5 闸5`。
