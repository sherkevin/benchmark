**逐条裁决：**

| # | 预测 | 实测 | 裁决 |
|---|---|---|---|
| P1核心 | 组内SD<0.12 | 均值 0.100 / 中位 0.089（但 2/6 超 0.12） | **过（勉强）**：比 triage 0.151 低，最好模型 0.024 极稳；路线 B 窄口径成立 |
| P2 | 强>弱 差≥0.15 p<0.05 | 强 0.200 vs 弱 0.212，**差 −0.012**，置换 p=0.42 | **否证**：判据⑥ 不成立，与 triage 同样失败 |
| P3 | 层型强>弱 | 强均 0.71 vs 弱均 0.62，各组各有一个触底（671B 0.19 / coder 0.13） | **否证**：层型把模型分两簇，但不沿强弱轴 |
| P4 | 测数正相关 | 皮尔逊 r=+0.36 | **过** |
| P5 | 强档均值 0.30~0.75 | 全体 0.088~0.272，**全部 <0.30** | **否证（关键）**：**全员触底** |

**根因（P5 解释 P2）：无一模型做外推。** 全体报 tc≈106~112，即"照可测最高 108"再抬一点点；
真值 120 需把层型趋势外推到可测窗口之外，**六个模型没有一个做到**。主判别关 cp_tc（权重 0.9）
对所有人触底 → 分差只是"谁偶尔多猜高一点"的噪声（deepseek-v3.2 单run最高 0.812 是过猜命中）。

**冒烟误读复盘：** 冒烟见 671B 0.074 < qwen 0.262 < 0.439，我读成"外推梯度"，
实为"测量次数 + 略过猜"梯度——0.439 对应报 tc≈113~114，仍非真外推到 120。

**裁决：不封存、不作判别题。** 路线 B 的窄claim（降组内方差）兑现了，但**降方差没换来区分度**，
因为判别技能（外推）对全员触底、强弱档真实差≈0。这是与 triage（方差淹没信号）**不同的失败模式**：
**信号本身不存在（地板效应）**。连续两题预登记判别假设被否 → 见 DECISIONS §6 坑⑧ 与流程补丁。
