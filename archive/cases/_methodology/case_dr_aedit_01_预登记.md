## 七、检验方案（事先定好，防事后挑口径）

- **主指标**：逐模型档差 Δ_m = mean(S_some) − S(basic)_m。S(basic) 为探针留痕的
  **样本级均值**（R1：与 S(some) 的单次 run 均值同聚合层级——"行为不变"时 Δ 才是 0）。
  Δ 显著性用 **some 档 n=20 分布对常数 S(basic) 的单样本 Wilcoxon 符号秩检验**，
  报 p 与中位差。
- **共同主指标 P1b**：q11/q12 逐题判对率（n=20 run 各贡献 1 次），与 basic 样本级
  50%（3/6）对照；报判对率本身与二项检验 p（H0: p=0.5）。
- **区分读法**：三个 Δ 的排序与符号（预期 deepseek 正、qwen/glm ≈0），不按总分排名次；
  结论按**单格证据**口径声称（R1②），不推广为能力级判决。
- **逐检查点**：cp_all / cp_single / cp_double / grounding 逐档逐模型分别报（§11.2），
  记录关只用于失败模式分型。
- **每格必报**：n、均值、离散度、剔除数与剔除原因（口径 B）。
- **噪声门**：均值差 > 组内离散度才声称差异（`goal.md` §7.5）。
- **注（glm q15）**：glm 的 basic 探针 q15 无有效样本。若 some 档 glm q15 答错，
  该题**不计入 glm 的档差**（basic 无对照），在报告中单列说明。
