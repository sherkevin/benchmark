# case_sc_chain_01 · 四步依赖链（含外推步）

> 一句话：**A** 找掩杂序列的 Tc 峰 → **B** 用峰值派生阈值筛第二族 → **C** 对**测不到**的材料归纳规律做外推预测 → **D** 从预测为高的里按元素数最少选终答。每步输出是下一步输入，早错则沿链拖垮。

**答案不可背 ✓（裸答基线 k=5，无工具）**：强 recaller(gpt-4.1/qwen-plus) total 最高仅 0.279、cpC=0.500(=随机)、cpD 0/5 → 无测量数据就答不准，区分来自真实归纳、非记忆。（对比 explore 裸答 0.9）

**分步诊断（方差来源）**：
- cpA 全模型饱和=1 → 无区分、无需去噪；
- **方差全在 cpB**（gpt-4.1 家族B筛选 2/5 轮完全崩到 0，temp0 下仍双峰＝真实模型不稳）；
- cpC 近平（0.6–0.8，turbo 反而最高 0.8）→ 外推步不是区分点；

**统计意义**：gpt-4.1 mean 0.728 与 max 0.639 之差 0.089 < gpt 的 SEM(~0.10) → 两者均值不可区分。严格看只有两档：弱(turbo 0.52) < 强簇(max≈gpt 0.64–0.73)。

**结论**：chain 有真实的弱-强信号（turbo 明显垫底、gpt 能冲 0.9）且答案不可背，但**在本模型池下不满足完整信号门**——强模型簇聚 0.639、唯一破簇者 gpt-4.1 不稳。单轮极差 0.417 是运气。第三次撞到「同档强模型簇聚」这堵墙（前两次：explore 记忆、dopant 太浅）。复现：`sweep_chain.py` + `judge_chain_multi.py`；裸答 `naked_baseline_chain.py`。

| 模型 | n | cpB均 | cpC均 | **cpD通过率** |

**关键：chain 是依赖链，区分度来自“卡在哪一步”，跨检查点分档（不是单看 cpD）。** 上表是 n=8-10 初测快照；顶部边界经加轮固化到 **n=20**（见下）。逐模型分档：

| 档 | 模型（具名·身份先验） | 特征 | 相邻边界检验（n=20 固化 + Bonferroni×2） |
|---|---|---|---|
| **低** | qwen-turbo | 连筛选关 cpB 都崩（F1 均 0.23）| — |

**→ 真 3 档能力序（turbo < max < gpt），两个相邻边界均抗 Bonferroni。** 与早前三次结论务必分清：
- ❌ 第一次“3 档”：单看 cpD、tol=0.15 凑档——伪造，废。
- ◐ 第二次“2 档”：只在 cpD 一关找档，漏了 cpB。
- ◐ 第三次：两关分档，但顶部边界 n=10 时只到 Bonf p=0.065，不够硬。
- ✅ 第四次（定稿）：**加轮到 n=20（预定后一次性检验，非跑到显著即停）**，具名模型 turbo<max<gpt：底部 cpB 置换 p<0.001、顶部 cpD Fisher p=0.008，**均抗 Bonferroni×2**。gpt 的 cpD 率诚实落定 0.35（非初测运气的 0.50），max 0/20 铁底。这是链式“早崩/晚崩/通关”的真实能力序、两个不同硬关各自显著、非凑档非循环。

## 二、考察的 agent 能力（对齐总纲第一根轴：infer / acquire）

**主轴 = infer 主导**：只给"做实验 / 查文献 / 交卷"这类基本工具，所有推断必须由 agent 自己完成；
acquire 只是取输入的手段，不替代推理。

| checkpoint | infer / acquire | 对应能力 | 测什么 |
|---|---|---|---|
| cpA 峰识别 | acquire 为主 + 轻 infer | 做实验取值 + #5 同族 Tc 趋势 | 测遍序列、找最大值 |
| cpB 阈值筛选 | acquire + infer | 做实验 + 派生量计算 + 集合完整性 | 用 T*-Δ 派生阈值、筛完整子集 |
| **cpC 外推（核心）** | **纯 infer（acquire 被拒）** | **#2 比例调整 + #6 element_count 交互推理** | **工具对这些材料拒答，只能从可测数据归纳规律再外推** |
| cpD 终选 | infer | 约束下择优（依赖 C 的预测集） | 从自己预测为 high 的集合里按元素数最少选 |

**这正是总纲"立足点 2"的 A/B 库落地**：可测材料 = **A 库**（agent 能 probe），10 个不可测材料
= **B 库**（gt 藏在里面、工具拒答），agent 只能通读 A 归纳规律、推断 B 里的 gt。cpC 就是
"open 任务 + A/B 库"的原子实例，也是全题唯一逼出纯 infer 的关卡。

**为什么这题能压住强模型**：库里的高 Tc 规律是**交互式**的，单因子必错——

- 单因子"含 Hg → 高"只有 49% 准；
- 但 **Hg + 5 元素 → 92% 高**，**Hg + 4 元素 → 仅 32% 高**；
- **Bi + 5 元素 → 仅 17% 高**（"5 元素→高"也错）；
- **含 La → 0% 高**（强否决）。

held-out 的 10 个材料专挑这些翻车点（含 Hg 却低的、Tl 一高一低、La 否决），单因子启发式只能对 7/10 —— 实测所有模型正好都停在 0.700，**说明它们抓到了主因子但没完全抓住交互**。

**依赖累乘的实证**：qwen-turbo 的 cpB=0（筛选集全错）直接导致 cpD 也错；qwen-plus 的 cpA 就错，整条链归零。

|---|---|---|
| 结果验证强度 | **强** | tc / element_count 全是库内真值，机器硬判，无 LLM judge |
| 问题范式 | **判别式（fixed）** | 候选（可测 + 不可测清单）都在题面，agent 是判/选而非从零生成分子；但借用 open 任务的 A/B 库思想——gt 藏在不可见的 B 库里 |
| 中间 check 点强度 | **弱衡量** | 把终答 answer.json 拆成 4 个字段逐个给部分分，本质是"对终答的另一种衡量"（总纲定义的弱）；**强衡量需状态转换锚点，按总纲明确推迟** |
| 工具供给 | **强推理 / 少工具** | 只给 get_property + literature_search + submit（基本工具）；cpC 工具主动拒答，逼纯 infer |

**作为 fewshot 的定位**：本 case 是"**infer 主导 · 判别式 · 弱衡量 · 基本工具（强推理）**"这一类的
第一个范例。可复制骨架 = 确定性热身步 + 中段嵌一个"acquire 被拒、必须纯 infer"的 A/B 库外推步
+ 末步依赖外推结果。后续同类 case 按此骨架换领域 / 换规律批量长出（case 优先，不预设 template）。

> **关于中间 check 的诚实说明**：本 case 结构上是递归链（A 输出→B 输入…，即总纲立足点 3 的形态），
> 但判分是读终态文件的分解给分，仍属**弱衡量**。要升级到**强衡量**需固定状态转换锚点
> （agent 的 trace 必须物理经过可验证的中间状态才算数）——这是总纲明确推迟的下一步。

## 四、判分标准与流程（标准 3）

**硬判定**：读金标准链 + agent 工具调用账本里的 `submit_answer`，机器对账，不采信自报值。判分器 [`judge.py`](judge.py) 可执行。

$$\text{total} = \frac{1}{4}\left(\underbrace{\mathbb{1}[\text{peak}\in P^*\wedge|T-T^*|\le 0.5]}_{cpA} + \underbrace{F_1(Q_1,\hat{Q_1})}_{cpB} + \underbrace{\frac{|\{h: \hat{y}_h = y_h\}|}{10}}_{cpC} + \underbrace{\mathbb{1}[\text{final}=f^*]}_{cpD}\right)$$

其中：

- $P^*$ —— 并列峰集合（`O6.210…` 与 `O6.220…` 的 Tc 都是 127K，任一均算对）；
- $T^*=127.0$ —— 序列峰 Tc，容差 0.5K；
- $Q_1$ / $\hat{Q_1}$ —— agent 报的 / 金标准的达标集（threshold1 = $T^*-32$ = 95.0），用 F1 给部分分；
- $\hat{y}_h,y_h$ —— agent 对第 $h$ 个不可测材料的预测 / 真实标签（high 定义为 Tc ≥ 90K），共 10 个；
- $f^*$ —— 金标准终答 `O4.180Cu1Ba2Hg1`（真值 high 里元素数最少、Tc 最高者）；
- 四关等权，各占 0.25。

复现：`cd cases/case_sc_chain_01 && python3 judge.py`

## 五、这道题为什么这样设计（三次失败换来的）

| 尝试 | 结果 | 教训 |
|---|---|---|
| 3 / 5 / 7 步**纯确定性**链 | 强模型**全部满分 1.0** | 确定性子任务上强模型单步 p≈1，$p^n$≈1，**加链长无效** |
| 压缩测量预算 | 能压分但**排序失真**（弱模型反超）| 把"测推理"变成"测运气"，违反立项原则 |
| **本版：链中嵌外推步** | **全部模型 ≤0.842，cpC 全 0.700** | 目标原文就要求"含至少一个外推/生成步防蒙"——之前漏了这条 |

**外推步之所以有效**：它不是"更难的查表"，而是**工具主动拒答**，把答案挪出可测空间，agent 只能靠归纳。这是唯一能压住天花板模型、又不破坏确定性硬判的杠杆。
