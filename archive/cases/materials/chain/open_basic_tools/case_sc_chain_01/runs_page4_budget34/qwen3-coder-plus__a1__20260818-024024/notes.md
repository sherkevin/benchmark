# Notes for Superconductor Tc Study

- Seed material: O6.080Ca1Cu2Ba2Hg1
- Budget: 34 units total
- Both tools cost 1 unit each use
- Definition: high Tc >= 90K, low Tc < 90K

## Step A - Series Peak
- Need to find homologous doping series members (same elements, varying oxygen)
- Find the composition with maximum Tc (T*)

## Step B - Filter Family B
- Materials containing Hg with exactly 4 elements
- Threshold1 = T* - 32
- Find all materials with Tc >= threshold1
- Call this set Q1

## Step C - Extrapolate
- Some materials cannot be measured ("no sample exists")
- Need to induce a rule from measurable materials
- Predict high/low for unmeasurable ones
- Single-factor rules are incorrect for several materials

## Step D - Final Pick
- Among unmeasurable materials predicted as high
- Choose the one with fewest elements
- Break ties by higher expected Tc
