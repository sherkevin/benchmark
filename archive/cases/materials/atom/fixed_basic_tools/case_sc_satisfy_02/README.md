# case_sc_satisfy_02 · 约束满足（完整满足集）+ 不可测解 —— 第一组「约束满足 · fixed · basic」合格 case

> 一句话：报出**完整**满足双约束（恰好 4 元素 **且** Tc∈[90,100]K）的候选集合。9 个满足者**全部落在"不可测"集**（tc 被工具拒答）；可测的 4 元素候选（La 系）Tc 仅 22–39K 全部越界，须实测才知道要排除。必须先实测排除 La 系、再从可测的 5 元素 Hg-1223 系（121–127K）归纳"Hg-Ba-Cu-O 体系 Tc 高"，才敢把不可测的 Hg/Tl-1201 判为满足。

**配置**：材料 · atom · fixed · 基本工具（ROADMAP 阶段 1）。题型：约束满足。

---

## 一、v1 → v2 → v2.1：三次迭代压掉"可背"

| 版本 | 关键设计 | 裸答基线（k=5，无工具）| 判定 |
|---|---|---|---|
| v1 (`satisfy_01`) | 交**任一**满足者 | **0.673**，`cp_satisfy` **5/5 全过** | ❌ 满足集 9 个 → 蒙中率 100% |
| v2 | 交**完整满足集**（F1）+ 1 个实测锚点 | **0.657**，`cp_sat_set` 0.941、`cp_excluded` 0.800 | ❌ "Hg系高/La系低"是粗粒度常识，仍可背 |
| **v2.1** | 完整满足集 + **双实测锚点**（`excluded_with_tc` 改为 id→**实测 Tc 数值**映射）| **0.458**，`cp_excluded`/`cp_measured` **全 0** | ✅ 精确 Tc 数值纯记忆答不出 |

**教训**：集合类产物（哪些满足/哪些排除）可被粗粒度常识猜中；**只有要求精确数值的实测锚点才真正防可背**。

## 二、判分（四关，机器硬判，真值取自离线真库）

| 关 | 判什么 | 口径 |
|---|---|---|
| `cp_sat_set` | **判别性主关**（连续 F1）| `satisfying_set` vs 真实 9 个满足者（全在不可测集）→ 只有敢外推者拿分 |
| `cp_ec_set` | 元素数合法集（连续 F1）| vs 真实 13 个 |
| `cp_excluded` | **实测锚点 2**（连续）| `excluded_with_tc` 是 id→实测Tc 映射，逐个按容差 2K 评分 |
| `cp_measured` | **实测锚点 1**（连续）| 可测的合法候选中最高者 id（0.5）+ 其精确 Tc 容差内（0.5）|
| **总分** | | 四关等权平均 |

`satisfying_set` **允许为空**——"不敢交任何不可测候选"是能力失败（F1=0），不是协议失败。

## 三、实测结果（3 模型 × **预定 n=20** 一次性检验）

| 档 | 模型 | n | 总分 | cp_sat_set | cp_ec_set | cp_excluded | cp_measured | 敢交不可测者 |
|---|---|---|---|---|---|---|---|---|
| **弱** | qwen-turbo | 20 | 0.510 | 0.041 | 1.000 | **0.000** | 1.000 | 1/20 |
| **中** | qwen3-coder-flash | 16 | 0.703 | 0.000 | 1.000 | **0.875** | 0.938 | **0/16** |
| **强** | gpt-4.1 | 20 | **0.818** | **0.310** | 1.000 | 1.000 | 0.961 | **7/20** |

（coder-flash 4 轮协议失败已剔除。）

### 统计检验：3 档，两个相邻边界均抗 Bonferroni×2

- **弱 ↔ 中**（`cp_excluded` 实测锚点）：0.000 vs 0.875 → 置换检验 **p < 0.001**，Bonferroni×2 < 0.001 ★
  → turbo 根本没去测那些要排除的候选；flash 测了。
- **中 ↔ 强**（硬关"敢交不可测者"）：gpt **7/20** vs flash **0/16** → Fisher **p = 0.0107**，Bonferroni×2 = 0.0213 ★
  → flash 实测做得对，但**从不敢**把不可测候选判为满足；gpt 敢，且交对时能拿到完整 9 个。

**能力序解读（"卡在哪一步"）**：弱模型连实测锚点都不做 → 中模型实测到位但不敢外推 → 强模型实测 + 敢外推。这与 chain_01 的分档机理一致（不同关分出不同档）。

## 四、验收结论

| 验收项 | 证据 | 判定 |
|---|---|---|
| 答案不可背 | 裸答 k=5 最高 **0.458**（v1 0.673 → v2 0.657 → v2.1 0.458），两个实测锚点全 0 | ✓ |
| 统计显著能力分档 | **3 档**：弱↔中 置换 p<0.001；中↔强 Fisher p=0.011；均抗 Bonferroni×2 | ✓ |
| 判分机器硬判 + 真值一致 | harness 与 judge 同读 `artifacts/ground_truth.json`；真值继承 constraint_01 同一离线真库快照 | ✓ |
| 预定轮次、非 optional-stopping | 开跑前定死 r1–r20 | ✓ |
| 检验方法 | 连续关置换检验、二值硬关 Fisher、Bonferroni 校正、具名模型（身份先验）防循环分组 | ✓ |

**诚实边界**：
1. gpt 的 `cp_sat_set` 只有 0.310（敢交时对，但 13/20 轮不敢交）——"强"= 有时能完成外推，非稳定；
2. `cp_ec_set` 三模型全 1.000（饱和关，无区分）——数元素谁都会，它只是热身关；
3. coder-flash 有 4/20 轮协议失败（未产出 answer.json），已剔除且如实登记。

**→ case_sc_satisfy_02 定为第一组「约束满足 · fixed · basic」合格 case。**
