# case_sc_dopant_01 —— Pr 掺杂抑制律的插值外推题

**测什么**：给两条已合成的边界曲线，能不能推出中间那条**未合成**曲线。这是材料信息学的真实工作流（已有样品做实验→归纳规律→预测没做过的），不是"选最高分"的白送题。

## 题面

体系 `RE(1-x) Pr(x) Ba2 Cu3 O7`：Pr 替位 RE 会抑制超导临界温度 Tc，抑制快慢取决于 RE。

- **已合成（可 `measure_tc` 测真值）**：Er 系（抑制最慢，上边界）+ Nd 系（最快，下边界），共 19 个。
- **未合成（没样品、测不了 → 必须预测）**：整条 Gd 系 11 个点。
- **交卷**：`answer.json` 里给出 Gd 系每一点的预测 Tc（`predictions` 字典）。

难度不来自人为 credit 上限，而来自"目标曲线根本没合成，只能靠两条边界曲线插值/外推推出"——`measure_tc` 对未合成材料如实返回 `{tc:null, sample_available:false}`（科学上唯一站得住的"测不到"理由是没有实物）。

## 三道可解性闸（造题时已过，本次重构复核仍成立）

1. **可插值**：Gd 系 informative 点 9/9 严格落在 Er/Nd 之间 → 真能从两条边界推出。
2. **可分辨**：相邻候选 Tc 差 9~21K，体系同配比噪声≈0，信噪比 ~18x。
3. **临界浓度唯一**：Gd 系仍超导的最大 Pr = 0.4（介于 Nd 的 0.3 与 Er 的 0.5 之间）——这是关键陷阱：**Gd 比 Er 先死**，照抄 Er 曲线或取中点都会在 cp1/cp4 上栽。

## 判分（cp1–4，机器硬判、无 LLM judge、真值离线库取，天然梯度）

| 关卡 | 判什么 | 口径 |
|---|---|---|
| cp1 分类 | 超导/不超导 | 只算 informative 点的准确率 |
| cp2 数值 | 预测精度 | 每点 `max(0,1-|err|/TOL)` 均值，TOL=8K（半个候选间距） |
| cp3 阈值 | Tc≥80K 的最大 Pr | 从预测曲线派生，精确命中=1 否则 0（真值 0.078） |
| cp4 临界 | 仍超导的最大 Pr | 从预测曲线派生，精确命中=1 否则 0（真值 0.4） |

`总分 = (cp1+cp2+cp3+cp4)/4`。协议失败（无 answer / predictions 不全或非数值）单独报，不计入分布。

## 实测结果（4 模型 × 5 轮 · 连续判分器 cp3/cp4 PR_TOL=0.10 · 2026-08-14）

| 模型 | 均值 | 轮次 | 轮间波动 |
|---|---|---|---|
| bailian/glm-5.2 | 0.638 | [0.662,0.463,0.650,0.946,0.471] | 0.483 |
| deepseek-v3.2 | 0.617 | [0.769,0.411,0.946,0.410,0.547] | 0.536 |
| qwen3.7-max | 0.546 | [0.545,0.589,0.493,(r4协议失败),0.556] | 0.096 |
| qwen3-coder-plus | 0.500 | [0.567,0.417,0.481,0.507,0.527] | 0.150 |

模型均值：min=0.500 max=0.638 总均=0.575 **极差=0.139**。

- **对照裸答基线（无工具 0.19–0.35）→ with-tools 0.50–0.64 明显更高**：工具确实加值、任务需实测外推（✓ 符合「答案不可背」）。
- **⚠️ 未过硬性前提①（信号非噪声）**：模型间极差 0.139 **远小于** glm/deepseek 的轮间波动 0.48–0.54 → 排序不跨轮稳定、单轮即可翻。噪声来源：cp4（临界 Pr）PR_TOL=0.10 仍近二值（偶中 →+0.25），叠加 cp2 逐轮 0.45–0.79 的真实抖动。
- **根因诊断（零成本再判 20 runs，三种算法）**：全4项 / 去cp4 / 只看cp2，模型间极差始终只有 **0.12–0.15**、均被轮间波动 0.33–0.54 淹没 → **不是 judge 的锅，是模型池的锅**：glm/deepseek/coder/max 四个同档强模型在本题能力太接近（同 explore 根因）。
- **d3 已试（OpenAI 端点 + 弱模型 qwen-turbo）→ 仍不分**：turbo 0.503 / coder 0.436 / max 0.542（max 仅1轮、其余生成超时），极差 0.106、且 turbo>coder 反序。根因更深：**“测两条边界再插值”这个核心动作，弱模型也会做**，所有模型 cp1 都是 6/9、cp2 都 ~0.45 → 没有能力梯度可分。与 explore 对比：explore 的区分来自记忆（不合法），dopant 无记忆但也无梯度（任务对全池一样难）。
- **结论**：dopant 是“答案不可背”的合格题，但**不是能区分本模型池的题**。第一组要么换一个“核心动作在池内真有强弱之分”的任务，要么改判**过程**（是否测全边界/顺序对）而非终值精度。待 owner 定向。

## 答案不可背验证（裸答基线 · 2026-08-14）

按 goal.md §4支柱5：不给工具、不给 Er/Nd 边界数值，直接让强模型凭记忆/推理写 Gd 11 点曲线，用本 case 的 judge 打分。

| 模型（裸答） | cp1 分类 | cp2 数值 | total |
|---|---|---|---|
| gpt-4.1 | 0.667 | 0.101 | 0.192 |
| qwen-plus | 0.667 | 0.105 | 0.193 |
| deepseek-v3.2 | 0.444 | 0.436 | 0.350 |

**结论：核心指标 cp2（数值精度）裸答最高仅 0.436、多数 ~0.10 → Gd 曲线的精确值背不出来**，必须实测 Er/Nd 边界再外推。与 explore（真名下强模型稳拿 0.9）形成对比，符合「真名 + 答案不可背」新原则。

注：cp1（超导/不超导粗分类）裸答可达 0.67，因单调抑制的大势可猜——故 cp1 不宜单独作区分主力，主力看 cp2。qwen3.7-max 因该端点生成超长推理超时未纳入（gpt-4.1/qwen-plus 同为顶级 recaller，已足够代表）。脚本：`src/probe_headless/naked_baseline_dopant.py`。
