# Notes on Tc Prediction for Pr-Doped Superconductors

## Measured Data

### Er Series (RE = Er):
- O7Cu3Ba2Pr0.030Er0.970: Tc = 93.9 K
- O7Cu3Ba2Pr0.150Er0.850: Tc = 82.9 K
- O7Cu3Ba2Pr0.300Er0.700: Tc = 61.1 K
- O7Cu3Ba2Pr0.500Er0.500: Tc = 28.6 K
- O7Cu3Ba2Pr0.800Er0.200: Tc = 0.0 K

### Nd Series (RE = Nd):
- O7Cu3Ba2Pr0.030Nd0.970: Tc = 85.1 K
- O7Cu3Ba2Pr0.150Nd0.850: Tc = 40.7 K
- O7Cu3Ba2Pr0.300Nd0.700: Tc = 5.6 K
- O7Cu3Ba2Pr0.500Nd0.500: Tc = 0.0 K
- O7Cu3Ba2Pr0.900Nd0.100: Tc = 0.0 K

## Observed Pattern

1. As Pr content increases, Tc decreases for both RE elements (Er and Nd).
2. The critical Pr content where superconductivity is lost (Tc = 0) is different for each RE:
   - For Er: Tc drops to 0 between Pr content 0.500 and 0.800
   - For Nd: Tc drops to 0 between Pr content 0.300 and 0.500

3. Both series follow a similar trend where increasing Pr suppresses superconductivity, but the exact relationship differs between RE elements.

## Predicted Relationship for Gd Series

Based on the observed trends, Gd (which has an ionic radius between Er and Nd) should follow a similar suppression pattern. Looking at the relative positions:
- Gd³⁺ ionic radius is between Er³⁺ and Nd³⁺
- I expect Gd to have a Tc suppression curve similar to but potentially between Er and Nd

From the data, it seems that the critical Pr content where Tc becomes 0 is lower for Nd than for Er. Since Gd is between Er and Nd in terms of ionic radius, I expect its behavior to be intermediate.

## Predictions for Gd Series

Using interpolation between Er and Nd behaviors:
- At low Pr content (0.030), Tc should be high (similar to Er and Nd at this level)
- As Pr content increases, Tc decreases
- Critical Pr content for superconductivity loss should be between Er and Nd values
