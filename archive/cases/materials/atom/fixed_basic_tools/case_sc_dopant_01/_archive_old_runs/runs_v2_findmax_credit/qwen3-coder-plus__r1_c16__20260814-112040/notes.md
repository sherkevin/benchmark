# Notes on Finding Highest-Tc Composition

## Initial Analysis
I have 30 candidate compositions and 16 measurement credits. Each composition follows the pattern O7Cu3Ba2Pr(x)M(1-x) where M is a rare earth element (Er, Gd, Nd) and x is the Pr concentration.

Looking at the compositions:
- Different Pr concentrations: ranging from 0.030 to 0.900
- Different rare earth elements: Er, Gd, Nd
- Each composition has a fixed total of 1.0 for Pr and the rare earth element

## Strategy
I'll use an adaptive strategy to find the highest Tc composition:
1. Start by measuring a few samples to understand the general trend
2. Focus measurements on areas showing promise
3. Use interpolation and pattern recognition to guide further measurements
4. Save some measurements for confirmation of the highest values found
