Scientific agents often choose among several tools that return plausible but conflicting answers. Correctness feedback appears only after termination, may be delayed, and must update later choices without inventing labels for unselected tools. We present MIRA-Relay, an outcome-aware routing loop that combines a frozen discriminative provider surface with a lightweight provider-local residual adapter and an explicit release ledger. At cold start the adapter is exactly the frozen selector; after a selected result is released, it updates only that provider's residual reliability and can move the next action. We evaluate a one-call BBB routing contract with public truth, four checkpoint-bound fresh providers, scaffold-disjoint confirmation molecules, selected-only feedback, and delays $D\in\{0,1,4\}$. On the natural fresh holdout, MIRA-Relay matches Frozen at 89.81\% selected correctness; under a preregistered controlled evaluator-side label flip applied when the fit-best provider is selected, it reaches 87.56\% versus 73.38\% for Frozen, a +14.18-point paired gain with a 95\% scaffold bootstrap interval of [+9.61,+19.03] points. The result isolates the claim: delayed selected-only feedback supports recovery from the declared drift, while a stationary fresh menu does not justify a generic online gain.
