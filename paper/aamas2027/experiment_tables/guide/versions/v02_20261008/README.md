# 实验目标 Guide

这是用户要求的预期目标稿，**不是实验结果，也不是效果预测**。它与真实正文的
Tables 3–8 / Figure 3 一一对应，用已有结果和可达上界确定下一步要补的差距。
Guide 的 E1–E6 是展示编号；生效评价标准中的 E6 指“冻结确认”，不能混为一谈。

## 本轮目的和衡量方式

1. 六组表有明确的实测参照和目标行，单独标 M / T。
2. 百分比从整数计数计算；延迟分层之和、净救回数、对照差值和效用严格一致。
3. 每页有斜向水印、页眉和页脚，目标行保留 T，截取表格也能识别。
4. 每个目标都写清条件和失败判据；不预填显著性、CI、内存等尚无依据的结果。
5. Guide 独立保存，不能导入正文绑定脚本或替换真实 main.pdf。

E1上界由既有原生概率与已绑定truth做只读计算：157题中110全对、40 mixed、7全错，
逐题oracle150/157=95.54%；它不同于事后选一个固定provider的90.45%。目标48/270，
只占Frozen可救记录决策的17.8%。这些上界描述菜单的选择空间，不证明合法特征能学到。

目标整数是**按现有分母表达的规划情景**，不是逐样本预测或未来数据的精确计数。
已被分析过的157题不能重新作为新候选的未读确认。后续先冻结候选、预算、统计和
新确认集；新集上看相应目标率，不能为了达到这些整数反复调整旧集。

## 未预填的部分

- 不生成目标置信区间、方差、p值或逐事件实验日志。目标计数不能决定scaffold配对CI。
- Live learner peak memory、完整编码/队列/恢复开销仍须真实测量，不能从receipt大小推断。
- hERG/AMES、自然lifecycle、33-provider新模型资格与agent闭环收益另需证据，本表不虚填。
- 数字目标是研究候选，未替换三份生效标准或双方确认的决议；完整科学闸门仍HOLD。

## 文件和版本

- `guide.tex` / `guide.pdf`：独立LaTeX与可阅读PDF。
- `target_spec.json`：实测锚点、来源hash、目标整数及假设。
- `build_guide.py`：只读已有结果，生成自包含LaTeX；不执行训练、provider或API。
- `arithmetic_audit.json`：计数、上界、差值、效用和正文隔离检查。
- `versions/v01_20261008/`：第一版源码、PDF和页面；保留caption/font警告现场。
- `versions/v02_20261008/`：当前版；目标数值不变，补条件式速度描述和修正caption/font。
- `reviews/`：独立科学及视觉审查。

排版沿用同目录已实读的VAR、Registers、Never Train等实验页：自然表宽、booktabs、
方法组分区、短标题和可读字号。目标不伪装成SOTA行，蓝色只标规划值。
