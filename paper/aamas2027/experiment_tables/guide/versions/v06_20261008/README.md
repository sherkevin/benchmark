# 实验分布与目标 Guide

当前阅读版为 **v06，5页**，对应正文 Tables 3–8 / Figure 3 的六组。已通过来源绑定的独立分布审查（21/24）及视觉审查，固定阅读入口为 [guide.pdf](guide.pdf)；候选和所有旧版本在 `versions/`。

目的：让科学家同时对标效果、联合错误、分层波动和机制要求。先读 [v06修订说明](v06_修订说明.md)，再看PDF。

## 三类数值

- **M 实测参照**：四工具联合正确向量、方法配对救回/误伤、各拟合折/seed/延迟/事件阶段、拒答覆盖率。原始计数不改。
- **B 条件误差预算**：先指定避免误伤和损失救回的比例，再用同一分子记录推导 pooled、scaffold 和分层均值。B不是可执行策略、未来样本或预测置信区间。
- **T 研究目标**：保留目标，同时写清需要达到的错误识别能力和控制条件。不把目标当作已经有高置信度支持的效果预测。

每页有水印、页眉和 M/B/T 页脚；独立保存，不进入真实正文结果导出。Guide E6是正文拒答展示编号，生效标准E6的“未读确认”是另一件事。

## 历史与下一步

v01–v05源码、PDF和失败现场完整保留。v05此前只通过来源/算术和视觉检查，“已通过科学复核”的表述已更正；它不再是可信预期分布。原先独立挑选的未来均值和单调延迟目标已被本版替代。

后续科学工作需要固定一个具体候选及共同对照，实测它是否能达到这些误差选择性，再校准未来效果分布。这里不改生效方法/标准/决议，也不降低论文的目标。Guide不向正式 `main.tex/main.pdf` 与实测表预览写入目标数值。
