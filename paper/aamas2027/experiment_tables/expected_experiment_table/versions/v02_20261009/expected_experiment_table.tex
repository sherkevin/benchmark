\textbf{Binding.}
The row order, column semantics, experiment IDs, and displayed methods follow the canonical
\texttt{main.tex} and its 9-page \texttt{main.pdf}. Exact hashes are in
\texttt{main\_input\_sha256.txt}. The preview is not the binding table numbering.

\textbf{Reading convention.}
Numbers are conservative targets anchored to the current recorded table and its documented estimands.
They express the intended direction: natural stationary routing is tied to or slightly below Frozen;
controlled correctness drift is where MIRA-Relay should outperform Frozen and the matched Online-SGD row;
the development objectives remain below Corrected Frozen; and cost is a separate trade-off.
A target range is a planning band, never evidence.
