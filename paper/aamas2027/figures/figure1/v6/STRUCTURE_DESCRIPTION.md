# Figure 1 v6 structure description

Read left to right in four bounded regions. Public context and released history enter a selector with an immutable fit-only fallback and the MIRA-Relay state. Exactly one provider is called. A runtime ledger records the selected output and status; an independent frozen endpoint judge emits chemical correctness only after termination. The delayed release queue sends released challenger feedback to family residual/provider bias and fallback feedback to a diagnostic ledger only.

The direct lifecycle has no post-call verifier, escalation, refusal, or second call. Those are E5 extensions and must not be inferred from this figure.
