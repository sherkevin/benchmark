# report · 裸答 × 工具难度交叉分析（BBB 族）

## 结论（先说答案）

**裸答 0.80 的高分几乎全部来自「工具也都答对」的简单分子；在工具打架的难分子上，裸答塌到 0–60%。读法 (b) 成立、读法 (a) 不成立：裸答高分不构成「BBB 诊断题作废」的证据，反而标出了题该出在哪。**

- **五个有效模型全部呈同一形态**（不是 qwen3.7-max 一家的巧合）：易分子（tool_wrong≤1，27/40 个）裸答 78–96%，难分子（tool_wrong≥4，5/40 个）裸答 0–60%。
- **踩作废线的 qwen3.7-max 恰是「易分子集中度」最高的一个**：易分子 26/27=96.3%，难分子 1/5=20%。它的 8 个错误里 7 个落在中难分子上（中难分子只占样本 32.5%）。
- **样本里唯一的伪共识分子 z002921（7 族全票一致但全错），裸答也答错了**（p_y1=0.85，真值 0）。在「工具和谐却全错」这种本项目要抓的失败模式上，无工具知识救不了模型——诊断题的核心场景没有被裸答穿透。
- **与 D2-① 互相咬合**：α_i 占误差方差 54.5% 说「误差大头是分子难度」；本分析说「裸答能力恰好只覆盖低难度那一段」。两份独立分析指向同一结论：**有价值的样本是高 α_i 难分子，题目应聚焦到那里**（U-8 选项 B 的方向），而不是因为 0.80 作废整个端。

**本任务不改判定、不替 owner 裁**：裸答基线仍是 INCONCLUSIVE（只跑了 1/5 轮），预注册政策「须先预注册扩展再补跑」不变，U-8 三选项仍由 owner 裁。本报告是把选项 (B) 从「猜测」升级成「有落盘数据支撑」的证据。

## 做了什么

1. 只读重放 2026-09-01 已落盘的裸答 n1 答案（5 个有效模型 × 40 个 p_y1），与存档 `results.json` 逐模型核对平衡准确率（5/5 一致，qwen3.5-plus 全 null 判 invalid 不计分）。
2. 用工具侧客观难度轴 `tool_wrong`（7 族投票中与真值不一致的族数，与 D2-① α_i 同源同口径）给 40 个样本分层，算每层裸答准确率。
3. 在 40 样本内找伪共识分子（7 族全票一致但与真值相反），记录裸答是否也错过。
4. 固化为仓库脚本 + 确定性 JSON + 20 条测试（三次变异验证：阈值 `>=`→`>` 2 失败、难度轴反向 5 失败、伪共识判据放开 2 失败），全仓 `src/probe_headless/tests/` 228 passed 1 skipped 无回归。

## 这个证据怎么改变 U-8 三选项的权衡（不替 owner 裁，只摆事实）

- **对选项 (A)（预注册扩展、补跑 n2–n5）**：补跑的风险判断可以更精细。STOP 规则按**总分** ≥0.80 触发，但总分混合了难易两段；本分析显示踩线完全由易分子驱动。若 owner 选 (A)，扩展预注册里可以考虑把判定**按难度分层报告**（不改阈值，只加分层视图），避免「总分触线」把一个仍有诊断价值的题一刀切作废。**这属于改判定口径，必须由 owner 在扩展预注册里裁，我不预设。**
- **对选项 (B)（重设计题面、聚焦高 α_i 难分子）**：这是本证据直接支持的方向。难分子（tw≥4）上五个模型裸答 0–60%，伪共识分子裸答也全错——题目聚焦到这里，「不用工具就能背」这条作废路径就被数据堵死了。14 个伪共识分子（D2-① 已量出）+ 高 tool_wrong 段是现成的种子池。
- **对选项 (C)（挂起）**：挂起的代价变小了——本分析已经用零 API 回答了「0.80 意味着什么」的大部分，挂起不再意味着这个问题完全没数。
