## 结论

- family sibling 的可用性、family state 的实际变化和 action consequence 已分开计数；不能把 residual_updated 直接当作 transfer success。
- 本报告只提供机制诊断，不改变 v3 paired effect 的分母或主结果，也不打开 seed1/A800。
- 如果 sibling opportunity 足够但 action difference 仍接近 0，下一步应修正 update scale / score margin 或收窄 family-sharing claim；如果 opportunity 本身很低，则先修 benchmark slice。
