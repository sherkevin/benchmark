# 条件第二次调用 v2：结果与下一步

2026-10-08。开发诊断；不替换生效方法，不进入主稿结果表。独立核验已通过，统计解释的限制单列如下。

## 本轮回答的问题

v1 用首次输出的绝对置信度估计第二次调用价值，丢掉了答案方向，也没有显式表达拒答边界。v2 固定工具、首次选择器、终局验证器、A/B/C 划分、调用预算和训练目标，只增加方向或拒答基函数，并加上同维度的置信度多项式对照。新增列在 B 上对旧列残差化，排除复制列削弱 ridge 惩罚的混淆。协议见 [实验卡](experiment_card.md)。

**这次修复没有过线。** 完整条件优于旧条件模型的点值，但仍低于简单 cascade；不能据此说方向信息、拒答基函数或二者组合已带来可靠增益。下一步返回目标与反馈结构，不继续搜索基函数或阈值。

## 归因与统计边界

runner 保存了预登记的 10,000 次 scaffold-block 重采样及每次预算重放。完整条件相对 cascade 的历史百分位范围为 [−0.012783,+0.002458]，相对旧模型为 [−0.006500,+0.006718]；所有预定归因范围跨零。完整条件也未胜过拒答单因素的点值。

**额外发现：旧重采样把相同 scaffold 连成块，原始订单却是逐分子随机排列。** 预算控制依赖顺序，因此这些百分位数不能未经论证就作为原始随机分子流效用的 95% 置信区间。原始数字与 `ci95` 历史字段保留；当前规范解释降为 *scaffold-block 重放敏感性范围*，不是重新计算或选择了另一组结果。独立核验同时审查此问题。

构造例（非实测）：4 个样本，前 3 次不能追加、第 4 次能追加一次，所有样本都请求追加。scaffold A 有 3 个样本、追加收益均 +0.24；B 有 1 个样本、收益 −0.76。逐分子均匀排列时末位属于 B 的概率为 1/4；把 A/B 各自成块后随机排两个块，末位属于 B 的概率为 1/2。对应平均追加收益分别 −0.01 和 −0.26。仅改变排列机制就改变目标量，不能用“重跑了预算”消除这个问题。

v2 的主要升级判据已经被原始订单负差值挡住；统计解释修正不会把这次诊断改成成功，也不构成对全部方向的否定。C 曾用于提出修复；任何重采样都不能消除开发选择偏差或补出独立确认。

## 下一步为何改变训练目标的审查顺序

已知调用成本是确定量，当前实现却与未知损失改善一起回归，而且惩罚了所有截距。因此先做一个等参数、等输入的成本隔离比较：只学习损失改善，再显式减成本。它检验正则化是否造成价值阈值偏移，是后续分解估计必须具备的匹配对照。

再判断是否采用即时动作变化概率与延迟条件收益的分解。五篇最近邻的原文和合同见 [提前反馈审计](../conditional_second_call_v1/partial_feedback_literature/report.md)。临时代填、响应修正本身已有先例；后续重点是当前任务的哪些早信息有用，以及整体机制能否改善终局效用。
