## 判断先行

**下一批只检验已知成本是否应从惩罚中移出。** 当前 ridge 把净收益连同确定的调用成本一起向零收缩，确实可能制造额外调用；这与“状态是否表达充分”是不同问题。把成本放在预测之外，是必须加入的强匹配比较，不是新算法主张。先关闭这个混淆，再判断即时动作变化状态能否形成有价值的整体机制。

v2 的 signed_refusal 为 −0.19806094，confidence_cascade 为 −0.19594183；差 −0.00211911。旧报告的区间 [−0.01278270,+0.00245828] 来自会同时改变样本及顺序分布的 scaffold block 重采样，当前只按回放敏感性描述；不能视为固定原订单的 95% coverage 保证。178 次追加中 142 次动作未变。它没有通过预登记修复线；旧报告各归因区间也均跨零，不能据此建立因素有效性。不能因此继续搜 basis，也不能由这些负结果断言所有条件调用或提前学习都无用。[v2 卡](experiment_card.md) 已要求返回反馈与终止规则审查。

当前最强反对意见是：**若一个分解或提前反馈方法只比“连确定成本都被收缩”的直接回归好，其改善可能完全来自修正成本先验。即便胜过修正后的回归，也可能来自两模型乘积的容量，而非更早反馈。** 这两层解释要依次排除。

## 1. 已知成本放在训练目标里，会改变什么

记两次终局动作的损失改善为 $\Delta$，额外调用成本为 $\kappa$，净收益为 $g=\Delta-\kappa$。固定损失为答对 0、答错 1、拒答 $\rho=0.25$；当前额外调用成本 $\kappa=0.01$。首次调用成本已是决定是否追加时的共同项，不重复计入 $g$。

构造案例（非实测）：第一次拒答、第二次答 1，若 $Y=1$，损失改善 $\Delta=0.25$，净收益 $g=0.24$；若动作没有变化，则 $\Delta=0$、$g=-0.01$。后者的成本是已知常数，不需要用训练样本估计。

### 同一 ridge 下的精确差异

$X$ 的每行是调用第二工具前冻结的特征，$W$ 为样本权重对角阵；$\phi$ 为一个待评分 pair 的同型特征。定义 $H=X^\top W X+\lambda I$。当前 base 有 16 列、每个 B pair 权重 $1/3$、$\lambda=1$，所以 $H$ 为 $16\times16$。下面两种拟合必须使用完全相同的 $X,W,\lambda$：

$$
\widehat g_{net}(\phi)
=\phi^\top H^{-1}X^\top W(\Delta-\kappa\mathbf1),\qquad
\widehat g_{offset}(\phi)
=\phi^\top H^{-1}X^\top W\Delta-\kappa.
$$

构造案例（非实测）：只看某一个 pair 的截距，令有效样本权重总和为 2、平均损失改善为 $0.012$、$\lambda=1$。直接拟合净收益得到 $\widehat g_{net}=\frac23(0.012-0.01)=0.001333$，会申请追加；先拟合改善再减成本得到 $\widehat g_{offset}=\frac23\times0.012-0.01=-0.002$，会停止。同样本、同正则、同特征，边界已经改变。

用 $h(\phi)=\phi^\top H^{-1}X^\top W\mathbf1$ 表示该 ridge 对恒为 1 的目标给出的预测，则：

$$
\widehat g_{net}(\phi)-\widehat g_{offset}(\phi)
=\kappa\bigl(1-h(\phi)\bigr).
$$

在上面的构造案例里，$h=2/3$，差正好为 $0.01/3$。这不是所有 query 上都为正的定理：包含斜率、外推和共享正则时，$h$ 可能超过 1 或为负。必须逐 query 保存实际偏移，不能笼统宣布现有模型处处乐观。

本设计的前 12 列是 ordered-pair one-hot，它们相加恒为 1。令 $e$ 的前 12 维为 1、其余为 0，则 $Xe=\mathbf1$，对合法 query 也有 $\phi^\top e=1$，因此：

$$
\widehat g_{net}(\phi)-\widehat g_{offset}(\phi)
=\kappa\lambda\phi^\top H^{-1}e.
$$

构造实例：对于“先工具 0、候选工具 2”的一行，12 个 pair 列只有该位置为 1；不管置信度斜率列是什么，点乘 $e$ 都等于 1。上式表示**确定成本被所有受罚系数共同近似后，留下的正则误差**；不是第二工具带来的新信息。

v2 的新增列先对旧 $X_0$ 正交残差化，记为 $Z_\perp$。因 $\mathbf1$ 已在 $X_0$ 的列空间，$Z_\perp^\top W\mathbf1=0$；联合 Gram 在旧列与新增列之间也为零。因此同一 fold 内，**所有 v2 basis 条件的成本偏移函数完全相同，新增列系数在目标加回常数成本后不变**。这是精确算术结论，实现按既有 $10^{-8}$ 容差核对即可。

构造实例：signed_only 新增的 4 列即便恢复了符号信息，它们也不能学习恒定的 $0.01$ 目标位移，因为该常数方向已被投影到旧 16 列。无需再拟合五种表示来找哪个“成本修复更好”。

### 这不是无条件纠错定理

直接净收益 ridge 的正则先验是“未知区域的净收益接近 0”；外置成本的先验是“未知区域的损失改善接近 0，因此净收益接近 $-\kappa$”。前者并非数学上非法，但它把不调用与调用无改善混在零点附近。对确定且可直接计算的调用成本，本审查建议把它保留在学习外侧，并公开这个先验改变。

构造案例（非实测）：一个此前没见过的 pair 若所有改善系数都为 0，外置成本自然给出 $-0.01$。这不授权取消探索：为获取该 pair 的知识而付费，需要单独预登记探索概率与预算，不能依赖受罚成本制造的微小正分来“碰巧探索”。目前未支持 pair 禁止追加的规则在本次匹配检查中保持一致。

本项目不存在平移不变性，因为所有 pair 截距也被惩罚。若一个能表示常数的截距方向完全不受罚，则两种目标的结果可以相同。等价地，外置成本也可写成净收益系数围绕 $-\kappa e$ 正则，而不是围绕零；这只是同一优化问题的重参数化。不要把“加一个不受罚截距”也塞进下一批，它另改了正则几何。

## 2. 即时动作变化与延迟改善的分解能提供什么

令 $C=1$ 表示两次终局动作不同，$C=0$ 表示相同。$C$ 在真正取得第二输出并应用同一冻结验证器后可知；$\Delta$ 在 $C=0$ 时恒为 0，其余一般等真值。$\phi$ 仍只含选择前信息，候选 provider 身份包含在 pair 特征里。

构造案例（非实测）：第一次拒答、追加后答 1，立即知道 $C=1$，并立即知道损失改善只可能是 $-0.75$ 或 $0.25$；仍不知道哪个成立。$C=1$ 自身不是正收益标签。

定义 $p(\phi)=P(C=1\mid\phi)$，$m(\phi)=E[\Delta\mid\phi,C=1]$，则：

$$
E[g\mid\phi]=-\kappa+p(\phi)m(\phi).
$$

这是条件期望分解，不需要假设 $C$ 与 $\Delta$ 独立。若 $p=0$，约定乘积为 0；此时条件均值 $m$ 没有可识别的样本依据，不能声称已学会它。

构造案例（非实测）：在某类同特征 pair 中，四成会改变动作，改变后的平均改善为 $0.10$，则平均净收益为 $-0.01+0.4\times0.10=0.03$。若动作改变很多但改变后的平均改善为 $-0.10$，同样的 $p=0.4$ 得到 $-0.05$；只学“会改变”远不足以判断值得调用。

### 全部终局转换的精确目标

下表是损失定义的构造枚举，不是 v2 观察频次。拒答记为 $\bot$；表中一格为“$\Delta$；$g$”，成本固定 $0.01$。

| 追加前 $d_1$ → 追加后 $d_2$ | $C$ | 真值 $Y=0$ | 真值 $Y=1$ |
|---|---:|---|---|
| 0→0、1→1、$\bot\to\bot$ | 0 | 0；−0.01 | 0；−0.01 |
| 0→1 | 1 | −1；−1.01 | +1；+0.99 |
| 1→0 | 1 | +1；+0.99 | −1；−1.01 |
| $\bot\to0$ | 1 | +0.25；+0.24 | −0.75；−0.76 |
| $\bot\to1$ | 1 | −0.75；−0.76 | +0.25；+0.24 |
| $0\to\bot$ | 1 | −0.25；−0.26 | +0.75；+0.74 |
| $1\to\bot$ | 1 | +0.75；+0.74 | −0.25；−0.26 |

例如 $0\to\bot$ 不应自动算伤害：当真值是 1，原来答错的损失 1 变为拒答的 0.25，净改善为 0.74。把所有改变动作都记成“成功复核”会直接违背这个合同。

### 识别、样本与延迟限制

- **合法观察与目标固定。** 只有实际 paid pair 才产生 $C$。固定验证器、阈值、损失和版本；在线修改验证器后不能继续把旧 $C,\Delta$ 当同一目标。案例：同样两个输出在旧阈值下均拒答、在新阈值下由拒答改答 1，$C$ 已改变。
- **支持。** 每个要比较的 pair/上下文要有正的获取概率；$m$ 还需要足够的 $C=1$ 样本。v2 的 36 条动作改变是其 C 区实际追加事件，不能冒充 B 区条件收益训练量。当前保存的 B pair×首次动作表也不是 B 的 $C=1$ 支持表；后者必须另外合法核对。案例：某 pair 只观察到 10 个 $C=0$，可以更新 $p$，却没有任何证据估计其非零 $m$。
- **延迟。** $p$ 用每个 acquired pair 的即时 $C$ 更新，$m$ 只用 $C=1$ 且已释放真值的事件。固定 D 对所有这些事件相同，可避免“相同 acquisition 时点中因收益值不同而先到”的差别；但不能据此排除时间漂移、策略自选样本和模型失配。案例：在 $C=1$ 内，正改善还比负改善晚到，$m$ 依旧有 informative-delay 偏差。
- **获取权重。** 原始 propensity 可用于明确目标分布下的 acquisition-IPW；它不能修复 missing-label 机制或错误的 $m$。案例：用 $1/0.2=5$ 修正获取概率，并不会让未到的 +0.25 标签凭空出现。权重、clip 和探索成本都要登记。
- **函数假设。** 恒等式不要求线性，但两个拟合器的准确性要靠数据。$p$ 应在 [0,1] 内；$m$ 可正可负，拒答方向与答题翻转方向也会混合。案例：同为 $C=1$，$\bot\to1$ 与 $1\to\bot$ 的两个真值目标相反，简单池化可能掩盖方向。

### 相对直接学习损失改善的实质差别

直接 centered-$\Delta$ ridge 用所有 mature pair 的改善（含大量 0）；分解模型让所有已取得 pair 立即监督 $p$，只用改变动作的 mature pair 监督 $m$。它可能更快得知“这里不会改变动作”，也可能因 $m$ 样本锐减而方差更高。

构造案例（非实测）：100 个 paid pair 中 90 个动作不变。直接模型最终有 100 条 $\Delta$ 标签；分解模型的 gate 有 100 条即时 $C$，条件收益模型只有 10 条标签。这个交换可能有利，也可能因 10 条样本不够而更差。

同一 $\phi$ 不意味着容量匹配：若 $p,m$ 都是线性头，乘积已经引入二次项，还多一套参数和不同的正则。构造案例（非实测）：一维合法特征 $x\in[0,1]$，取 $p(x)=x,m(x)=0.2x$，乘积是 $0.2x^2$，单个线性 centered-$\Delta$ 头一般不能表示。D=0 下分解胜出也可能只是这一原因。真正检验“即时状态有价值”，后续必须在**同一分解模型、同一初始化与 paid stream**下比较即时 $C$ 与把 $C$ 人为延迟到真值时刻；不能只拿它对比当前有成本偏移的 16 维回归。

这与已核读的 [Esposito 2023](../conditional_second_call_v1/partial_feedback_literature/sources/esposito2023.pdf) 中间状态框架相邻，但本任务仍需上下文和选择支持；[Lancewicki 2021](../conditional_second_call_v1/partial_feedback_literature/sources/lancewicki2021.pdf) 解释了早到标签偏差；[Evolving FTRL](../conditional_second_call_v1/partial_feedback_literature/sources/baron2025.pdf) 已覆盖旧反馈修订。标准分解和补账本身不承担新颖性。创新目标保留在付费信息获取、提前确定的任务损失、延迟状态更新与后续可信调用之间的整体机制及其可证伪收益。

## 3. 推荐下一次唯一的决定性开发测试

**主假设：把确定成本一起向零收缩，是当前错误追加决策的一个有实际效用影响的原因。** 只做 `base_confidence` 的同特征成本隔离；不同时上分解模型、不新增 basis、不改验证器、不搜阈值或 $\lambda$，也不把这批静态检查称为 online 实验。

| 项目 | 冻结建议 |
|---|---|
| 已有对象 | 复用 v1/v2 的 A/B/C、冻结验证器、16 维 base 特征、B 权重 $1/3$、$\lambda=1$、菜单和原订单；C 仍是已查看开发数据 |
| 唯一处理 | 原来学习 $g$；处理组学习 $\Delta=g+0.01$，评分时精确减 0.01。固定 `gain>0` gate、pair 支持和同一因果 1.25 调用预算 |
| 必要比较 | 当前 net-$g$ base 是唯一机制对照；confidence_cascade、stop_only、pair_mean_gain 原样重放，合计五条策略。固定以 cascade 作最强控制参照，不逐副本重新挑 baseline |
| 执行前代数闸门 | 从 B 的 $X,W$ 求 $h$；所有 policy 可见 query 的差应符合 $0.01(1-h)$，最大绝对误差不超过 $10^{-10}$。只读 query 特征，不使用 C truth 计算这个差。若所有请求候选及 stop/call 完全相同，则同控制器轨迹应相同，这构成后续各订单 utility 差为零的可核验预测；仍按最终冻结卡完成 smoke/full 和所有 128 组排列 |
| 主指标 | 相同输入序列下，处理组与 net-$g$ base 的终局 utility/input 配对差；必须重跑 token 控制器，不能固定旧 call 集合来评估新 policy |
| 归因证据 | 保存每个 query 的 $h$、预测差、候选排序变化、0 阈值跨越；evaluator 事后标注这些变化对应动作不变、改善或伤害。不能把省下成本与转移预算后得到的改善混成同一计数 |
| 顺序敏感性 | 原订单单独报告。再按最终卡的每 fold 种子 $20261009+fold$ 生成 128 组排列：每组在各 fold 内将固定 C 分子均匀打乱，每个分子恰出现一次，所有 policy 共用同一组排列。每 fold 重置预算控制器，模型保持固定。只报告描述性均值、范围、分位数和差值符号比例；不算 population CI，不称为显著性检验，也不选有利订单 |
| 确定停止 | 若代数对账失败，先修实现，不解读效果；若 query 请求逐项相同，成本收缩在此协议下不解释行为失败；若实际 utility 不改善，不再调成本、阈值或正则追胜 |
| 可证伪读数 | 原订单中，处理组相对 net-$g$ base 的实际配对差不大于 0，则这条流不支持效用修复。若不胜 cascade 的原订单点值，或 128 组排列多数不胜 cascade，则按最终卡不升级为有希望的解决方案。它们是开发停止判据，不是总体显著性/等效性检验 |
| 推进边界 | 若只赢原 net-$g$ base，结论限于这条开发流的成本处理改善；同时报告与固定 cascade 之差。即使原订单和多数副本都胜出，也只登记开发信号，不打开旧 CI gate 或科学 gate。无论结果如何，都不把成本恒等式申报成原创机制 |

构造判据案例（非实测）：若所有 query 的预测只降 $0.0002$，但仍为同一候选且 gate 不变，utility 差严格为零；最终卡保留的全部排列应验证这个预期，不是用来寻找有利例外。若少了一个不改变动作的调用，眼前节省 0.01，但它释放的预算可能改变后续调用，故必须完整重放而不能只加 0.01 到旧汇总。

顺序协议的执行前注意事项：每个 replica 必须以分子为单位、在原 fold 内排列，不能把同分子的多个候选 pair 当独立到达；聚合使用固定分母 722，不能按调用数加权。原订单不能混入随机 128 组当作另一个随机样本。若“均匀排列”只改变 fold 顺序或 scaffold 次序，它与这里的分子排列目标不同，必须在开跑前裁定；不能用事后挑选的排列决定是否保留修复。

这批以现有快照和线性方程即可完成；不需要新增 provider/API/GPU 或 confirmation。它是分解/提前反馈比较之前的对照修复。后续机制仍围绕原来的可信工具调用与实时学习目标推进，是否保留即时状态分解由合法支持、同模型的时序消融和实际 utility 决定。
