# 终局验证器信息价值：独立审查

2026-10-08。只读审查 [理论候选](verification_value_review.md)、现有实现和既有近邻；仅写本文件。没有运行诊断、重拟合、修改方法、runner 或论文。

## 结论

**数学成立；现有 masked-logistic 有未约束的概率一致性问题，但尚未发现它在本数据上实际失效，更没有定位为追加失败根因。值得保留一次很小的 B-only 诊断；当前先完成 arrival，不并行更换验证器。** 诊断的作用是决定下一张卡先检查终局融合，还是继续价值估计/反馈时序；不能直接授权新的联合模型。

## 1. 风险、tower 与 Jensen：通过

答 0、答 1、拒答的条件损失分别是 $q,1-q,\rho$，故 $R(q)=\min(q,1-q,\rho)$ 正确，且作为仿射函数的最小值为凹函数。只要两次概率对应同一联合分布、嵌套的信息集合及同一损失/可选动作集，就有 $\mathbb E[q'\mid E]=q$，从而 $R(q)-\mathbb E[R(q')\mid E]\geq0$。构造实例：$q=.5$、后验等概率取 .1/.9，风险从 .25 降到 .1；扣 .01 成本后净值 .14。无需工具条件独立。

此结论要求**取得输出后仍可选原动作**，且使用真实条件概率下的最优动作。固定拟合规则可能错误地利用信息。候选中“无信息的第二输出把拟合分数 .9 推成 .1”的反例有效；它说明规则可受损，不证明现有数据中发生了这种误差。调用净收益仍可能因成本为负，即使信息的期望毛价值非负。

单样本 harm 不能反证后验一致性。构造一个完全一致的实例（非实测）：调用前 $q=.9$；第二输出以概率 .1 产生 $q'=.1$，以概率 .9 产生 $q'=89/90$。后验均值仍是 .9，最优期望风险从 .1 降为 .02；但在第一种分支且 $Y=1$ 时，原答 1 正确、新答 0 错误，该事件概率为 .01。故必须比较适当条件下的平均损失，不能用 harm 条数定性。

即使真实后验有变化，信息价值也可以为零：构造 $q=.5$，后验等概率为 .4/.6，均落在拒答区间，风险始终 .25。动作不变可能是损失阈值的正确结果；不能自动归咎验证器无能力。上述结论都是标准 Bayes 决策论，不承担创新主张。

## 2. 代码中存在什么缺口，以及竞争解释

[可见特征](/Users/jingwu/work/benchmark/src/probe_headless/run_conditional_second_call_v1.py:71)是四个 provider mask 加四个 masked native logit；[拟合](/Users/jingwu/work/benchmark/src/probe_headless/run_conditional_second_call_v1.py:155)用 A 的每分子十个集合、每行权重 .1，共享九个 logistic 参数。目标没有拟合第二输出的条件分布，也没有施加跨 mask 边缘化约束。因此“共享系数”不保证 tower；但在合适的数据分布下，该形式也可以表示一致后验，不能先验宣布不一致。

**另有选择条件转移，必须保留为竞争解释。** A 中每个分子均匀展开四个 singleton 和六个 pair；[B 标签生成](/Users/jingwu/work/benchmark/src/probe_headless/run_conditional_second_call_v1.py:323)先由分子特征上的冻结 selector 决定首次 provider，再只展开包含该 provider 的三个候选 pair。因此在 B 的“首次选 a”子集里，真值与输出的条件分布可能不同于 A 的“人为显示 a”训练分布。验证器没有显式输入该 selector 的分子特征或分数。

构造例（非实测）：相同工具输出 .5 的完整群体阳性率为 .5；selector 利用分子特征只在阳性率 .9 的一个子群选它。对全群体校准的 .5，在首次选中子群里会偏低。这可由选择条件造成，即使全群体上的各 mask 概率一致。因此 Brier、校准或风险变差不能唯一归因为“跨 mask 不一致”；有限样本、正则、模型失配和选择条件转移都需保留。理论中的 $E$ 必须明确包含什么选择事件与合法先验信息，两次条件概率必须使用同一口径。

## 3. B-only 诊断的最小有用范围（尚未执行）

直接复用已存 [B_paired_targets.jsonl](/Users/jingwu/work/benchmark/experiments/logs/task49_conditional_second_call_20261008/full_v1/B_paired_targets.jsonl) 与 A-only 冻结系数；不需要再拟合验证器。诊断卡只需固定以下三项，不能把它变成模型搜索：

1. **真实损失与成本分开。** 记录毛改善 $\Delta=\ell(d_1,Y)-\ell(d_2,Y)=g+.01$ 和净收益 $g$。构造例：两次均拒答时 $\Delta=0,g=-.01$；这不是负信息价值。比较所有 B 已展开候选，明确其目标是“冻结首次选择后，三个候选等权”的离线面板；不是当前 acquisition policy 的已调用分布。
2. **概率质量与真实决策效果同时看。** 比较单输出/双输出的 Brier、预测减真值的校准残差及真实终局损失；模型内部 $R(\widehat q)$ 只作辅助。预先固定 ordered pair 和首次动作 0/拒答/1 分组，报告各组独立分子数、动作改变数、损失改善/伤害。不得看结果后选择阈值、合并分组或重新校准。
3. **把 tower 检查降为必要矩检查。** 对上述预定的调用前分组比较平均 $\widehat q_{pair}-\widehat q_{single}$，可发现候选一致性的偏离信号，但零均值不证明逐条件 tower。构造例：两个等重子组的差分别为 +.1 和 −.1，整体均值为零仍隐藏条件偏差。该均差也等于两套分数平均校准残差之差，不能当两份独立证据。

每个 B 分子的三个 pair 总权重保持 1；同分子跨 fold 的重复记录也应保留关联，不能将 1,518 行当 1,518 个独立样本。A/B 在各 fold 内隔离并不意味着跨 fold 的训练/验证记录彼此独立。这个已查看开发集上的小诊断先报告支持量与按 fold 的描述性读数；若要作置信判断，须另写与重复/训练依赖匹配的统计合同，不能沿用旧重排 bootstrap。

## 4. 它如何改变下一步，而不扩大提案

| B-only 可能出现的读数（均尚未观察） | 可采取的下一步 | 不能据此声称 |
|---|---|---|
| 有支持的固定分组中，双输出真实风险变差，且概率误差也变差 | 单独冻结一张终局融合诊断卡，保留“忽略第二输出、沿用首动作”作控制；进一步区分选择条件与融合失配，再决定是否需新验证器 | 已证明唯一根因是 mask 不一致；联合模型必然更好 |
| 概率明显变化但大多仍在同一动作区，毛改善接近零 | 把重点放在跨阈值概率及其样本支持；不直接增加验证器复杂度 | 第二工具没有信息；动作变化必有收益 |
| 双输出概率/真实损失未见明显退化，而条件 gain 仍无法排序 | 保留冻结终局规则，继续审价值估计、候选支持及同模型即时/延迟状态比较 | 已证明后验一致，或已证明提前状态会有收益 |
| 分组太稀疏、跨 fold 方向不稳定、解释无法区分 | 记录为未识别，停止这条诊断的扩展，不按 B 追调模型 | 无显著差异等于验证器正确 |

这些读数只改变开发优先级，不直接提升方法或覆盖全部解释。尤其不能因为 Bayes 毛信息价值非负，就裁掉实际负 $\Delta$ 标签或强迫追加：现有 gain 的目标是**固定规则的真实效用**，负标签合法。

[Cascade Routing 同任务合同](../conditional_second_call_v1/nearest_contract.md)中的预期固定规则损失下降减成本关系，无需验证器等于真实后验，仍然成立。[已有 partial-feedback 审计](../conditional_second_call_v1/partial_feedback_literature/report.md)中的同动作精确早标签也只依赖冻结动作与损失相消，不依赖校准；验证器疑问不推翻它。MetaBIO 的状态损失、evolving feedback 的修订以及延迟补账，都不能自动修复错误终局融合。因此本检查有明确的分流用途，但不能替代合法的即时/延迟比较，也不构成一个新的 baseline 名称。

**最终建议：保留候选，下一张 B-only 诊断卡有价值；现在不运行、不改验证器，优先完成已冻结 arrival 实验。** 可直接复用的资产是现有 B 的双分数/双动作/双损失记录、A-only 系数和固定分组；无需新 API、provider 推理、GPU 或文献大搜。
