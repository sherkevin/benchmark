# B-only 融合诊断：对完整目标的优先级核查

## 判断：值得做一次，但用途必须止于选择下一项干预

**建议冻结修订后的卡，执行一次有界 B-only 诊断。** 它对完整目标有实质价值，因为当前缺的不是再证明回执可恢复，而是让第二次调用真正改善最终答案/拒答的净效用。现有失败同时混有“选择哪个第二工具”和“如何利用已取得输出”两部分；继续只改 gain 特征，可能一直在修错误的环节。

这次诊断的收益是减少一次无依据的模型改造：在相同冻结模型和 B 记录上，把选择条件、终局融合、动作阈值和价值预测的竞争解释分开，按卡内规则决定下一张干预卡。它不直接证明根因，不贡献新有效模型，也不能关闭任何完整效果主张。若最后是低支持或未识别，停止这批 B 上的诊断扩展也是有用结果。

修订卡已落实独立审查的两个关键条件：S/U 比较使用同一 `(fold,a,b,d1)`；第二分支没有模糊的兜底条件。卡内 `≤2 分钟 / ≤1 GiB / ≤50 MiB`、零拟合/采样/provider/API/GPU、显式文件白名单足以约束这一步。无需先做另一轮大调研或更换 backbone。

## 剩余三个关键科学缺口

### 1. 取得第二份证据，尚未形成胜过强简单策略的净价值

**对应标准：** 故事 `H4/H5、S3/S4/S6`；方法 `H4/H6、M5/M8/M13`；Benchmark `H7、Gate B 的 B2–B4、Gate C 的 C1–C3、B9/B12/B14、R3`。

**已有证据：** v2 的完整方向/拒答条件效用为 −0.19806，cascade 为 −0.19594；178 次追加中 142 次终局动作不变。成本隔离在随机订单上仍多数输给 cascade。相反，主稿静态拒答相对 always-accept 的效用有 +0.0338 secondary 信号，说明“会拒答”与“会花钱取得有用的新证据”是两件尚未连通的能力。不能把任何一个正数当作整个链条已成立。

**B-only 能推进什么：** 按已冻结的支持/方向谓词，选择先改训练展示分布、只改终局融合、或保持验证器研究动作变化/价值预测。它必须区分毛改善 `Δ`、净收益 `g=Δ−κ`、已付费后 ignore-second 和调用前 stop；动作不变本身不是融合失效。

**什么结果才能关闭：** 下一张卡只改上述一个环节，冻结终局损失、首选、可见字段与调用预算；在适当隔离的评价上，完整策略的效用达到事前规定的实际收益门槛，并胜过最强合法控制。已有 v2 的开发门槛是 `+0.01 utility/题` 且有效配对不确定性下界大于零；不能为新候选事后降低它，也不能继续使用已被指出到达机制不匹配的旧 block CI。必须同时报告错误、拒答、调用数、救回/损害和无用追加。

最低对照包括 stop、同预算 confidence cascade、去掉新环节的 matched control，以及保真的输出条件 CR 对照。`CR-utility` 与同估计器/同终局规则下的 G 决策等价时只计一行；不能通过换名增加 baseline。开发越线只是进入下一阶段的依据，独立确认另见缺口 3。

### 2. 实时学习对完整证据决策的独立增益与机制必要性还没有证明

**对应标准：** 故事 `H3/H4、S4/S5`；方法 `H4/H5/H6/H9、M5/M6/M8/M9/M10/M11/M12`；Benchmark `Gate B、Gate C、B7/B8/B10/B12、R5`。

**已有证据：** 一次调用的 source-aligned 更新有受控恢复与 permutation 消融支持，arrival 已补统计合同；这不是空白。自然 pooled 负差也是真实边界。对后续证据决策，OCL 已有付费标签与在线 gate，CR 已有输出条件质量/成本决策；因此“加第二次调用”“加在线更新”本身不能完成整体机制的近邻区分。当前静态拒答和静态 gain 结果都不能证明延迟学习的附加价值。

**什么结果才能关闭：** 在缺口 1 确定的同一终局规则/价值模型上，先用同一已取得 pair 流、同初始化，单独比较新反馈/状态机制与 matched delayed/online/replay 更新；再在同调用预算的闭环中验证终局效用增益。动作变化的即时标签只能来自已付费取得的 pair，不能用缓存的未选输出补标签。`D=0/1/4`、propensity/探索权限、负差与反馈支持必须完整记录。若两种释放规则在零延迟下本应等价，应作为数值控制保留。

这个比较必须回答“删掉新增状态或改变释放时序后，哪一种可观测决策收益消失”，并与已有 partial/evolving-feedback、CR/OCL 的实际信息合同对照；不能以 Brier 下降或某个 gate 打开代替任务收益。实际最小增益应在执行卡中先固定；arrival 的 `>0` 方向检验不自动成为完整方法的实际价值门槛。

“高效实时”还有一个具体硬缺口：主稿目前测的是局部 policy p95，明确没有 live learner memory。下一个真正主矩阵应一起记录 score/update 的 p50/p95、encoder/queue/serialization、pending/快照内存、冷启动和硬件；与 matched updater 同口径比较。arrival 进程总 RSS 不能替代在线模块内存。无需为了这一项另造数据集或先开昂贵训练。

### 3. 新完整候选需要自己的 benchmark/baseline 资格和未用于选择的确认

**对应标准：** 故事 `H6/H8、S11`；方法 `H8、M12/M15`；Benchmark `H3/H6/H7/H8/H9、Gate A 的 A3/A4、Gate B、B3/B4/B13/B15、E6`。

**已有证据：** 公共 TDC truth 与项目 routing layer 已区分，四-provider 切片有 checkpoint/lineage、合法反馈和 matched 基线证据，不应重新无边界地寻找“更权威 benchmark”。但 157 分子现已查看，arrival 是该集合的回顾性稳健性；B 是逐 fold 的开发口径且跨 fold 有实体重用，不能因不读 C 就称新 holdout。序列复核的最近邻原文/合同已经有材料，保真实现和对应闭环结果尚待完成。

**什么结果才能关闭：** 先冻结完整候选、成本/拒答损失、所有对照、实际收益门槛和有意义的统计单位，再审计一个未用于当前候选选择的确认 manifest。分别记录分子/scaffold 隔离与 provider 训练暴露；若无合格未读数据，就明确此阶段被资格阻挡，不能重用 157 或旧 B/C 重新命名。确认时所有预定基线完整运行、独立恢复，负结果照报，达成缺口 1/2 的预定主比较后才提升对应主张。

BBB 上新的合法确认可以关闭 BBB 范围内的完整闭环主张；若要主张跨端点或自然生命周期适应，仍需 hERG/AMES 的独立语义/lineage 资格或真实版本事件证据。它们不强加给现有一次调用切片，也不会从长期目标中消失。无需把 PILOT/GraphRouter 或更多数据集仅为凑数量塞进当前矩阵。

## 下一步顺序与停止无用功的条件

1. **现在只做一次修订后的 B-only 描述诊断。** 先绑定白名单/hash 和卡，逐项执行完整分支规则；不选择 B 上最优 gain 模型，不新拟合、不增设阈值。唯一产出应是“下一项先干预哪里及其依据”，或者“支持不足/未识别”。
2. **只有预定分支得到支持，才冻结一张单因素干预卡。** 不同时换 backbone、融合器、gain learner 和反馈机制；不把诊断直接升级为采用联合模型的结论。现有模型和真实输出缓存直接复用。
3. **没有分支触发就停止扩展这批 B。** 分组稀疏、fold 方向冲突或只有成本导致净负时，不降支持门槛、不合并到有利子组、不再搜索 basis。转向一项已经有清晰合同的同模型时序比较，或解决新的合法评价支持；二者均需自己的冻结卡。
4. **若新干预只改善概率拟合，未改善正确终局动作与净效用，停该候选。** 若只赢弱控制或靠更多调用取胜，先补公平近邻/预算，不继续放大训练。若诊断脚本/复核持续膨胀超过其固定资源预算，保留 incomplete 并缩回问题本身，不为“诊断完备”新建平台。
5. **不重复已有关闭项。** 不再重跑 arrival 来追更漂亮的正数，不对其多分子 scaffold 负贡献删样本或调旧确认参数，不把排版/哈希整理当作科学进展。八页主版已有，当前最高价值工作回到证据决策与实时增益。
