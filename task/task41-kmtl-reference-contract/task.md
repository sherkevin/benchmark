# Task41 — KMTL固定工具核参考实现与反馈接线

> 状态：已完成（固定核参考实现与人工fixture验收）；不代表医药有效性或官方轨迹fidelity。

## 科学目的

Task40已将“相关→联合估计→UCB”判为被最近邻覆盖。把最直接的KMTL参考变成可执行、能核对方程的信息合同，防止后续用弱化基线制造新颖性。不是新增Ours，也不是重新扩benchmark。

## 方法与范围

逐式对照Deshmukh等NeurIPS2017 Eq(2)/(3)/(4)、Algorithm1，实现固定PSD工具核×线性context核的小批参考。逐工具次数变化时重新计算全部历史权重；明确全局N缩放和未见臂初始化两处论文表述差异，提供显式选项，不暗中选有利口径。

实现不加载真实预测缓存、不接LLM API、不学工具核B；输入为调用者明确给出的固定B、context、合法已观测反馈。Task36适配只在整题终止后导入真实被调用工具的反馈；失败None不当0；拒绝未调用/重复/跨题反馈及不合法数组。

## 验收

固定人工小矩阵中，逐个历史前缀核对primal/dual预测与宽度；测试次数变化导致旧权重重算、零历史/秩亏核/无共享特例、无效输入原子性、预测不修改状态。用Task36实际类加人工cache验证终止前不更新，全部调用后仍无即时反馈，失败和重复结算保持合法。

测试结果逐字节可复验，不使用真实医药分子/标签拟合。明确只完成方程层和人工fixture对等，不宣称官方实现轨迹fidelity或医药有效性。代码/测试/report/verification落盘，Task38裁定与其他保护文件不变。
