# 固定工具核参考：与原文一致到哪一层？

一手依据：Deshmukh/Dogan/Scott，NeurIPS2017，*Multi-Task Learning for Contextual Bandits*，官方PDF第3–5页，式(2)–(4)及Algorithm1。2026-09-23重新核读正文并截图确认第4页排版；来源链接与哈希见Task40来源索引。

## 1. 原文到实现的逐项对应

| 原文对象 | 本次实现 | 不能省略的条件 |
|---|---|---|
| 工具核×上下文核 | 固定PSD矩阵B乘线性内积 | 没有训练B，不声称完成§3.2核估计 |
| η的每工具次数权重 | `weighting=per_arm_mean` | 新观察改变同臂全部旧观察权重，不能仅追加一次rank-one统计 |
| 式(3)和式(4) | 对称等价系统M=K+λW^{-1}，解均值及几何宽度 | 参数缩放显式；不是通用概率置信区间 |
| 未观察臂的特殊处理 | `cold_start`必须调用方指定 | 原文初始段与式(4)缩放有歧义，不能默选有利版本 |
| 单次选择后的奖励 | 核心observe由终止适配器调用 | 当前适配器只允许单调用，不偷偷把多调用变成立即反馈 |

固定B且权重相同的方程等价已通过独立primal求解逐前缀核对；没有执行作者官方代码，不宣称官方动作轨迹fidelity。此处是可读的小批方程参考，求解为O(n³)，不是大规模优化实现。

## 2. 三处会使基线被偷偷改弱的细节

第一，按工具次数归一化与普通累计Ridge不是同一算法。对同一臂重复完全相同的样本，平均损失本身不变；在λ不变时，本参考的预测与宽度不变，而累计损失版本的宽度会收缩。因此B=I只是独立的加权估计，不能不加限定地称“恰为标准固定λ LinUCB”。此差异用人工反例测试，不拿它宣称原论文无效。

第二，式(2)损失带全局1/N，而式(3)η按正文定义仅1/n_a。匹配两者须吸收正则比例：λ式3=N·λ式2。本代码让loss_scale显式选1或1/N；改变损失与λ共同尺度时均值不变，几何宽度与β还须一致缩放才能保持动作得分。测试覆盖该换算，不以含混的“λ=1”假装相同。

第三，式(4)宽度含λ^{-1/2}，第4页未见臂段落文字只写sqrt(kdiag)。`shared`沿联合核方程向未见臂迁移；`paper_zero_eq4`按原文零均值、零扣除项但保留式(4)缩放；`paper_literal`按该段字面sqrt(kdiag)。三个均具名，正式实验前需预登记一种及敏感性处理，不看医药结果再选。

## 3. 反馈与失败边界

适配器只接受自己选定的provider、同一episode对象、同entity_id、一次真实调用以及终止后的Task36格式反馈。未调用奖励、额外行、非法数值、重复结算和多调用协议均拒绝。合法有效正确性要求整数0/1；失败保持None、不添加观察，未裁真值保持unscorable。模型核心支持一般[0,1]收益，但不能借此放松判分器的二值正确性合同。

这些检查依赖可信trainer/evaluator，不是对恶意判分器的认证。不能阻止拥有宿主权限的人伪造同格式正确性；没有OS沙箱。跨episode重放同分子、分子/骨架划分、训练确认集隔离仍由未来运行器与P02保证。API检查不替代这些条件。

当前对象只估计有效调用的正确性。若系统要优化包含失败的成功且正确率，需要另外规定可用性/失败收益，不能把这个参考直接称为对所有失败已最优的系统。源码没有改Task36的None或奖励定义。
