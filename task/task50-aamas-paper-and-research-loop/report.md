## AAMAS 对齐

已核读官方主轨征稿、投稿说明和 reviewer guidelines，原页与哈希保存在 [模板来源目录](../../paper/aamas2027/reference/sources.json)。官方要求的相关性、原创性、重要性、可靠性、可复现性与清晰度，转成当前项目的六个问题：

| 审查问题 | 我们必须交出的证据 |
| --- | --- |
| 为什么属于智能体学习？ | 每轮主动选工具，只有所选动作的反馈；更新改变后续选择。比较完整策略的累计错误和适应过程 |
| 新方法在哪里？ | 与 PILOT/BayesianRouter 的具体算法差异及假设；标准闭式递推不重新命名为创新 |
| benchmark 能说明什么？ | 独立实验真值、可比端点、上游训练曝光、开发与最终确认边界 |
| 对照是否有竞争力且公平？ | 原论文到本任务的适配记录；相同初始标签、反馈、预算和 backbone 机制对照 |
| 能否解释效果来源？ | 预训练表示、在线更新和候选机制分别消融；同时量错误和完整计算成本 |
| 结果能否复核？ | 逐样本日志、版本、固定划分、失败记录；核心证据在主文可理解 |

LEARN 官方明确包含单智能体学习和适应，因此本任务不必人为增加多智能体设定。领域选择暂以 LEARN 为候选；最终选择要与实际贡献相符。该判断来自征稿领域定义，不意味着具备论文接收保证。

官方模板已下载到 `paper/aamas2027/reference/`，题目与摘要源码在 `paper/aamas2027/main.tex` 和 `abstract.tex`。当前是内部问题与方案草稿，尚无实验结论。

## 2026-09-26 更正：指纹诊断已完成

上面的执行边界对应论文草稿建立时点。随后按 Task49 指纹实验卡完成了一条真实 A800 诊断：40 个 fit、5,776 条 outer evaluation 和 40 个 checkpoint 全部通过独立恢复。结果为负：Best Fixed `0.9155`，MLP `0.8961/0.8906`，BT+CLS `0.8878/0.8947`；因此摘要仍不写方法收益，论文主表也不回填这批 development 数字。

这条结果改变了方法顺序：当前先验证 calibrated switch 能否控制“离开强固定 provider”的损害，再比较 selected-only 在线更新。只有普通切换不能解释收益时，才把 Laya 或新的动态表示更新升为方法候选。完整证据与范围见 [Task49 指纹报告](../task/task49-pharma-benchmark-baseline-freeze/fingerprint_diagnostic_v1/report.md)。

calibrated switch 的后续分析也已完成：MLP seed 0/1 的 outer accuracy 为 `0.8947/0.9100`，10 个 outer fold 均未超过 Best Fixed `0.9155`。因此下一轮可以合理地进入 Laya 表示和 selected-only 在线 baseline，不再继续在 Morgan 指纹上调阈值。
