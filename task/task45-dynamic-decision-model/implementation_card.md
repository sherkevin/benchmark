# Task45 第一版适配卡：预训练选择先验与在线收益头

日期：2026-09-23。状态：作者侧可实现候选；未运行、未冻结实验超参数、未获当前科学模型池训练授权。与[研究报告](report.md)配套。

## 要检验的主张

固定主Agent与实际反馈流时，预训练判别表示/先验能否改善同功能工具选择的早期效果，在线更新能否进一步降低后续错误。
第一版是可复用结构的组合，不以新算法命名。正式近邻为PILOT与BayesianRouter，另有NeuralLinear；新增机制须通过这组强对照。
冷启动主条件是不使用当前具体工具在目标分布上的已标注效果；有此类历史的版本单列warm start。两种结果不合并。

## 冻结输入与表征

- 输入为当前分子/功能、具名工具卡，以及调用前已知的真实历史；不读未调用输出、当前真值或测试集统计。
- 固定Laya权重、tokenizer、类型、模板、截断规则与全部预训练表征层；选择菜单及排列一并记录。
- 在 `DecisionModel.forward` 增加只读输出，取最终scorer前的候选marker向量；原接口只返回logits，不能假称已有embedding API。
- 每个marker向量做固定L2归一化并附常数项，得到特征 `phi_a`。它依赖整份菜单，不能跨不同菜单直接复用缓存。
- 原始Choice输出记为 `p0(a)`，仅作策略先验。记录其温度及截断，不把它当收益概率或后验置信度。先验完全无领域证据时保持有限权重。
- 先做token审计：版本/训练域等区分性字段若被截没，应修订模板或小池协议；不能在测试集上挑保留哪些字段。

## 真正在线更新的参数

两个共享logistic头：`v_a = sigmoid(w_v · phi_a)`、`c_a = sigmoid(w_c · phi_a)`。
分别表示有效返回概率和有效返回条件下的正确概率，选择收益为 `q_a = v_a * c_a`。
无合法历史标签时两个权重向量均为零，所有候选初始收益相同；不能把Choice概率写进正确率头当标签。
两个头跨候选共享统计，泛化取决于表征是否含有效信息；这正是待测假设。

## 实际采样分布

```text
b_t(a) = softmax_a(q_a / tau)
gamma_t = gamma_max * kappa / (kappa + n_truth)
pi_t(a) = (1-epsilon) * [gamma_t*p0(a) + (1-gamma_t)*b_t(a)] + epsilon/K
a_t ~ Categorical(pi_t)
```

`n_truth`仅计已到达且被更新的合法正确性反馈；`K`是当前可选工具数。
首批工程建议值为 `epsilon=0.1, gamma_max=0.5, kappa=32, tau=0.1`，全部是待审超参数，不是理论或经验最优值。只允许在独立源数据/开发划分定值，并在开测试前冻结。
该公式给每个候选至少 `epsilon/K` 的机会；未验证先验不能占满策略。衰减只是一条简单日程，不称为已证明的先验可信度学习。
实际执行前做mask后，重新归一化并记录最终 `pi_t(a_t)`；不把 `p0(a_t)`当行为概率。第一版使用随机探索，不伪称具有Bayesian后验区间。

## 反馈与更新时钟

1. 选择时存 `episode_id / request_id / provider_version / menu / phi / p0 / pi / policy_version`，即时返回真实工具输出。
2. 一题内参数快照保持不变，主Agent自行请求复核或停止；真值不可提前泄露给主Agent或学习器。
3. 整题结束后，实际调用失败则只以 `valid=0`更新有效率头；有效返回以 `valid=1`更新该头。
4. 有效返回且经核验的真实标签已到达时，以 `correct∈{0,1}`更新正确率头；未知时入pending队列，不当成0。反馈延迟按实际到达时刻记录。
5. 每条允许的头标签仅消费一次。使用二元交叉熵作一次SGD更新；学习率建议0.05、L2建议0.0001，须与其余参数一起审查冻结。
6. 所有未调用工具的当题标签保持未知。在线拟合所选记录无需凭空给其他工具负标签；做跨策略评价/总体风险估计时另处理选择偏差和支持问题。

这让外挂读出头真的随反馈改变。预训练表示保持冻结；若以后更新adapter/编码器，须另定缓存特征、历史梯度及后验统计的处置方案。

## 与第二次调用的连接

本卡先把首请求闭环钉清，未将二次调用偷换成相同的独立正确率目标。
主Agent再次请求时，Task44定义的状态加入首个具名工具及真实返回，目标换为追加证据对固定参考决策的补益。
该头的训练需要同题成对调用及合法真值；仅有单调用记录不能补出这种收益。二次策略、目标与候选mask另行冻结，主Agent复核/停止职能保留。

## 最小对照与否定条件

| 对照 | 隔离什么 |
|---|---|
| 固定最佳合法训练工具、直接性质预测器 | 选工具相对简单解决问题方式的价值 |
| 静态Laya；冻结相同起点在线头 | 实际反馈更新的作用 |
| 关闭 `gamma`；普通分子特征替换Laya特征 | 选择先验与预训练表示各自的作用 |
| 同信息PILOT、BayesianRouter适配 | 是否超过已有预训练＋在线路由方案 |
| 固定先验权重、预登记的先验衰减、后续候选可信度学习 | 先验错误时恢复机制的作用 |

需同时报告累计/后期错误、实际反馈数、失败、调用量和新增推理/更新开销；固定Agent和其余信息权限。
