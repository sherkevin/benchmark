修复提案：从具体模型条件选择走到有价值的复核

2026-09-23 作者侧研究建议；不是 Owner 已确认的论文主张、已批准协议或已完成实验。文中 [1]–[15] 均为一手发表页/原文，完整书目见末尾。仓内数字只描述已探索的 BBB 候选池。

Executive Summary｜执行摘要

当前已明确的首要研究能力是：针对输入，在同功能的具体模型/版本中选得更准确；更大的科学问题是主 Agent 如何在这些可能出错的返回上决定取证、复核、作答或弃答。修复应先检验具体模型的条件选择确实可学，再问已见一个结果后，哪个具体模型能改善最终判断。第一次调用的条件准确率与后续调用的证据价值不是同一目标。主 Agent 决定请求哪种功能、是否复核、作答或弃答；工具管理器把功能 key 落到具体模型。BBB 单功能实验只能检验其中的复核与停止，不能宣称已验证跨功能或跨领域泛化。首个试点限定至多两次调用，避免在只有成对观测时虚构第三次调用价值。

经过近邻审查，不能把“序列调用＋相关错误＋成本＋弃答”称为原创：Gao–Koller 2011 已按既有输出的条件信息价值动态调用分类器 [1]；Cascade Routing 2025、Kelly 等 2025、ECED 2017 和早期级联也覆盖大块问题 [2], [3], [4], [5]。本报告建议把后续调用的候选研究问题收窄为：当推断时只有被调模型可见、且只在有实验真值的题目终止后才能得到正确性反馈，能否用合法观察学到“下一次调用对最终错误的可实现边际收益”，并让受训 Agent 使用它？ 这是一项可能改变现有方法重点的作者建议，未获 Owner 确认，也不是已证新算法。调用数是资源，不预设实际金钱成本。若同信息适配的 Gao/Kelly/Cascade 或直接 x→y 预测器追平，应撤回方法创新说法。

现有 722 个 BBB 候选分子与 33 个具体输出已经被全表分析；具体粒度审计中的完整面板 652 个里，最好固定具体模型答对 607 个，事后 45 个错例里 43 个有别的具体模型答对，但这不是可实现救回率。七家族共同错 14 个，33 个具体输出全部错仅 2 个，不能把 14 当作当前具体动作空间的伪共识样本数。更关键的是，Task38资格表中 29 个模型只核实发布身份而外部测试资格仍为 UNKNOWN、4 个未审；Owner裁定明确禁止当前池开训。Task42 的 128 题提案也未批准；它只适合探索，不足以证明少见共同错误。现阶段不能把此方案写成已准备好的 AAMAS 主轨论文。

Introduction｜问题与背景

Owner 指定的阶段汇报将总问题定为：当科学工具正常返回却可能给错证据时，主 Agent 是否知道何时取证、复核、作答或弃答。2026-09-22 更新的目标同时要求把“针对输入选择更准确的具体模型”作为首要研究能力。两项能力应在同一条最终判断链上检验。当前成果证明了真实工具分歧与错误互补的存在，尚未证明 Agent 会识别错误或复核具有净收益。

Main Analysis 1｜第一原则与需删去的旧主张

目标不是“多找几个同意的工具”，而是在给定真实可见证据时最小化最终错误、弃答和调用的代价。来源相近的两个模型都答 1，不等于拿到了两份独立证据。Task40 的反例中，三个准确率均为 3/4 的克隆都答 1，真实后验仍只有 3/4；按独立证据相乘却会误报为 27/28。只观察单次调用的正确性，不能无假设学到两个模型的联合错误结构。共同分子难度、给定分子特征后的残余依赖，以及估计器的不确定性必须分开。

因此删去三类承诺：不说 Agent 能从一致输出本身“识破”全部共同错误；不把 43 个事后可救错例当策略可救回的样本；不把固定工具核、图共享、价值信息、相关融合或弃答重命名为 Ours。KMTL-UCB 已覆盖固定任务核下的条件能力共享 [15]；Gao–Koller 已直接提出序列分类器的价值计算 [1]；相关分类器融合也已有成熟模型 [7–8]。我们的能力只能靠未见分子上的实际作答轨迹证明。

3. 候选方法 v0：两层决策、一份合法信息合同

一题输入为分子结构 x、允许的功能 key 与调用上限。主 Agent 的主实验状态只含 x、已调用模型的身份/返回值/失败状态、剩余调用次数；风险摘要若加入，必须作为单独消融，不能替代 Agent 要学的判断。它可请求 BBB_prediction、作答 0/1 或弃答；不能看本题真值、未调用模型输出、全表正确率排名。工具管理器的动作始终是一个具名 provider/version，来源家族仅作统计收缩，不替换具体动作。每次真实调用都计数，失败不从任务分母删掉。BBB 只有一个功能 key，暂不检验“请求哪类功能”的能力。

先学 q_a(x)=P(模型 a 有效且正确 | x)，用固定工具、独立 LinUCB 与 Task40 的 KMTL 参考检验“针对输入选更准确的具体模型”是否可学。某个模型单独准确，不代表它在 Agent 已见一个结果后仍有复核价值。完整策略令 s=(x, 已见结果, 剩余预算)，由训练区校准的 d(s) 在答 0/1/弃答中选期望损失最小的终端动作；下一具体模型的目标为

va(s) = 𝔼[ℓ(d(s), Y) − ℓ(d(s ∪ {a, Za}), Y) ∣ s] − λcall.

研究顺序上，q_a(x) 是首道独立判据：若合法的条件选择还不如固定工具或标准 Bandit，就先撤回“选得更准”的论断，不让后续 Agent 掩盖它。只有该能力显示信号，才考察 v_a(s) 在第二次请求中是否带来额外价值；第一次由 v_a(空证据状态) 决定只能作为另一个对照。这里的 d(s) 是为估计调用价值而在训练区构造的固定参考决策器，不是运行时替主 Agent 作停机决定的控制器。参考决策器、增益模型与调参/校准数据要交叉分开，避免用同一标签给自己打分。此处的价值信息原理来自 [1]，不是本项目公式创新。

若目标是部署时只调用需要的模型，且训练日志本来只有单调用，则估计第二次调用价值需要同题共调用或额外结构假设。一种候选做法是在有实验真值的训练题上，第一次返回后以登记的非零概率随机再调合格模型，记录 (x, a1, z1, a2, z2, 两次选择概率, 失败, 终止标签, 调用数)；没有实验真值的题不作正确性更新。未调用模型既不补输出，也不伪造正确性。当前已有全模型缓存若后来取得合法资格，则全信息监督方法必须作为同等正经的对照；不能人为遮蔽它来证明 Bandit 必要。试点可建议把动作池限为有证据支持的约 4–6 个具体模型、至少两个来源家族，对研究的模型对保持正探测概率；这不是现行协议或上游资格承诺。成对探测与倾向修正、策略风险置信序列本身都有先例 [9,11]，这里只将它们当识别和审计手段。总体风险界不等于逐分子无假设正确性保证。

可执行的第一版估计器保持简单：第一次选择用训练区分子特征与具名模型 ID 拟合带正则的条件有效且正确概率，题终只用实际调用且取得真值的记录更新；第二次选择用交叉拟合的 d(s) 和题后真值计算每条随机成对日志的“调用前损失减调用后损失”，按已记录探测概率拟合具名模型和来源家族的收缩回归，预登记权重截断并报告有效样本数。若某状态/模型对没有足够探测支持，就不估其条件收益，Agent 在此只能按已校准停机规则行事。这个回归是具体可运行的候选实现，尚未证明比已有价值估计器新或好；与 Gao/Kelly/Cascade 的合法适配对照就是它的淘汰试验。式中的调用项只表示预登记的调用预算影子价格，主表仍在相同调用次数下比较，不将缓存运行时间或假定人民币成本写成事实。

主实验中，工具管理器只向主 Agent 返回所选模型身份与真实工具结果，Agent 自己决定继续或停止；“额外提供风险/查询价值摘要”仅作独立消融，以防判断职责转移。主 Agent 的 Prompt、SFT、RL 依次比较：SFT 用训练区实际可见的轨迹教会功能请求与停机格式；RL 在版本锁定的真实工具缓存回放中采样完整轨迹，奖励按最终错误、弃答和调用计算，真实调用 LLM、真实更新 LLM 参数，并记录权重哈希与 API/训练日志。缓存回放只能称真实输出上的交互式离线训练，不能称科学模型现场重跑或真实部署在线实验。具体 GRPO/PPO 和旧 LLM 门禁需在 P08 前裁定。固定脚本 Agent 比较管理器，固定管理器比较 Prompt/SFT/RL，最后才做交叉组合；另设不调用科学工具的 x→Y 同标签预算基线。若规则控制器已能达到同等结果，就不能将 LLM 参数训练包装为必要机制。

Synthesis｜一条主张、三项能推翻它的检验

唯一主张候选： 在资格合格的未见分子上、相同可见训练标签、平均调用数和作答覆盖率下，利用少量真实共调用学习的条件证据价值，能让两层 Agent 比最强合规序列方法少做错误判断。所谓“识别伪共识”只作罕见压力测试，不列为没有足够样本的主要效果主张。

第一项检验先固定 Agent：只比较具体模型选择。第一次调用要胜过训练集选出的固定模型和合法条件 Bandit；第二次调用必须同信息比较 Gao–Koller 价值策略、Cascade Routing、Kelly 式相关专家查询、条件独立 VOI、随机/固定复核。所有方法都只能读同一探测日志；若某发表实现依赖全表训练输出，给它一个明确的全信息上界栏，另给合规稀疏适配栏。直接 x→Y 使用相同可恢复的题后标签 ID；失败和弃答保持同一总分母。

第二项检验是机制：在相同调用和覆盖率下，去掉成对探测/已见结果/家族收缩后，第二次调用的实际损失下降是否消失？按分子整体配对分析错误作答率，报告风险—覆盖—调用曲线、增益预测校准、模型/来源分组和失败率。若仅多调用或多弃答带来表面收益、条件增益在留出分子上预测不准、强近邻或直接分类器追平，就撤回新增方法贡献。需要额外样本才能支持区间时，结果应写“证据不足”，不能调测试集直到显著。

第三项检验固定工具管理器：Prompt、真实 SFT 和真实 RL 是否改变 Agent 的请求、复核与停止行为及最终错误？同一模型、题目、工具与调用上限比较，保留全部原始轨迹、token/API/训练记录和权重摘要。若只学会统一弃答、重复调用同源模型或复述风险摘要，系统层解释不成立。若仍能在新 provider/性质保持相同决策能力，才增加“迁移”主张；hERG/AMES 须先完成独立真值连接。

建议首个正式比较预登记为：每题最多两次调用，在训练验证集选阈值；测试集主要读出为90% 作答覆盖且平均调用不超过 1.5 次时，按独立分子计的错误作答率。1.5 次低于逐题两调用上限，才会真正检验复核决策的资源取舍；同时给完整覆盖—调用曲线，不能通过某方法多弃答或丢失败获胜。90%/1.5 次是本报告的待裁建议，非 Task42 或 Owner 已冻结阈值；真实功效需根据盲化试点的策略不一致率确定。Task42 的 128 题试点只用于排实现/方向，不作终局显著性结论。若未来研究第三次调用价值，需要另采同题三模型联合观测或声明并检验足够强的联合分布假设。

Limitations｜数据资格、规模与投稿门槛

先在 P01 为每一个入池权重锁定哈希、训练/验证/调参分子名单，再挑与所有入池权重均无曝光的外部 BBB 原始实验真值；原始测量、终点阈值、分子规范化和冲突裁决要可复核。ADMET-AI 的五权重集成必须对五个权重都无曝光，仅一折测试名单重叠不合格。没有成员证据的具体动作退出外部确认池，不以 33 个动作凑数。现有 722 个已被看过，只可做开发/探索；独立确认集必须在方法与阈值冻结后才打开。当前 Task38 状态为 29 UNKNOWN、4 未审，故本报告没有执行任何训练或新预测。

旧目标要求至少 5,000 名义任务、500 个独立难样本、50 个伪共识样本，仍需 Owner 显式裁决承接方式，不能为截止日期悄悄下调。Task24旧难样本口径是 56/722；按当前比例粗投影，50 个七家族共同错需约 2,329 个独立分子，500 个旧 BBB 难样本约需 6,447 个；若要求 50 个“33 具体输出全错”，则约需 16,300 个。它们只是基于小池发生率的规划估算，新外部池不保证相同；同一分子衍生上千组合题不增加独立证据。128 题预计仅约 2.7 个七家族共同错、0.4 个具体全错，不支持“学会识别伪共识”。再作功效敏感性算例：若两策略约 10% 的独立分子结局不一致，双侧 5% 水平、约 80% 功效下，检测 5 个百分点的配对净提升约需 306 个独立分子，2 个百分点约需 1,953 个；骨架聚类会进一步降低有效样本量。它不是正式样本量计算，须用盲化试点估计不一致率后登记。
