# 制药科学预测冲突诊断与恢复 Agent Benchmark：Proposal

## 1. 背景与动机

###  1.1 基本事实
1. 当前制药 Agent 已能调用大量分子性质、对接、亲和力、ADMET、蛋白结构和成药性预测工具。但这些工具多为统计学习或模拟计算，即使正常返回、格式正确、数值看似合理，也会因训练偏差、适用域变化、构象与参数假设等产生误差。多个工具可能对同一性质给出矛盾结论，甚至在错误方向上形成“伪共识”。

2. 化学信息学的工具生态极度碎片化，同一功能有一堆互不兼容的实现，而且差异大到有文献专门讨论。最典型的是 logP：RDKit 的 Crippen 算法、XLogP3、ALOGPS、ChemAxon 对同一个分子能差出 1-2 个 log 单位——这直接决定这分子是"成药性好"还是"成药性差"。你不用编造冲突，去跑一遍就有。这是天然存在的，且在制药领域这个问题尤为突出

### 1.2 研究动机

本项目的出发点是一个关于 agent 工具使用的 **一般性观察** ，以及它在制药域的一个**可测量外显**。

**A（本质问题，一般层）**：训练后 agent 的工具偏好分布 ≠ 任务最优分布。根本原因：训练-推理 harness 不一致 + 注意力向熟悉 token 集中，导致 agent 对训练时见过的工具过度自信、对功能等价的新工具系统性回避。这其实是一个很 general 的问题，可以称之为 **工具过拟合**，本质上是在训练的时候见过一些工具过多，在后续真正的生产环境工作的时候会更偏好这种工具，和这些工具的契合度更好，但是外部工具是多种多样的，其价值不取决于 agent 在训练时候见过没见过，而是取决于对于任务本身的裨益，这就产生了一个 gap，也就是本身的模型任务指标和其训练的 gap

**B（外显，行为层）**：在 K 个功能重合的工具间，agent 偏向"更熟悉的"而不是"在这个任务上更可能有效的"。因为工具过拟合的一就是对工具使用过于自信，这就是问题 A 的外显

**C（信号，数据层）**：要捕捉这个外显的 B 行为，就要有一个可衡量的信号可量化这个行为的程度，当 Agent 根据自己的偏好选择对应的工具后若该工具出现了结果错误，即捕捉到了该信号，我们要做的就是对该信号进行建模


我们本质上是想要解决问题 A，问题 A 是一个根本问题，是一个 general 的问题，在这里就是工具过拟合问题，没办法直接来解决它而只能通过他的外显来间接缓解它，表现 B 就是问题 A 的一个外显，这个 B 就是选工具有偏好，这个 B 动作会产生一个信号就是 C，也就是工具选错，这个选错的判断来自于其输出结果不对，从而我们拿到了一个信号，通过建模这个信号并将其看作一个与 loss 关联的值，通过消掉 loss 去解决 B，从而缓解 A，这是一个比较清晰的故事线，而且是有价值的，因为其最终指向了一个 general 的问题。


在叙述上，我们说真正关键的问题不是 Agent 能否处理超时或异常，而是：**当科学工具正常工作但结果不可靠时，Agent 能否利用同功能工具和其他相关性质发现异常、定位可疑属性、选择更可靠的结果，并恢复后续研发决策。** 这直接影响虚拟筛选、先导优化、蛋白/抗体设计和候选优先级判断的可信度。

## 2. 别人做了什么，我们剩下什么

按本提案的主张切六个维度，不按各家自己的研究目标切：冲突是天然还是人工造的、判对错靠什么、有没有多个功能重合的工具、有没有评"该不该相信这个结果"、agent 能不能弃答、分数能不能拿去训练。

### 2.3 我们剩下什么

**不声称的**：校准方法上的创新。上表已经把这块占满了。

**可声称的两条**：

1. **数据生态位**。化学是目前唯一能同时提供客观实验金标准、天然多工具冲突、真实决策代价这三样的领域，上表所有工作都缺其中至少两样。
2. **任务形态**。把主任务从"挑哪个工具准"改成"这组结果能不能拿去做决策"，是定义层的改动，理由见 §3.5。

## 3. 我们要做什么

### 3.1 七站全景

**一句话**：把"多个工具对同一分子给出矛盾预测、且该分子有实验值可对照"做成账本，摊成一批题，题面问"手上这些结果能不能拿去做决策"；先用不花显卡的检验判断有没有真信号，通过了才动模型；改完在换工具与换领域两个方向验证。

| 站 | 干什么 | 进什么 | 出什么 | 状态 |
|---|---|---|---|---|
| 0 | 造账本 | 一批分子 + 四个本地预测模型 | 七百余行"工具—预测—实验值"记录 | 已完成 |
| 1 | 真值体检 | 账本 + 真值来源文件 | 可用分子名单 + 工具训练归属标注 | 必须先过 |
| 2 | 造题 | 体检后的账本 | 约一万道题，各带"该不该弃答"的标签 | 规则已定 |
| 3 | 答题与判分 | 一道题 | 一条曲线 + 一个总损失数 | 口径已定 |
| 4 | 前置检验与证伪实验 | 题目 + 传统统计方法的对照 | 五个通过或不通过的判定 | 必须先过 |
| 5 | 两条干预路线 | 题目 + 判分器 | 会先估把握再决定的 agent | 未开工 |
| 6 | 评测与迁移 | 干预后的 agent | 换工具、换领域两组成绩 | 未开工 |

**要显卡的只有站 5 路线乙和站 6**。站 1 到站 4 全是脚本与传统统计方法，成本以分钟计。这个安排是有意的：让所有能判死方向的检验都排在花钱之前。

**贯穿全章的例子**：账本第一行那个分子，每站都拿它走一遍。

**全章数字分两类，读的时候必须分开**：

- **不依赖真值的**：账本多少行、哪些行工具互相矛盾、复测是否稳定、题目多少道。筛选过程没碰真值，结论稳固。
- **以真值当裁判的**：谁对谁错、准确率排名、弃答标签、参照线、代价区间。站 1 已查出真值字段自身有矛盾，所以这一类全是体检前读数，**站 1 之后须整批重算**，本章保留它们只为说明量级。

### 3.2 站 0 · 账本

**已完成。** 对同一批分子，用四个原理不同的本地模型各预测一遍能否透过血脑屏障，再挂上实验测定值，得到一张可逐行核对"谁对谁错"的表。这是个二分类问题，答案只有能透过和不能透过。

**四个工具**：ADMET-AI，以及 DeepPurpose 预训练的三个变体，分别基于卷积网络、Morgan 指纹和消息传递网络。全部是本地模型真实推理，不是查表。

**数据来源**：公开数据集 Therapeutics Data Commons 里名为 BBB_Martins 的血脑屏障条目，冻结成固定快照后使用。分子结构写成 SMILES，即把分子写成一行文本的通用格式。

**一行长这样**，账本第一行原文，数值未改：

```
分子编号   z000282
分子结构   C[N+](C)(C)CCO        胆碱
实验测定   能透过血脑屏障
状态       跨体系冲突，三轮复测结论一致

ADMET-AI          判"不能透过"   错
DeepPurpose 卷积   判"能透过"     对
DeepPurpose 指纹   判"能透过"     对
DeepPurpose 消息   判"能透过"     对
```

**三个字段的含义**：

- **跨体系冲突**：分歧发生在 ADMET-AI 与 DeepPurpose 之间，不是同一来源的三个变体内部打架。这个区分对应 §3.10 第三条风险。
- **三轮复测结论一致**：同一批输入跑三遍，冲突判定没变过，说明稳定而不是碰巧。
- 每个模型还给出一个 0 到 1 的概率，概率与真值的差额也记在账本里，用来区分错得离谱和擦边错。

**为什么选这一行做例子**：胆碱带永久正电荷的季铵盐结构，按常规判断透不过细胞膜，实验值却是能透过——它有专门的转运体。ADMET-AI 给出的正是那个听起来很有道理的错误答案。

**规模**：七百余行全部达终态，约四百行跨体系冲突。四个工具正确率最高接近九成、最低不到六成。十来个分子四个工具全错，三百多个全对。精确数见 §3.11。

**为什么不能省**：没有它，"工具会出错"只是一句判断；有了它，"哪一行谁错了、错多少"是可逐行核的记录。后面所有题目、标签、参照线都从这张表按规则导出。

**边界**：只覆盖一个性质。其他数据源还没有账本，见 §3.9。

### 3.3 站 1 · 真值体检

**必须先过，不通过则下游全部数字不成立。** 账本里"谁对谁错"完全由实验真值那一个字段说了算，而这个字段是从外部数据集原样直取的，核查发现它自己就有矛盾。

**查出了什么**：

| 检查项 | 结果 |
|---|---|
| 文件有没有被改动 | 没有。校验码与行数都对得上 |
| 内容有没有人逐条审过 | 没有。托管平台只发布不审内容；每条记录的出处指向数据集平台的论文而不是测这个分子的实验文献；全部记录出处文本相同，做不到逐条溯源 |
| 源文件自身是否自洽 | 不自洽。十来个分子的标签自相矛盾，同一分子同时被标成能透过和不能透过 |
| 矛盾行有多少进了账本 | 八个进了账本，其中七个落在跨体系冲突集内 |
| 同一分子有两条时取哪一条 | 取最后出现的那一条，八行全部符合。**这意味着真值由源文件行序决定，调一下行序标签就翻转** |
| 真值是否同时是工具的训练标签 | 是。四个工具都在同源数据上训练过，取数时也没限定只用它们的测试集 |

**污染落在最吃重的地方**：站 0 那批四个工具全错的分子里，有一个正是上面八个矛盾行之一。而那批分子撑起了站 2 里全部"天然该弃答"的题目。

**要产出三样东西，都还没做**：

1. **矛盾行的处置结论**。逐行裁决取哪个标签或整行剔除，裁决留依据。举例：普萘洛尔是脂溶性 β 阻滞剂、有明确的临床中枢副作用，把它标成不能透过的那条基本可判为错行。
2. **训练归属标注**。逐个标出哪几个工具训练时见过这个分子，之后只在四个工具都没见过的子集上比对错。
3. **重算后的参照线**。§3.11 现有数字在体检前都是待重算状态。

**哪些结论不受影响**：

- **可用**：四个工具在约四百个分子上互相矛盾这个事实。冲突判定三轮都稳定，流程上锁死了真值必须在冲突集密封之后才允许挂上去，每行带可机器核验的指纹。
- **不可用**：一切以真值当裁判的量，包括判定对错、误差排序、边际准确率、多数票、理想选择器。

**为什么不能省**：跳过它，站 2 的标签、站 3 的参照线、站 4 的方差分解全建在一个自己打自己的字段上。这类错误训完模型之后查不出来——那时所有数字都自洽，只是全都偏了。

**副产品**：那十来处矛盾本身是素材。连人工汇编的实验数据集都会对同一分子给出相反结论，说明"计算结果不可靠"在数据层就已成立。

### 3.4 站 2 · 造题

**问题**：账本里四个工具全错只有十来行，太稀疏，考不出"该不该认怂"。

**做法叫遮蔽**：每道题只让 agent 看到四个工具中的一个子集，把稀疏信号摊开。全部由脚本按固定规则生成，同一输入永远给同一输出。

**三条规则**：

1. **题目怎么来**。每个分子配上工具的每一个非空子集各生成一道题。四个工具有十五个非空子集：四个只给单个工具，六个给两个的组合，四个给三个的组合，一个是全集。题目总数约一万道。
2. **遮蔽的含义**。子集以外的工具不出现在这道题的工具目录里，agent 看不到也不知道它们存在。
3. **弃答标签的定义**。这道题的可见工具全部判错，就标为该弃答，由账本按规则判定。

**难度梯度是自带的**：遮得越狠该弃答的题越多。只给一个工具时超过两成，四个工具全给时只有百分之一点几。各层精确数见 §3.11。

**该弃答的题必须按来源分两桶**，混了就说不清测的是什么：

- **天然的**：四个工具本来就全错，考"真的判不了时认不认怂"。
- **遮蔽造成的**：本来有工具能答对但被遮掉了，考"能不能察觉证据不足"。天然的只来自那十来个分子，遮蔽造成的占绝大多数。

**一个能手算的例子**：取"第一、第三个工具答对，第二、第四个答错"的分子。遮掉答对的两个、只给答错的两个，可见工具全错，这题该弃答且来源是遮蔽造成的；反过来遮掉答错的两个，可见工具全对，这题不该弃答。**同一分子换一个子集，标签就翻转**，这就是摊开稀疏信号的机制。

**两条自查恒等式**：两工具组合的该弃答数应等于这两个工具在全集上同时答错的行数；遮掉某一个工具后的数应等于其余三个同时答错的行数。对不上就是生成脚本有错。

### 3.5 站 3 · 答题与判分

**agent 是主动的，不是被动看结果。** 题面不预先摆出预测值，只给一份工具目录，agent 自己决定调哪个、要不要再多调一个复核，每次调用付代价。

**为什么必须主动**：经典的适用域判定方法在这个领域已有几十年积累，它做的事是给定一个分子和一个预测值、输出一个可信度分数。在那件事上我们没有优势。能拉开差距的是经典方法做不到的那一步——判断"我现在信息不够"，然后自己选一个动作去补。

**一条工程前置**：现在的运行面只有一个查表工具。要跑主动形态，必须先把账本包成四个可独立调用的工具接口，各有自己的名字、参数格式与返回结构。见 §3.10 第九条风险。

**遮蔽与自主调用不冲突**：工具目录里只列这道题的可见子集，被遮的工具不在目录也不在提示中，调不回来。agent 的自主性限于两件事——在可见子集内调哪个调几个，以及作答还是弃答。

**答卷四个字段**：

| 字段 | 含义 | 是否被直接监督 |
|---|---|---|
| 把握值 u，0 到 1 | 手上这些结果能用的把握。连续数，不是信与不信两档 | 是，训练唯一的监督目标 |
| 风险分 r，0 到 1 | 把题从敢答到不敢答排序，画曲线用。取 r = 1 − u 就够 | 否，由 u 导出 |
| 动作：作答或弃答 | 由 u 按下面的阈值规则导出 | 否 |
| 若作答：判定、采信了哪个工具、简要依据 | | 判定对错进结果项 |

另外记录 agent 实际调了哪些工具、调了几次，这决定成本项。

**风险分有一条硬规则：禁用工具自报的置信度**，只准用可见工具之间的一致与分歧结构。理由是实测发现自报置信度在这批数据上是反指标——四个工具里正确率最低的那个，在它自称最有把握的那批行上错了六成以上。至于"结构证据"具体怎么落成一个数，本轮未定，须在跑之前预注册冻结。曲线只依赖 r 的排序，任何保序写法给出同一条曲线。

**阈值规则可以直接算，不是待定超参**。作答的期望损失是答错概率 1 − u，弃答的损失固定是 c，两者比大小即得：

$$\text{作答} \iff 1-u < c \iff u > 1-c$$

c 取 0.25 时阈值是 0.75，取 0.5 时是 0.5。所以训练只需产出连续的 u，阈值由部署环境的成本比决定，换环境不必重训。

**为什么主任务是"能不能用"而不是"哪个准"**。把工具 k 在分子 i 上的误差拆开：

$$e_{ik} = \mu + \alpha_i + \beta_k + \gamma_{ik} + \varepsilon_{ik}$$

其中：

- $e_{ik}$：工具 k 对分子 i 的预测与实验值的偏差；
- $\mu$：全局平均误差，常数；
- $\alpha_i$：**分子主效应**，这个分子对所有工具都难的程度，是分子的属性；
- $\beta_k$：**工具主效应**，这个工具的全局精度。四个工具正确率从不到六成到接近九成，差的就是这一项；
- $\gamma_{ik}$：**交互项**，这个工具偏偏在这类分子上特别偏，同时绑定分子和工具；
- $\varepsilon_{ik}$：残差，含实验测定噪声。

由此得到一个绕不开的两难：

| 若主任务是 | 答案由哪项决定 | 换一套工具后 |
|---|---|---|
| 从几个预测里挑最准的 | 交互项，绑定具体工具 | 失效，学到的偏好全部作废 |
| 判断这组结果能不能用 | 分子主效应，是分子的属性 | 仍然有效 |

**说白了**：困难若来自分子本身，所有工具会一起变差，挑哪个没有信息量；挑哪个若确实有信息量，信息只能来自交互项，而交互项按定义绑在具体工具上。**"有信号"和"能迁移"在这个任务定义下不能同时成立**，这是定义层的排斥，不是实验能裁定的。

**评测与训练的分工**：

| | 内容 | 用途 |
|---|---|---|
| 评测侧四类任务 | 同性质冲突识别；跨性质异常诊断；预算约束下的复核与仲裁；下游决策恢复 | 量失败模式，全部保留，不进训练环 |
| 训练侧一个任务 | 选择性作答：给把握值，再决定作答还是弃答 | 唯一进训练环的 |

**判分四个量**，只吃答卷动作与账本真值两种输入，机械可判。先立两个术语：风险-覆盖曲线指把"多大风险才值得弃答"从松到紧排一排，看每档留下来作答的题答得多准；选择性预测指 agent 自己决定每题作答还是弃答。

覆盖率，某阈值下留下来作答的题占多少：

$$\mathrm{cov}(\tau)=\frac{1}{N}\sum_{i=1}^{N}\mathbb{1}\{g_i=\text{答},\ r_i\le\tau\}$$

其中 $N$ 是题目总数，$g_i$ 是动作，$r_i$ 是风险分，$\tau$ 是阈值，$\mathbb{1}\{\cdot\}$ 表示条件成立记 1、否则记 0。

风险率，该覆盖档内答错的比例：

$$\mathrm{risk}(\tau)=\frac{\sum_i \mathbb{1}\{g_i=\text{答},\ r_i\le\tau,\ a_i\neq y_i\}}{\max\left(\sum_i \mathbb{1}\{g_i=\text{答},\ r_i\le\tau\},\ 1\right)}$$

其中 $a_i$ 是 agent 采信的那个工具的预测，$y_i$ 是冻结真值，分母取与 1 的较大者是防除零。

曲线下面积，用一个数概括整条曲线，越小越好：

$$\mathrm{AURC}=\frac{1}{K}\sum_{k=1}^{K}\mathrm{risk}(\tau_k),\qquad \tau_k=\frac{k}{K}$$

其中 $\tau_k$ 是把阈值均匀切成 $K$ 档的格点，$K$ 取一百。agent 若不输出风险分，这个量退化成单点风险率，报告须标注。

代价敏感总损失，**主指标**：

$$E=\frac{1}{N}\sum_{i=1}^{N}\left(\mathbb{1}\{g_i=\text{答},\ a_i\neq y_i\}+c\cdot\mathbb{1}\{g_i=\text{弃答}\}\right)$$

其中答错一次的代价定为 1 作为单位，$c$ 是弃答一次相对答错一次的代价倍数，运行前冻结。

**两个诊断率**，不进总损失，只看损失偏向哪头：弃答过头的比例指弃答的题里可见工具本有答对的占多少；该弃没弃的比例指没弃答的题里可见工具全错的占多少。

**参照线**，任何成绩必须对着这几条读，精确数见 §3.11：

| 参照线 | 定义 | 读法 |
|---|---|---|
| 优先级链 | 从不弃答，按四个工具在全集上的准确率排序取第一个可见的 | 总损失必须低于它，否则弃答机制没创造价值 |
| 多数票 | 可见工具投票，平票按优先级链裁决 | 工具误差相关时会失效 |
| 理想弃答 | 只在该弃的地方弃，上帝视角 | 下界，不可达 |
| 每题都弃答 | 损失恒等于 c | 总损失不能高于它，否则是无脑全弃 |
| 从不弃答 | 与优先级链同一个策略 | 同上 |

**多数票有个值得单独说的现象**：它在"只遮一个工具"这一层反而比优先级链差，因为投票把权重分给了准确率最低的那个工具。所以参照线必须逐层报，只看全集会把这种结构性差异拖平。

**代价 c 从两个锚推，不拍脑袋**：锚一是从不弃答的损失，等于优先级链的全集错误率；锚二是理想弃答的比例。由此三条恒等式——理想策略损失等于锚二乘 c，每题都弃损失等于 c，从不弃损失等于锚一。于是每题都弃赢从不弃当且仅当 c 小于锚一；理想策略赢从不弃当且仅当 c 小于锚一除以锚二。**这两个边界之外，所有聪明策略都被极端策略压死、排名贴边**，所以有效区间取两个边界之间，区间内取三档正式比较，区间外各放一档当哨兵自检判分器。两个锚都是以真值当裁判的量，站 1 之后须一并重推。

**评测环境**：可执行沙箱，每次调用有成本，拿不到隐藏真值，完整记录工具回执、参数、证据引用与决策时间。

### 3.6 站 4 · 前置检验与证伪实验

**必须先过，全部通过才进站 5，五条顺序不可颠倒。** 用传统统计方法回答一个问题：这批题里到底有没有可学的东西。

| 序 | 验什么 | 怎么做 | 不通过意味着 |
|---|---|---|---|
| 1 | 方差分解 | 估出分子主效应占总误差方差的比例；再扰动真值，看分类结论翻转的比例 | 占比低说明没有分子难度区可学，主任务不成立；翻转率高说明标签在拟合测定噪声 |
| 2 | 裸答天花板与恒答基线 | 不给任何工具预测直接问模型能不能透过；再算"一律说不可信"能拿多少分 | 能背出来说明测的是记忆；恒答得分高说明必须同时报弃答率 |
| 3 | 经典方法擂台 | 同一张表上训随机森林，再跑 conformal prediction，比静态判断准确率 | 打平或更好，说明不能在静态判断上宣称贡献，差异只能落在主动取证上 |
| 4 | 证伪实验 | 见下面的消融矩阵 | 只用几个数字就能做到同样好，说明模型没在读分子，方向重做 |
| 5 | 纯采样基线 | 不改任何东西，只把采样量加大，看能不能匹配干预后的成绩 | 提升不超纯采样，说明拿到的是分布锐化不是真实增益 |

**检验 1 有个开工条件**：本数据的性质是二分类，误差退化成对与错两档，标准方差分解不能直接套。必须先定下二值响应下的分解形式，改用模型输出的连续概率而不是硬标签是最直接的做法。**这一步还没做。**

**通过线本轮未定**。上表每条的方向明确，但"多低算低、多接近算打平"的门槛没定。判据必须在跑之前预注册冻结，否则事后挑门槛等于没有关卡。

**什么是证伪实验**：专门设计来推翻我们自己核心主张的实验，且必须在花钱训练之前先做。核心主张是"agent 学会读分子内容才判断得准"，推翻它只需一件事——拿掉分子、只留四个预测数字，用逻辑回归跑。若打平，说明 agent 没在读分子，学的只是"几个数字差得远就别信"，而这条规律与化学无关。**它与普通消融的区别在后果**：普通消融看掉多少分，这个打平就地停止。

**消融矩阵**。同一批分子，按骨架切分，即把结构骨架相似的分子整组划到同一侧，防止训练集和测试集出现几乎同一个分子。成绩报自助法置信区间，即有放回重抽多次、每次算一遍成绩，用散布给区间。

| 编号 | 输入 | 怎么读 |
|---|---|---|
| 甲 全管线 | 分子结构 + 推理过程 + 四个工具预测 | 主方法 |
| 乙 只给数字 | 只给四个预测数值，逻辑回归就够 | **与甲打平，则"读分子内容"作废，方向重定** |
| 丙 只给工具身份 | 工具名加四个预测，不给分子内容 | 好于甲，说明工具身份比分子内容重要 |
| 丁 随机 | 无 | 下界 |
| 戊 conformal | conformal prediction 基线 | 经典擂台，与检验 3 同族 |
| 己 内容错配 | 预测与分子故意配错，保留预测值分布 | **成绩不变，说明用的是数值分歧不是分子内容** |

**为什么必须前置**：几百个分子这个量级上，最强的可学信号很可能就是"几个数字分歧大就别信"。这条规律跨领域通用，所以**迁移测试会看起来成功**，是个结构性假阳性。乙和己就是专门用来打死它的。

**另加留一个工具不训的检验**：把四个工具里的一个整个扣掉当新工具。训练只用可见子集完全落在其余三个之内的题，十五个子集里有七个满足；测试只用可见集包含被扣工具的题。子集枚举不用改，四个工具各扣一次轮流做。

**换工具必须同报残差相关系数**：把两个工具在同一批分子上的误差各拉成向量算相关。相关高说明两个工具错在同样的分子上，那么"迁到新工具仍有效"很可能只是因为新旧工具本来就像。四个工具里三个同属一个体系，误差相关是已核实的风险。及格线本轮未定。

**止损点**：若"只给数字"打平全管线，停掉训练线，把已有设施整理成一篇纯评测论文。约一万道题、参照线、预注册的代价表加上证伪实验结果，本身就是最小可发表单元。

### 3.7 站 5 · 两条干预路线

**目标**：让 agent 把"先估把握、再决定信不信"变成默认动作。先做不改权重的那条，它同时是另一条的对照基线。

**路线甲 · 只改外壳**，不动任何参数，改三样东西：

1. **统一工具目录的呈现**。名称、参数格式、返回结构统一成一套写法，让模型没法靠名字眼熟来选。
2. **加一步强制自检**。要求 agent 采信任何预测之前先写出"这个工具在这类分子上是否可靠、我的把握是多少"。
3. **加一步强制复核**。把握值低于阈值时必须再调一个工具，不许直接下结论。

**路线甲的两层价值**：不用显卡、几天出结果；更重要的是它是路线乙的对照基线——不先做这条，训练涨的分说不清是权重的功劳还是外壳的功劳。

**路线乙 · 改权重，分两步**。为什么必须分两步：强化学习只能放大策略里已有的行为，不能凭空造。基座模型若从来不在采信预测前估把握，采样出的轨迹里就没有这种行为供奖励筛选。

**第一步，冷启动，学形式**：让模型自己在题目上多采样几条轨迹，按结果过滤，只留"把握报得准且判定对"的做监督微调，推理漂亮但答案错的丢掉。这叫拒绝采样自举——不引外部强模型当老师，只用模型自己产生、被结果验证过的轨迹。**两条硬约束：不用老师模型、不做蒸馏。** 这一步之后"先报把握值"成为默认动作，部署时不需要特殊提示。

**第二步，强化，学准**。权重符号特意避开 §3.5 误差分解里的 $\beta_k$ 与 $\gamma_{ik}$：

$$R = \mathbb{1}\{\text{判定对}\} - w_{\text{cal}}\cdot(u - a)^2 - w_{\text{cost}}\cdot(\text{工具调用数} - 1)$$

其中：

- $\mathbb{1}\{\cdot\}$：判定对得 1、错得 0；
- $u$：模型报的把握值；$a$：这题实际对错，对记 1 错记 0，由账本查出；
- $(u-a)^2$：**Brier 分数**。它是严格 proper 的评分规则，意思是诚实报告真实把握是唯一全局最优，靠报 0.5 对冲拿不到好处；
- $w_{\text{cal}}$：Brier 项权重；
- $w_{\text{cost}}$：每**多**调一次工具的代价。减 1 是因为第一次调用是必需的、不计代价，只对额外复核收费。它与 Brier 权重的比值有真实锚点——一次实验验证的钱对一次计算调用的钱。两个权重取值本轮未定，与 c 一并预注册。

**三条设计约束**：

| 约束 | 理由 |
|---|---|
| 把握值必须连续，阈值留到部署时套 | 动作若离散成两档各配固定奖励，最优策略会解析地落在一个常数动作上：阈值只由代价比决定，弃答便宜时阈值趋近 1，模型会"正确地"学成几乎永远弃答。这是代价敏感学习的定理推论，调参绕不开 |
| 算法用 REINFORCE++ 或带价值网络的 PPO | 不用组内相对归一化那一类。它指对同一题采一组答案、用组内均值方差把奖励标准化，在"一组全对或全错"时组内方差为零、给出零梯度，恰好在最需要信号的极端题上失效 |
| 训练时保留工具身份，遮蔽只放评测侧 | 训练时抹掉身份，两个观测看起来一样、实际可靠性不同的输入会强迫模型给同一个把握值，等于逼它报错 |

**抗过度锐化**：有了误差账本，"模型极少产生但确实正确"的轨迹可被无歧义标出，可以定向强化。数学题上做不到，因为无法判断哪条罕见推理是对的。**这是待验假设。** 任何提升必须同时报纯采样基线与路线甲的成绩。

### 3.8 站 6 · 评测与迁移

**四个可观测的行为变化**，用来判断是真学会了还是只是分数变好：

| 序 | 信号 | 怎么看 |
|---|---|---|
| 1 | 把握值与准确率对齐 | 报 0.8 的那批题实测正确率接近八成 |
| 2 | 换工具不掉 | 留一工具不训的设置下迁到新工具仍优于随机，且同报残差相关系数 |
| 3 | 该认怂时认怂 | 可见工具全错的题上弃答召回率高，且与"四个工具全给"那层的结论一致 |
| 4 | 总损失赢两头 | 低于从不弃答、不高于每题都弃，三个主档都成立，跨档排名稳定 |

**迁移落在有公开金标准的异质领域**：数学问答、代码执行、检索冲突。"迁移到没有真值的真实场景"按定义不可测，只作方向声明，不进贡献清单。

**迁移凭什么可能成立**：模型学到的不是血脑屏障知识，而是一套通用的读证据习惯——先看几个来源是否互相支持，再折算成把握值，把握不足就不下结论。数学题里"几条解法给出不同答案"、代码题里"几次执行结果不一致"，结构上是同一件事。

**凭什么可能不成立**：如果模型学到的只是"几个数字分歧大就别信"，那它本来就与领域无关，迁移会成功却什么化学内容都没用上。**所以迁移结果只有在证伪实验通过之后才可解读，顺序不能反。**

**五条待验假设**。编号用"假设 N"，避免与 §3.4 的遮蔽分层混淆：

| 序 | 假设 | 判据 |
|---|---|---|
| 假设 1 | 曲线下面积优于两条参照线；总损失同时赢两头 | 弱信号，只说明选择性预测在这批题上有信号 |
| 假设 2 | 证伪实验里"只给数字"打不平全管线 | **整条故事线的命门** |
| 假设 3 | 留一工具不训下迁到新工具仍优于随机，且残差相关系数同报 | 泛化证据 |
| 假设 4 | 数学问答与代码执行上不经训练就优于基线 | 迁移证据 |
| 假设 5 | 若假设 2 或 4 失败，贡献退化为带实验真值的选择性作答评测集加校准不迁移的负结果 | 负结果也可发表 |

### 3.9 扩量路线

**账本目前只有一个性质。** 下列数据源是候选，都还没有建账本。

**小分子侧**：CACHE 提供面向真实靶点的候选提交与实验测定，可构造虚拟筛选排序与命中恢复；SAMPL 提供 pKa、logD、溶剂化与结合自由能的盲测数据，适合比较系统误差；D3R 与 CASF-2016 提供结合构象、亲和力排序与打分数据，可构造对接冲突；ChEMBL、BindingDB、TDC 提供大规模活性与吸收分布代谢毒性端点，用于扩量与外推。

**蛋白抗体侧**：AIntibody 提供盲测设计、实验亲和力与成药性测量，适合构造跨性质冲突；CASP、CAPRI、FoldBench 提供结构与界面预测冲突，实验真值取自 PDB；ProteinGym 汇集深度突变扫描数据，可测多个适应度预测器不一致时的复核。

**四条切分原则**：

1. 先统一实体、质子化状态、构象、单位、实验条件与端点定义，避免把"定义不同"误标成"工具错误"。
2. 不以随机篡改数值为主，而从真实残差里抽取自然分歧、错误共识、适用域外、活性悬崖与高置信度错误。
3. 按骨架、蛋白家族、靶点和时间切分开发集、校准集、冻结测试集与隐藏外推集，真值只留在私有判分器里。
4. 每个来源记录许可证、可再分发范围与下载日期；不能公开再分发的只发布构建脚本与评测接口。

**扩量前必须先做一件事**，这是站 1 的教训：任何外部权威标签进库前，先在文件内查同一实体的标签是否自洽。这一步零成本。**托管平台的名气不传递数据可信度，溯源记到数据集级别不等于逐条可溯源。**

### 3.10 边界、风险与止损

**可声称的三点**：化学是目前唯一能同时提供客观实验金标准、天然多工具冲突、真实决策代价的领域；主任务从交互项改到分子主效应是定义层改动；冲突来源真实、逐条带实验真值、可重建。**不声称校准方法上的创新**，见 §2.3。

## 4. 期望结论与分析

以下六条是待验证的预期，不是预设结论。它们说的是"我们预计会观察到什么行为"，与 §3.8 那五条"方法成不成立的判据"不是一回事。

1. 通用能力更强的 agent 不一定更谨慎。它可能更稳定地盲从专业工具，因为工具在它看来比自己专业。
2. 只看一个工具自报的置信度不足以判断它这次对不对。把工具之间的分歧、分子是否落在工具擅长的范围内、以及其他相关性质放在一起看，应该更有效。
3. 多数投票在工具误差高度相关时会失效。我们四个工具里有三个同源，这种情况尤其可能出现。
4. 复核不是越多越好。多调一个工具能提升准确率，但存在一个拐点，过了拐点只增加成本。
5. 规则型的门控、agent 自己推理、以及两者结合，可能各自适合不同的风险与预算场景，而不是有一个通用最优。
6. agent 即使最后答对，过程也可能是错误诊断加上运气。所以过程和结果必须同时评。

### 4.1 资源预算

以下全部是估算。整条管线的开销集中在一处：站 5 路线乙的强化阶段。这一处占全流程算力的绝大部分，它前面所有关卡都不需要显卡。所以预算上的关键决定不是"总共要多少"，而是"要不要走到那一步"——站 4 五条检验没过就不走，成本冻结在几乎为零。

| 站 | 要不要大模型 | 要不要显卡 | 时间量级 |
|---|:---:|:---:|---|
| 站 0 造账本 | 只用本地预测模型 | 不用 | 已完成 |
| 站 1 真值体检 | 不用 | 不用 | 一两天，主要花在人工裁决那几行 |
| 站 2 造题 | 不用 | 不用 | 分钟级 |
| 站 3 判分 | 跟着各站一起跑 | 不用 | 贯穿全程 |
| 站 4 前置检验与证伪实验 | 五条里有两条要 | 不用 | 几天 |
| 站 5 路线甲 只改外壳 | 要 | 不用 | 几天 |
| 站 5 路线乙 冷启动 | 要 | 要，一张卡 | 几天 |
| 站 5 路线乙 强化 | 要 | 要，数张卡。全流程主要开销在这里 | 一到两周 |
| 站 6 评测与迁移 | 要 | 要 | 几天 |

三条说明：

- 走公开接口还是本地部署，成本结构完全不同。前面几站用量小，走接口最省事；强化阶段要反复采样，用量大，本地部署更划算。我们此前的实测参照是一轮十几次运行花几美元、耗时半小时量级。
- 用多大的模型还没定。冷启动之后看拒绝采样的保留率：保留率太低说明基座模型撑不住这个行为，要换更大的，显卡预算同比例上调。
- 强化阶段的开销随题目数量线性放大。站 4 之后若需要扩量，这一项跟着涨；站 1 若剔除受污染的行，题目数会变少。

## 5. 这件事对制药领域有什么用

本项目不做新的对接、性质预测或结构预测模型，做的是这些工具之上的一层可靠性评测。具体产出四样东西：

- 一批带实验真值的工具冲突数据，以及配套的评测协议。冲突来自真实模型残差，不是人工注入的。
- 一套判分口径，能量出 agent 在真实模型误差下"什么时候该相信计算结果"的判断质量，而不只是任务完成度。
- 一份关于"哪片化学空间不能信计算"的读数。这对研发团队的直接用处是决定哪些候选必须做实验验证。
- 一条从评测到改进的通路：先用不改权重的办法改外壳，再看改权重能不能再进一步，两者都对着同一批题和同一套参照线读。

## 6. 未来可继续推进的方向

§3 已经把"学习哪片区域不能信工具""预算约束下的主动复核""面向恢复过程的训练""换一套工具重测"这四条收进主线了，本节只列还没进主线的方向。

1. 跨性质约束推理。建立一个可执行的约束层，把结构、亲和力、物化性质、代谢与毒性、稳定性、成药性连起来，帮 agent 区分三种情况：真的互相矛盾、单位或定义不同、以及本来就该随条件变化。本轮只作为判分侧的配套，用来校验 agent 给出的理由是否成立，不作为提示喂给 agent——否则测的就变成指令遵循了。
2. 规划、执行、审计三个角色分工。让一个角色专门检查证据来源、参数一致性、未验证的假设和替代解释。与本项目"单个 agent"的硬边界冲突，本轮不启动。
3. 人机协同与湿实验闭环。在高风险或者确实判不了的情形下允许 agent 向专家求助，再进一步做前瞻性盲测或小规模湿实验。专家介入会破坏可重复性，湿实验目前没有条件，所以本轮只保留"把问题交出去"作为 agent 的一个输出选项，不真的接人。
4. 扩到其他模态与研发阶段。从小分子和蛋白抗体扩到核酸、蛋白降解剂、细胞与组学工具，研究上游的冲突如何传播到候选排序、安全性判断和继续或停止的决定。与"本轮收敛到制药单一性质"的裁定冲突，本轮不启动。
