## 3. 我们要做什么

### 3.1 七步流程

| 步 | 要做什么 | 产出 |
|---|---|---|
| 0 | 取一批有实验测定值的分子，用几个原理不同的工具各预测一遍同一个性质 | 一张记录表，逐行可核对谁对谁错 |
| 1 | 核查实验值本身可不可信 | 可用分子名单 |
| 2 | 遮住一部分工具，把记录表变成一批题 | 一批题，各带"该不该弃答"的标签 |
| 3 | 让 agent 自己调工具作答，按固定口径算分 | 一个总损失数 |
| 4 | 确认这批题里的信号不是"几个数字分歧大就别信" | 通过或不通过 |
| 5 | 两条改进路线：只改提示，或改权重 | 会先估把握再决定的 agent |
| 6 | 换一套工具、换一个领域，看能不能带走 | 泛化与迁移两组成绩 |

**两道关卡排在改模型之前**：第 1 步查真值站不站得住，第 4 步查信号是不是真的。任一不过就不往下做，这样最坏情况下只损失前四步，而前四步都是脚本和传统统计方法。

### 3.2 第 0 步 · 建多工具预测记录表

取一批有实验测定值的分子，用几个原理不同的工具各预测一遍同一个性质，逐行记下每个工具的预测和实验值。首版选血脑屏障渗透，理由是它有公开实验数据集，也有多个可本地运行的预测模型，同一分子上很容易出现两个不同来源的模型给出相反结论。

**每一行要记的**：分子结构、每个工具的预测值与判定、实验测定值、这一行是否出现跨体系分歧。同一批输入要重复跑几轮，只有几轮结论一致的分歧才算，避免把随机波动当分歧。

举一行看这件事长什么样：胆碱带永久正电荷，按常规判断透不过细胞膜，实验值却是能透过，因为它有专门的转运体。工具里凡是按常规规律推的都会判错，而那正是听起来最有道理的答案。

先做一个性质，验证做法成立后再扩到 pKa、logD、对接打分等同样有盲测或实验数据的性质。

### 3.3 第 1 步 · 核查实验值可信度

实验值从公开数据集直取，而这类数据集不保证内容被逐条审过——初步核查已经发现同一个分子出现相反标签的情况，取哪一条取决于源文件的行序。所以在拿它当裁判之前必须先查。

**要做两件事**：逐行裁决取哪个标签、或者整行剔除，裁决留依据；标出每个分子被哪些工具在训练时见过，之后只在都没见过的子集上比对错。

**为什么这一步不能往后放**：跳过它，后面所有以真值当裁判的数字都不成立，而这类错误在训完模型之后查不出来——那时数字都自洽，只是全都偏了。

### 3.4 第 2 步 · 遮工具造题

几个工具全错的分子很少，太稀疏，考不出"该不该认怂"。做法是每道题只让 agent 看到工具的一个子集，工具的每一种非空组合都出一道题，题量因此放大一个量级。

**弃答标签怎么定**：这道题的可见工具全部判错，就标为该弃答，由记录表按规则算出来，不需要人工判断。

**这批题要分两类**：本来所有工具就全错的，考"真的判不了时认不认怂"；有正确工具被遮掉的，考"能不能察觉证据不足"。两类混在一起会说不清测的是什么。

**同一个分子换一个子集，标签就翻转**。这就是把稀疏信号摊开的机制。

### 3.5 第 3 步 · agent 答题与算分

题面不预先摆出预测值，只给一份工具目录，agent 自己决定调哪个、要不要再多调一个复核，每次调用付代价。它要输出一个把握值，再据此决定作答还是把问题交出去。

**为什么要它主动**：给定一个分子和一个预测值、输出可信度分数，这件事经典方法已经做了几十年，我们没有优势。能拉开差距的是判断"我现在信息不够"，然后自己选一个动作去补。

**怎么算分**：答错罚一分，把问题交出去付一个较小的固定代价，两者加起来是总损失。**这样"什么时候该多查一步"不用我们规定，它从代价里自己长出来。** 成绩要对着三条参照线读——从不交出去、按多数票、只在该交时才交（上帝视角）。

**主任务是"这组结果能不能用"，不是"哪个工具准"**。后者的答案绑在具体工具上，换一套工具就作废；前者问的是这个分子本身难不难，换工具仍然成立。

**一条工程前置**：记录表要先包成几个可独立调用的工具接口，各有自己的名字和参数格式，否则这个形态跑不起来。

### 3.6 第 4 步 · 排除假信号

拿掉分子、只留几个工具的预测数字，用逻辑回归跑一遍。**若成绩打平，说明 agent 没在读分子**，学的只是"几个数字差得远就别信"——这条规律与化学无关，整条故事线作废。

这一步必须排在动模型之前。因为这个假信号跨领域通用，等到测迁移时它会显得很成功，看起来是好消息，实际是假阳性。

同时跑三条零成本对照：模型能不能直接背出答案；一律说"不可信"能拿多少分；同一张表上训个随机森林能做到多好。第三条若打平，说明我们在静态判断上没有贡献，差异只能落在主动取证上。

### 3.7 第 5 步 · 两条改进路线

**路线甲，不动模型**：统一工具目录的呈现方式，让模型没法靠名字眼熟来选；要求 agent 采信任何预测之前先写出自己的把握；把握低时强制再查一个工具。

**路线乙，改权重**：先让模型自己产生轨迹、按结果过滤，用留下来的做监督微调，把"先估把握"变成默认动作；再用一个对把握值的评分规则把它调准。不引外部强模型当老师。

**乙必须跟甲比。** 不先做甲，训练涨的分说不清是权重的功劳还是提示的功劳。

### 3.8 第 6 步 · 验证通用能力

两个方向。一是扣掉一个工具完全不训、只在它上面测；工具之间误差本来就可能相关，所以这里必须同时报两个工具误差的相关系数，否则"换工具仍然有效"这句话无法证伪。

二是换到非化学的、有标准答案的领域测，比如数学题或代码执行。**这个方向的结果只有在第 4 步通过之后才可解读**，顺序不能反。

如果第 4 步或迁移这一步失败，剩下的产出是一套带实验真值的评测集，加上"校准不迁移"这个实证负结果。负结果也可发表。
