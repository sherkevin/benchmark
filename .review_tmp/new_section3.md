## 3. 我们要做什么

### 3.1 一句话与全章主线

**一句话**：先把"多个工具对同一个分子给出互相矛盾的预测、且这个分子有实验测定值可以对照"这件事做成一张账本；再把账本机械地摊成一批题，题面问的不是"哪个工具准"而是"这一组预测能不能拿去做研发决策"；先用不花机时的检验判断这批题里有没有真信号，通过了才训模型；训完之后在**换一套工具**和**换一个领域**两个方向上验证，学到的是通用能力还是对这个工具池的记忆。

**读这一章能带走什么**：一个人只读本章，应该能复述出七站数据流、知道每一站的输入输出长什么样、知道哪几站已经做完、哪几站是闸门、以及方案在什么条件下判死。本章不依赖任何外部文档，所有公式、基线数字、阈值推导都在正文内给全。

**关键事实**（均为已核实，逐条出处见对应站）：

| # | 事实 | 数字 |
|---|---|---|
| 1 | 账本规模 | 730 个分子 × 4 个工具，每行带一条实验真值 |
| 2 | 冲突分布 | 400 行跨体系冲突、330 行无冲突；三轮复测概率漂移 0 |
| 3 | 四工具在 730 全集上的正确率 | morgan 87.67% ＞ admet_ai 86.99% ＞ mpnn 77.53% ＞ cnn 59.86% |
| 4 | 难度分布 | 12 个分子四个工具全错，318 个分子四个工具全对 |

### 3.2 站 0 · 账本：一个分子、四个工具、一条真值（已完成）

**这一站在做什么**：对同一批分子，用四个原理不同的本地模型各预测一遍同一个性质（能否透过血脑屏障），再把该分子的实验测定值挂上去，得到一张可以逐行核对"谁对谁错"的表。

**进什么**：730 个分子的 SMILES（分子结构的文本写法）。数据取自仓库冻结的 bbb 属性行。

**做什么**：四个模型各跑一遍，同一批输入跑三轮（discovery / replay1 / replay2）看结果是否稳定。四个模型是 ADMET-AI 1.4.0，以及 DeepPurpose 预训练的 BBB_MolNet 三个变体（cnn / morgan / mpnn）。全部是本地模型推理，不是查表。

**出什么**：一行长这样（`screening_ledger.jsonl` 第一行原文，数值未改）：

```
entity_id:        z000282
canonical_smiles: C[N+](C)(C)CCO          （胆碱）
experimental_truth.label: 1                （实验测定：能透过血脑屏障）
experimental_truth.source: frozen repository BBB_Martins property row

四个工具在这一行上的表现：
  admet_ai_1_4_0                 概率误差 0.6247   判定错  ← 唯一判错的
  deeppurpose_bbb_molnet_cnn     概率误差 0.0648   判定对
  deeppurpose_bbb_molnet_morgan  概率误差 0.0371   判定对
  deeppurpose_bbb_molnet_mpnn    概率误差 0.4296   判定对

initial_conflict_pairs: 3 对，scope 均为 cross_family
  （admet_ai 分别与 cnn / morgan / mpnn 冲突）
state: terminal_reproducible_cross_family_conflict
```

其中：

- **概率误差**（`absolute_probability_error`）= |模型输出概率 − 真值标签|。胆碱真值为 1，admet_ai 误差 0.6247 意味着它输出约 0.375，即倾向判"不能透过"；cnn 误差 0.0648 意味着它输出约 0.935。
- **判定对错**（`action_correct`）= 把概率按 0.5 二值化后与真值比。
- **cross_family**（跨体系）= 冲突发生在 ADMET-AI 与 DeepPurpose 两个不同来源的模型之间，不是同一来源的三个变体内部打架。区分这一点的原因见 §3.10 第 1 条。
- **terminal**（终态）= 三轮复测结论一致，这行的冲突判定不再变动。

胆碱是个说明性很强的例子：它带永久正电荷的季铵盐结构，按常规判断"透不过膜"，而实验值是能透过（胆碱有专门的转运体）。admet_ai 给出的正是那个"听起来很有道理"的错误答案。

**规模与结构**（`summary.json` 实测）：

| 项 | 值 |
|---|---|
| 达终态行数 | 730 / 730（`terminal_accounting_balanced = true`） |
| 跨体系冲突 | 400 行 |
| 无冲突 | 330 行 |
| 真值分布 | 522 阳 : 208 阴（偏斜） |
| 每个分子"对的工具个数" | 0 个:12 ｜ 1 个:56 ｜ 2 个:82 ｜ 3 个:262 ｜ 4 个:318 |
| 至少 2 个工具错 | 150 行；至少 3 个工具错 68 行 |
| 复测稳定性 | 四个模型均漂移 0（`numerically_drifting_replay_rows = 0`） |
| 可重建性 | 12 份 run 回执 + 内容指纹（`contract_sha256 = be642e41…`、`initial_conflict_set_sha256 = 7758ee6f…`）+ 密封自校 |

四个模型在 730 全集上的正确数：morgan 640（87.67%）、admet_ai 635（86.99%）、mpnn 566（77.53%）、cnn 437（59.86%）。

**为什么必须有这一站**：没有它，"工具会出错"只是一句判断；有了它，"哪一行谁错了错多少"是可以逐行核的记录。后面所有题目、标签、基线都从这张表机械导出，不再需要人工判断。

**这一站的边界（据实）**：账本目前只覆盖**一个性质**（血脑屏障渗透，二分类）。§3.9 列的其他数据源都还没有账本，属于扩量候选，不是已有资产。

### 3.3 站 1 · 真值体检：先确认"谁对"这件事站得住（阻塞闸门，零机时）

**这一站在做什么**：站 0 的账本里，"谁对谁错"完全由 `experimental_truth.label` 说了算。这个标签不是本项目做的文献调研，而是从外部数据集原样直取的。2026-09-02 的零机时核查发现它自己就有矛盾，所以在用它当裁判之前必须先体检。**这一站是新增的，位置在造题之前，不通过则下游全部数字不成立。**

**进什么**：账本 730 行 + 真值源文件（Harvard Dataverse `datafile/4259566`，2039 行，md5 `4c7ddf7260f9573476ba2d4ca877957f`，实测与清单逐字符一致）。

**做什么，以及查出了什么**（已核实）：

| 检查项 | 结果 |
|---|---|
| 传输层是否完整 | 硬。行数、md5、字节可核，文件没被动过 |
| 内容层是否有人逐条审过 | 没有。托管平台只发 DOI 不审内容；每一条的 `source_paper_doi` 记的是数据集平台论文，不是测该分子的实验文献；730 条溯源文本完全相同，做不到逐条溯源 |
| 源文件自身是否自洽 | **不自洽**。按入库口径归一后，**11 个分子的标签自相矛盾**（同一分子同时标 0 和 1） |
| 矛盾行有多少进了账本 | **8 个进了 730 行**（`z002970 z002971 z002986 z007002 z015731 z015796 z034653 z070887`），其中 **7 个落在 400 冲突集内** |
| 入库取的是哪一条 | "取文件里最后出现的那条"，8/8 符合。**这意味着真值由源文件行序决定，调行序标签就翻转** |
| 真值是否同时是工具的训练标签 | **是**。admet_ai 的 checkpoint 证据显示它在含该性质的 31 个分类任务上多任务训练；三个 DeepPurpose 变体在同源数据上训练；预登记 `screening.train_test_subset = false`，未限定测试集 |

一处交叉比对（本次新查）：站 0 那 12 个"四工具全错"的分子里，`z034653` 正是上面 8 个标签矛盾行之一。而这 12 个分子在站 2 里撑起 180 个"天然应升级"场景（§3.4），所以污染不是边缘噪声，它落在最吃重的那一小撮样本上。

**出什么**（这一站要产出的三样东西，尚未做）：

1. **11 行矛盾的处置结论**：逐行裁决取哪个标签，或整行剔除。裁决须留依据（例如普萘洛尔是脂溶性 β 阻滞剂、有临床中枢副作用，标"不能透过"那条基本可判为错行）。
2. **训练归属标注**：给 730 个分子逐个标注"哪几个工具在训练时见过它"。只在都没见过的子集上比较工具对错。
3. **一份重算后的基线表**：§3.5 现有的基线数字（0.15717 等）在清污前是**待重算**状态。

**哪些结论不受这一站影响**（已核实的可用边界）：

- **可用**——"四个工具在 400/730 个分子上互相矛盾"这个事实。冲突判定三轮 `stable = true`，且预登记锁死了真值在冲突集密封之后才 join（每行带 `joined_after_initial_conflict_set_sha256`，可机器核），整个筛选过程不碰真值。
- **不可用**——一切以真值当裁判的量：判定对错、概率误差排序、边际准确率、多数票、理想选择器。

**为什么必须有这一站**：跳过它，站 2 的"应升级"标签、站 3 的五条基线、站 4 的方差分解全部建在一个自己打自己的标签上。这类错误在训完模型之后是查不出来的——那时所有数字都自洽，只是全都偏了。

**这一站的副产品**：11 处矛盾本身是有用的素材。连人工汇编的实验数据集都会对同一分子给出相反结论，说明"计算结果不可靠"在数据层就已成立，不需要额外论证。

### 3.4 站 2 · 造题：把 730 行摊成 10950 道题（零机时，规则）

**这一站在做什么**：账本里"四个工具全错"只有 12 行，太稀疏，不足以考"该不该认怂"。做法是遮蔽——每道题只让 agent 看到四个工具中的一个子集，把稀疏的"全错"信号摊开。

**进什么**：清污后的账本。

**做什么**（规则，对固定输入给固定输出，无主观判断）：

- 每个分子 × 每个非空可见子集 V ⊆ {admet_ai, cnn, morgan, mpnn} 生成一道题。非空子集共 15 个（4 个单工具 + 6 个两工具 + 4 个三工具 + 1 个全集），故全集 N = 730 × 15 = **10950**。
- **遮蔽**的含义：子集外的工具不进题面，agent 看不到它们的预测，也不知道它们存在。
- **"应升级"标签**：V 内全部可见工具都判错 ⇒ 这道题应升级（意思是"手上这些工具答不了，该交给人或做实验"）。由账本机械判定。
- **一条硬规则**：agent 算风险分只准用结构证据（可见工具之间是一致还是冲突），**禁用工具自报的概率**。理由是已核实的反直觉现象——cnn 自称高置信（|p−0.5| ≥ 0.4）的 247 行里错了 153 行，自报置信度在这批数据上是反指标。

**出什么**（分层计数主表，实测；这张表同时就是难度梯度）：

| 层 | 定义 | 题数 | 应升级 | 分解 |
|---|---|---|---|---|
| H1 遮 3 留 1 | 只给 1 个工具 | 2920 | 642 | 单见 cnn 293 / mpnn 164 / admet 95 / morgan 90 |
| H2 遮 2 留 2 | 只给 2 个工具 | 4380 | 322 | admet+cnn 44 / admet+morgan 43 / admet+mpnn 78 / cnn+morgan 23 / cnn+mpnn 83 / morgan+mpnn 51 |
| H3 遮 1 留 3 | 只遮 1 个工具 | 2920 | 104 | 遮 morgan 38 / 遮 cnn 35 / 遮 admet 17 / 遮 mpnn 14 |
| H0 不遮 | 四个工具全给 | 730 | 12 | 即那 12 个四工具全错的分子 |
| 合计 | | **10950** | **1080（9.86%）** | 天然 180 / 遮蔽致假 900 |

遮得越狠应升级越多：应升级率从 H0 的 1.64% 单调升到 H1 的 21.99%。

**两个来源必须分桶**，不能混成一个池：

| 层 | 天然（四个工具本来就全错） | 遮蔽致假（有正确工具被遮掉了） |
|---|---|---|
| H1 | 48 | 594 |
| H2 | 72 | 250 |
| H3 | 48 | 56 |
| H0 | 12 | 0 |
| 合计 | **180** | **900** |

天然项只来自那 12 个分子（12 × 15 个子集 = 180）。这两类是两种病："真的没法判"考的是认不认怂，"恰好都错"考的是能不能察觉证据不足，报告强制分开报。

**走一个具体例子**（照表就能判，不用跑任何模型）：取"admet 对、cnn 错、morgan 对、mpnn 错"这个模式（共 40 行）。遮掉 admet 和 morgan、只给 cnn + mpnn，两个可见工具全错 ⇒ 应升级，来源标"遮蔽致假"；反过来遮掉 cnn 和 mpnn、只给 admet + morgan，两个可见工具全对 ⇒ 不应升级。**同一个分子换一个子集，标签就翻转**——这正是把稀疏信号摊开的机制。

两个机械恒等式，造题时可当交叉校验：H2 某一对的应升级数 = 该两工具在 730 全集上的同错行数；H3 遮某工具的应升级数 = 其余三工具的同错行数（例如遮 morgan 的 38 = 四工具全错 12 + 只有 morgan 对 26）。

**为什么必须有这一站**：不遮蔽的话，10950 道题退化成 730 道，其中只有 12 道考"该认怂"，统计上什么也测不出来。

### 3.5 站 3 · 答题与判分：agent 输出什么、成绩怎么算

**这一站在做什么**：把一道题交给 agent，收一张答卷，再把答卷折算成两个可比的数。

**进什么（题面）**：一个分子的结构与基本性质 + 可见工具子集 V 的预测值 + 一句任务描述。真值不在题面里，agent 拿不到。

**出什么（答卷三件）**：

| 输出 | 含义 | 是否被直接监督 |
|---|---|---|
| **u ∈ [0,1]** | "这一组预测能用的把握"。连续数，不是"信/不信"两档 | **是**，训练唯一的监督标量 |
| **g ∈ {答, 升级}** | 门控动作。部署时由 u 按预先冻结的阈值导出 | 否 |
| 若 g = 答：最终判定 + 采信了哪个工具 + 简要依据 | | 判定对错进结果项 |

**为什么主任务是"能不能用"而不是"哪个工具准"**：把工具 k 在分子 i 上的误差拆成四块：

$$e_{ik} = \mu + \alpha_i + \beta_k + \gamma_{ik} + \varepsilon_{ik}$$

其中：

- $e_{ik}$：工具 k 对分子 i 的预测与真值的偏差；
- $\mu$：全局平均误差，一个常数；
- $\alpha_i$：**分子主效应**——这个分子对所有工具都难的程度。它是分子的属性；
- $\beta_k$：**工具主效应**——这个工具的全局精度（例如 morgan 87.67% 比 cnn 59.86% 高，差的就是这一项）；
- $\gamma_{ik}$：**交互项**——"这个工具偏偏在这类分子上特别偏"。它同时绑定分子和工具；
- $\varepsilon_{ik}$：残差，含实验测定噪声。

由此得到一个绕不开的两难：

| 若主任务是 | 答案由哪一项决定 | 换一套工具之后 |
|---|---|---|
| 从 K 个预测里挑最准的 | **$\gamma_{ik}$**（绑定具体工具） | **失效**，学到的偏好全部作废 |
| 判断这组预测能不能拿去做决策 | **$\alpha_i$**（分子的属性） | **仍然有效** |

说白了：如果困难来自分子本身，那么所有工具会一起变差，"挑哪个"这件事没有信息量；如果"挑哪个"确实有信息量，那信息只能来自交互项，而交互项按定义就绑在具体工具上。所以"有信号"和"能迁移"在这个任务定义下不能同时成立——这是定义层的排斥，不是实验能裁定的。因此进训练环的主任务定为后者。

**四类评测任务与训练主任务的分工**（这条以前埋在小字里，现在明写）：

| | 内容 | 用途 |
|---|---|---|
| 评测侧（四类递进任务） | ① 同性质冲突识别 ② 跨性质异常诊断 ③ 预算约束下的复核与仲裁 ④ 下游决策恢复 | 量失败模式，**全部保留**，不进训练环 |
| 训练侧（一个任务） | 选择性作答：输出 u + 门控动作 | 唯一进训练环的任务 |

**判分口径**（四个公式，只吃"答卷动作 + 账本真值"两种输入，机械可判）。先立两个术语：**风险-覆盖曲线**就是"把'多大风险才值得升级'从松到紧排一排，看每一档留下来作答的题答得多准"；**选择性预测**指 agent 自己决定每题作答还是升级。

覆盖率（该阈值下留下来作答的比例）：

$$\mathrm{cov}(\tau)=\frac{1}{N}\sum_{i=1}^{N}\mathbb{1}\{g_i=\text{答},\ r_i\le\tau\}$$

其中：$N$ = 题目全集 10950；$g_i$ = agent 对第 i 题的动作，从答卷固定字段直接读；$r_i$ = 风险分，只用结构证据算，禁用工具自报概率，越大表示越不敢答；$\tau$ = 阈值，从松到紧扫过。

风险率（该覆盖档内答错的比例）：

$$\mathrm{risk}(\tau)=\frac{\sum_i \mathbb{1}\{g_i=\text{答},\ r_i\le\tau,\ a_i\neq y_i\}}{\max\left(\sum_i \mathbb{1}\{g_i=\text{答},\ r_i\le\tau\},\ 1\right)}$$

其中：$a_i$ = agent 采信的那个工具的预测，由答卷指定、账本查出；$y_i$ = 冻结真值；分母取 max(·,1) 防零除，覆盖为 0 时风险率定义为 0。

曲线下面积（一个数概括整条曲线，越小越好）：

$$\mathrm{AURC}=\frac{1}{K}\sum_{k=1}^{K}\mathrm{risk}(\tau_k),\qquad \tau_k=\frac{k}{K},\quad K=100$$

其中：$\tau_k$ = 把阈值均匀切成 100 档的格点。曲线只依赖风险分的大小排序，不依赖量纲。若 agent 不输出风险分，AURC 退化为单点风险率，报告须标注"单点、非曲线"。

代价敏感总损失（**主指标**，三种模式互相比较用它）：

$$E=\frac{1}{N}\sum_{i=1}^{N}\left(\mathbb{1}\{g_i=\text{答},\ a_i\neq y_i\}+c\cdot\mathbb{1}\{g_i=\text{升级}\}\right)$$

其中：错答代价 $\lambda \equiv 1$，是代价单位；$c$ = 一次升级相对一次错答的代价倍数，运行前冻结（取值见下）。

另有两个诊断率，不进 $E$，只用来看损失偏向哪一头：**过度升级率** = 升级的题里"可见工具中本来就有对的"的占比；**漏升级率** = 没升级的题里"可见工具全错"的占比。

**五条强制参照线**（实测于 10950 全集；任何 agent 的成绩必须对着这张表读。⚠️ 站 1 清污后须重算）：

| 策略 | 定义 | 全集 | H1 | H2 | H3 | H0 |
|---|---|---|---|---|---|---|
| Ref-A 优先级链 | 恒不升级，按 morgan＞admet＞mpnn＞cnn 取第一个可见者（顺序与 730 准确率一致） | 错误率 **0.15717** | 0.21986 | 0.14247 | 0.12500 | 0.12329 |
| Ref-B 多数票 | 可见工具多数票，平票按 Ref-A 链裁决 | 错误率 0.16356 | 0.21986 | 0.14247 | 0.14932 | 0.12192 |
| oracle 升级 | 只在应升级处升级（开了上帝视角的参照） | 升级率 **0.09863** | 0.21986 | 0.07352 | 0.03562 | 0.01644 |
| 恒升级 | 每题都升级 | 损失恒为 $c$ | — | — | — | — |
| 恒不升级 | 即 Ref-A | 损失恒为 0.15717 | | | | |

表里有一个直读现象：Ref-B 在 H3 层反而比 Ref-A 差（0.14932 ＞ 0.12500）——多数票把投票权分给了准确率只有 59.86% 的 cnn，被拖累。所以基线必须逐层报，只看全集会把这种结构性差异拖平。

**用法**：agent 的 $E$ 必须同时赢两头——低于恒不升级的 0.15717（说明升级机制创造了价值），且不高于恒升级的 $c$（说明不是无脑全升）。

**升级代价 c 怎么定**（不拍脑袋，从冻结数字推）：

- 锚 1：恒不升级的损失 = Ref-A 全集错误率 = 0.15717。
- 锚 2：理想升级率 = 1080 / 10950 = 0.0986。
- 三条恒等式：oracle 总损失 = 0.0986·c（升级的题付 c、作答的题全对）；恒升级损失 = c；恒不升级损失 = 0.15717。于是恒升级赢恒不升级 ⟺ c ＜ 0.157；oracle 赢恒不升级 ⟺ 0.0986·c ＜ 0.15717 ⟺ c ＜ 1.5935。
- 结论：c ＜ 0.157 时恒升级占优、c ＞ 1.59 时恒不升级占优，界外所有"聪明"策略都被极端策略压死、排名贴边。所以**有效区间取 (0.157, 1.59]**。

| c | 位置 | 恒不升级损失 | 恒升级损失 | oracle 损失 = 0.0986c | 用途 |
|---|---|---|---|---|---|
| 0.25 | 区间内 | 0.15717 | 0.25 | 0.0247 | 主档 |
| 0.5 | 区间内 | 0.15717 | 0.5 | 0.0493 | 主档 |
| 1.0 | 区间内 | 0.15717 | 1.0 | 0.0986 | 主档 |
| 0.1 | 界外（下） | 0.15717 | 0.1 | 0.0099 | 哨兵 |
| 2.0 | 界外（上） | 0.15717 | 2.0 | 0.197 | 哨兵 |

正式比较只用三个主档；两个哨兵档不进成绩表，作用是自检判分器——c=0.1 下"恒升级必胜"是恒等式，若实测不是，先修判分器再跑正式。全部规则（公式、基线、档位、来源分桶）在 agent 运行前写入预注册文件冻结。跨档要算排名一致性（Kendall τ：1 = 完全同序，0 = 无关），任何排名翻转逐条列出，不许埋。

**评测环境**：agent 在可执行沙箱里拿到初始预测和工具目录，可自主调用同功能或互补工具；每次调用有成本；拿不到隐藏真值。系统记录完整工具回执、参数、证据引用和决策时间。

**这一站在做什么**：在申请任何 GPU 之前，用不花机时的方法回答"这批题里到底有没有可学的东西"。五条**顺序不可颠倒**，全部通过才进站 5。

| 5 | **纯采样基线** | 不训练，只把采样量加大（pass@k：采 k 个答案里有一个对就算对），看能不能匹配训练后的成绩 | 训练提升不超纯采样 ⇒ 拿到的是锐化不是真实增益 |

**杀实验的消融矩阵**（730 分子、按骨架切分、报 bootstrap 置信区间）：

| 模型 | 输入 | 判读 |
|---|---|---|
| A 全管线 | 分子结构 + 推理过程 + 四个工具预测 | 主方法 |
| **B scalar-only** | 只给四个预测数值（逻辑回归就够），没有任何化学内容 | **B ≈ A ⇒ 内容叙事作废，方向重定** |
| C identity-only | 工具名 + 四个预测，没有分子内容 | C ＞ A ⇒ 工具身份比分子内容重要 |
| D random | — | 下界 |
| E conformal | conformal prediction 基线 | 经典擂台（与检验 3 同族） |
| **F content-shuffled** | 把预测和分子故意错配（打断内容与校准的关联，但保留预测值的分布） | **性能不变 ⇒ 用的是数值方差，不是分子内容** |

为什么这条必须前置：730 个分子这个量级下，最强的可学信号很可能就是"四个数字分歧大 = 别信"。这个规律不需要任何化学知识，而且因为它跨领域通用，**迁移测试会看起来成功**——这是一个结构性的假阳性。B 和 F 两个消融就是专门用来把这条假阳性打死的。

**另加 LOTO（leave-one-tool-out，留一个工具不训）**：用 3 个工具训、在第 4 个上测。换工具重测时**必须同时报残差相关系数**——四个工具里有三个同属 DeepPurpose，误差本来就相关，不报相关系数的话"换工具仍然有效"这句话不可证伪。

**止损点**：这一站结束时若 scalar-only 打平全管线，停掉训练线，把已有设施整理成一篇纯 benchmark 论文（10950 道题 + 五条强制基线 + 预注册代价表 + 杀实验结果，本身就是最小可发表单元）。

### 3.7 站 5 · 训练：从题目到梯度（需 GPU）

**这一站在做什么**：让模型把"先估把握、再决定信不信"变成默认动作。

**为什么要分两步**：强化学习只能放大策略里**已经有**的行为，不能凭空造出来。如果基座模型从来不会在采信一个预测前先估把握，那么无论跑多少轮，采样出来的轨迹里压根没有这种行为供奖励去筛选。所以必须先有一步冷启动把行为的"形"灌进去，再用奖励把它的"准"磨出来。

**第一步 · 冷启动（学形式）**

- 做法：**拒绝采样自举**——让模型自己在题目上多采样几条轨迹，按结果过滤，只留"把握报得准且最终判定对"的，用它们做监督微调。推理漂亮但答案错的丢掉。
- 硬约束两条：**不用 teacher 模型、不做蒸馏**。
- 这一步之后，"输出一个把握值"成为模型的默认动作，部署时不需要任何特殊提示。

**第二步 · 强化（学准）**

奖励函数：

$$R = \mathbb{1}\{\text{最终判定对}\} - \beta\cdot(u - a)^2 - \gamma\cdot(\text{工具调用数} - 1)$$

其中：

- $\mathbb{1}\{\cdot\}$：判定对得 1、错得 0；
- $u$：模型自己报的把握（$[0,1]$ 的连续数）；
- $a$：这一题实际的对错（对 = 1，错 = 0）；
- $(u-a)^2$：**Brier 分数**，把"报的把握"和"实际对错"的差平方。它是**严格 proper 的评分规则**——意思是诚实报告自己真实的把握是唯一的全局最优解，靠报 0.5 对冲拿不到额外好处（真的不确定的题本来就该报 0.5）；
- $\beta$：Brier 项的权重；
- $\gamma$：每多调一次工具的代价。$\gamma$ 与 $\beta$ 的比值有真实锚点——一次实验验证的钱对一次计算调用的钱，不是拍脑袋的超参。

三条设计约束：

| 约束 | 内容 | 理由 |
|---|---|---|
| u 必须连续 | 训练只产出连续的把握值，答 / 升级的阈值留到部署时按真实成本比套 | 若把动作设成离散几档并各配一个奖励数，最优策略会解析地落在一个常数动作上（阈值 $p^* > 1-\varepsilon/\lambda$，代入 $\varepsilon=0.1,\lambda=2$ 得 0.95，等于几乎永远升级）。这是 cost-sensitive learning 的定理推论，不是训练技巧能绕的 |
| 算法用 REINFORCE++ 或 PPO+critic | 不用组内相对归一化那一类 | 组内归一化在"一组采样全对或全错"时给出零梯度，是有偏估计，正好在需要信号的地方失效 |
| 训练面保留工具身份 | 遮蔽只在评测侧做 | 训练时若把工具身份抹掉，两个观测相同而实际可靠性不同的输入会强迫模型给出同一个把握值，等于逼它报错 |

**抗过度锐化**：本项目有一个特殊条件——有了误差表，"模型极少产生但确实正确"的轨迹可以被无歧义地标出来，可以对这类轨迹做定向强化。数学题上做不到这一点，因为无法判断哪条罕见推理是对的。这条是**待验假设**，不是已成结论。任何训练带来的提升，必须同时报站 4 第 5 条那个纯采样基线。

**资源**：见 §4.1。这一站是全流程 token 消耗的大头（约六成落在强化阶段的采样上）。

### 3.9 数据扩量路线（候选，尚无账本）

站 0 的账本目前只有一个性质。下列数据源是扩量候选，**均未建账本**，写在这里是为了说明扩量往哪走、以及每一处能贡献什么冲突类型。

**小分子侧**

- **CACHE**：面向真实靶点的候选提交、实验测定与公开结果，可构造虚拟筛选排序、错误共识与命中恢复。
- **SAMPL**：pKa、logD、溶剂化与结合自由能等盲测数据，适合比较多个性质预测或自由能工具的系统误差。
- **D3R、CASF-2016**：蛋白—配体构象、亲和力排序、打分与筛选数据，可构造对接与亲和力冲突。
- **ChEMBL、BindingDB、TDC**：大规模生物活性、结合常数与吸收/分布/代谢/毒性端点，用于扩量、校准与外推。

**蛋白与抗体侧**

- **AIntibody**：盲测设计 + 实验亲和力 + 表达、热稳定性、聚集、多反应性等成药性测量，适合构造跨性质冲突。
- **CASP、CAPRI、FoldBench**：结构、蛋白—蛋白与抗体—抗原界面、全原子预测冲突；实验结构真值取自 PDB。
- **ProteinGym**：深度突变扫描数据，可测多个适应度/稳定性预测器不一致时的复核与恢复。

**四条统一与切分原则**

1. 先统一实体、质子化状态、构象、单位、实验条件与端点定义，避免把"定义不同"误标成"工具错误"。
2. 不以随机篡改数值为主，而从真实工具残差里抽取自然分歧、错误共识、适用域外、活性悬崖与高置信度错误；必要的受控注入也按真实误差分布生成。
3. 按骨架、蛋白家族、靶点和时间切分开发集、校准集、冻结测试集与隐藏外推集，实验真值只留在私有判分器里。
4. 每个来源记录许可证、可再分发范围与下载日期；不能公开再分发的只发布构建脚本、样本标识与评测接口。

| 7 | 730 行对强化阶段的采样量偏小；评测够用，训练不够 | 扩量见 §3.9 |
| 8 | 训练栈未就位：仓库无相关依赖、无强化学习实现代码 | 站 5 的工程前置 |
| 9 | 现行 benchmark 运行面仍是单一真值表（只有一个查表工具、无工具分歧、无置信度字段），账本尚未接进 agent 的工具面 | 站 2/站 3 的工程前置 |
