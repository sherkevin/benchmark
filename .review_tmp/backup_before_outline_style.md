# 制药科学预测冲突诊断与恢复 Agent Benchmark：Proposal

## 1. 背景与动机

###  1.1 基本事实
1. 当前制药 Agent 已能调用大量分子性质、对接、亲和力、ADMET、蛋白结构和成药性预测工具。但这些工具多为统计学习或模拟计算，即使正常返回、格式正确、数值看似合理，也会因训练偏差、适用域变化、构象与参数假设等产生误差。多个工具可能对同一性质给出矛盾结论，甚至在错误方向上形成“伪共识”。

2. 化学信息学的工具生态极度碎片化，同一功能有一堆互不兼容的实现，而且差异大到有文献专门讨论。最典型的是 logP：RDKit 的 Crippen 算法、XLogP3、ALOGPS、ChemAxon 对同一个分子能差出 1-2 个 log 单位——这直接决定这分子是"成药性好"还是"成药性差"。你不用编造冲突，去跑一遍就有。这是天然存在的，且在制药领域这个问题尤为突出

### 1.2 研究动机

本项目的出发点是一个关于 agent 工具使用的 **一般性观察** ，以及它在制药域的一个**可测量外显**。

**A（本质问题，一般层）**：训练后 agent 的工具偏好分布 ≠ 任务最优分布。根本原因：训练-推理 harness 不一致 + 注意力向熟悉 token 集中，导致 agent 对训练时见过的工具过度自信、对功能等价的新工具系统性回避。这其实是一个很 general 的问题，可以称之为 **工具过拟合**，本质上是在训练的时候见过一些工具过多，在后续真正的生产环境工作的时候会更偏好这种工具，和这些工具的契合度更好，但是外部工具是多种多样的，其价值不取决于 agent 在训练时候见过没见过，而是取决于对于任务本身的裨益，这就产生了一个 gap，也就是本身的模型任务指标和其训练的 gap

**B（外显，行为层）**：在 K 个功能重合的工具间，agent 偏向"更熟悉的"而不是"在这个任务上更可能有效的"。因为工具过拟合的一就是对工具使用过于自信，这就是问题 A 的外显

**C（信号，数据层）**：要捕捉这个外显的 B 行为，就要有一个可衡量的信号可量化这个行为的程度，当 Agent 根据自己的偏好选择对应的工具后若该工具出现了结果错误，即捕捉到了该信号，我们要做的就是对该信号进行建模


我们本质上是想要解决问题 A，问题 A 是一个根本问题，是一个 general 的问题，在这里就是工具过拟合问题，没办法直接来解决它而只能通过他的外显来间接缓解它，表现 B 就是问题 A 的一个外显，这个 B 就是选工具有偏好，这个 B 动作会产生一个信号就是 C，也就是工具选错，这个选错的判断来自于其输出结果不对，从而我们拿到了一个信号，通过建模这个信号并将其看作一个与 loss 关联的值，通过消掉 loss 去解决 B，从而缓解 A，这是一个比较清晰的故事线，而且是有价值的，因为其最终指向了一个 general 的问题。


在叙述上，我们说真正关键的问题不是 Agent 能否处理超时或异常，而是：**当科学工具正常工作但结果不可靠时，Agent 能否利用同功能工具和其他相关性质发现异常、定位可疑属性、选择更可靠的结果，并恢复后续研发决策。** 这直接影响虚拟筛选、先导优化、蛋白/抗体设计和候选优先级判断的可信度。

## 2. 别人做了什么，我们剩下什么

这一节按本提案的主张来切维度，不按各家自己的研究目标切。要问的是六件事：冲突是天然的还是人工造的、判对错靠什么、有没有多个功能重合的工具、有没有评"该不该相信这个结果"、agent 能不能弃答或者把问题交出去、以及分数能不能拿去训练。

### 2.2 校准与选择性作答类方法

这一类是对本提案威胁最大的一批，因为它们做的正是"让模型把自己的把握报准"。2026-09-02 的文献评审把它们逐条列了出来，结论是本提案在方法层没有创新空间。

| 工作 | 它做了什么 | 在什么域上做 | 涉及工具冲突 | 有决策代价 | 与本提案的重叠 |
|---|---|---|---|:---:|:---:|---|
| Rewarding Doubt | 用严格评分规则加结果奖励训模型报把握，并展示了跨任务迁移 | 事实问答 | 无 | 无 | 最直接的先例。"训校准能迁移"这句话已被它说过 |
| Taming Overconfidence | 改造策略优化算法压过度自信 | 通用问答 | 无 | 无 | 与训练侧的奖励设计重叠 |
| DCPO | 指出准确率目标与校准目标之间存在梯度冲突 | 可验证奖励任务 | 无 | 无 | 本提案的两段式管线必须回应这个冲突 |
| RefGRPO | 让 agent 当自己的验证器，只对判为正确的轨迹下结论 | agent 任务 | 部分 | 无 | 与"作答或交出去"的动作设计重叠 |
| Tool-R0 / Agentic-DPO | 遮蔽工具名与函数签名，提升对新工具的泛化 | 工具调用 | 无 | 无 | 与遮蔽设计重叠 |
| RLMF | 两段式解耦校准，也声称可泛化 | 通用 | 无 | 无 | 与两段式训练重叠 |
| Know Your Limits 弃答综述 | 系统梳理弃答问题 | 通用 | 无 | 部分 | "把问题交出去"属于其中一类 |

所以本提案不声称校准方法上的创新。**剩下的位置是数据来源与任务形态两条**：其一，化学是目前唯一能同时提供客观实验金标准、天然多工具冲突、以及真实决策代价这三样的领域，而上表所有工作都缺其中至少两样；其二，把主任务从"挑哪个工具准"改成"这组结果能不能拿去做决策"，是任务定义层的改动，理由见 §3.5。

## 3. 我们要做什么

### 3.1 一句话与全章主线

一句话：先把"多个工具对同一个分子给出互相矛盾的预测、且这个分子有实验测定值可以对照"这件事做成一张账本；再把账本机械地摊成一批题，题面问的不是"哪个工具准"而是"手上这些结果能不能拿去做研发决策"；先用不花显卡的检验判断这批题里有没有真信号，通过了才动模型；改完之后在换一套工具和换一个领域两个方向上验证，看学到的是通用能力还是对这个工具池的记忆。

读完这一章应该能做到四件事：复述七站的顺序、说出每站的输入与输出、指出哪几站是必须先过的关卡、以及说出方案在什么条件下判死。本章不依赖其他文档，公式、术语、判分规则都在正文里给全。本章正文只给量级，全部精确读数集中在 §3.11。

七站主线：

| 站 | 干什么 | 进什么 | 出什么 | 由谁完成 | 现在什么状态 |
|---|---|---|---|---|---|
| 0 | 造账本 | 一批分子 + 四个本地预测模型 | 七百余行"工具—预测—实验值"记录 | 脚本调本地模型 | 已完成 |
| 1 | 真值体检 | 账本 + 真值来源文件 | 可用与不可用的分子名单、工具训练归属标注 | 脚本查文件 + 人工裁决少数几行 | 必须先过，不用显卡 |
| 2 | 造题 | 体检后的账本 | 约一万道题，每题带"该不该交出去"的标签 | 脚本按固定规则生成，无人工判断 | 规则已定，不用显卡 |
| 3 | agent 答题、程序判分 | 一道题 | 一张答卷，折算成一条曲线和一个总损失数 | agent 答，脚本判 | 判分口径已定 |
| 4 | 前置检验与证伪实验 | 题目 + 传统统计方法做的对照 | 五个通过或不通过的判定 | 脚本跑随机森林、逻辑回归等，不用大模型 | 必须先过，不用显卡 |
| 5 | 两条干预路线 | 题目 + 判分器 | 一个会先估把握再决定的 agent | 路线甲改提示与工具呈现，路线乙改模型权重 | 路线甲不用显卡，路线乙要用 |
| 6 | 评测与迁移 | 干预后的 agent | 换工具、换领域两组成绩 | 脚本 | 要用显卡 |

关于"不用显卡"这个说法：本章用它指这一站只跑传统统计方法或规则脚本，不需要大模型推理、也不需要训练，成本以分钟计。要用显卡的站需要反复采样与参数更新，成本以卡天计。

贯穿全章的例子：账本第一行那个分子。后面每一站都拿它走一遍，看它在这一站变成什么。

关于全章数字的一条统摄声明：本章的数字分两类。第一类不依赖真值，包括账本有多少行、哪些行的工具互相矛盾、复测是否稳定、题目有多少道；这些在筛选过程中没有碰过真值，站 0 的密封机制保证了这一点，结论稳固。第二类以真值当裁判，包括四个工具谁对谁错、准确率排名、"该不该交出去"的标签、参照线、代价区间；这些都建立在实验真值这一个字段上，而站 1 已经查出这个字段自身有矛盾。**第二类数字一律是体检前的读数，站 1 之后须整批重算**，本章保留它们只为说明量级与结构，不作为结论引用。

### 3.2 站 0 · 账本：一个分子、四个工具、一条实验值。这一站已经做完

这一站做的事：对同一批分子，用四个原理不同的本地模型各预测一遍同一个性质，再把该分子的实验测定值挂上去，得到一张可以逐行核对"谁对谁错"的表。选的性质是能否透过血脑屏障，这是个二分类问题，答案只有能透过和不能透过两种。

进什么：七百余个分子的结构，写成 SMILES，这是把分子结构写成一行文本的通用格式。分子与实验值取自公开数据集 Therapeutics Data Commons 里名为 BBB_Martins 的血脑屏障条目，本项目把它冻结成一份固定快照后使用。

做什么：四个模型各跑一遍，同一批输入连跑三轮，看结果是否稳定。四个模型是 ADMET-AI，以及 DeepPurpose 预训练的三个变体，分别基于卷积网络、Morgan 指纹和消息传递网络。全部是本地模型真实推理，不是查表。

出什么：一行记录长这样，这是账本第一行的原始内容，数值未改：

```
分子编号   z000282
分子结构   C[N+](C)(C)CCO        这是胆碱
实验测定   能透过血脑屏障
真值来源   公开数据集 BBB_Martins 的冻结快照

四个工具在这一行上的表现：
  ADMET-AI          判"不能透过"   错
  DeepPurpose 卷积   判"能透过"     对
  DeepPurpose 指纹   判"能透过"     对
  DeepPurpose 消息   判"能透过"     对

这一行被标为：跨体系冲突，且三轮复测结论一致
```

其中三个字段需要解释：

- **跨体系冲突**指分歧发生在 ADMET-AI 与 DeepPurpose 这两个不同来源的模型之间，不是同一来源的三个变体内部打架。这个区分很重要，理由见 §3.10 第三条风险。
- **三轮复测结论一致**指同一批输入跑三遍，这一行的冲突判定没有变过，所以它是稳定的而不是碰巧。
- 每个模型除了给出判定，还给出一个 0 到 1 之间的概率。概率与真值的差额也记在账本里，用来区分"错得离谱"和"擦边错"。

胆碱这个例子说明性很强。它带永久正电荷的季铵盐结构，按常规判断应该透不过细胞膜，而实验值是能透过——胆碱有专门的转运体把它运进去。ADMET-AI 给出的正是那个"听起来很有道理"的错误答案。

规模与结构如下，精确数见 §3.11。账本七百余行全部达到终态，其中约四百行是跨体系冲突、三百多行没有冲突；真值分布偏向"能透过"一侧；四个工具的正确率最高的接近九成、最低的不到六成；有十来个分子四个工具全部答错，三百多个分子四个工具全部答对。三轮复测中四个模型的输出概率都没有漂移。整批产物带十二份运行回执和内容指纹，可以重建。

为什么必须有这一站：没有它，"工具会出错"只是一句判断；有了它，"哪一行谁错了、错多少"是可以逐行核的记录。后面所有题目、标签、参照线都从这张表按规则导出，不再需要人工判断。

这一站的边界：账本目前只覆盖一个性质。§3.9 列的其他数据源都还没有账本，属于扩量候选，不是已有资产。

### 3.3 站 1 · 真值体检：先确认"谁对"这件事站得住

这一站做的事：站 0 的账本里，"谁对谁错"完全由实验真值那一个字段说了算。这个字段不是本项目做的文献调研，而是从外部数据集原样直取的。2026-09-02 的核查发现它自己就有矛盾，所以在用它当裁判之前必须先体检。这一站排在造题之前，不通过则下游全部数字不成立。

进什么：账本全部行，加上真值的来源文件。来源文件的传输完整性已核过——行数、校验码、字节都与清单逐字符一致，文件没有被改动过。

做什么，以及已经查出了什么：

| 检查项 | 结果 |
|---|---|
| 文件本身有没有被改动 | 没有。校验码与行数都对得上 |
| 内容有没有人逐条审过 | 没有。托管平台只负责发布不审内容；每一条记录的出处指向数据集平台的论文，而不是测这个分子的实验文献；全部记录的出处文本完全相同，做不到逐条溯源 |
| 源文件自身是否自洽 | 不自洽。按本项目取值时用的归一口径处理后，有十来个分子的标签自相矛盾，即同一个分子同时被标成"能透过"和"不能透过" |
| 矛盾行有多少进了账本 | 八个进了账本，其中七个落在跨体系冲突集内 |
| 同一分子有两条时取的是哪一条 | 取源文件里最后出现的那一条，八行全部符合这个规律。这意味着真值由源文件的行序决定，调一下行序标签就翻转 |
| 真值是不是同时也是工具的训练标签 | 是。ADMET-AI 在包含这个性质的多任务集合上训练过；三个 DeepPurpose 变体在同源数据上训练过；而且取数时没有限定只用这些工具的测试集 |

还有一处交叉比对：站 0 那批"四个工具全错"的分子里，有一个正是上面八个标签矛盾行之一。而那批分子撑起了站 2 里全部"天然该交出去"的题目，所以污染不是边缘噪声，它落在最吃重的那一小撮样本上。

出什么，这一站要产出三样东西，都还没做：

1. 矛盾行的处置结论。逐行裁决取哪个标签，或者整行剔除。裁决要留依据。举个例子，普萘洛尔是脂溶性 β 阻滞剂、有明确的临床中枢副作用，那么把它标成"不能透过"的那一条基本可以判为错行。
2. 训练归属标注。给每个分子逐个标出"哪几个工具在训练时见过它"，之后只在四个工具都没见过的子集上比较对错。
3. 重算后的参照线。§3.11 现有的参照线数字在体检前都是待重算状态。

哪些结论不受这一站影响：

- 可用的是"四个工具在约四百个分子上互相矛盾"这个事实。冲突判定三轮都稳定，而且流程上锁死了真值必须在冲突集密封之后才允许挂上去，每一行都带着可机器核验的指纹，整个筛选过程不碰真值。
- 不可用的是一切以真值当裁判的量：判定对错、误差排序、边际准确率、多数票、理想选择器。

为什么必须有这一站：跳过它，站 2 的标签、站 3 的参照线、站 4 的方差分解全部建在一个自己打自己的字段上。这类错误在训完模型之后是查不出来的——那时所有数字都自洽，只是全都偏了。

这一站还有个副产品：那十来处矛盾本身是有用的素材。连人工汇编的实验数据集都会对同一个分子给出相反结论，说明"计算结果不可靠"在数据层就已经成立，不需要额外论证。

### 3.4 站 2 · 造题：把账本摊成一批题

这一站做的事：账本里"四个工具全错"只有十来行，太稀疏，不足以考"该不该认怂"。做法是遮蔽——每道题只让 agent 看到四个工具中的一个子集，把稀疏的信号摊开。

进什么：体检后的账本。

做什么，全部是固定规则，同一输入永远给同一输出，没有人工判断：

- 每个分子配上工具的每一个非空子集，各生成一道题。四个工具一共有十五个非空子集：四个只给单个工具，六个给两个工具的组合，四个给三个工具的组合，还有一个是全集。所以题目总数是分子数乘十五，约一万道。
- 遮蔽的含义：子集以外的工具不出现在这道题的工具目录里，agent 看不到它们、也不知道它们存在。
- "该交出去"这个标签的定义：这道题的可见工具全部判错。由账本按规则判定。
- 一条硬规则：题面可以让 agent 调出工具的预测概率，但 agent 判断风险时不准把这个自报概率当可信度用，只能用可见工具之间的一致与分歧结构。完整理由与实测依据见 §3.5。

出什么：约一万道题，按遮蔽程度分成四层。遮得越狠，"该交出去"的题就越多——只给一个工具时这个比例超过两成，四个工具全给时只有百分之一点几。这个梯度本身就是难度梯度。各层的精确题数与标签数见 §3.11。

这批"该交出去"的题必须按来源分成两桶，不能混：

- **天然的**：四个工具本来就全错。考的是"真的没法判时认不认怂"。
- **遮蔽造成的**：本来有工具能答对，但它被遮掉了。考的是"能不能察觉手上的证据不足"。

天然的那一桶只来自那十来个分子，数量固定；遮蔽造成的占绝大多数。这是两种不同的病，报告里强制分开报。

走一个具体例子，照账本就能判，不用跑任何模型：取"第一个和第三个工具答对、第二个和第四个答错"这个模式的分子。遮掉答对的那两个、只给答错的两个，于是可见工具全错，这道题标为该交出去、来源是遮蔽造成的；反过来遮掉答错的两个、只给答对的两个，可见工具全对，这道题就不该交出去。同一个分子换一个子集，标签就翻转。这就是把稀疏信号摊开的机制。

造题时有两条恒等式可以当交叉校验用：两工具组合的"该交出去"数量，应该等于这两个工具在全集上同时答错的行数；遮掉某一个工具后的数量，应该等于其余三个工具同时答错的行数。对不上就说明生成脚本有错。

为什么必须有这一站：不遮蔽的话题目总数只有七百余道，其中只有十来道考"该认怂"，统计上什么都测不出来。

### 3.5 站 3 · agent 怎么答、成绩怎么算

这一站做的事：把一道题交给 agent，收一张答卷，再把答卷折算成两个可以互相比较的数。

进什么，也就是题面：一个分子的结构与基本性质，一份工具目录，里面只列出这道题的可见子集，另有一句任务描述。真值不在题面里，agent 拿不到。

**agent 是主动的，不是被动看结果**。这一点是本提案与经典做法的分界，要说清楚：题面不预先把可见工具的预测值全部摆出来，而是给一份工具目录，agent 自己决定调哪个、要不要再多调一个来复核。每次调用都要付代价。这样设计的理由是，经典的适用域判定方法在这个领域已有几十年积累，它做的事是给定一个分子和一个预测值、输出一个可信度分数，本提案在那件事上没有优势；能拉开差距的是经典方法做不到的那一步——判断"我现在信息不够"，然后自己选一个动作去补。

由此带来一条工程前置：现在的运行面只有一个查表工具，账本还没被包成多个可独立调用的工具。要跑主动取证形态，必须先把账本包成四个工具接口，各自有自己的名字、参数格式与返回结构。这是站 2 与站 3 开工前的工程条件，见 §3.10 第九条风险。

遮蔽与"可自主调用"不冲突，因为工具目录里只列出这道题的可见子集，被遮蔽的工具不在目录里、也不在任何提示中出现，agent 无法把它调回来。agent 的自主性体现在两件事上：在可见子集内决定调哪个、调几个，以及决定作答还是把问题交出去。

出什么，一张答卷有四个字段：

| 字段 | 含义 | 是否被直接监督 |
|---|---|---|
| 把握值 u，取 0 到 1 | "手上这些结果能用的把握"。是连续的数，不是"信"与"不信"两档 | 是，训练唯一的监督目标 |
| 风险分 r，取 0 到 1 | 用来把所有题从"敢答"到"不敢答"排序，画曲线用。取 r = 1 − u 就够 | 否，由把握值导出 |
| 动作：作答，或者把问题交出去 | 由把握值按下面的阈值规则导出 | 否 |
| 若作答：最终判定、采信了哪个工具、简要依据 | | 判定对错进结果项 |

同时系统记录 agent 实际调了哪些工具、调了几次，这决定成本项。

关于风险分那条硬规则的理由：实测发现工具的自报置信度在这批数据上是反指标——四个工具里正确率最低的那个，在它自称最有把握的那批行上错了六成以上。所以风险分只准用可见工具之间的一致与分歧结构。至于"用结构证据"具体怎么落成一个数，也就是分歧的对数、可见工具个数、极端概率的个数各占多少权重，本轮未定，要在跑之前预注册冻结。曲线只依赖风险分的大小排序，所以任何保序的写法给出同一条曲线。

阈值规则可以直接算出来，不是待定的超参。作答一题的期望损失就是答错的概率，也就是 1 − u；把问题交出去的损失固定是 c，也就是交出去一次相对答错一次的代价倍数。两者比大小即得：

$$\text{作答} \iff 1-u < c \iff u > 1-c$$

所以 c 取 0.25 时阈值是 0.75，c 取 0.5 时阈值是 0.5。这条规则解释了为什么训练只需要产出连续的把握值：阈值完全由部署环境的成本比决定，同一个模型换个成本环境不必重训。

**为什么主任务是"能不能用"而不是"哪个工具准"**。把工具 k 在分子 i 上的误差拆成几块：

$$e_{ik} = \mu + \alpha_i + \beta_k + \gamma_{ik} + \varepsilon_{ik}$$

其中：

- $e_{ik}$：工具 k 对分子 i 的预测与实验值的偏差；
- $\mu$：全局平均误差，一个常数；
- $\alpha_i$：分子主效应，指这个分子对所有工具都难的程度。它是分子的属性；
- $\beta_k$：工具主效应，指这个工具的全局精度。四个工具正确率从不到六成到接近九成，差的就是这一项；
- $\gamma_{ik}$：交互项，指"这个工具偏偏在这类分子上特别偏"。它同时绑定分子和工具；
- $\varepsilon_{ik}$：残差，包含实验测定本身的噪声。

由此得到一个绕不开的两难：

| 若主任务是 | 答案由哪一项决定 | 换一套工具之后 |
|---|---|---|
| 从几个预测里挑最准的 | 交互项，它绑定具体工具 | 失效，学到的偏好全部作废 |
| 判断这组结果能不能拿去做决策 | 分子主效应，它是分子的属性 | 仍然有效 |

说白了：如果困难来自分子本身，那么所有工具会一起变差，"挑哪个"这件事没有信息量；如果"挑哪个"确实有信息量，那信息只能来自交互项，而交互项按定义就绑在具体工具上。所以"有信号"和"能迁移"在这个任务定义下不能同时成立，这是定义层的排斥，不是实验能裁定的。因此进训练环的主任务定为后者。

四类评测任务与训练主任务的分工：

| | 内容 | 用途 |
|---|---|---|
| 评测侧，四类递进任务 | 同性质冲突识别；跨性质异常诊断；预算约束下的复核与仲裁；下游决策恢复 | 量失败模式，全部保留，不进训练环 |
| 训练侧，一个任务 | 选择性作答：给出把握值，再决定作答还是交出去 | 唯一进训练环的任务 |

**判分口径**，四个公式，只吃"答卷动作"和"账本真值"两种输入，机械可判。先立两个术语：风险-覆盖曲线指"把'多大风险才值得交出去'从松到紧排一排，看每一档留下来作答的题答得多准"；选择性预测指 agent 自己决定每道题是作答还是交出去。

覆盖率，即某个阈值下留下来作答的题占多少：

$$\mathrm{cov}(\tau)=\frac{1}{N}\sum_{i=1}^{N}\mathbb{1}\{g_i=\text{答},\ r_i\le\tau\}$$

其中：$N$ 是题目总数；$g_i$ 是 agent 对第 i 题的动作，从答卷固定字段直接读；$r_i$ 是风险分；$\tau$ 是阈值，从松到紧扫过；$\mathbb{1}\{\cdot\}$ 表示条件成立记 1、不成立记 0。

风险率，即该覆盖档内答错的比例：

$$\mathrm{risk}(\tau)=\frac{\sum_i \mathbb{1}\{g_i=\text{答},\ r_i\le\tau,\ a_i\neq y_i\}}{\max\left(\sum_i \mathbb{1}\{g_i=\text{答},\ r_i\le\tau\},\ 1\right)}$$

其中：$a_i$ 是 agent 采信的那个工具的预测，由答卷指定、账本查出；$y_i$ 是冻结真值；分母取与 1 的较大者是为了防止除零，覆盖为 0 时风险率定义为 0。

曲线下面积，用一个数概括整条曲线，越小越好：

$$\mathrm{AURC}=\frac{1}{K}\sum_{k=1}^{K}\mathrm{risk}(\tau_k),\qquad \tau_k=\frac{k}{K}$$

其中：$\tau_k$ 是把阈值均匀切成 $K$ 档的格点，$K$ 取一百。曲线只依赖风险分的大小排序，不依赖量纲。如果 agent 不输出风险分，这个指标退化成单个点的风险率，报告时必须标注"单点，非曲线"。

代价敏感总损失，这是主指标，比较不同做法用它：

$$E=\frac{1}{N}\sum_{i=1}^{N}\left(\mathbb{1}\{g_i=\text{答},\ a_i\neq y_i\}+c\cdot\mathbb{1}\{g_i=\text{交出去}\}\right)$$

其中：答错一次的代价定为 1，作为代价单位；$c$ 是交出去一次相对答错一次的代价倍数，在 agent 运行前冻结。

另有两个诊断率，不进总损失，只用来看损失偏向哪一头：交出去过头的比例，指交出去的题里"可见工具中本来就有答对的"占多少；该交没交的比例，指没交出去的题里"可见工具全错"占多少。

**参照线**，任何 agent 的成绩必须对着这几条读。精确数值见 §3.11。

| 参照线 | 定义 | 读法 |
|---|---|---|
| 优先级链 | 从不把问题交出去，按四个工具在全集上的准确率排序，取第一个可见的 | agent 的总损失必须低于它，否则说明"交出去"这个机制没有创造价值 |
| 多数票 | 可见工具投票，平票时按优先级链裁决 | 工具误差相关时它会失效，实测里它在某一层反而比优先级链更差 |
| 理想交出去 | 只在该交的地方交，开了上帝视角 | 下界参照，不可达 |
| 每题都交出去 | 损失恒等于 c | agent 的总损失不能高于它，否则说明是无脑全交 |
| 从不交出去 | 与优先级链同一个策略 | 同上 |

多数票那一行有个值得单独说的现象：它在"只遮一个工具"这一层反而比优先级链更差，原因是投票把权重分给了准确率最低的那个工具。这说明参照线必须逐层报，只看全集会把这种结构性差异拖平。

**交出去的代价 c 怎么定**，不拍脑袋，从两个锚推：

- 锚一是"从不交出去"的损失，等于优先级链在全集上的错误率。
- 锚二是理想交出去的比例，等于该交的题数除以总题数。

再用三条恒等式：理想策略的总损失等于锚二乘 c；每题都交的损失等于 c；从不交的损失等于锚一。于是"每题都交"能赢"从不交"当且仅当 c 小于锚一；理想策略能赢"从不交"当且仅当 c 小于锚一除以锚二。这两个边界之外，所有"聪明"策略都会被极端策略压死、排名贴边，指标失去区分度。所以有效区间就取这两个边界之间，区间内取三档做正式比较，区间外各放一档当哨兵——哨兵档的胜负是恒等式可以预先算出的，实测若与预期不符，先修判分器再跑正式。

注意这两个锚都是"以真值当裁判"的量，站 1 重算之后区间与档位要一并重推。跨档还要算排名一致性，任何排名翻转逐条列出。

**评测环境**：agent 在可执行沙箱里拿到题面与工具目录，每次调用有成本，拿不到隐藏真值。系统记录完整的工具回执、参数、证据引用和决策时间。

### 3.6 站 4 · 前置检验与证伪实验：先证明这批题里有信号

这一站做的事：在动任何显卡之前，用传统统计方法回答"这批题里到底有没有可学的东西"。五条检验顺序不可颠倒，全部通过才进站 5。

| 序 | 验什么 | 怎么做 | 不通过意味着 |
|---|---|---|---|
| 1 | 方差分解 | 估出分子主效应占总误差方差的比例；再把真值扰动一下，看分类结论翻转的比例。**这一条有个开工条件**：本数据的性质是二分类，误差退化成对与错两档，标准的方差分解不能直接套，必须先定下二值响应下的分解形式，改用模型输出的连续概率而不是 0/1 硬标签是最直接的做法。这一步还没做 | 分子主效应占比低，说明没有"分子难度区"可学，主任务不成立；翻转率高，说明标签在拟合测定噪声 |
| 2 | 裸答天花板与恒答基线 | 不给任何工具预测，直接问模型这个分子能不能透过，看它能答对多少；再算"一律说不可信"能拿多少分 | 能背出来，说明测的是记忆检索而不是判断；恒答得分高，说明必须同时报交出去的比例，否则分数没有意义 |
| 3 | 经典方法擂台 | 在同一张表上训一个随机森林，再跑一遍 conformal prediction，比静态判断的准确率。conformal prediction 是一类经典方法，它不给单个预测值，而是给出一个"以指定概率包含真值"的集合，集合越大表示越不确定 | 经典方法打平或更好，说明不能在"静态判断"上宣称贡献，差异只能落在主动取证上 |
| 4 | 证伪实验 | 见下面的消融矩阵 | 只用几个数字就能做到同样好，说明模型根本没在读分子，方向要重做 |
| 5 | 纯采样基线 | 不做任何改动，只把采样量加大，看能不能匹配干预后的成绩。这里用的指标是同一题采多个答案、只要有一个对就算对 | 干预带来的提升不超过纯采样，说明拿到的是分布锐化而不是真实增益 |

关于通过线：上表每一条的方向是明确的，但"多低算低、多接近算打平"的具体门槛本轮未定。五条检验的判据必须在跑之前写进预注册文件冻结，否则事后挑门槛等于没有关卡。这是本站开工前必须补齐的一项。

**证伪实验的消融矩阵**。所谓证伪实验，指专门设计来推翻我们自己核心主张的那个实验，而且必须在花钱训练之前先做。我们的核心主张是"agent 学会了读分子内容才判断得准"，要推翻它只需一件事：拿掉分子、只留四个工具的预测数字，用一个逻辑回归去跑。如果这样也能做到一样好，说明 agent 根本没在读分子，学到的只是"几个数字互相差得远就别信"，而这条规律与化学无关。它与普通消融的区别在于后果：普通消融是看掉多少分，这个是打平就地停止。全部在同一批分子上做，按骨架切分——把结构骨架相似的分子整组划到同一侧，防止训练集和测试集出现几乎同一个分子。成绩报自助法置信区间，即从样本里有放回地重抽很多次、每次算一遍成绩，用这些成绩的散布给出区间，避免拿单次数字下结论。

| 编号 | 输入 | 怎么读 |
|---|---|---|
| 甲 全管线 | 分子结构 + agent 的推理过程 + 四个工具的预测 | 主方法 |
| 乙 只给数字 | 只给四个预测数值，逻辑回归就够，不给任何化学内容 | **乙与甲打平，则"读分子内容"这条叙事作废，方向重定** |
| 丙 只给工具身份 | 工具名加四个预测，不给分子内容 | 丙好于甲，说明工具身份比分子内容更重要 |
| 丁 随机 | 无 | 下界 |
| 戊 conformal | conformal prediction 基线 | 经典擂台，与检验 3 同族 |
| 己 内容错配 | 把预测和分子故意配错，打断内容与判断之间的关联，但保留预测值的分布 | **成绩不变，说明用的是数值分歧而不是分子内容** |

为什么这一条必须前置：在几百个分子这个量级上，最强的可学信号很可能就是"几个数字分歧大就别信"。这个规律不需要任何化学知识，而且因为它跨领域通用，迁移测试会看起来成功——这是一个结构性的假阳性。乙和己两个消融就是专门用来把这条假阳性打死的。

**另加一条留一个工具不训的检验**：把四个工具里的一个整个扣掉，当成"没见过的新工具"。做法是，训练只用可见子集完全落在其余三个工具之内的那些题，十五个子集里有七个满足这个条件；测试只用可见集包含被扣掉那个工具的题。这样十五个子集的枚举不用改，只是按子集是否碰到被扣工具做一次划分。四个工具各扣一次，轮流做。

换工具重测时必须同时报残差相关系数：把两个工具在同一批分子上的误差各拉成一个向量，算这两个向量的相关系数。相关系数高说明两个工具错在同样的分子上，那么"迁到新工具仍然有效"很可能只是因为新工具和旧工具本来就像。四个工具里有三个同属一个体系，误差相关是已核实的风险，不报这个系数的话泛化声明不可证伪。及格线本轮未定，与其余门槛一并预注册。

**止损点**：这一站结束时若"只给数字"打平全管线，停掉训练线，把已有设施整理成一篇纯评测论文。约一万道题、参照线、预注册的代价表、加上证伪实验结果，本身就是最小可发表单元。

### 3.7 站 5 · 两条干预路线

这一站做的事：让 agent 把"先估把握、再决定信不信"变成默认动作。有两条路线，先做不改权重的那条，它同时是另一条的对照基线。

**路线甲 · 只改外壳，不改权重**

改三样东西，都不动模型参数：

1. 工具目录的呈现方式。把每个工具的名称、参数格式、返回结构统一成同一套写法，让模型没法靠"这个名字眼熟"来选。
2. 提示里加一步强制自检。要求 agent 在采信任何一个预测之前，先明确写出"这个工具在这类分子上是否可靠、我的把握是多少"，再往下走。
3. 加一步强制复核触发。当把握值低于阈值时，提示要求它必须再调一个工具，而不是直接下结论。

路线甲的价值有两层：它不用显卡、几天就能出结果；更重要的是，它是路线乙的对照基线——不先做这条，训练涨的分说不清是权重的功劳还是外壳的功劳。

**路线乙 · 改模型权重，分两步**

为什么必须分两步：强化学习只能放大策略里已经有的行为，不能凭空造出来。如果基座模型从来不会在采信一个预测前先估把握，那么无论跑多少轮，采样出来的轨迹里压根没有这种行为供奖励去筛选。所以必须先有一步冷启动把行为的形式灌进去，再用奖励把它的准确度磨出来。

第一步，冷启动，学形式：让模型自己在题目上多采样几条轨迹，按结果过滤，只留下"把握报得准、且最终判定对"的，用它们做监督微调。推理写得漂亮但答案错的丢掉。这个做法叫拒绝采样自举——不引入外部的强模型当老师，只用模型自己产生的、被结果验证过的轨迹。两条硬约束：不用老师模型、不做蒸馏。这一步之后，"先报一个把握值"成为模型的默认动作，部署时不需要任何特殊提示。

第二步，强化，学准。奖励函数如下。权重符号特意避开 §3.5 误差分解里的 $\beta_k$ 和 $\gamma_{ik}$，那两个是另一回事：

$$R = \mathbb{1}\{\text{最终判定对}\} - w_{\text{cal}}\cdot(u - a)^2 - w_{\text{cost}}\cdot(\text{工具调用数} - 1)$$

其中：

- $\mathbb{1}\{\cdot\}$：判定对得 1、错得 0；
- $u$：模型自己报的把握值；
- $a$：这一题实际的对错，对记 1、错记 0，由账本查出；
- $(u-a)^2$：Brier 分数，把"报的把握"和"实际对错"的差平方。它是严格 proper 的评分规则——意思是诚实报告自己真实的把握是唯一的全局最优解，靠报 0.5 对冲拿不到额外好处，真的不确定的题本来就该报 0.5；
- $w_{\text{cal}}$：Brier 项的权重；
- $w_{\text{cost}}$：每多调一次工具的代价。减 1 的意思是第一次调用是完成任务必需的、不计代价，只对额外的复核收费。这个权重与 Brier 权重的比值有真实锚点——一次实验验证的钱对一次计算调用的钱，不是拍脑袋的超参。两个权重的具体取值本轮未定，与 §3.5 的 c 一并预注册。

三条设计约束：

| 约束 | 内容 | 理由 |
|---|---|---|
| 把握值必须连续 | 训练只产出连续的把握值，作答与交出去的阈值留到部署时按 §3.5 的规则套 | 若把动作离散成两档、各配一个固定奖励去训，最优策略会解析地落在一个常数动作上：阈值只由代价比决定，当交出去很便宜时阈值趋近 1，模型会"正确地"学成几乎永远交出去。这是代价敏感学习的定理推论，不是调参能绕开的 |
| 算法用 REINFORCE++ 或带价值网络的 PPO | 不用"组内相对归一化"那一类 | 组内相对归一化指：对同一道题采样一组答案，用这组答案的均值和方差把奖励标准化，再据此判定谁是正例。它在"一组采样全对或全错"时组内方差为零、给出零梯度，是有偏估计，恰好在最需要学习信号的极端题上失效。另外两种算法改用全局基线或独立的价值网络来估基线，不受这个问题影响 |
| 训练时保留工具身份 | 遮蔽只放在评测侧 | 训练时若把工具身份抹掉，两个观测看起来一样、实际可靠性不同的输入会强迫模型给出同一个把握值，等于逼它报错 |

关于防止分布过度锐化：本项目有一个特殊条件——有了误差账本，"模型极少产生但确实正确"的轨迹可以被无歧义地标出来，可以对这类轨迹做定向强化。数学题上做不到这一点，因为无法判断哪条罕见推理是对的。这条是待验假设，不是已成结论。任何训练带来的提升，必须同时报站 4 第五条那个纯采样基线，以及路线甲的成绩。

资源估算见 §4.1。这一站是全流程算力消耗的大头。

### 3.8 站 6 · 怎么算学会了：评测与迁移

这一站做的事：用四个可观测的行为变化判断 agent 是真学会了还是只是分数变好。

| 序 | 信号 | 怎么看 |
|---|---|---|
| 1 | 把握值和准确率真的对齐 | 报 0.8 的那批题，实测正确率接近八成 |
| 2 | 换工具不掉 | 留一个工具不训的设置下，迁到没训过的那个工具仍优于随机，且同时报残差相关系数 |
| 3 | 该认怂时认怂 | 可见工具全错的题上，交出去的召回率高；且这个召回与"四个工具全给"那一层的结论一致 |
| 4 | 总损失赢两头 | 低于"从不交出去"，且不高于"每题都交出去"，三个主档都成立，跨档排名稳定 |

迁移测到哪里：落在有公开金标准的异质领域——数学问答、代码执行、检索冲突。"迁移到没有真值的真实场景"按定义不可测，只作未来方向声明，不进贡献清单。

迁移凭什么可能成立，以及凭什么可能不成立。这一跳是假设，不是已证。假设成立的机制是，模型学到的不是血脑屏障知识，而是一套跨领域通用的读证据习惯：先看手上几个来源是否互相支持，再把支持程度折算成一个把握值，把握不足就不下结论。数学题里"几条解法给出不同答案"、代码题里"几次执行结果不一致"，在结构上是同一件事。但这个机制有一个已知的替代解释：如果模型学到的只是"几个数字分歧大就别信"，那它本来就与领域无关，迁移会成功，却什么化学内容都没用上。这正是站 4 那两个证伪实验要排除的东西。所以迁移测试的结果只有在证伪实验通过之后才可解读，顺序不能反。

五条待验假设。编号用"假设 N"，避免与 §3.4 的遮蔽分层混淆：

| 序 | 假设 | 判据 |
|---|---|---|
| 假设 1 | 选择性作答的曲线下面积优于两条参照线；总损失同时赢两头 | 弱信号，只说明选择性预测在这批题上有信号 |
| 假设 2 | 证伪实验里"只给数字"打不平全管线 | 整条故事线的命门 |
| 假设 3 | 留一个工具不训的设置下迁到新工具仍优于随机，且残差相关系数同报 | 泛化证据 |
| 假设 4 | 数学问答与代码执行上不经训练就优于基线 | 迁移证据 |
| 假设 5 | 若假设 2 或假设 4 失败，贡献退化为"一套带实验真值的选择性作答评测集，加上校准不迁移的实证负结果" | 负结果也可发表 |

### 3.9 数据扩量路线

站 0 的账本目前只有一个性质。下列数据源是扩量候选，都还没有建账本。写在这里是为了说明扩量往哪走、以及每一处能贡献什么类型的冲突。

小分子侧：

- CACHE 提供面向真实靶点的候选提交、实验测定与公开结果，可构造虚拟筛选排序、错误共识与命中恢复。
- SAMPL 提供 pKa、logD、溶剂化与结合自由能等盲测数据，适合比较多个性质预测或自由能工具的系统误差。
- D3R 与 CASF-2016 提供蛋白与配体的结合构象、亲和力排序、打分与筛选数据，可构造对接与亲和力冲突。
- ChEMBL、BindingDB、TDC 提供大规模生物活性、结合常数与吸收分布代谢毒性端点，用于扩量、校准与外推。

蛋白与抗体侧：

- AIntibody 提供盲测设计、实验亲和力，以及表达、热稳定性、聚集、多反应性等成药性测量，适合构造跨性质冲突。

四条统一与切分原则：

1. 先统一实体、质子化状态、构象、单位、实验条件与端点定义，避免把"定义不同"误标成"工具错误"。
2. 不以随机篡改数值为主，而从真实工具残差里抽取自然分歧、错误共识、适用域外、活性悬崖与高置信度错误。必要的受控注入也按真实误差分布生成。
3. 按骨架、蛋白家族、靶点和时间切分开发集、校准集、冻结测试集与隐藏外推集，实验真值只留在私有判分器里。
4. 每个来源记录许可证、可再分发范围与下载日期。不能公开再分发的只发布构建脚本、样本标识与评测接口。

扩量前必须先做一件事，这是站 1 的教训：任何外部权威标签进库之前，先在文件内查同一实体的标签是否自洽。这一步零成本，站 1 那十来处矛盾就是这样查出来的。托管平台或机构的名气不传递数据可信度，溯源记到数据集级别不等于逐条可溯源。

## 4. 期望结论与分析

以下六条是待验证的预期，不是预设结论。它们说的是"我们预计会观察到什么行为"，与 §3.8 那五条"方法成不成立的判据"不是一回事。

1. 通用能力更强的 agent 不一定更谨慎。它可能更稳定地盲从专业工具，因为工具在它看来比自己专业。
2. 只看一个工具自报的置信度不足以判断它这次对不对。把工具之间的分歧、分子是否落在工具擅长的范围内、以及其他相关性质放在一起看，应该更有效。
3. 多数投票在工具误差高度相关时会失效。我们四个工具里有三个同源，这种情况尤其可能出现。
4. 复核不是越多越好。多调一个工具能提升准确率，但存在一个拐点，过了拐点只增加成本。
5. 规则型的门控、agent 自己推理、以及两者结合，可能各自适合不同的风险与预算场景，而不是有一个通用最优。
6. agent 即使最后答对，过程也可能是错误诊断加上运气。所以过程和结果必须同时评。

### 4.1 资源预算

以下全部是估算。整条管线的开销集中在一处：站 5 路线乙的强化阶段。这一处占全流程算力的绝大部分，它前面所有关卡都不需要显卡。所以预算上的关键决定不是"总共要多少"，而是"要不要走到那一步"——站 4 五条检验没过就不走，成本冻结在几乎为零。

| 站 | 要不要大模型 | 要不要显卡 | 时间量级 |
|---|:---:|:---:|---|
| 站 0 造账本 | 只用本地预测模型 | 不用 | 已完成 |
| 站 1 真值体检 | 不用 | 不用 | 一两天，主要花在人工裁决那几行 |
| 站 2 造题 | 不用 | 不用 | 分钟级 |
| 站 3 判分 | 跟着各站一起跑 | 不用 | 贯穿全程 |
| 站 4 前置检验与证伪实验 | 五条里有两条要 | 不用 | 几天 |
| 站 5 路线甲 只改外壳 | 要 | 不用 | 几天 |
| 站 5 路线乙 冷启动 | 要 | 要，一张卡 | 几天 |
| 站 5 路线乙 强化 | 要 | 要，数张卡。全流程主要开销在这里 | 一到两周 |
| 站 6 评测与迁移 | 要 | 要 | 几天 |

三条说明：

- 走公开接口还是本地部署，成本结构完全不同。前面几站用量小，走接口最省事；强化阶段要反复采样，用量大，本地部署更划算。我们此前的实测参照是一轮十几次运行花几美元、耗时半小时量级。
- 用多大的模型还没定。冷启动之后看拒绝采样的保留率：保留率太低说明基座模型撑不住这个行为，要换更大的，显卡预算同比例上调。
- 强化阶段的开销随题目数量线性放大。站 4 之后若需要扩量，这一项跟着涨；站 1 若剔除受污染的行，题目数会变少。

## 5. 这件事对制药领域有什么用

本项目不做新的对接、性质预测或结构预测模型，做的是这些工具之上的一层可靠性评测。具体产出四样东西：

- 一批带实验真值的工具冲突数据，以及配套的评测协议。冲突来自真实模型残差，不是人工注入的。
- 一套判分口径，能量出 agent 在真实模型误差下"什么时候该相信计算结果"的判断质量，而不只是任务完成度。
- 一份关于"哪片化学空间不能信计算"的读数。这对研发团队的直接用处是决定哪些候选必须做实验验证。
- 一条从评测到改进的通路：先用不改权重的办法改外壳，再看改权重能不能再进一步，两者都对着同一批题和同一套参照线读。

## 6. 未来可继续推进的方向

§3 已经把"学习哪片区域不能信工具""预算约束下的主动复核""面向恢复过程的训练""换一套工具重测"这四条收进主线了，本节只列还没进主线的方向。

1. 跨性质约束推理。建立一个可执行的约束层，把结构、亲和力、物化性质、代谢与毒性、稳定性、成药性连起来，帮 agent 区分三种情况：真的互相矛盾、单位或定义不同、以及本来就该随条件变化。本轮只作为判分侧的配套，用来校验 agent 给出的理由是否成立，不作为提示喂给 agent——否则测的就变成指令遵循了。
2. 规划、执行、审计三个角色分工。让一个角色专门检查证据来源、参数一致性、未验证的假设和替代解释。与本项目"单个 agent"的硬边界冲突，本轮不启动。
3. 人机协同与湿实验闭环。在高风险或者确实判不了的情形下允许 agent 向专家求助，再进一步做前瞻性盲测或小规模湿实验。专家介入会破坏可重复性，湿实验目前没有条件，所以本轮只保留"把问题交出去"作为 agent 的一个输出选项，不真的接人。
4. 扩到其他模态与研发阶段。从小分子和蛋白抗体扩到核酸、蛋白降解剂、细胞与组学工具，研究上游的冲突如何传播到候选排序、安全性判断和继续或停止的决定。与"本轮收敛到制药单一性质"的裁定冲突，本轮不启动。
