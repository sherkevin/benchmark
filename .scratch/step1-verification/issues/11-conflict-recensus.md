# 11 · 冲突重新普查：工具体系从 2 个扩到 N 个

Type: task
Status: open
Blocked by: 10

## 为什么这是本轮的真正价值

既有普查的 4 个模型其实只有**2 个工具体系**（admet_ai 一个 + DeepPurpose 三个编码器算一个），正式跨体系冲突口径只有 3 对。提案要论证的是"多工具生态不可靠"，2 个体系太薄。本轮把体系数扩上去，冲突对数会显著增长——这是新数据的主要贡献。

## 做什么

1. 按 family 分组统计跨体系冲突对（沿用既有 `cross_family` 口径）
2. 与既有 400 个冲突实体、502 跨体系对、780 体系内对对比，出增量报告
3. 三轮稳定性判定：只有三轮 label 全一致的冲突才算 `stable: true`（既有口径）
4. 重新封条：`conflict_set_seal_v3.json`，记初始冲突实体数、对数、`experimental_truth_in_projection: false`、以及预登记与冲突集的哈希

## 重点看什么

- **伪共识样本**：所有工具都错的分子（提案 §3.8 捷径诊断要用这组）
- **体系数与冲突率的关系**：从 2 体系到 N 体系，冲突率怎么变——这是可以写进论文的观测
- **版本漂移对**：ADMET-AI 1.4.0 vs 2.0.1 在同一分子上的分歧。这是零训练成本的天然冲突源，且是 ADR-0001 的实证

## 验收

- `conflicts_v3.json` + `conflict_set_seal_v3.json`
- 增量报告：新增体系数、新增冲突对数、伪共识样本数
- ADMET-AI 双版本逐分子差异分布（这一项单独出图，因为它直接支撑 ADR-0001）
