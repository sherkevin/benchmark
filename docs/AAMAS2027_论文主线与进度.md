## 一、首个可证伪切片：选对当前工具

首个可测问题是：面对一个未见分子和一个明确的预测功能，能否比固定使用某一工具更准确地选择具体模型。它服务于更大的可靠调用目标；随后必须检验同一状态模型对证据验证、复核、作答和拒答的作用。调用数、反馈量和算力用于说明取得可靠性的代价，不能反过来把问题改成通用新工具上线或金融式回本分析。

### 一个任务贯穿动态模块与主 Agent

以预测分子能否穿过血脑屏障为例，主 Agent 请求 `BBB_prediction`，工具选择器根据分子特征选择 DeepPurpose-Morgan、graphB3 或其他合格模型。缓存环境返回被选模型当时的原始输出，Agent 再决定回答、复核或弃答；有可验证真值后，训练器才给出正确性反馈。

| 层 | 输入与动作 | 学习或验证的对象 | 当前状态 |
|---|---|---|---|
| 主 Agent | 任务、可用功能、已见结果；请求功能、复核、作答、弃答 | 工具结果应如何用于最终判断 | 桌面汇报中有 Prompt/SFT/RL 计划；当前医药端到端训练未完成 |
| 动态工具适应模块 | 当前分子特征、同功能候选模型、合法历史反馈、预算；选择具体模型并估计验证收益 | 当前输入上哪个模型更可能正确、是否值得追加证据 | Contextual Bandit 是首个动作的候选形式；当前具体模型主实验未完成 |
| 回放与判分环境 | 模型标识、分子标识、固定快照；返回缓存并在终止后判分 | 原值、信息隔离、成本和轨迹是否记对 | Task36 已实现并验证进程内接口 |

Contextual Bandit 是带上下文的多臂老虎机：每轮看到任务特征，选一个工具，收到该选择的反馈后更新。主 Agent 的文字生成训练是另一件事；GRPO/PPO 属于那一层的可选优化方法，不是工具 Bandit 的必需前置，也不是论文创新名称。

当前单次工具选择首先估计的是条件正确率：

$$
q_a(x)=\mathbb{E}[r\mid x,a],\qquad r=\mathbb{I}(\widehat y_a=y).
$$

其中，$x$ 是当前任务的特征向量，维数由后续特征方案确定；$a$ 是同功能组内一个具体模型/版本的标识；$\widehat y_a$ 是其二分类预测；$y$ 是独立参考真值；$r$ 是有效预测的正确性标量，取 0 或 1；$q_a(x)$ 是取值在 $[0,1]$ 的条件正确概率。缺失、报错和未解决真值在现环境中单独标记，不擅自填成正确或错误标签。

选择策略依据估计值与不确定性权衡利用已有经验和获取反馈。具体参数化、探索规则和初始数据量尚未冻结；这正是需要研究的内容，不能用一个 UCB 公式占位后就称方法完成。

### 三种成本不能混为一谈

从本地表读取预测，避免重新运行科学模型，但不意味着模拟中可以让策略免费看完所有模型答案。需要分别记录实际计算开销、策略请求了哪些工具、获得了多少可验证反馈。

Owner 已强调当前首先要“学到更准确的工具”。因此先比较固定反馈与调用条件下的正确性，不在缺少实测时间或价格时擅加经济成本，不把人为设置的惩罚系数写成科学事实。

## 二、证据：互补是真，可学待证

当前最有价值的事实，不是工具总数大，而是具体模型在相同医药输入上的错误不同。下面使用同一批 652 个七家族结果完整且排除已知矛盾真值的分子，不能与包含缺失结果的 722 个可用分子口径混排。

| 事实 | 当前读数 | 直接出处与含义 |
|---|---:|---|
| 最佳固定具体模型 ADMETlab | 607/652 正确 | `pharma_tool_granularity_audit_v2.json` 的 `concrete_output_panel.best_correct`；这是全表描述值，不是训练集选模后的测试成绩 |
| 它的错误中存在其他具体模型正确 | 43/45 | 同产物 `best_wrong_rescuable`；事后看真值计算的可救集合 |
| 全部具体输出都错 | 2/652 | 同产物 `all_wrong_ids`；只适用于本批 33 个已存输出 |
| 七家族汇总票都错 | 14/652 | 同产物 `family_panel.all_wrong_count`；与上一行不是同一粒度 |
| 家族票全错但内部有正确模型 | 12/14 | 同产物 `family_all_wrong_with_correct_concrete_output` |

来源：[粒度审计](../data/tool_results/divergence/pharma_tool_granularity_audit_v2.json)及[复验](../data/tool_results/divergence/pharma_tool_granularity_audit_verification.json)。33 个输出包含同一家族的多个配置，不能称为 33 个独立来源。

### 例子说明为什么要选具体模型

分子 `z002905` 的库内参考标签为 1。DeepPurpose-CNN 的缓存概率是 0.0030845485161989927，Morgan 是 0.977143406867981；按已定 0.5 阈值，前者错、后者对。该例的第三个 DeepPurpose 模型也输出 0，家族多数票因而是错误的 0，掩盖了 Morgan 的正确输出。

这说明 Owner 选择“具体模型/版本”具有实际影响，不能直接沿用旧七票分析的动作空间。该例只解释输出粒度，不意味着概率大的工具总是更准；两家工具也可能都很自信地答错。

### 不能从可救集合跳到可学习结论

Morgan 总体答对 584/652，却能答对 ADMETlab 的 45 个错例中的 34 个。反过来，在 ADMETlab 答对的样本里，Morgan 又答错了 57 个；盲目换成 Morgan 会净少答对 23 个。

> 我的算术：Morgan 总错误为 $652-584=68$；在 ADMETlab 错例中自身错误为 $45-34=11$；故在 ADMETlab 正确样本中的错误为 $68-11=57$。这组计数来自审计逐样本标签，不是新的模型实验。

真正需要证明的是：分子结构或合法历史信息能否识别“该换谁”的样本，而不是事后知道每个模型哪里答对。即便随机误差也能产生事后选择上界，所以 $650/652$ 的逐样本最佳结果不能直接当作可实现目标。

### 共同错误也要按动作池定义

“14 个工具全错”原本指七家族票，不能当作 33 个具体输出的共同错误标签。弃答和可靠性研究必须按冻结后的实际候选池重新标记困难样本，不能为了凑旧数量继续沿用不对应的标签。

同时，只有两个全模型共同错误的样本不足以证明普遍的伪共识识别能力。当前应把它作为边界现象保存，而不是把整篇论文押在 Agent 一定能识别所有共同错误上。

## 四、方法：先固定正确问题

推荐的首个完整学习闭环是固定医药功能和具体模型池的 Contextual Bandit，而不是立即加入新工具到达、跨领域、复核优化和大模型参数更新。先隔离“是否选对工具”这一能力，再接回主 Agent，才能知道提升来自哪里。

### 首轮协议应回答五个问题

| 问题 | 执行建议 | 尚需完成的交付 |
|---|---|---|
| 选择谁 | 明确可调用的具体模型/版本，保留来源家族，不按当前准确率挑赢家 | 入训清单、快照、标签方向和资格理由 |
| 看什么 | 主输入先为分子结构特征；真值、未调用预测、事后难度不进入决策 | 特征方案与观察字段白名单 |
| 用哪些历史 | 固定共享的初始训练数据；单独声明全反馈预训练和后续所选反馈更新 | 训练/验证/测试与反馈权限表 |
| 学什么 | 当前输入上的正确率与不确定性；先建立标准监督和 Bandit 对照 | 固定模型、探索规则、调参预算和日志 |
| 怎么验 | 同一分子划分、同一流与反馈预算；在线更新前先计分，避免先学答案再算成绩 | 每轮预测、选择、反馈、更新时序及配对统计 |

训练、验证和最终测试先按分子或骨架隔离，再生成工具子集。不能将同一分子的多个子集分到训练与测试，也不能把换随机顺序的多次模拟当成新增独立分子。

自然组成的测试与特意增加难样本的挑战集需要分别报告，不能把挑战集性能当成自然部署平均表现。难度标签与可救集合可以用于判分侧分析，不提供给策略作输入；任何新的最终确认集必须说明是否曾参与问题选择或调参。

### 完整缓存不构成 Bandit 的必要性证明

缓存记录了所有模型输出，是环境用于廉价回放的能力，不是部署策略天然拥有的信息。若假设部署只有所选工具的反馈，必须说明反馈从哪里来、何时到达；医药实验真值不会随每次模型调用免费出现。

应同时保留两类比较：同初始历史、同后续反馈下比较探索和更新；使用全部训练缓存的监督选择器则明确其数据权限。后者若已经解决任务，应承认监督方法足够，不能通过人为削弱它来证明 Bandit 必须存在。

### 推荐的基础对照

- 训练集选出的最佳固定模型，不能在测试集挑全局最优后当可部署基线。
- 均匀或预登记随机选择，以及不看分子特征的 UCB/Thompson Sampling，用来检验上下文是否真的有用。
- 监督式条件正确率预测器，以及使用相同特征与反馈的 LinUCB/LinTS；非线性方法只在前者不足且诊断支持时增加。
- 相同调用预算的多数票或固定组合；它与单调用策略的结果、调用数分别报告，不做免费多工具比较。
- 逐样本最佳模型只作事后上界；未见工具无历史的实验放到泛化部分，不取代主协议。

推荐的系统主指标是单次工具请求成功率：分母为参考真值有效的全部被评测任务，分子为所选工具成功返回且预测正确的任务。失败或无有效返回在这个系统指标中不能算成功；另报“仅有效返回上的预测准确率”和失败率，避免通过排除失败行抬高分数。未知或矛盾真值仍为不可评分，不能作为工具失败或错误标签。

这是待在 P02 冻结并实现的汇总口径，不修改当前缓存的缺失值或 Task36 返回的 `correct=None`。还需报告累计错误、每轮调用与反馈数、学习曲线以及按分子/骨架形成的配对区间；比较主 Agent 时再加入回答覆盖率、错误接受率、复核次数，不能把多弃答造成的表面准确率提升当作选工具改进。

## 五、贡献：分三块，不能冒领

论文可以沿“真实问题与资源 → 条件工具选择机制 → Agent 中的有效性”组织三块贡献，但完成度不同。当前第一块有实质资产，第二块最缺，第三块仍待实验；不能把三块都写成已经实现的创新。

| 拟贡献 | 当前可用基础 | 还缺什么才成立 |
|---|---|---|
| 医药工具错误结构与评测资源 | 同输入多模型真实输出、实验标签、粒度审计、原值与失败记录 | 真值与训练重叠审计、正式划分、与已有资源的精确差异；“工具会错”本身不是新发现 |
| 面向任务的工具能力学习 | Contextual Bandit 问题已对齐，缓存环境可用 | 非平凡机制、最近邻对照、同反馈条件下改善；直接套标准 Bandit 不等于新算法 |
| 选择能力对 Agent 的贡献 | 功能请求与具体工具选择分离，主 Agent 可靠性计划存在 | 固定 Agent 换选择器、固定选择器比较 Agent 策略、再验组合；需要端到端结果和泛化边界 |

### 方法创新的优先候选

当前应先检验“分子特征能否解释不同模型的相对正确性”。若存在信号，再考察能否利用同功能模型的相关经验，在少量反馈下更快估计条件能力，且不把同家族多个版本误当独立证据。

这是研究候选，不是已成立新方法。共享表示、多任务 Bandit、动态分类器选择已有相关方法类型；需要明确哪些信息被共享、怎样更新不确定性、为何优于独立建模，而不是给模块换一个新名字。

我建议优先比较一个明确机制：独立估计每个模型的正确率，与利用训练区中模型错误的相关结构进行联合估计。后者可先从训练缓存学习“哪些模型在哪类分子上会一起出错”，在线获得一个模型的反馈时更新能力后验，而不是伪造其他未调用模型的正确标签；它仍然是一次选一个工具的 Bandit，不强制改成多次复核任务。

这个候选必须有正反两面检验：相同反馈量下是否比独立模型和标准共享表示更准；来源相关性被打破或遇到不同家族时，是否发生负迁移。若只利用家族身份记住平均排名、或现成共享模型已得到同样效果，则不能作为新算法贡献。尚未做对应近邻核验和实验，故本轮只把它列为优先比较的机制，不称为 Ours。

“复核时根据已见输出选互补模型”列为后续候选，而非当前已批准的替代主线。只有基础条件选择成立，再验证历史输出是否产生额外收益；选择更不同意的模型并不自动等于选择更准确的模型。

### 方法冻结不是等到先刷出好分数

开训前应该固定问题定义、候选机制、最接近的方法、信息权限与能推翻假设的对照，不要求预先拥有正结果。冻结后按一个小批次执行；结果不支持时修改科学主张，而不是换题、换分母或挑一组模型当赢家。

第一道否定条件：监督式条件选择在可靠划分上也无法利用特征时，不直接扩大 Bandit 或 LLM；先区分表示不足、样本不足与工具误差不可预测。第二道否定条件：标准方法已实现同等效果时，不把其包装成 Ours。第三道否定条件：改进仅存在于同家族近亲或潜在污染样本时，不声称跨工具泛化。

## 六、旧结论：保留证据，纠正解释

### 方差分解不是不可学习定理

[ADR-0006](adr/0006-training-goal-decision-usability.md) 的历史论证把“分子主效应占主导”进一步解释为“有信号和可迁移在定义层互斥”。这个数学结论不能从方差分解本身推出；它是本轮科学复核的异议，不是对 ADR 原文的静默改写。

> 说明性反例，不是项目实验：令两个分子特征 $z,x\in\{-1,1\}$，两个工具的错误概率为 $e_1=0.5+0.25z+0.1x$、$e_2=0.5+0.25z-0.1x$。其中 $e_1,e_2$ 均为 $[0,1]$ 内标量；$z$ 产生较大的共同难度变化，$x$ 产生较小的相对能力变化。$x=1$ 时工具2更准，$x=-1$ 时工具1更准，共同难度较大并不阻止从 $x$ 学到选择规则。

固定模型池上对未见分子的泛化，与没有任何反馈的新模型零样本识别，也是两件事。前者需实验判断，后者在没有共享结构或元信息时受可识别性限制；不能拿后者的困难否决前者。

### 四类历史材料各有用途

| 材料 | 保留价值 | 当前不得代替的内容 |
|---|---|---|
| 七家族方差、投票与 Task26 BBB 可学习性 | 原粒度的事实与模型失败线索 | 33 具体模型的正式主实验、伪共识标签和条件能力结论 |
| LLMRouterBench/ASlib 与 Task27–35 | 通用模拟代码、反馈隔离经验、反例和实现参考 | 医药论文主证据与研究目标 |
| Task25 冒烟 | API 调用、账本和工具壳的工程经验 | 完整 BBB 模型选择或主 Agent 参数训练 |
| 桌面阶段汇报和旧 ADR | 用户意图、既有质量约束及历史依据 | 将未来轨迹数、算法选择或假设写成已经完成 |

原有“至少 5000 题、500 独立难样本、50 伪共识”的要求尚未达成，也不能把名义工具组合数当独立样本数。具体模型粒度改变后，相关标签和题量可行性必须重新核对；这些旧验收数字如何承接应显式记录，不默默降低，也不让它们阻塞必要的小批诊断准备。

GRPO 与旧 ADR 的冲突只在真正启动主 LLM 参数训练时处理。它不影响医药缓存审计、动态工具适应模块或 Contextual Bandit 首轮协议设计；当前不再把此冲突当整个项目停摆的原因。

## 七、论文：按问题链写

推荐的工作题意是“基于任务反馈学习医药工具可靠性”，而不是“通用新工具接入”。正式标题在方法和贡献确定后再定，不能先起强标题再反推实验。

| 章节 | 要回答的问题 | 证据安排 |
|---|---|---|
| 引言 | 工具都正常运行时，为什么仍需要学习选择？ | 一个真实分子及总体/局部错误差异，避免只列冲突率 |
| 相关工作 | 普通算法选择、监督路由、Bandit 和 Agent 工具使用分别解决什么？ | 正面比较最近邻，不能把已有原理换名 |
| 数据与任务 | 什么是一个模型、一道任务、可见信息和正确反馈？ | 具体输出、来源家族、真值、划分、快照与失败规则 |
| 方法 | 条件能力如何估计，反馈如何利用，选择如何更新？ | 定稿算法和模块输入输出，不按开发编年史组织 |
| 实验 | 是否选得更准，为什么，信息和成本是否对等？ | 固定模型/监督/Bandit 主表、机制消融、学习曲线 |
| Agent 验证与边界 | 选择提升是否转化为最终医药判断改善？ | 控制主Agent和选择器的交叉对照；新工具、跨性质后置 |
| 结论 | 得到什么可复用的科学认识？ | 只总结经过验证的认识，不总结做过多少任务 |

当前可以写背景、任务定义、已核的数据事实和实验设计。结果摘要、Ours 优势、算法保证、跨工具泛化和 RL 增益必须留到相应证据产生后，不能编数或用旧接入实验填空。

本会话此前核验的 AAMAS 2027 截止是 2026-10-01 摘要、2026-10-08 全文；桌面汇报另有八周工程计划，两者不能当成已自然对齐。若当前贡献与证据赶不上截止，应明确调整投稿主张或安排，而不是宣布全部八周任务已能完成，也不擅自取消用户要求的系统层训练。

## 判决：先把选择能力做实

论文对象不再摇摆：用医药真实工具结果研究任务条件化的工具选择，Contextual Bandit 是核心学习问题，主 Agent 提供使用场景和可靠性验证。当前成绩是数据和测量基础，不是已经解决了工具选择；当前缺口是可学习性、公平基线与非平凡方法贡献，不是更多泛化口号或更大 GPU。

下一步应交出一个可审核的医药选择协议和机制比较方案，然后完成一次具体模型层面的标准学习闭环。若它站不住，就沿数据、表示、反馈与模型逐项定位；若标准方法已足够，就据此调整贡献定位，而不是不断改题寻找一个看似新颖的失败场景。
