# 方法论评价标准

- 版本：v001；状态：已归档（当前生效版本的历史副本）；对应主文档：`../02-方法论.md`

## 必须通过的检查

1. 输入、动作、反馈、延迟、状态和终止条件都有定义，并且每个符号有一个具体案例。
2. 调用前和调用后的信息严格分开；未选输出、当前真值和未来反馈不能泄漏。
3. 更新规则是事件级、可恢复、可审计的；不能只给伪代码和最终均值。
4. 候选方法与最近邻 baseline 的差异可写成公式、约束或机制，不靠命名。
5. 冷启动、共同 warm start、selected-only 在线更新和 evaluator-only Oracle 分开。
6. 报告更新时间、内存、失败、缺失和延迟；实时性不能只凭“模型很小”。
7. 有 matched-backbone、延迟、菜单/家族和调用后 verifier 消融。
8. 结果能被独立脚本从原始事件日志恢复；confirmation 不回流调参。

## 不能通过的情形

- 目标函数依赖选择前看不到的完整面板。
- 把标准算法换符号后声称原创。
- 只展示有利 seed，不报告失败和停止条件。
- 先看 confirmation 再选 epoch、阈值、菜单或预算。
- 用无法恢复的 notebook 状态或手工表格作为唯一证据。

## 审稿式结论

公式能落到代码、代码能落到事件日志、事件日志能重算指标，方法才算可审查。若信息合同本身不支持预期收益，应把它写成边界，不用更复杂的 head 掩盖问题。

## 来源等级

- **官方硬要求**：AAMAS 评价 technical contribution 的 soundness、reproducibility、clarity、relevance 和 state of the art；正文必须足以理解和评价核心贡献，不能把核心证明和实验全放进补充材料。见 [Reviewer Guidelines](https://warwick.ac.uk/fac/sci/dcs/aamas2027/guidelines-and-policies/reviewer-guidelines/) 和 [Submission Instructions](https://warwick.ac.uk/fac/sci/dcs/aamas2027/guidelines-and-policies/instructions/)。
- **代表性论文规律**：成熟范式加一个明确现实困难，且方法、分析和实验都围绕该困难；详见 `research/AAMAS_2023-2026_论文调性与DynamicToolRouting选题调研.md`。
- **项目特定门槛**：selected-only 信息合同、延迟队列、可恢复事件日志和 matched baseline 是本项目为避免泄漏和伪实时性增加的验收条件，不是所有 AAMAS 论文的统一要求。
