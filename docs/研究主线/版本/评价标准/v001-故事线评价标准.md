# 故事线评价标准

- 版本：v001；状态：已归档（当前生效版本的历史副本）；对应主文档：`../01-故事线与创新.md`

审稿人看完后，应该能用一句话复述“真实失败是什么、方法在哪个时点介入、实验如何证明”。

## 必须通过的检查

1. 开头直接写具体失败场景，不从“人工智能快速发展”起笔。
2. 只有一个主问题：工具选择与结果可信度如何在延迟反馈下改善；验证/升级是调用后环节，不凭空再开一条论文。
3. 故事链每一步有证据：分歧、信息限制、候选方法、最近邻、可证伪实验。
4. 创新写成机制和必要性，不能把模块数量、换 backbone 或换名字当创新。
5. 已证事实、候选方案、尚未核实的假设分开写；数字给出处和口径。
6. 负结果有边界：它说明哪个候选或哪种信息合同不行，不自动推翻全部研究问题。
7. 论文主张不超过 confirmation 和 provider 资格能支持的范围。

## 明确不通过的写法

- 用自建 33-provider 回放冒充公认 benchmark。
- 用调用后的 confidence 解释调用前 selector 的收益。
- 只说“动态 JEV 有效”而不给延迟、反馈权限和最强对照。
- 把标准 bandit、SGD 或 Bayesian update 改名后写成创新。
- 用一次失败、一次跑崩或单个数字单方面删掉已确认的创新假设。

## 审稿式结论

如果问题、信息边界、创新机制和证伪实验能连起来，故事线可进入方法审查；如果只剩“医药数据 + 多个模型 + 在线更新”的拼装，故事不通过。

## 来源等级

- **官方硬要求**：AAMAS 2027 主轨要求评价 originality、significance、soundness、reproducibility、clarity、relevance、presentation 和 state of the art，并要求说明应用语境、agent 作用和 benefit/feasibility/impact 证据。见 [Call for Main Track](https://warwick.ac.uk/fac/sci/dcs/aamas2027/calls/call-for-main-track/)。
- **代表性论文规律**：具体技术瓶颈 → 形式化 → 针对性机制 → 最近邻对照 → 边界分析，来自 2023–2026 代表性论文的定性阅读，详见 `research/AAMAS_2023-2026_论文调性与DynamicToolRouting选题调研.md`。
- **项目特定门槛**：一条故事链、事实与候选分开、创新不因一次失败自动改写，是本项目的审稿防守线，不是 AAMAS 官方评分条款。
