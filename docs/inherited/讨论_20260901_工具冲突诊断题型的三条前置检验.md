## §1 提案要测什么（owner 原意，非转述）

不是"agent 会不会调工具"，而是：**工具正常返回、格式正确、数值看似合理，但结果不可靠时，
agent 能否发现异常、定位可疑属性、选择更可靠的结果、并恢复后续决策。**

四类递进任务：① 同性质冲突识别 ② 跨性质异常诊断 ③ 预算约束复核与仲裁 ④ 下游决策恢复。

## §3 判分设计（讨论中厘清的部分）

### 3.1 真值分两层，不可混

- **第一层：工具的真值。** 工具预测值与实验实测值比，误差小者准。静态、离线，与 agent 无关。
- **第二层：agent 判断的真值。** agent 说"信 A 不信 B"，这个判断对不对。

**第二层由第一层算出，但不等于第一层。**

### 3.2 必须逐实例，不能用全局平均

$$e_{i,k} = |\hat{y}_{i,k} - y_i| \qquad k^*_i = \arg\min_k e_{i,k}$$

其中：
- $\hat{y}_{i,k}$：第 $k$ 个工具对实例 $i$ 的预测值；
- $y_i$：实例 $i$ 的**实验实测值**，唯一真值来源，agent 不可见；
- $e_{i,k}$：工具 $k$ 在实例 $i$ 上的误差（单位随性质而定）；
- $k^*_i$：**该实例上误差最小的工具** ⇒ 这就是判分 GT。

❗ **若 GT 取"全局哪个工具平均最准"，则 agent 永远选那一个即可拿高分，什么诊断都没做。**
这与 `DECISIONS.md §6` 已登记的"按结果回调参数"同类：判据本身给了退化捷径。

### 3.3 冲突的定义须锚在决策后果，不锚数值差

两个打分差 0.5 算不算冲突，**取决于它们指向的决策是否相反**：

- 都指向"保留" ⇒ 有数值差异但**非实质冲突**；
- 一个保留一个淘汰 ⇒ **实质冲突**。

按"数值差超过阈值"定义会引入人为拍定的阈值，重犯"刻度自己调出来"的坑；
锚在决策后果则是二值、机械可判。

### 3.4 评估三条参照线

$$\underbrace{\min_k \tfrac{1}{N}\textstyle\sum_i e_{i,k}}_{\text{下限：最佳固定单工具}}
\;\ge?\;
\underbrace{\tfrac{1}{N}\textstyle\sum_i e_{i,\hat{k}_i}}_{\text{agent}}
\;\ge\;
\underbrace{\tfrac{1}{N}\textstyle\sum_i e_{i,k^*_i}}_{\text{上限：实例级理想选择器}}$$

其中 $\hat{k}_i$ 为 agent 在实例 $i$ 实际选的工具。

**核心判据一句话**：agent 平均误差必须**显著低于下限**，否则其行为等价于"记住哪个工具好然后一直用"，
不构成诊断能力。配套：选择正确率（选中 $k^*_i$ 的比例）、后悔值 $e_{i,\hat{k}_i} - e_{i,k^*_i}$。

**全程无需 LLM 裁判**，均为数值比较 ⇒ 与 `RSI 硬约束：禁用 teacher 与 llm-judge` 相容。

### 3.5 "该相信谁"这个问题出题人不必回答

我们有实验真值故知道答案；agent 拿不到真值，须靠可观测线索自行推断。
⇒ **我们只需能判定它判得对不对，不需要教它怎么判。** 这与"题是我们出的、真值是我们算的"同源。

## §4 三条前置检验（全部零机时，顺序不可颠倒）

| 顺序 | 验什么 | 怎么验 | 不成立的后果 |
|---|---|---|---|
| **1** | **答案能不能被背出来** | 取一批实例做**裸答基线**：不给任何工具，直接问实验值 | 能背 ⇒ 测到的是记忆而非诊断。**已有同类翻车**：某材料题模型靠背"汞系铜氧化物临界温度最高"得 0.9，等价符号替换后最强模型 0.9→0.658、另两个归零 |
| **2** | **最优工具会不会换人** | 逐实例算 $k^*_i$，看其分布是否集中于单一工具 | 集中 ⇒ 上限等于下限，**无题可出** |
| **3** | **可观测信息里有没有信号** | 用 agent 实际可见的量预测 $k^*_i$：$k^*_i \sim f(\text{置信度}, \text{分歧程度}, \text{分子特征})$，看准确率能否显著超过随机（$1/K$） | 超不过 ⇒ 题在信息论上不可解，**测的是运气不是能力** |

**为何第 1 条排最前**：它最便宜（几十次裸答问答即可），且一旦不成立，后两条验了也白验。

❗ **第 1 条是 owner 追问"如果有真值还要工具干什么"时逼出来的，执行方原先未列。**
其要害在于：CASF-2016 / SAMPL / ProteinGym 等**全部公开**，数据集越有名、被模型背过的可能性越大。

## §5 已识别的三个硬约束（提案按原规格做不了的理由）

| # | 问题 | 实测依据 |
|---|---|---|
| 1 | **成本量级差一个数量级以上** | 提案要求"对同一分子—靶点运行 AlphaFold / Boltz / Chai / ESMFold / Rosetta"，属 GPU 集群量级；本项目现行成本为一轮 12 个 run 计 3.74 美元、26 分钟（纯 API + 本地 RDKit）。**绕法**：CASF-2016 已存多个打分函数对同一批复合物的评分，CASP/CAPRI 存各家提交结果 ⇒ **用别人已跑好的分歧，不自己造分歧** |
| 2 | **这是扩大范围，不是收敛** | owner 08-28 已裁定从 AI4S 收敛到制药、材料与基因冻结（`决议_20260828_收敛到制药与判产物优化.md`）。提案首版即覆盖小分子 + 蛋白抗体，未来方向另列 RNA / PROTAC / 细胞组学。而现状是**一道药物题都还没跑出稳定信号**：六格那批属已作废评分范式、`cns_01` 负结果、`sarflip_01` 只跑两条臂（三档零 run）|
| 3 | **四类任务中有两类按本项目判据属高风险** | 用"测完之后还要不要再想一步"筛：任务①**不要**（比数值即知）⇒ 工具价值直接进分；任务③中间；任务②④**要**（测完才开始判断）⇒ 与 `cns_01` 同构，而该题实测差 +0.056、需每臂 462 run。另：四类任务"递进"即链式依赖，与 `chain_01` 同构，而该题三模型全 1.000 |
