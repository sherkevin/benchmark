# 继承决议链：本目录装什么、为什么在这里

本目录装的是本项目训练目标这条线的决议链原文，共 9 个文件。它们原先散在 `archive/governance/` 下，而 `archive/` 是 git 未跟踪目录，远程 clone 这个仓根本看不到。本项目从 2026-09-13 起整体移交远程工程师，决议链看不见等于没有决议链，因此逐字复制到这里入库。

**全部是复制，不是移动。** `archive/` 下的原件一个没动，每个文件的 md5 都与原件核过一致，对账表见本文件末尾。复制而非移动的理由：`archive/` 是 owner 的未提交工作区状态，动它等于替 owner 做决定。

**这些文件是台账级。** 记的是当时的判断与证据，发现错了追加更正段，不改写原文。它们不约束当前执行——当前执行口径在 `docs/计划_全工具远程跑批与结果库.md`，训练目标的待裁冲突在 `docs/目标.md` 的「一处待裁的目标冲突」。

## 七步稿就是 v2：我的判断与九条依据

ADR-0028 要求的 v2 文件名是 `提案_20260902_制药工具冲突选择性作答训练管线_v2.md`，这个文件名在全仓与全部 git 历史中都不存在。我上一轮据此登记「v2 至今没有落盘」，这个登记是错的，已在 `docs/目标.md` 追加更正。

我的判断是：七步稿就是那份 v2，只是沿用了原文件名、没按触发动作改名。九条依据，前八条是内容吻合，第九条是时间顺序。

1. §2.2 的工具置信度对照表逐行列出 Rewarding Doubt、Taming Overconfidence、DCPO、RefGRPO、Tool-R0 与 Agentic-DPO、RLMF。这正是 ADR-0028 的 F2 点名「novelty 基本被前置工作吃光」时列举的那批工作。358 行入库版的 §2 是散文列表，没有这张表。
2. §2.3「我们剩下什么」把贡献定位成数据生态位：要训「什么时候该信工具」得同时有不靠人判断的对错标准、工具之间本来就存在的分歧、答错要付的真实代价，而化学三样都有。并明写「不声称的是把模型的把握训准这件事本身」。这是 ADR-0028 的 D5 叙事重定位，从「calibration 方法创新」降级为「数据生态位创新」。
3. §2.3 第 2 条把问法写成「已有工作问哪个工具准，我们问手上这组结果够不够下结论」，并说明前者学到的偏好绑在具体工具上、后者问的是分子本身难不难。这是 D1 主任务换轨的结论。
4. §3.1 的 Step 2 是「核查实验值本身有没有自相矛盾」，举的例子是曲美沙特在源文件里既标能透过又标不能透过、入库取到了错的那条。ADR-0028 §5 新增的站 1「真值体检」正是为此而立，理由写的是 TDC `BBB_Martins` 有 11 个分子标签自相矛盾。
5. §3.5 的 Step 4「排除假信号」两条做法：拿掉分子只把几个工具的预测数字喂给一个逻辑回归；把预测值和分子故意配错再跑一遍。这是 D2-④ 的 scalar-only 与 content-shuffle 消融。
6. §3.5 另配三条零成本对照：直接问模型这个分子的答案看它会不会背、一律回答「不可信」能得多少分、同一张表上训一个随机森林。这是 D2-①②③。
7. §3.8 的 Step 7 第 1 条是扣掉一个工具完全不参与训练、只在它上面出题测成绩，同时报被扣工具与其余工具的误差相关系数。这是 ADR-0028 的 A1 把 property rotation 作废后改用的 LOTO。第 2 条换到非化学但有标准答案的领域，举的是数学题多条解法与代码题多次执行，这是 A6 要求的「迁移证据必须落在有真值的异质域」。
8. 全文没有 GRPO，没有 property rotation。D3 作废清单里的两项没有出现。
9. mtime 09-02 23:49 晚于 ADR-0028 的 09-02 20:52，且早于 `docs/Proposal.md` 入库的 09-09。

**这个判断能被什么推翻**：如果 owner 记得七步稿其实写于 ADR-0028 之前、只是后来被编辑器碰过 mtime，那第九条不成立，前八条就变成「两份文档独立收敛到同一批文献与同一套检验」，巧合到这个程度不太可能但不是不可能。请 owner 确认。

## 七步稿没有完整吸收 ADR-0028：两处缺口

把七步稿认作 v2，不等于认为它合格。逐条对 D1–D5 与 D2 的五条检验，有两处缺。

**缺口一，D2-⑤ 纯采样基线 pass@k 没有落进七步稿。** 全文搜不到 `pass@k`。ADR-0028 的 D2 要求五条检验顺序不可颠倒，第 5 条是纯采样基线，用来区分锐化与真实增益；§3.4.6 另有一条报告硬约束写明阶段 3 的任何提升必须同时报「不训练、只加大采样量」的基线。七步稿的 §3.5 只配了三条零成本对照加 Step 4 的两条消融，合起来是 D2-①②③④，第五条缺失。

**缺口二，§3.1 的方差分解式没有出现在七步稿里。** 全文搜不到「方差分解」「α_i」「γ_ik」。D1 的整条理由建立在这个分解上：选最准工具的答案由交互项 γ_ik 决定，绑定具体工具，换一套工具任务失效；判断能不能用的答案由分子主效应 α_i 决定，换工具仍然有效。七步稿在 §2.3 写了这个结论，但没有写推导，也没有写「若坚持选工具任务，则能迁移与任务有信号在定义层互斥」这条二难。推导只在 358 行入库版的 §3.4.1 里。

这两处缺口的后果是：读七步稿的人拿不到换轨的理由，只拿到换轨的结论，也就无法判断结论对不对。要补齐，得把 358 行入库版的 §3.4.1 与 ADR-0028 的 D2-⑤ 并进去。

**另有一处需要 owner 判断是否越线。** 七步稿 §3.6 的 Step 5 第 1 条要求把各工具的名称、参数格式、返回结构统一成一套写法，让模型没法靠名字眼熟来选。ADR-0028 的 A2 裁定是训练面保留工具身份、遮蔽只在评测侧做。Step 5 是「改提示，不动模型」，算评测侧还是算训练面，文档里没有写明。我倾向算评测侧因而合规，但这一条是我的推断，不是文档里的裁定。

## `docs/Proposal.md` 是从七步稿退回六步的

`docs/Proposal.md` 的 §2 与七步稿同形：同样两张对照表，同样列出 ADR-0028 F2 点名那批工作。09-01 原稿与 358 行入库版的 §2 都是散文列表。所以 `docs/Proposal.md` 的 §2 来自七步稿这条线，不是来自入库版。

但它的 §3 是六步，§2.3 写的是「训练目标空白：缺乏针对训练诱导的工具偏好过拟合的专门矫正」，§3.7 的训练目标是「矫正训练诱导的工具偏好过拟合」。这是 ADR-0028 之前的口径，也正是 D1 取消训练地位的那一档。全文搜不到前置检验、方差分解、pass@k，三项都是 0 命中。

它保留了 LOTO：§3.1 表格第 6 行写的是 leave-one-tool-out 工具泛化测试，这来自 ADR-0028 的 A1。

**所以 `docs/Proposal.md` 是部分吸收**：拿了七步稿的 §2 文献表与 LOTO，丢了 D1 的主任务换轨与 D2 的前置闸门，并把 §2.3 的贡献定位换回了纠偏心。它入库时间 09-09 晚于七步稿的 09-02，是这条线上最新的一份，也是唯一已提交在役的一份。`docs/目标.md` 的六步路线依据的就是它。
