# 方向7第二轮深推：工具遮蔽、风险-覆盖曲线与升级代价的预注册

一句话结论：方向7（人机协同与湿实验闭环）可以全部落成机械可判的评测——工具遮蔽把 730 分子扩成 10950 个场景、"应升级"样本从 12 行扩到 1080 行（9.86%），升级代价 c 用两个机械锚锁进 (0.157, 1.59] 区间并在运行前预注册；"理想选择器 100%"这个无信息天花板被 oracle 机械包络替换；唯一立不住的是池内时间切分——730 池与两工具训练语料同源，前瞻声明必须靠池外新真值。

## 三、问题2：风险-覆盖曲线的完整指标定义

指标 = 四个公式 + 两个诊断率 + 五条强制基线，全部只吃"答卷动作 + 台账真值"两种输入，机械可判。先立术语：风险-覆盖曲线（risk-coverage curve）就是"把多大的错答风险才值得升级，从松到紧排一排，看每档留下来的题答得多准"；选择性预测（selective prediction）指 agent 自己决定每题作答还是弃权/升级。

覆盖曲线（该阈值下 agent 留下来作答的比例）：

$$\mathrm{cov}(\tau)=\frac{1}{N}\sum_{i=1}^{N}\mathbb{1}\{g_i=\text{答},\ r_i\le\tau\}$$

其中：

- N：场景全集 10950；
- g_i：门控位，agent 对场景 i 的动作（答 / 升级），取自答卷闭集 JSON 字段，判分器直接读；
- r_i：预注册风险分，只用结构证据（可见工具间一致/冲突模式）算出，禁用工具自报概率；τ 从松到紧扫过，r_i 越大表示"越不敢答"。

风险曲线（该覆盖档内答错的比例）：

$$\mathrm{risk}(\tau)=\frac{\sum_i \mathbb{1}\{g_i=\text{答},\ r_i\le\tau,\ a_i\neq y_i\}}{\max\!\left(\sum_i \mathbb{1}\{g_i=\text{答},\ r_i\le\tau\},\ 1\right)}$$

其中：

- a_i：作答行里 agent 所采信工具的预测，由答卷指定、台账查出；
- y_i：冻结真值（BBB_Martins 行），台账给出；
- 分母取 max(·,1) 防零除：覆盖为 0 时 risk 定义为 0，不产生未定义数。

曲线下面积（一个数概括整条曲线，越小越好）：

$$\mathrm{AURC}=\frac{1}{K}\sum_{k=1}^{K}\mathrm{risk}(\tau_k),\qquad \tau_k=\frac{k}{K},\quad K=100$$

其中：

- τ_k：覆盖格点，把风险分阈值均匀切成 K=100 档（风险分先保序归一到 [0,1]；曲线只依赖 r_i 的大小排序、不依赖量纲，任何保序归一化给同一条曲线）；
- 若 agent 输出不可用作风险分（例如答卷不吐风险分），AURC 退化为单点 risk，报告须标注"单点、非曲线"。

代价敏感总损失（主指标，比较三种模式用它）：

$$E=\frac{1}{N}\sum_{i=1}^{N}\left(\mathbb{1}\{g_i=\text{答},\ a_i\neq y_i\}+c\cdot\mathbb{1}\{g_i=\text{升级}\}\right)$$

其中：

- 错答代价 λ≡1，是代价单位（一次错答 = 1，其余代价都以它折算）；
- c：一次升级的代价，相对一次错答的倍数，取值由第四节预注册，任何 agent 运行前冻结；
- g_i、a_i、y_i：同前两个公式的定义，不另改口径。

两个诊断率（分别量"升多了"和"该升不升"）：

- 过度升级率 = 升级行中"可见集内本有正确工具"的占比——针对 1080 个应升级场景之外多升的行（明明有对的工具还甩给专家）；
- 漏升级率 = 未升级行中"可见集内全部工具错"的占比（答必错还硬答）。

这两个率不进 E，只作诊断：E 已把"升多了"（每次多付 c）和"答错了"（每次付 λ）都计价，诊断率回答的是损失偏向哪一头。

强制参考基线（实测，10950 场景全集；任何 agent 的成绩必须对照这张表读）：

| 策略 | 定义 | 全集 | H1 | H2 | H3 | H0 |
|---|---|---|---|---|---|---|
| Ref-A 优先级链 | 恒不升级，按 morgan>admet>mpnn>cnn 取第一个可见者（序与 730 准确率一致） | 错误率 0.15717 | 0.21986 | 0.14247 | 0.12500 | 0.12329 |

| 恒升级 | 每题都升级 | 损失恒为 c | — | — | — | — |

自洽校验已含：Ref-A、Ref-B 在 H1 层的错误率 = 该层应升级率 0.21986（只给 1 个工具且它错时怎么答都错），且各层 refA_err ≥ 该层应升级数。表里还有一个直读现象：Ref-B 在 H3 层反而比 Ref-A 差（0.14932 > 0.12500）——多数票把投票权给了准确率只有 59.86% 的 cnn，被拖累；这印证了基线必须逐层报，只看全集合拖平这种结构性差异。基线用法：agent 的 E 必须同时赢过两头——低于恒不升级的 0.15717（说明升级机制创造了价值）且不高于恒升级的 c（说明不是无脑全升）；AURC 对照 Ref-A/Ref-B 的同曲线读。

## 四、问题3：升级代价 c 的预注册与敏感性

c 不拍脑袋：两个机械锚先于任何 agent 运行从冻结数字推出，把有效区间锁死为 (0.157, 1.59]，区间内取三档、区间外放两个哨兵档，全部写入 preregistration.json 冻结（预注册 = 跑之前把规则写死冻存，防事后挑数）。

### 4.1 两个机械锚的推导

- 锚 1：λ_A = 恒不升级损失 = Ref-A 全集错误率 = 0.15717（第三节基线表实测）。
- 锚 2：u\* = oracle 升级率 = 1080/10950 = 0.0986。
- 区间推导只靠三条恒等式：oracle 总损失 E\* = u\*·c（升级行损失 c、作答行全对）；恒升级损失 = c；恒不升级损失 = λ_A。于是——恒升级赢恒不升级 ⟺ c < λ_A = 0.157；oracle 赢恒不升级 ⟺ u\*·c < λ_A ⟺ c < λ_A/u\* = 0.15717/0.09863 = 1.5935（精确值 1721/1080；下文统一保守记 1.59）。
- 结论：c < 0.157 时恒升级占优、c > 1.5935 时恒不升级占优，界外指标区分度塌缩（所有"聪明"策略被极端策略压死、排名贴边），所以有效区间取 (0.157, 1.59]——上界把精确值 1.5935 保守收整到 1.59，右端点 1.59 仍满足 oracle 占优，故取闭端。哨兵档的预期读数由此直接读出：c=0.1 时恒升级损失 0.1 < 0.15717，恒升级必胜；c=2.0 时恒不升级 0.15717 < 2.0，恒不升级必胜。

|---|---|---|---|---|---|
| 0.25 | 区间内 | 0.15717 | 0.25 | 0.0247 | 主档 |
| 0.5 | 区间内 | 0.15717 | 0.5 | 0.0493 | 主档 |

### 4.3 敏感性协议

1. 逐档报：最优 E、AURC、过度升级率、漏升级率、模型排名。
2. 跨档算 Kendall τ（两档下模型排名的一致性：1 = 完全同序，0 = 无关）。
3. 任何排名翻转逐条列示，不许埋。
4. 全部规则（公式、基线、档位、origin 分桶、召回一致性检查）写入 preregistration.json，agent 运行前落盘。
5. 哨兵档兼作判分器自检：c=0.1 下恒升级损失 0.1 < 0.15717 是恒等式，若实测读数不是恒升级必胜，先修判分器实现再跑正式。

## 六、一句话判断

能。应升级样本从 12 行扩成 1080/10950（9.86%），"理想选择器 100%"这个无信息天花板（不管 agent 多笨、冲突行必有一工具对，恒 100%）被换成机械包络：上界 oracle E\* = 0.0986c、下界恒不升级 0.157、恒升级 c——全升与全答两类作弊在 c∈(0.157, 1.59] 内都被数值压死，"纯 Agent vs Agent+规则 vs Agent+专家"三种模式可以在同一张 E 表上机械比出高下。

## 七、已知风险与边界

1. 遮蔽分布是人造的：须报 origin 分桶 + 对 12 行天然全错的升级召回及与 H0 层的一致性（第二节 2.4）。
2. 四工具中三个属 DeepPurpose 同体系、误差相关，H2/H3 层的"工具间冲突"结构证据可能弱于真实多源场景。
3. BBB 单任务二分类，结论外推到多性质/回归任务未验证。
4. c 档是先验锚定、非市场定价，敏感性报告必须随行。
5. 730 池与训练语料同源，池内任何"前瞻"声明不成立（见第五节）。
6. LLM agent 若能从记忆背出分子 BBB 真值，遮蔽/冲突构造会被绕过；"风险分只准用结构证据"的规则同时是部分缓解。
7. 读数噪声底：benchmark 跑间方差实测的噪声底为 0.18–0.29（出处：跑间方差实测，非本次 BBB 普查产物），模式间/模型间的分差落在这个量级以内时不得声称优劣。
