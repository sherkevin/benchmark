# ADR-0022：持续推进研究，每个小任务后检查主线

日期：2026-09-26

状态：Accepted，依据 Owner 本轮对执行计划的明确同意。

## 背景

ADR-0021 已将主任务收窄为医药单次工具选择与题后在线学习。
Owner 同意按 Task49 的下一步计划持续推进，并要求每项工作实际改善故事、方法或实验依据。
本轮另外要求设置持续目标，实验使用星云 A800，开始用 AAMAS 官方 LaTeX 模板写题目与摘要。

## 决定

以“形成有真实证据支撑、适合 AAMAS 审查的完整研究与复现材料”为持续工作目标。
每个小任务结束，都留下四项简短记录：解决了什么科学问题、得到什么证据、对故事/方法/实验有何影响、下一最小行动。
单纯增加文档、代码、实验数量不算目标推进；否定一个不成立的机制也可以是有效进展。

数据资格、baseline 适配和方法推导可并行，按 Task49 计划相互约束。
遇到真实困难，先查一手研究和 Owner vault 笔记中可复用的原理、实现或数据线索，明确哪条新证据会改变判断。
不为了跑出正结果改变测试分母、挑工具池或反复打开最终确认数据。

实验在有明确假设、最近邻、预算和否定条件后开展。
沿用星云项目 `damo_genomic_gene` 的 A800 任务式执行、直连网络和仓内 `tools/nebula/neb` 入口；一次只建一条任务，保留配置、逐样本记录和失败。
本轮持续研究和实验推进已获授权；旧文档的“尚未获本轮执行授权”不再描述当前状态，数据资格和证据质量要求仍须满足。
平台管理、删除他人资源、改全局账号配置及对外投稿不在这项授权内。

题目和摘要现在即可起草，使用核实过来源的 AAMAS 2027 官方模板。
方法未冻结、结果未获得的内容明确标作内部草稿；不写虚构结果，不以草稿冒充完成稿。
根据官方征稿和审稿文件检查相关性、原创性、重要性、可靠性、可复现性与表达；不能承诺被接收。

## 理由

当前最大的风险是路线反复变化，以及把已有在线更新机制重新包装成新方法。
用同一任务定义约束数学、baseline、实验和论文，可以尽早发现这种偏移。
先写题目与摘要能暴露故事缺口；预先明确证伪条件能降低昂贵实验的浪费。

## 影响

- Codex 持续目标已建立，完成标准是研究产物与证据的一致性，不是运行次数。
- Task49 的 `next_plan.md` 从计划草案进入执行；各阶段的科学验收仍按实际证据判断。
- Task50 保存论文模板来源、AAMAS 对齐、阶段复盘和初稿；不重复建立另一套主 benchmark。
- README、目标及文档入口更新到直接选择主线，旧复核/拒答与通用 routing 方案保留作历史。
