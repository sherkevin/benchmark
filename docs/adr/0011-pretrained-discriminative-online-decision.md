# ADR-0011：预训练判别式决策模型与真实反馈在线适应

日期：2026-09-23

状态：Accepted（研究方向）；具体模型、算法与实验协议仍待验证。

## 背景

当前目标要求在同功能具体模型/版本中选得更准确，并让主 Agent 可靠使用结果。
原阶段汇报已将主 Agent 的功能请求与外挂工具管理器的在线选择分开。
Task43/44 给出了首选模能力与追加复核价值的候选，但预训练能力如何进入冷启动尚未写清。

Owner 本轮提出：以 Jev 类判别式决策模型帮助外挂模块冷启动，保留真实反馈实时学习，研究“动态 Jev”；论文可以不使用 Jev 名称。
随后明确以 `https://github.com/NandhaKishorM/laya` 为开源判别式模型参考。

## 决定

将**预训练判别式决策能力与真实执行反馈的持续适应**作为当前工具管理器的研究方向。
预训练模型负责提供任务/候选的表征或初始选择先验；在线学习负责校正具体环境中的选择。
Bandit 是部分反馈学习的候选建模与实现方式，不将特定算法名称当成研究目标。
Laya 是可复用的开源候选，Jev 是功能参照；不锁定产品、模型检查点或论文命名。

## 理由

判别式模型的输入输出直接对应“状态与候选进入、结构化决策出来”。
预训练先验可能减少从零探索，而真实反馈有机会纠正先验与环境之间的偏差。
两者的实际收益可以通过冷启动、持续更新和错误先验恢复对照逐项验证。

## 后果与未定事项

需区分候选选择概率、工具真实成功概率与用于探索的估计不确定性。
需明确冷启动究竟允许哪些源任务/当前工具历史标签，不能混称零样本。
需同信息比较PILOT、BayesianRouter、LLM-PriorCB等已有方法。
“够一篇论文”尚属待验证研究判断，不作为已证新颖性或效果记录。
主Agent功能请求、复核和停止，以及其既有真实SFT/RL目标继续承接。
本决定不放行Task38当前模型池训练、新预测、星云写入或Git提交推送。
具体损失、先验强度、更新头/adapter、反馈合同与第二次调用机制见Task45候选，未在此批准。
