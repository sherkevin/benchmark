# 决议文件

这里存放项目讨论后形成的小而关键的统一标杆。完整故事线、方法论、benchmark、baseline 和评价标准放在 [研究主线文档](../研究主线/README.md)；执行记录、实验日志和临时意见不放在这里。

## 管理规则

1. 一项决议一个文件，文件按 `0001-短标题.md` 递增编号。
2. 决议状态分为：`待双方确认`、`生效`、`被替代`。只有状态为 `生效` 的文件可以作为执行依据。
3. 新增内容、修改内容或推翻既有内容，必须先由用户和 Codex 分别明确确认，之后才能写入生效决议。
4. 不静默覆盖历史文件。后续变化写入新的编号文件，并在旧文件标记“被替代”及替代文件编号。
5. 实验结果可以作为决议的证据，但结果本身不能未经讨论自动改变决议；需要先说明它影响哪条判断，再形成修订决议。
6. 遇到抉择、无法决断或任务漂移时，先查阅本目录中所有生效决议，再决定是否继续；如果现有决议不足，先写候选决议，不直接改变主线。
