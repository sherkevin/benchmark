# 0016 — 论文唯一主版与迭代合并

- 状态：被替代（2026-10-09，见 0017；历史主版路径及自动合入安排不再作为当前执行依据）
- 日期：2026-10-08
- 关联：0002、0014

## 背景

全文、实验表和图稿都在独立迭代。用户要求保留一个位置固定的论文主版：协作者可以先写自己的版本，完成后必须把修改合并到主版，主版放在迭代目录的上层，避免需要在多个候选文件中猜测哪个是最新全文。

## 决议

1. 论文全文唯一主版为 `paper/aamas2027/main.pdf`。
2. 全文合并入口为同目录的 `main.tex` 及其引用资产。协作者的候选源码、PDF 和审查记录放在独立版本目录中。
3. 全文编译迭代保存在 `paper/aamas2027/build/submission_<timestamp>/`；主版保持位于这些迭代目录的上层。
4. 完成的修改先合入全文源码，核对结果、引用、版面和来源，再生成完整 PDF。不能只更新独立预览而遗漏主版。
5. 主版正文保持恰好 8 页，参考文献从第 9 页开始；参考文献不计入正文页数。检查数字与证据对应关系，并实际查看受影响页面。
6. 通过检查后，使用现有 `make promote-main SOURCE=...` 更新主版；同步 `main_provenance.json` 和论文 README 的当前入口。
7. 每次替换前保留旧主版及其来源记录，归档在 `paper/aamas2027/archive/promotions/`。不覆盖历史迭代和失败现场。
8. 图稿 QA 主版和实验表预览继续承担各自用途。它们通过局部检查后，仍需合入并重新编译全文，才算更新了论文主版。

## 理由

固定入口便于用户阅读和协作者合并；独立版本便于比较与回溯。源码、构建和主版的对应记录用于确认看到的 PDF 确实包含本次合并内容。

## 后果

- 对用户展示全文时，默认链接 `paper/aamas2027/main.pdf`。
- 独立预览完成和全文主版更新分别记录，不能混报。
- 排版及构建检查通过，不等于三份科学验收标准已全部通过。
- 本决议补充论文全文的主版规则，不替代 0014 的图稿选择与归档规则。

## 双方确认

用户：明确要求维护主版 main PDF，独立版本完成后合并同步，并放在迭代版本的上层目录。

Codex：确认以本文件所列路径和流程执行，当前主版已按此方式维护。
