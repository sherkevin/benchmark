# 0014 — 图稿迭代与主版 PDF 同步机制

- 状态：生效
- 日期：2026-10-07
- 关联：0012、0013

## 背景

图稿需要反复用 AI 生成、审查和比较。独立迭代目录适合保留失败现场，但论文写作还需要一个明确的主版 PDF，避免当前引用散落在多个试验目录里。用户确认：可以先在独立版本中修改，完成后把修改合并到主版；主版放在迭代版本的上一层目录。

## 决议

1. 每一轮试验放在独立版本目录，例如 `figures/qa/build_v09/`，保留源文件、编译日志、失败现场、PDF 和渲染页。
2. 图稿 QA 的主版放在这些版本目录的上一层：`paper/aamas2027/figures/qa/main.tex` 与 `paper/aamas2027/figures/qa/main.pdf`。
3. 独立版本通过图级审查和 7 英寸排版检查后，才允许同步到主版；未通过或尚未由用户选择的版本不能自动覆盖主版。
4. 同步主版时保留被替换的主版副本和同步记录，写清楚图版本、源文件 hash、PDF hash、审查路径和同步日期。
5. `paper/aamas2027/main.tex` 是否引用主版图稿仍是单独的论文构建决策；图稿主版更新不等于自动改变投稿构建。
6. 所有 AI 原图、prompt、manifest 和审查报告继续按 0013 保存，不因主版同步而删除或改名。

## 理由

独立版本保证可回溯，主版保证当前状态清楚；把“审查通过”“用户选定”“论文引用”分成三个状态，可以避免试验版本静默进入正文，也能在需要时恢复上一版。

## 后果

- 当前建立 `figures/qa/main.*` 作为主版入口；Figure 1 v12 仍处于独立审查，不立即覆盖主版。
- 主版每次更新都有可核对的来源和 hash。
- 旧版本继续出现在版本画廊中，用户可以比较全部版本。

## 双方确认

用户：明确要求维护上一层目录中的主版 main PDF，并在独立版本完成后合并同步。
Codex：确认按上述目录、审查门槛和回溯规则执行。
