# 远程跑批任务：本地装不上的工具

这份文档写给在远程机器上执行跑批的同事。本地是一台苹果芯片的 Mac，下面这些工具在这台机器上装不起来，需要放到远程跑。读完这份文档不需要看别的资料。

## 你要做的事

把下面列的工具在远程机器上装好，拿我们给的那批分子（730 个）喂给每个工具，把结果存成文件带回来。

## 最重要的三条规矩

**一，每个工具一个独立环境，不许共用。**

这些工具互相之间依赖冲突得厉害——比如一个要老版本的 numpy、另一个要新版本的 TensorFlow，装到一个环境里会互相顶坏。所以**每个工具单独建一个虚拟环境**（用 conda 或 venv 都行），一个工具一个，互不干扰。宁可多建几个环境，也不要图省事共用。

**二，每一次运行的结果都要留下来，不许覆盖。**

同一个工具跑两遍，两遍的结果分开存，都留着。我们要靠对比两遍来判断这个工具的输出稳不稳定。文件名里带个标记区分（比如加 _run1、_run2），别用同一个文件名覆盖。

**三，装不上就如实记录，不要硬修。**

某个工具装不起来，把完整的报错信息抄下来、记清楚卡在哪一步，然后跳过它装下一个。**装不上这件事本身是有用的信息**，不要为了让它跑起来去改它的代码或者编一个结果。一个工具花两小时还装不上就放弃，记下原因。

## 输入

分子清单文件 `molecule_pool.json` 会单独给你，730 个分子，每个是一条化学结构（SMILES 格式，一种用文字表示分子结构的写法）。每个工具都跑这一批。

## 输出

每个工具一份结果文件，CSV 格式，一行一个分子。至少包含这几列：分子编号、输入的分子结构、工具给出的预测值。多跑一遍就多存一份。

## 要装的工具

下面每个工具给出：代码在哪、我们本地卡在哪、它测什么性质。

---

### 1. OPERA（优先）

**测什么**：理化性质和毒性，覆盖最广——细胞渗透、熔点、沸点、急性毒性、两个激素受体等。

**代码**：https://github.com/kmansouri/OPERA

**本地为什么装不上**：官方只发 Windows 和 Linux 的安装包，没有 Mac 版。远程是 Linux 的话正好。

**装时要注意**：它装的时候会自动去 mathworks.com 下载一个 MATLAB 运行库，所以**装它的那台机器要能连上外网**。官方明确说了装好之后是**完全离线运行**的，不联网。

**许可证**：MIT，随便用。

---

### 2. EPA TEST

**测什么**：急性毒性、致突变、生态毒性（鱼、水蚤、藻类）、熔点沸点这些。

**代码**：https://github.com/USEPA/test-app （Java 写的）

**本地为什么装不上**：它主要是 Windows 软件，Mac 上要自己从源码编译，我们没试通。

**装时要注意**：需要 Java。官方自己说这个版本有已知问题，如果跑着不对劲不是你装错了。

**许可证**：没标注。它是美国政府环保署出的，美国政府作品一般不受版权限制，但既然没写清，内部用没问题。

---

### 3. VEGA QSAR

**测什么**：致突变、致癌、皮肤致敏、生态毒性，这个工具里同一个性质有好几个不同的模型可以互相印证。

**代码**：https://www.vegahub.eu/download/vega-qsar-download/ （下载压缩包）

**本地为什么装不上**：它只给 Windows 和 Linux 的启动脚本，而且**第一次运行必须联网**去下一些补充文件。

**装时要注意**：需要 Java 17 或更高。第一次跑的那一下要联网，之后就离线了。

**许可证**：GPL 3。

---

### 4. TRIDENT

**测什么**：水生生物毒性（鱼、无脊椎动物、藻类），是唯一一个用现在主流的大模型思路（Transformer）做的工具。

**代码**：https://github.com/StyrbjornKall/TRIDENT

**本地为什么装不上**：它分两部分，一部分在我们克隆下来的仓库里，另一部分（微调好的主干模型）存在 HuggingFace 上，**我们这台机器访问不了 HuggingFace**。

**装时要注意**：如果远程能访问 HuggingFace 就直接下；不行的话它提供了 Docker 镜像（在 Docker Hub 上，名字是 styrbjornk/streamlit-app-trident-serve-v4.1），用 Docker 跑可能更省事。

**许可证**：MIT。

---

### 5. CONCERTO

**测什么**：致癌性。

**代码**：https://github.com/bowang-lab/CONCERTO

**本地为什么装不上**：它要先加载另一个叫 GROVER 的预训练模型的输出，那个模型在第三方仓库里，我们没验证过现在还下载得到。如果远程能拿到 GROVER 的预训练权重，这个就能跑。

**许可证**：MIT。

---

### 6. CypReact

**测什么**：CYP450 酶的底物预测（这个分子会不会被某种肝药酶代谢）。

**代码**：https://github.com/Le0nT1/CypReact

**本地为什么装不上**：它是 Java 写的，仓库里没给编译好的包，要自己用 Maven 编译，我们没编译成功。

**装时要注意**：需要 Java 和 Maven。提一句，这个仓库挂在作者个人账号下、不是实验室官方账号，如果你找到更正式的发布渠道（比如 Wishart 实验室的组织账号）优先用那个。

---

### 7. CardioTox

**测什么**：心脏毒性（hERG 通道阻断）。

**代码**：https://github.com/Abdulk084/CardioTox

**本地为什么装不上**：它的模型是用很老版本的 TensorFlow（2.3.1）存的，这个版本没有苹果芯片的安装包。远程如果是普通 Linux 服务器就能装。

**装时要注意**：按它仓库里的 environment.yml 建 conda 环境。权重的归一化参数它也给全了（这点很难得）。

**许可证**：没标注，代码在 GitHub 公开。内部研究用没问题。

---

### 8. BayeshERG

**测什么**：也是心脏毒性，和 CardioTox 是同一件事的不同方法。它的好处是会告诉你这个预测有多不确定。

**代码**：https://github.com/GIST-CSBL/BayeshERG

**本地为什么装不上**：它要的 PyTorch 和 DGL 版本很老，新版本对不上，版本配对在我们这台机器上调不出来。

**装时要注意**：按 environment.yml 建环境。它默认对每个分子跑 30 遍取平均，所以跑 730 个会比较慢，留出时间。

**许可证**：注意——代码是 MIT，但**训练好的模型权重是 CC-BY-NC-4.0**，意思是研究能用、商用不行。内部评测没问题。

---

### 9. CYPlebrity

**测什么**：CYP450 酶的抑制（这个分子会不会抑制某种肝药酶），覆盖五个亚型。

**代码**：https://github.com/molinfo-vienna/cyplebrity

**本地为什么装不上**：它的模型是用老版本 scikit-learn（0.23.2）存的，那个版本依赖的 numpy 在苹果芯片上编译不出来；而且模型文件里引用的一个内部模块在新版本里被删了，所以装新一点的版本也读不出来。

**装时要注意**：它不在 PyPI 上，要克隆下来用 conda 装。远程如果是 x86 的 Linux 机器，老版本应该能装上。

**许可证**：BSD-3-Clause。

---

### 10. CYPstrate

**测什么**：CYP450 酶的底物，九个亚型。和 CypReact 是不同团队做的，正好互相印证。

**代码**：https://github.com/molinfo-vienna/cypstrate

**本地为什么装不上**：它能 pip 装，但它钉死的四个依赖（numpy 1.19.2、scikit-learn 0.23.2、gensim 3.8.3、pandas 1.2.1）都太老，在苹果芯片上编译不过去。

**装时要注意**：`pip install cypstrate` 就行，权重在包里。远程如果是普通 Linux 应该没这个问题。

**许可证**：BSD-3-Clause。

---

## 装完怎么算装好

每个工具装好以后，先拿这三个分子试，确认它出数：

- 咖啡因：`CN1C=NC2=C1C(=O)N(C)C(=O)N2C`
- 地西泮（一种安眠药）：`CN1C(=O)CN=C(c2ccccc2)c2cc(Cl)ccc21`
- 一个糖类片段：`OC[C@H]1O[C@@](O)(CO)[C@@H](O)[C@@H]1O`

能出数、数的方向合理，再跑全部 730 个。

## 带回来什么

每个工具一个结果文件，加上一个说明文件，写清楚：装上了没有、装的什么版本、什么时候跑的、跑了几遍、装不上的话卡在哪一步的完整报错。
