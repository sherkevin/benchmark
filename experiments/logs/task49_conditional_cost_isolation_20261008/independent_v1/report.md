## 范围与可复用产物

这是已经查看过的固定 development 数据上的成本处理和到达顺序诊断。
排列统计不是总体置信区间，不包括分子抽样或训练不确定性；不能推导新颖性、
在线学习或端到端 agent 收益。成本外置改变正则先验，也不意味着所有 query
的旧分数都向上偏。本次没有扩大这些声明。

`verification.json` 是核验结果；`model_equation_checks.json` 保存逐折误差；
`verified_order_metrics.jsonl` 流式保存逐折逐订单复算；
`recomputed_call_decompositions.json` 保存全部 645 份完整收益分解；
`recomputed_order_utilities.npy` 保存全部 129×5 个 pooled utility。

可复用的是成本偏移的独立代数检查、旧轨迹绑定、全字段控制器重放，以及
包含后续预算变化的收益分解。未来研究仍应以 `known_cost_ridge` 为匹配对照，
避免把已知成本处理误归因为新状态或提前反馈。
