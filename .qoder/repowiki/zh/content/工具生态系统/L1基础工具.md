## 简介
本技术文档聚焦于L1基础工具，覆盖分子操作、物理化学计算与数据结构转换等能力。文档面向不同技术背景的读者，提供从高层架构到代码级实现的渐进式说明，包括：
- 工具能力边界与职责划分
- 参数配置、输入输出格式与错误处理机制
- 与RDKit、OpenBabel等化学信息学库的集成方式
- 批量处理与性能优化实践
- 工具间依赖关系与数据流转路径

## 核心组件
L1基础工具围绕以下能力域展开：
- 分子结构与SMILES校验与编辑
- 分子基本属性与理化性质计算
- 分子相似性与拓扑/结构度量
- 氢键、疏水性、电荷分布等特性指标
- 序列有效性检查（多肽/蛋白质）
- 化合物检索与外部数据库对接
- 分子对接与相互作用分析（基于PROLIF、EQuiScore、GOCADock等）
- 结合亲和力预测（Boltz2、Chai1、ESMFold等）
- 蛋白结构准备与MD相关预处理（PDBFixer、OpenMM、Sidechain Packing等）
- 采样与生成（Linker/R-group/De Novo/Mol2Mol/Peptide）
- 可视化与文件传输辅助

上述能力通过统一的“技能”元数据（skill.json）进行声明，并由评估框架加载与编排。

## 架构总览
整体架构由“技能注册—任务编排—工具执行—结果汇总”构成。评估器读取基准配置，解析变量与工具路由，按顺序或并行调用相应L1工具，收集并标准化输出以供评测。

```mermaid
sequenceDiagram
participant U as "用户"
participant ER as "评估运行器(eval_runner)"
participant RL as "基准加载(bench_loaders)"
participant TR as "工具路由(tool_routing)"
participant T as "L1工具(技能)"
participant O as "外部库(RDKit/OpenBabel等)"
U->>ER : 启动评估
ER->>RL : 加载基准与任务清单
RL-->>ER : 返回任务与输入数据
ER->>TR : 解析工具路由与变量映射
TR-->>ER : 返回可执行计划
loop 遍历任务
ER->>T : 调用具体工具(参数/输入)
T->>O : 调用化学信息学库
O-->>T : 返回中间结果
T-->>ER : 返回结构化输出
end
ER-->>U : 汇总评测结果
```

## 详细组件分析

### 分子结构与SMILES校验与编辑
- 能力范围
  - SMILES合法性校验、规范化、去盐、立体化学修复
  - 官能团编辑、片段替换、连接子/末端基团采样
- 典型输入/输出
  - 输入：SMILES字符串、可选过滤规则、编辑策略
  - 输出：经处理的SMILES列表、变更日志、失败原因
- 错误处理
  - 非法SMILES抛出明确错误码与提示
  - 对不合法结构进行回退策略（如保留原样或跳过）
- 集成点
  - 主要依赖RDKit进行结构解析与操作；必要时使用OpenBabel进行格式互转
- 示例调用模式
  - 单条SMILES校验与规范化
  - 批量SMILES清洗与统计报告
- 性能建议
  - 批量处理时启用进程内缓存（如已计算的指纹/属性）
  - 合理设置并行度，避免I/O瓶颈

### 分子基本属性与理化性质计算
- 能力范围
  - 分子量、LogP、HBA/HBD、TPSA、旋转键数、环系计数、复杂度等
  - 药物相似性评分（如QED、类药性）
- 典型输入/输出
  - 输入：SMILES或结构文件
  - 输出：JSON字典（字段名与单位需统一）
- 错误处理
  - 缺失原子/价态异常时记录并跳过
  - 数值越界给出警告
- 集成点
  - RDKit属性计算为主；部分指标可能依赖第三方库
- 示例调用模式
  - 单分子属性计算
  - 批量属性计算并导出CSV
- 性能建议
  - 预构建分子对象缓存，避免重复解析
  - 使用向量化计算减少Python层开销

## 性能考虑
- 批处理策略
  - 将小任务聚合为批次，减少进程/线程切换开销
  - 对I/O密集型任务采用异步与缓冲写入
- 资源利用
  - CPU密集：合理设置worker数量，避免上下文切换过多
  - GPU密集：批大小与显存占用平衡，启用混合精度
- 缓存与复用
  - 分子对象、指纹、网格、模型权重等全局缓存
  - 中间结果持久化，支持断点续跑
- 监控与诊断
  - 记录耗时与内存峰值，定位热点
  - 失败重试与熔断机制，提升鲁棒性

## 故障排查指南
- 常见问题
  - 依赖缺失：确认RDKit/OpenBabel/深度学习框架安装与环境变量
  - 输入格式错误：核对SMILES/PDB/FASTA规范与编码
  - 资源不足：检查磁盘空间、内存与GPU显存
  - 网络问题：数据库检索超时或限速，启用重试与代理
- 定位方法
  - 查看工具日志与错误码
  - 缩小输入规模复现问题
  - 逐步禁用下游工具隔离问题源
- 恢复措施
  - 修正输入或参数后重试
  - 切换到CPU回退或降级模式
  - 清理临时文件与缓存后重跑
