## 简介
本指南面向“工具”开发者，围绕以下目标提供系统化说明：
- 工具注册机制与接口规范
- 开发框架使用方法（以现有评估与Agent框架为参考）
- SKILL.md 编写规范、参数定义与文档生成机制
- 测试策略、调试技巧与性能分析方法
- 打包、部署与版本管理最佳实践
- 与核心框架的集成方式与扩展点使用
- 常见问题与排障建议

本指南基于仓库中已有的评估框架、模板系统、工具注册示例与任务执行脚本进行归纳总结，确保读者可据此快速上手并产出高质量工具。

## 详细组件分析

### 工具注册机制与接口规范
- 注册表设计
  - 通过集中式注册表维护工具名称到实现的映射，支持动态发现与按需加载
  - 典型能力：注册、列出、获取、校验签名与参数
- 接口规范
  - 输入：结构化参数（键值对），类型与约束由注册表或工具描述声明
  - 输出：标准化结果对象（含状态码、消息、数据体）
  - 错误：异常应被捕获并转换为统一错误格式，便于上层处理与日志追踪
- 路由与变量映射
  - 工具路由根据上下文选择合适工具
  - 变量路由将外部变量注入到工具参数中，减少硬编码

```mermaid
classDiagram
class ToolRegistry {
+register(name, impl, schema)
+get(name)
+list()
+validate_params(name, params)
}
class ToolImpl {
+call(params) Result
}
class Router {
+route(context) name
+map_variables(context) params
}
ToolRegistry --> ToolImpl : "管理"
Router --> ToolRegistry : "查询"
```

### Agent与工具调用流程
- 最小Agent负责：
  - 接收用户意图或任务描述
  - 借助LLM客户端生成工具调用计划
  - 通过注册表查找并调用工具
  - 记录轨迹并返回结果
- LLM客户端封装了请求构造、重试与限流策略
- 轨迹记录用于回放与诊断


### SKILL.md 编写规范、参数定义与文档生成
- 编写规范
  - 明确工具目的、适用场景与前置条件
  - 定义输入参数（名称、类型、默认值、约束）
  - 定义输出结构（字段、含义、单位）
  - 提供错误码与失败处理建议
  - 给出示例用法与边界情况
- 参数定义
  - 建议在注册表中声明schema，并在SKILL.md中保持一致
  - 使用变量路由将外部配置注入参数
- 文档生成
  - 模板系统可将SKILL.md与注册表信息渲染为统一文档
  - 工具路由与变量路由模板帮助自动生成调用说明

### 工具测试策略与调试技巧
- 单元测试
  - 针对每个工具的输入/输出进行断言
  - 覆盖正常路径、边界条件与异常分支
- 集成测试
  - 通过最小Agent与注册表端到端验证工具调用链
  - 使用模拟LLM客户端避免外部依赖
- 回归测试
  - 固定基准数据与随机种子，确保结果稳定
- 调试技巧
  - 启用轨迹记录，定位调用顺序与参数传递问题
  - 在注册表层打印工具清单与签名，辅助排查路由问题
  - 使用统一的错误格式，便于日志聚合与分析

### 性能分析与优化建议
- 指标采集
  - 在工具实现中埋点耗时、内存占用与I/O次数
  - 在评估运行器中汇总指标并生成性能报告
- 并行与缓存
  - 对无副作用的工具进行并发调用
  - 对重复查询结果进行缓存（注意失效策略）
- 资源限制
  - 设置超时与重试上限，防止长尾任务拖慢整体评估
- 基准对比
  - 使用ranking_metrics对不同实现进行排序与对比

## 性能考量
- 工具侧
  - 避免阻塞I/O；必要时异步化
  - 控制单次调用数据量，分块处理大对象
  - 合理设置超时与重试退避策略
- 评估侧
  - 批量加载基准数据，减少重复IO
  - 使用缓存命中热点查询
  - 并行执行独立任务，但需考虑资源竞争
- 监控与告警
  - 记录关键指标（延迟、吞吐、错误率）
  - 设定阈值触发告警，及时定位瓶颈

## 故障排除指南
- 工具未找到或路由失败
  - 检查注册表是否成功注册与命名一致性
  - 确认工具schema与调用参数匹配
- 参数校验失败
  - 核对SKILL.md与注册表schema的一致性
  - 使用变量路由前确保外部变量已正确注入
- LLM调用异常
  - 检查网络与认证配置
  - 增加重试与降级策略
- 评估结果不稳定
  - 固定随机种子与基准数据
  - 检查工具幂等性与缓存失效策略
- 性能退化
  - 查看轨迹与指标，定位慢调用
  - 引入并发与缓存，优化I/O路径
