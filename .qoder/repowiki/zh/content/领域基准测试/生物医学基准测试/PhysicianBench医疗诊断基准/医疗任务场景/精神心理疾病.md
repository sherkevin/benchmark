## 引言
本文件围绕精神心理疾病相关临床任务，聚焦以下主题：难治性抑郁症（TRD）增效治疗、SSRI不耐受换药、SNRI到SSRI滴定、阿片类药物使用障碍（OUD）等。文档从系统实现角度梳理评估工具、量表应用、鉴别诊断思路、药物治疗原则、心理治疗技术与危机干预策略，并给出不良反应监测、自杀风险评估与家属支持指导的落地建议。内容既面向临床工作者，也便于工程与数据团队理解评测框架与任务编排方式。

## 项目结构

## 详细组件分析

### 难治性抑郁症（TRD）增效治疗
- 临床要点
  - 明确TRD定义与既往足量足疗程抗抑郁治疗失败情况
  - 评估共病（焦虑、躯体症状）、风险因素（自杀意念、物质滥用）
  - 选择增效策略：非典型抗精神病药、锂盐、甲状腺素、安非他酮、米氮平、文拉法辛等；必要时考虑物理治疗或转诊
  - 关注药物相互作用、代谢与心电图影响
- 评估与量表
  - 抑郁量表：PHQ-9、HAM-D、MADRS
  - 功能评估：WHODAS 2.0
  - 风险筛查：C-SSRS、SAD PERSONS
- 流程图（概念）
```mermaid
flowchart TD
Start(["开始"]) --> Assess["全面评估<br/>病史/量表/风险"]
Assess --> DefineTRD{"符合TRD标准？"}
DefineTRD -- 否 --> NonTRD["按一般抑郁路径处理"]
DefineTRD -- 是 --> ChooseAug["选择增效策略<br/>结合共病与安全性"]
ChooseAug --> Monitor["密切随访与监测"]
Monitor --> Reassess{"疗效/耐受性达标？"}
Reassess -- 否 --> Adjust["调整方案/联合/转诊"]
Reassess -- 是 --> Maintain["维持治疗与复发预防"]
NonTRD --> End(["结束"])
Maintain --> End
Adjust --> End
```

### SSRI不耐受换药
- 临床要点
  - 区分副作用类型（胃肠道、性功能障碍、失眠/嗜睡、体重变化、QT间期延长等）
  - 选择替代药物：同属内换药、跨类换药（SNRI、NaSSA、NDRI、多靶点等）
  - 交叉换药与洗脱策略，避免撤药综合征与血清素综合征
- 评估与量表
  - PHQ-9跟踪疗效
  - 不良事件记录与严重程度分级
- 流程图（概念）
```mermaid
flowchart TD
S(["开始"]) --> Intol["识别不耐受类型与严重度"]
Intol --> Decide{"是否需立即停药？"}
Decide -- 是 --> Stop["立即停药并对症处理"]
Decide -- 否 --> Cross["设计交叉换药/洗脱计划"]
Stop --> Switch["选择替代药物并起始"]
Cross --> Switch
Switch --> Follow["短期随访与监测"]
Follow --> Eval{"症状改善/副作用可控？"}
Eval -- 否 --> Replan["重新评估并调整"]
Eval -- 是 --> Continue["继续治疗与教育"]
Replan --> Continue
Continue --> End(["结束"])
```

### SNRI到SSRI滴定
- 临床要点
  - 滴定目标：在控制抑郁的同时降低SNRI相关副作用（如血压升高、出汗、性功能障碍）
  - 逐步减量SNRI并同步起始SSRI，注意半衰期差异与撤药反应
  - 合并心血管风险时优先选择对血压/心率影响较小的SSRI
- 评估与量表
  - PHQ-9、血压/心率监测、肝功能与电解质复查
- 流程图（概念）
```mermaid
flowchart TD
A(["开始"]) --> Plan["制定SNRI减量与SSRI起始计划"]
Plan --> Step1["第1阶段：小步减量SNRI + 低剂量SSRI起始"]
Step1 --> Check1{"耐受/症状稳定？"}
Check1 -- 否 --> Adjust1["微调剂量/延长过渡期"]
Check1 -- 是 --> Step2["第2阶段：继续递减SNRI并递增SSRI"]
Step2 --> Check2{"达到目标剂量且耐受良好？"}
Check2 -- 否 --> Adjust2["回到上一稳定阶段并缓慢推进"]
Check2 -- 是 --> Maintain["维持与长期随访"]
Adjust1 --> Step2
Adjust2 --> Step2
Maintain --> End(["结束"])
```

### 阿片类药物使用障碍（OUD）
- 临床要点
  - 识别与诊断：DSM-5标准、成瘾行为特征、戒断症状
  - 药物治疗：美沙酮、丁丙诺啡（含纳洛酮复方）诱导与维持；疼痛管理中的谨慎使用
  - 心理社会干预：动机访谈、认知行为疗法、同伴支持、家庭参与
  - 危机与安全：过量风险评估、纳洛酮配备、复吸预防
- 评估与量表
  - DAST-10、ASSIST、CIWA-Ar（戒断评估）、C-SSRS（自杀风险）
- 流程图（概念）

### 药物治疗原则与注意事项
- 个体化与循证：基于证据选择一线药物，结合共病、年龄、性别、妊娠/哺乳、肝肾功能
- 起始与滴定：低起始、慢滴定，定期评估疗效与不良反应
- 相互作用与禁忌：CYP450相互作用、QT间期延长、5-羟色胺综合征风险
- 特殊人群：老年、青少年、孕产妇、慢性病患者

## 故障排查指南
- 任务未找到或路径错误
  - 检查run_task.py的任务参数与README路径是否正确
- 工具不可用或权限不足
  - 确认tool_registry.py已正确注册fhir_api_functions.py提供的工具，并配置访问凭证
- 数据缺失或不一致
  - 使用eval_helpers.py进行数据校验与缺失值处理
- 输出格式不符合评测要求
  - 对照prompts.py的模板规范，确保输出字段完整与顺序一致
