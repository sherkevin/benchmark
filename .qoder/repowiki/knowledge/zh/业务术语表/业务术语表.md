### 过程量
- 定义：项目对 agent 在长程科学任务执行过程中产生的中间产物与决策信号的统称，包括工具调用、中间数值、决策点、求助行为等；本项目以“过程量度量”为技术主轴，区别于仅评最终答案的现有 AI4S benchmark。
- 别名：中间过程量、trace 过程量

### checkpoint（卡点）
- 定义：嵌入在任务金标准轨迹中的可被对照裁判判定的中间状态谓词；不约束 agent 走哪条路径，只验证必经中间状态是否达成，是过程量的具体操作化形态。
- 别名：里程碑、subgoal、key node、milestone

### 对照裁判
- 定义：手握外部 ground truth 做低难度比对的判定器；可靠性来自外部 GT 而非裁判自身知识，与 LLM-as-judge 凭知识硬判形成对比，且必须用人工标注做 κ 校准并公开。
- 别名：GT-based judge、对照式评判

### 介入-成功率曲线
- 定义：横轴为人类介入深度（L0→L3），纵轴为对应成功率，用于刻画 prompt 详细度或干预强度对任务完成概率的影响；是“人类介入度”作为过程量的一种操作化指标。
- 别名：intervention-success curve、介入度曲线

### autonomy@0
- 定义：agent 在不接受任何人类介入（L0 提示）的情况下独立完成任务的概率；随介入深度递增单调递降，是衡量 agent 自主性的核心单点指标。
- 别名：零介入自主性

### 介入守恒
- 定义：固定 cohort 下，前置 prompt 详细度与运行时求助总量之和近似为常数；过量前置提示被视为浪费，binding 占比塌缩即违反该守恒律。
- 别名：intervention conservation

### 许可校准诊断
- 定义：衡量 agent 在高风险动作节点上请求介入的意愿与其实际是否需要介入的一致性；与自主性正交，well-calibrated≈1.0 vs never_asks≈0.5。
- 别名：permission calibration

### pass^k
- 定义：同一任务重复运行 k 次全部正确的概率，用于度量长程稳定性；本项目将其推广为“介入条件化 pass^k”，区分不同介入深度下的稳定性差异。
- 别名：pass-at-k、k 次全对率

### DRBEκP 工作流
- 定义：项目方法论流程：Discover（调研先行）→ Retrofit（改造现有 benchmark）→ Borrow & Build（借法构造新题）→ Expert review（专家审核）→ κ 校准 → Paper（论文）；禁止跳过 D 直接造题。
- 别名：DRBEκP 流程、防偏差工作流

### 测量机器
- 定义：autonomy_mvp 内核的代称：输入一个 agent 及其轨迹，输出 autonomy@0、介入-成功率曲线、介入守恒账、prompt 详细度敏感性、许可校准诊断等一套过程量指标的可运行系统。
- 别名：measurement machine、评测内核
