模块按 PRD §2.3/§2.5 划分为六个内聚子模块,依赖方向单向: `harness` → `judge` + `interruption` → `metrics`/`conservation`,`sim_agents` 仅被 harness 和报告脚本消费。

- 数据层 `tasks.py`:用 dataclass 定义 `Stage`(ranking/value_set/selection 三 kind)+`TaskSpec`(含 L0-L3 prompts、分级介入卡 D1-D3、反事实变体),JSON loader 从 `tasks/` 或 `tests/fixtures/` 读取。
- 裁判层 `judge.py`:按 stage.kind 分派到 `_judge_ranking`/`_judge_value_set`/`_judge_selection`,复用 `ranking_metrics`(hits@3/AUROC/enrichment factor/F1)做低难度偏离比对,不自行推理。
- 中断分类 `interruption.py`:把运行中事件分为 CAPABILITY(计入预算)与 PERMISSION(统一 auto-approve 不计入),并提供 `calibration_score` 作为与自主性正交的许可校准诊断。
- 评测回路 `harness.py`:固定每阶段 base noise,对 b=0..max_budget 计算有效噪声 eff=sigma/(1+pre+b),强制 success_at_budget 单调,产出 need_total、permission_events 等扁平记录。
- 指标套件 `metrics.py`:`autonomy@0`、`intervention_success_curve`、`budget_to_threshold`、`pass_hat_k`(按任务组组合估计)、`prompt_detail_sensitivity`。
- 守恒框架 `conservation.py`:PRE_WEIGHT(L0-L3)与 runtime depth_weighted 相加,提供 per-instance cohort 无偏守恒表。
- 合成参考 `sim_agents.py`:oracle/strong/medium/weak/random/reversed/never_asks 七类模拟器,实现 `produce(stage,eff,base,rng)` 与 `permission_at` 接口,供 harness 驱动。
- 入口 `run_validation.py`:argparse 驱动 agents×tasks×L_levels×seeds 笛卡尔积,生成五段 markdown 报告并可选写入 `results.md`/`results_real.md`;真实任务集在 `tasks/*.json`,合成 fixture 在 `tests/fixtures/`。
