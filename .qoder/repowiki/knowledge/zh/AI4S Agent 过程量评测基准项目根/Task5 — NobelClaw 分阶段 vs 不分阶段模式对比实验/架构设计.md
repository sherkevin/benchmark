模块由一个自包含的 Python 运行器 `runner.py` 与配套文档组成,按职责分为三层:
- 数据层:`questions.md`(整条 whole-question 题目)、`ground_truth.md`(两层 GT:实验真值 + 派生一致性)提供输入与判分口径。
- 执行层:`runner.py` 以 curl 直接调用 `http://nobelclaw.aliyun-inc.com/api/v1`,通过 SSE(`Accept: text/event-stream`)流式接收事件;核心流程为 `run(qid,qtext,mode)` → `new_session()` → 首轮发送触发 decomposition → 若 mode=parallel 则用 confirmed_tasks 进入子 agent 并行,否则追加 SUFFIX 走单步 → 解析 `decomposition/tool_call/synthesis_start/message/done` 等事件 → 统计工具调用正确率并写出 `/tmp/exp/{qid}_{mode}.json`、`*_report.md`。
- 产出层:`runs/` 存放 12 份最终报告(每域 2 题 × 两模式),`experiment/` 记录每次探针与根因分析,`results.md`/`CONCLUSION.md` 汇总打分与结论。
依赖方向单向:runner → 外部 HTTP API → /tmp/exp 中间产物 → runs/experiment 归档,无内部包结构,并发由 `concurrent.futures.ThreadPoolExecutor(max_workers=4)` 控制。
