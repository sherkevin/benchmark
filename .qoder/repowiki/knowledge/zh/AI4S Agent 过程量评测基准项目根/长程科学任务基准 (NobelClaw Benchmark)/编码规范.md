- 所有外部库(rdkit/pymatgen)采用 try-import 延迟加载,缺失时返回 None 让上层报「不可用」,禁止静默降级。
- 网络请求统一封装为带指数退避重试的 `_fetch_json`,用于抵御 OQMD/EBI 等服务的瞬时 502/SSL EOF。
- 判分器遵循统一签名 `(gold, out, thr) -> {"passed": bool, "score": float, "reasons": [...]}`,并通过 `_DISPATCH` 字典按 kind 分发。
- ckpt 与 verifier 的绑定集中在 `CKPT_MAP` 中声明,避免在实例脚本里硬编码判别逻辑。
- JSON 实例文件命名遵循 `<prefix><case_id>_<variant>.json`(如 `matD_Ba-Ti-O.json`、`drug2_GLP-1R.json`),并以 `_index.json` 或 `_audit.json` 作索引/审计产物。
- 每个 case 配套「实例化脚本 + README 说明 + instances 目录 + 可选杀手实验/批量脚本」四件套,新形状必须齐备。
