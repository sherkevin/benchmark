根目录不承载代码,只承担三件事:
- **目标锚定**: `goal.md` v1.0 把 PRD 的「人类介入度」主轴还原为更一般的「中间 checkpoint / 过程量度量」,并规定 DRBEκP(Discover-Retrofit-Borrow&Build-Expert-κ-Paper)工作流;所有子模块产出必须回指本文件。
- **进度聚合**: `PROJECT_RESULT.md` 作为全项目唯一汇总,把 task1–5 的结果按发现/决策/风险/交付物四栏对齐到 goal.md 的三层 GOAL,并给出 Go/No-Go 判定。
- **构造方法学**: `construction_methodology.md` 把 goal 的方法论落地为 Phase1–6 执行手册,统一每题 spec schema、Tier1/Tier2/Tier3 cp 配额(≥70% Tier1)、三层评分公式与 κ 门槛(≥0.7),供 task6(task7 POC)直接复用。
