本模块按用途划分为四个并列子目录：
- `docs/prd/molbench_repo/`：MolClaw 主仓库的只读副本，包含三层技能体系（L1_tools/L2_workflows/L3_methodology）、molbench 多任务数据集（ms-1/2/3 与 mo 编辑/优化）、eval 统一评估入口（`eval_runner.py`、`run_eval_bench.py`）及 baseline YAML 配置；通过 `environment.yaml` 与 `.env.template` 声明运行环境。
- `docs/prd/task4_papers/`、`docs/prd/task6_papers/`：按 task 归档的 arXiv XML/HTML 原始论文素材，供检索与引用。
- `docs/search/`：调研过程产物（事实核查、中间 JSON 结果），与 PRD 原始素材解耦。
- `docs/templates/`：标准化 task 范式（goal + experiment + result 三件套）与写作约定，作为新增文档的唯一入口。
- `docs/决议/`：项目级决策记录（ADR 风格）。
依赖方向单向向外：search 与 templates 引用 prd 素材产出结论，不反向依赖代码实现。
