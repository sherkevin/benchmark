- 每个 benchmark 子目录统一包含 REPO_README.md 与 README_采样说明.md 两份说明文件，前者来自上游仓库，后者记录本地采样策略。
- 样本文件命名遵循 `<source>_sample_<N>cases.json(.l)` 或 `<split>.jsonl` 的固定模式，便于快速浏览前几个样例。
- download_samples.py 中每个 benchmark 对应一个独立的 `dl_xxx()` 函数，并通过 `steps` 列表顺序注册，新增 benchmark 只需追加函数与步骤名。
- 网络请求统一封装为 `http_get(url, headers, timeout, rng)`，所有外部访问均通过 curl 子进程发起，避免 Python urllib 的 TLS 兼容问题。
