本模块为纯数据仓库，按 benchmark 名称在 `datasets/` 下平铺子目录，每个子目录包含：REPO_README.md（上游仓库说明）、README_采样说明.md（本地采样规则）、以及若干 `.json/.jsonl/.parquet` 样本文件；部分复杂 benchmark（如 TheAgentCompany、AgentBoard）还附带 `DATASET_README.md`、`docs_EVALUATION.md`、`evaluator.py`、`checkpoints.md`、`task.md` 等评估相关工件。根目录提供 `download_samples.py` 统一脚本，通过 GitHub API、ModelScope API 和 GitHub LFS 三种通道拉取各数据集的前 N 行或随机样例，并按 benchmark 分步执行（`step(name, fn)` 模式）。依赖方向单向向下：脚本 → 外部仓库，模块内无代码逻辑耦合。
