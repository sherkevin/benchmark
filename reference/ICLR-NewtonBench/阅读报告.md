## 0. 一句话

把"科学发现"从**静态函数拟合**升级为**交互式模型发现**：agent 必须自己设计实验、调参、观测输出，从一个被改写过的"反事实物理定律"里反推出隐藏公式；靠系统性改写正典定律来同时拿到规模化、科学相关性与抗记忆三件事。

## 1. 数据量

| 量纲 | 数值 |
|---|---|
| 种子正典定律 | **12** 条（跨 12 个物理领域，如万有引力、Snell 定律等） |
| 改写后定律 | **108** 条（每条种子 → easy/medium/hard 三档，各由 1–2 次表达式树突变累加得到；三位领域专家共同人工把关科学合理性） |
| 最终任务数 | **324** = 108 条改写定律 × 3 种系统复杂度（Vanilla Equation / Simple System / Complex System） |
| 被测模型 | 11 个前沿 LLM，每例 4 次独立运行，temperature 0.4 |
| 交互预算 | 每例最多 **10 轮实验**，每轮最多 **20 组输入参数**（论文明说这是为了"防止无界交互、隔离策略设计"） |

对照表（论文 Table 1）里的同类规模：AI Feynman 120、LSR-Transform 111、LSR-Synth 128、PhysSymbol 5,000（纯合成）、EmpiricalBench 9。**结论：这条赛道 ICLR 可接受的数据量在 10² 量级**，PhysSymbol 那种 5,000 是靠牺牲科学相关性换来的。

## 2. 数据集形态（一条样本长什么样）

一条样本 = 一个**可执行的黑箱模型系统** + 一份隐藏的目标方程，不是一行 JSON。

- **Equation**：一棵表达式树（AST）。叶子是输入变量或数值常量，内节点是一元/二元算子。
- **Model** `M = (f₁, …, f_k)`：一个有序方程序列。后面方程的输入可以取模型的原始输入 `V_M`，也可以取前面任意方程的输出。其中恰有一个 `f_target` 是隐藏的待发现定律，其余 `F_assist` 作为"已知信息"写在 prompt 里给 agent。
- **三档系统复杂度**：Vanilla（`M` 只含 `f_target`）→ Simple System → Complex System（`f_target` 被埋在带混淆变量的多方程系统里）。
- **agent 侧接口**：`<run_experiment>` 工具（提交一组 `V_M` 赋值 → 返回系统级输出 `Y_M`）+ 可选 `<python>` 代码解释器。
- **防污染机制**：counterfactual law shift——对表达式树做算子突变（加法改乘法）或常量突变（指数 2 改 3）。因为改写会破坏量纲一致性，所以**每条目标定律必须内含至少一个物理常量**，用来吸收量纲变化。这是一个很硬的工程约束，值得我们照抄思路。

## 3. "长"体现在哪

**"长"不来自步数，来自搜索空间的深度与观测的间接性。**

1. **假设空间深**：hard 档定律距正典 4–6 次突变，纯靠回忆无解，必须真的做"假设 → 实验 → 修正"循环；
2. **观测是间接的**：Complex System 下 `f_target` 的效应被 `F_assist` 层层包裹，agent 只能看到系统级输出，必须先用已知的辅助方程反解出中间量才能隔离目标定律；
3. **交互轮数其实很短**：官方上限 10 轮，实测各模型平均 3–8 轮（论文 Table 13：GPT-4.1 平均 7.6 轮，o4-mini 只有 3.35 轮）。

⚠️ **这是它的软肋，也是我们的机会**：NewtonBench 的 horizon 只有个位数轮次，"长程"含量远低于 Toolathlon（~20 turns）或我们的 checkpoint DAG。它的难在"深"不在"长"。

## 4. 判分粒度

**纯终态判分，没有过程分。**

- **Symbolic Accuracy（SA）**：二元指标，检查 agent 给出的方程 `f̂` 与真值 `f_target` 是否**数学等价**；等价性检查**故意忽略物理常量的取值**（因为常量是量纲补偿用的）。
- **RMSLE**：预测保真度（论文明确说选 RMSLE 而非 NMSE）。
- **过程只被"分析"不被"判分"**：他们确实统计了 exploration rate（把 agent 每步意图打成 explore / confirm / verify 标签再算比例），但这个标签是**用 LLM 事后标注**的（附录 §4072），只进 analysis 章节，不进主指标。

⚠️ 直接对上我们的红线 3（不用 LLM judge）：**NewtonBench 想看过程但没有硬判过程的办法，只能上 LLM 标注 + 只敢放进分析**。这正是我们"过程量 hard checkpoint"的立论缺口。

## 5. 对我方：可借 / 可打点

**可借（三条，建议直接吸收）**

1. **"评测三难困境（trilemma）"这个 framing 极好用**：科学相关性 ↔ 可规模化 ↔ 抗记忆，三者传统上只能取二。我们的 GT-first 反查 + 分子匿名化恰好也是在破这个三难，**Introduction 可以沿用这个坐标系再把自己放进去**，审稿人一眼看懂位置。
2. **counterfactual shift + 量纲补偿常量**：我们的匿名化目前只是"抹名字"，抗记忆强度弱于"改写定律"。可以考虑在材料/药物线加一层**受控反事实**（如把某性质阈值系统性平移、或构造一个"平行宇宙"的性质数据库），并用类似"必须含一个补偿自由度"的约束保证物理自洽。
3. **难度双维正交控制**：内在复杂度（定律突变次数）× 外在复杂度（系统方程数）。我们的难度目前主要靠宇宙规模 + 查证预算，可以补一个正交轴（如"陷阱组密度"或"约束冲突深度"）。

**可打点（我们相对它的差异化）**

| 维度 | NewtonBench | 我们 |
|---|---|---|
| 过程 | 只分析不判分，且靠 LLM 标注 | **hard checkpoint DAG，可执行断言判过程** |
| horizon | ≤10 轮 | 20+ 步、含依赖不可逆的拓扑序约束 |
| 领域 | 物理（12 个教科书定律） | 材料发现 + 药物发现（有真实数据库真值） |
| 真值来源 | 人工构造的反事实定律 | 科学数据库反查（真分子真性质） |
| 判分 | 二元 SA | reward ∈ [0,1] 部分分 + 路径闸门 |

**风险提示**：NewtonBench 已经把"科学发现 + 交互探索 + 抗记忆"这套话术占住了。我们若只讲"发现类任务"，会被审稿人问 "how is this different from NewtonBench?"。**答案必须落在过程判分与领域真值上，不能落在"我们也做发现"。**
