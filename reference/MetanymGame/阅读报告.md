# MetanymGame · 构造上就免污染（无固定测试集可泄漏）

> **原文**：The Metanym Game: A Self-Contained, Self-Consistent LLM Peer-Community Benchmark for Structural Intelligence
> **出处**：arXiv:2606.21008，2026-06-19（v2 2026-07-30），71 页
> **阅读方式**：基于完整摘要与元数据

## 0. 一句话
**它的抗污染是"构造性"的**：题目内容全部由参赛模型现场创造，**没有固定测试集可以泄漏进训练数据**（contamination-resistant by construction）。

## 1. 关键数字
| 项 | 内容 |
|---|---|
| 形式 | 竞争性词语游戏，衡量"结构智能"，锚定既有认知科学构念 |
| 内容来源 | **不预先给任何内容**，全部由参赛者创造 |
| 判定方式 | 同侪评议（council-of-peers）：参赛者互评彼此的创作 |
| **核心方法** | 对评审者评分矩阵做**一次奇异值分解（SVD）**，同时得出他们"作为生成者"与"作为真值判定者"的能力 |
| 相关性 | 事实性评分与 **GPQA Diamond 相关 r = 0.92** |
| **关键发现** | **生成与判定是可分离的**，且**判定是更稀缺的技能** —— 最强的生成者只是中等判定者，最敏锐的判定者是中游生成者 |

## 2. 机制与判分
同侪互评 + SVD 分解。**无金标准、无 oracle 模型**——作者称其解决了"没有标准答案也没有 oracle 时如何评事实准确性"这个难题。

## 3. 对我方
**可借**：①**"生成与判定可分离，且判定更稀缺"**这个发现很重要——它解释了为什么"让 LLM 当裁判"不可靠（会生成不等于会判断），是我们不用 LLM 裁判的又一条论据；②**构造性抗污染**（无固定测试集）是第三条抗污染路径（前两条：EvoBrowseComp 的持续更新、URSA 的未公开答案），可与我们的匿名化并列对比。

**可打点**：它是词语游戏（无科学域），且判定靠同侪互评（软）。归入"抗污染方法"类。
