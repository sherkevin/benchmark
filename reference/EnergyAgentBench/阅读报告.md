# EnergyAgentBench · 活数据上的长程工具链（3–48 次顺序调用）

> **原文**：EnergyAgentBench: Benchmarking LLM Agents on Live Energy Infrastructure Data
> **出处**：arXiv:2605.15230，2026-05-13（v2 2026-08-03），econ.EM
> **阅读方式**：基于完整摘要与元数据

## 0. 一句话
**它的任务需要 3 到 48 次顺序工具调用**，是长程工具链评测里链长跨度最明确的一篇；而且它的真值来自**训练好的 XGBoost 成本曲面模型（R² 0.967–0.995）** 与官方技术基线。

## 1. 关键数字
| 项 | 内容 |
|---|---|
| 任务变体 | **70 个**，分 5 个族 |
| **顺序工具调用** | **3 到 48 次** |
| 数据源 | 活端点：QuarluxAI 平台 · 美国 EIA · NREL |
| 真值来源 | 训练好的 XGBoost 成本曲面模型（**R² 0.967–0.995**）+ NREL ATB 2024 |
| 评测规模 | 9 个模型（Anthropic / OpenAI / HuggingFace），**1,414 次运行**，3 个随机种子 |
| 最佳 | Claude Sonnet 4.6 **0.900**（成本仅为 Opus 4.7 的四分之一，后者 0.889） |
| 反直觉 | Claude **Haiku 4.5** 在长程程序化选址上领先（**0.986**），**超过贵 16 倍的前沿模型** |
| 区分度最高的族 | F3 因果诊断，Sonnet 0.793 vs Llama 3.3 70B 0.486，**跨度 30.7 分**（对比 F1 选址仅 6.6 分） |
| **失效分类** | 135 个编码失效：**NREL 数据空值处理占 70%** · 因果任务上过早承诺 20% · 对抗注入盲区 6% |

## 2. 机制与判分
多族任务，按与真值模型的偏差打分。**判定是硬的**（数值比对）。含完整失效分类法。

## 3. 对我方
**可借（三条，都可直接用）**：

1. **"3 到 48 次顺序调用"这个跨度报告方式我们应该抄**。我们目前只说"长程"，没给链长分布。**应统计 150 题的金标准工具调用次数分布**，这是"长程"的量化证据。

2. **不同任务族的区分度差异很大（30.7 vs 6.6 分）** —— 提示我们：**我们三类题型（约束满足/约束最优/开放发现）的区分度可能也不同**，应分别报告，而非只报总均值。

3. **失效分类法（135 个编码失效按类型占比）** —— 这是我们矩阵结果分析该有的产物，目前没有。

**可打点**：能源经济域。归入"长程工具链评测"类。它的**便宜模型打赢贵模型**这一发现，与我们"过程分能区分蒙对与真做"的关切相通——**便宜模型赢，可能是任务本身考不出深度**。
