## 一条完整 case（长什么样）

任务：A/B 测试结束，从 BigQuery `ab_testing` 读点击流→算各场景转化率的算术平均→填 `record.csv`→若 B 胜则建前缀 `promo-assets-for-b` 的 GCS bucket，否则向日志 bucket 写一条指定 JSON。判分脚本读 agent 产出的 record.csv 与期望值按 0.1% 容差逐项比对 + 检查 bucket 是否存在

## 数据格式

每 task 一个目录：`docs/task.md`(NL 指令) + `docs/*_system_prompt.md` + `evaluation/main.py`(确定性判分脚本，比对最终环境状态) + `files/*`(真实初始文件)。108 题 / 32 应用 / 604 工具
