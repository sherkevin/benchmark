# 3D-Fit · 空间约束下的分子生成（token 高效的评测策略）

> **原文**：Do Language Models Dream of Binding Molecules? Benchmarking LLMs under Spatial Constraints
> **出处**：arXiv:2607.18144，2026-07-20
> **阅读方式**：基于完整摘要与元数据

## 0. 一句话
**它测的是 LLM 能不能同时满足多个空间约束**——蛋白口袋 + 锚点片段 + 药效团点 + 强制的口袋-配体相互作用。结论：**仍落后于专用扩散模型，但已能同时处理多个空间约束**。

## 1. 关键数字
| 项 | 内容 |
|---|---|
| 任务 | 基于结构的药物设计（SBDD）：口袋条件下的 3D 配体生成 |
| 约束类型 | 锚点片段 · 药效团点 · **强制的口袋-配体相互作用** |
| 对照 | 专用扩散模型（当前主导范式） |
| 评测特性 | **token-efficient**（token 高效）的评测策略 |
| 结论 | LLM 落后 SOTA，但**有前景且能同时处理多个空间约束**，可扩展到异质设置 |

## 2. 机制与判分
生成分子的几何与相互作用约束满足度（硬判定，物理/几何可算）。

## 3. 对我方
**可借**：①**"多约束同时满足"这个任务形态与我们的约束满足题型同类**——我们的 fixed 题也是给一组性质区间让 agent 找满足的候选。区别是它要**生成**，我们要**检索选择**；②**token-efficient 评测策略**这个考虑与我们的 token 留痕要求同向（都关心评测成本）。

**可打点**：单轮生成、无工具调用、无长程过程。归入"分子生成评测"类，与 TOMG/S²-Bench 同类。
