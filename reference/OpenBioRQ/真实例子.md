## 1 测什么（一句话）

**测 agent 面对"学界尚未解决、没有答案键"的生物医学研究问题时，能不能真去调工具找证据、把结论**扎在**真实文献上、并且如实承认哪部分仍未知** —— 而不是编一个流畅、带着"能打开但对不上"的引用的答案。

> 论文立论句（Abstract 第 1 句 / §1 Introduction）：
> *"A working citation looks like proof -- but the fact that a link resolves does not mean the cited paper supports the claim."*

## 3 预期答案

**关键：这个 benchmark 没有"标准答案"可比对。** 每题带一个 `gold_answer`，但论文 §4.2 明确说它**只用来生成 rubric 时当参考上下文，绝不当匹配目标、也绝不当引用真值**。

理由是实测出来的（§4.2）：gold answer 里引的 PMID **≈100% 都能打开**，但 **≈74% 是错配**（cited work 并不支撑那个说法；LLM judge，n≈360，双裁判稳健）。所以拿它当真值等于把"看着可信但没依据"的归因直接灌进指标。

`gold_answer` 是结构化的，7 个字段：`current_knowledge` / `unknown_aspects` / `evidence_landscape` / `key_citations` / `mcp_tool_plan` / `answer_summary` / `self_completeness`。

本题 `gold_answer` 摘录（原文照抄，来源 `data/full_core_657.jsonl`）：

- `unknown_aspects`（这是开放题的核心 —— 明确列出"什么仍不知道"）：
  > "Despite the documentation of glymphatic suppression, the mechanistic hierarchy remains unclear. Specifically, it is unknown whether AQP4 depolarization is a cause or consequence of neurodegeneration, and what molecular signals initiate AQP4 mislocalization. The relative contributions of arterial pulsatility loss, astrocytic reactivity, AQP4 mislocalization, and meningeal lymphatic impairment to overall glymphatic failure have not been quantified. ..."
- `evidence_landscape`：
  > "Evidence is predominantly from preclinical rodent models (AQP4 knockout mice, APP/PS1 transgenic mice) and limited human imaging studies using intrathecal contrast agents. No large-scale RCTs exist. ..."
- `key_citations`（6 条，`{type, id, relevance}`）：PMID 22529832（Iliff 2012 原始描述）、24136970（Xie 2013 睡眠依赖清除）、28555461（Zeppenfeld 2017 人脑 AQP4 去极化）、28494655（Ringstad 2017 MRI）、30046111（Da Mesquita 2018 脑膜淋巴）、38345416（源综述）
- `mcp_tool_plan`（5 步，每步 `{tool, query, purpose}`）：`pubmed` ×2 → `opentargets`（AQP4/AD）→ `uniprot`（AQP4 human）→ `clinicaltrialsgov`（glymphatic Alzheimer imaging）
- `self_completeness`：**0.55**

**所以"预期答案形态"是**：一篇长文回答，要求同时做到三件事 ——（a）说出关键机制、（b）把机制**引到真实可支撑的文献**上、（c）**明确承认**哪一层因果关系至今没定论。这三件事分别对应下面 rubric 的三类 criterion。

## 4 怎么判分

### 4.1 判分机制：per-question 冻结 checklist（**软判，LLM 裁判，但 rubric 是硬编码的**）

论文 §4.1。对每题，一个强模型**先**起草 5–8 条"具体、可二元核对、题目专属"的 criterion，**然后冻结**，再拿去判分。criterion 四型：

| 类型 | 含义（§4.1 原文） |
|---|---|
| `must_mention` | 答案该包含的关键事实/机制/方法 |
| `must_acknowledge` | 必须标出的不确定性/空白/开放面（**对未解决问题至关重要**） |
| `must_ground` | 必须用真实引用（PMID / trial / 工具结果）撑住的主张 |
| `must_avoid` | 不该出现的行为（对开放问题下定论、编造引用、**谎称工具什么都没返回**） |

裁判**只读答案文本 + 它的 tool calls**，逐条给 `v ∈ {1, 0.5, 0}`（met / partial / not_met）。`must_avoid` **极性反转**（v=1 表示成功避免了禁止行为），所以分数**不可能奖励编造**。每条带权重 `w ∈ {1,2,3}`：

```
score(q) = Σ(wᵢ·vᵢ) / Σ(wᵢ)  ∈ [0,1]
solve  ⟺  score ≥ 0.5   （T=0，单次确定性作答，headline "solve rate"）
```

0.5 这个阈值论文说只是**报告约定**，不承重（结论靠能力排序和跨档区间，由均分 0.39/0.44/0.53 固定）。

**冻结 checklist 的收益（Abstract + §4.1）**：把自由形式的维度打分换成冻结 checklist，裁判间（LLM-vs-LLM）一致性 **Spearman 0.35 → 0.82**。人类专家一致性论文承认**尚未做**（deferred，见 Limitations）。

rubric 生成的硬约束（Appendix B, "Rubric generation"）：每条必须**二元可核**且**实例锚定** —— "Identifies AQP4 depolarization as a candidate mechanism" 合格，"Discusses the mechanism well" 不合格；且每题**至少各有一条 `must_acknowledge` 和一条 `must_avoid`**。

## 数据集构成（补充）

**构造流水线（§3）**：`crawl → extract → refine → dedup → export`。两层标签（openness、difficulty）**加在导出文本之上**，不烧进文本，所以各自可独立重审。去重用 MiniLM-L6 余弦 ≥ 0.90 收拢近重复。

**四条 track（§3, Table 1）**：

| track | 来源 | 题量 |
|---|---|---|
| `retrieval_verified` | PubMed / trials / arXiv | 6,648 |
| `expert_consensus` | JLA PSPs, NICE recs | 5,905 |
| `priority_setting` | WHO/CHNRI/NASEM, Delphi（经 Europe PMC） | 525 |
| `expand` | Cochrane research gaps | 483 |

前两条构成 **12,553 题基础语料**，跨 **12 个 L1 taxonomy 域**，无单域主导（Figure 3）；后两条是附加、且已与基础语料去重。带 gold answer 的切片 **1,969 题**（`mcp_benchmark_with_gold.jsonl`）用于 rubric 生成与 agentic 评测。

**"开放性"怎么验（§3.2）**：不靠模型记忆源文怎么表述，而是**用真实后续证据重判**。只看源文表述的做法产生了**彻底的确认偏误**（零题被标为 answered 或 unknown）。改成 retrieval-grounded Stage-2 judge（必须引证据 ID，否则退回 `unknown`）后，200 题样本里 **56.5% 状态被改写**、14% 落到 unknown。对最难的 657 题 core 重审：**0/657 检测到已被解决**。污染阳性对照（34 条注入的已知污染项）**100% recall、0% 假阳**。verbatim / perplexity 成员推断：无记忆化特征（中位最长逐字重合仅 **3 词**，题面中位 22 词，token Jaccard 0.23；86.5% 的题与源文共享 ≤5 个连续词）。

**难度怎么定（§3.3）**：**不手标**。每题由三个 roster 模型（GLM-5.1 / Qwen3.6 / DeepSeek-V4）在**全工具**下作答并按冻结 checklist 打分；**三个全失败（score < 0.5）即为 core**。在最干净的 `priority_setting` track（n=525，端到端题粒度标注）上得 **49% core / 45% discriminating / 6% easy**，三个 roster 模型均分**都在 0.5 阈值以下**。

**⚠️ 难度对解码温度敏感（§5.3，这条容易漏）**：分桶是在 **T=0.3** 下定的，当时三个 roster 模型都在 ~0.3 分、solve rate 基本为 0；**同一个 core 在 T=0 下重测就翻了**（GLM-5.1 变 26.6%）。所以论文另定 **frozen core = 657 中三个 roster 在 T=0 仍全失败的 423 题**。论文自陈：那个 "≈0%" 是 **T=0.3 的假象**。

**公开 release 的 657 题构成（HF README）**：来源 PMID 541 / NCT 83 / arXiv及其他 33；题型 mechanism 328、treatment 202、methodology 57、diagnosis 36、epidemiology 21、prognosis 8、prevention 5；状态 open 433 / partially_answered 224；L1 前几名 Clinical Medicine 145、Neuroscience & Psychiatry 120、Oncology 94、Infectious Disease & Immunology 63、Public Health 43、Surgical Sciences 43。

**为什么只放冻结产物而不是可重跑流程（§6 + Appendix D）**：因为文献和工具 API 在动，重跑会得到实质不同的 core。所以作者 release 的是**固定的 423 题 task_id 清单 + tool-response replay cache**（replay 命中率 ~99%），而非一个可重新执行的过程；openness 是**带日期的 as-of 属性**。

## 顺手记：对我方的两条可打点

1. **"open"一词歧义必须写清**。OpenBioRQ 的 open = **真的没有答案**，判分只能靠 LLM 裁判 + rubric（软判）。我方 open 类是**有唯一 gt、只是不可检索**，判定是**硬**的。不说清会被混淆。
2. **它的"工具无用"是我方 cp1/cp3 的正面靶子**。OpenBioRQ 只看终态答案文本 + tool calls 是否支撑，因此只能测出"工具没带来分数增益"这个**结果**；而 cp1（文献检索）/cp3（性质查证）判的是"有没有真去调"这个**过程**。建议在矩阵结果里专门统计 zero-tool 轨迹占比，与它的 §5.2（priority track 上 GLM-5.1 65% / DeepSeek-V4 62% zero-tool；GPT-5.5 在 657 core 上仅 2.1%，我实测）对照。
