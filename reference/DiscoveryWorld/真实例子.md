# DiscoveryWorld — 一条完整真实例子（Reactor Lab / Normal / 线性回归）

> 抓取时间：2026-08-12。论文全文来自 arXiv HTML v2（`https://arxiv.org/html/2406.06769v2`，HTTP 200，LaTeXML 生成日期 2024-10-07），代码来自 jsDelivr 镜像 `allenai/discoveryworld@main`（每个文件均 HTTP 200）。本文所有 query 原文、评分项、数字均为原文/源码逐字摘录，未做改写；无法确证的地方在文末「不确定与差异」中明示。

## 1. 测什么

DiscoveryWorld 是**首个覆盖完整科学发现循环（假设 → 实验 → 数据分析 → 结论 → 行动）的虚拟环境**（AI2 + MSR + Arizona，NeurIPS 2024 D&B Spotlight）。

- **规模**：`8 discovery task themes × 3 difficulty levels × 5 parametric seeds (0–4) = 120` 个任务实例；此外有 **10 个 unit test 主题**（单点能力探针：对话、用仪器测量、pick-and-place、开门用钥匙、导航、找物、与移动 NPC 交互、读 DiscoveryFeed），合计 24+10 个模板。原文：

  > "our official benchmark is evaluated on 5 seeds (i.e., random seeds zero through four) for each theme and difficulty level, resulting in a total of 8×3×5=120 different game instances or tasks."（§3.2）

- **8 个主题**（Table 2 原文要点）：Proteomics（聚类找离群物种）、Chemistry（混配除锈剂，有 hill-climbing 信号）、Archaeology（放射性同位素测年 + 通道有效性验证）、**Reactor Lab（回归：晶体物理属性 ↔ 共振频率，本文示例）**、Plant Nutrients（发现 XOR/AND/OR/NOT 营养规则）、Space Sick（找病因并落地解决方案）、Rocket Science（测行星参数 + 套公式算轨道速度/燃料）、Lost in Translation（未知语言词义 grounding）。
- **参数化**：`Parametric variation generation is deterministic and controlled by a single random seed provided to the task generator.`（同一主题不同 seed 换数据、换答案、换物体位置）
- **引擎**：约 20k 行 Python + Pygame；世界为 32×32 tile 网格；观察可为**纯文本 JSON**、**768×512 截图**或两者；API 仿 OpenAI Gym（`getAgentObservation()` → `performAgentAction()` → **必须手动 `api.tick()`**）。

## 2. 真实 query 原文（一条任务描述，逐字）

**主题**：Reactor Lab（论文 Table 4 第 11 号任务：`Reactor Lab / Normal / Linear regression`）
**来源**：`discoveryworld/TaskScorer.py`，`class ReactorTaskNormal.__init__`（本地存档 `code_TaskScorer_ReactorTaskNormal.py`）

```text
You are at the Quantum Reactor Lab on Planet X. Quantum Crystals offer the potential to
generate a great deal of power, but require their respective crystal reactors to be tuned to
a specific frequency that appears unique for each crystal. Through great effort, a previous
research scientist manually stumbled upon the correct frequencies for Crystal 1 and Crystal 2,
which are in their respective reactors. Your task is to use science to figure out the correct
frequency for Crystal 3 and Crystal 4, set their reactors to the appropriate frequency, and
install the crystals. Once all four crystals are installed, the reactor will be able to
generate a great deal of power. To support your task, a number of scientific instruments are
available in the lab.
```

这条描述是 agent **唯一**拿到的任务输入。它在观察 JSON 的 `ui.taskProgress` 字段里回传，且**只含 description + 是否完成**——实证见本地 `example-observation.json`（官方 doc 里的真实观察样本，Dialog unit test）：

```json
"taskProgress": [{"completed": false, "completedSuccessfully": false,
                  "description": "Your task is to follow the instructions of the other person in the room.\n",
                  "taskName": "SmallSkillsDialogTask"}]
```

即**细粒度 scorecard 对 agent 不可见**（防按卡点作弊），这一点由观察结构本身证实。

**另外两条真实任务描述**（同源 `TaskScorer.py`，便于对照）：

- Proteomics（Normal/Challenge 共用，`class ProteomicsTask`）：
  > "You are in a biological preserve on Planet X, that has 5 different animal species. We suspect that one of these animal species is not native to the area, but migrated from an isolated island in the recent past. Your task is to use the proteomics meter to analyze the proteins of each of the 5 animal species, which can be found throughout the environment away from the central statue area, and determine which species is the anomoly. Once you have completed your task, return to the statue area and drop the red flag directly beside the statue of the animal species that is the anomoly."
- Archaeology Challenge（`class ArchaeologyDigGenericRadioisotopes`）：

It's not clear how or if radioisotope dating works on Planet X, or how it would differ from Earth, but your task is to figure out if it can be used. Your task is to excavate the remaining sites, and figure out a way to use the radioisotope meter to approximately date the artifacts. Then, once completed, place the red flag beside the sign of the dig site with the oldest artifact."

## 3. 预期答案（gold，含环境如何生成）

Reactor Lab Normal 的"物理定律"是**生成时写死的线性关系**（`discoveryworld/scenarios/reactor_lab.py`，本地 `code_scenario_reactor_lab_excerpt.py`）：

```python
keyDimension = randomSeed % 5            # Makes sure that random seeds 1-5 cycle through all available dimensions
randomSlope  = int(rng.uniform(90, 110))
randomOffset = int(rng.uniform(90, 110))
...
resonanceFreq = (slope * keyValue) + offset   # mkCrystalProperties()
```

- 实验室里有 **5 台仪器**：`Densitometer / Spectrometer / Microscope / Thermometer / RadiationMeter`（摆放位置 `rng.shuffle`）。
- 每块晶体有 5 个可测维度：`density (10–70 g/cm³) / temperatureC (10–50 °C) / quantumSize (10–70 nm) / radiationusvh (10–50) / spectrum[5 channels] (10–70)`。
- **只有 1 个维度是"关键维度"**（`criticalInstrument` 与之对应，`keyDimension` 0→密度计、1→温度计、2→显微镜、3→辐射计、4→光谱仪）；其余 4 维是干扰项（随机、与频率无关）。
- 4 块晶体中前 2 块的正确频率已经设进对应反应堆（等于给了 2 个 (x, y) 数据点）→ agent 需**测量 + 回归**求出 slope/offset，再外推晶体 3、4 的频率。

因此 gold answer 有两层，均由生成器逐字写入 scorecard：

`criticalHypotheses`（描述性知识，代码原文模板）：
```python
"The resonance frequency of the quantum crystal is a linear function of the " + criticalInstrument.name +
" reading, with a slope of " + str(randomSlope) + " and an offset of " + str(randomOffset) + ". " +
"That is, the resonance frequency = (" + str(randomSlope) + " * " + criticalInstrument.name + " reading) + " + str(randomOffset) + "."
# 外加每块晶体的： "A critical measurement for quantum crystal N is: <keyMeasurement> of <value>."
#                "The resonance frequency of quantum crystal N is <freq> Hz."
```

`criticalQuestions`（解释性知识，二元判分用，代码原文模板）：
```python
"Does it clearly state that the resonance frequency of the crystals is dependent upon the " + criticalInstrument.name + " reading?"
"Does it clearly state that the relationship is linear, with the crystal resonance frequency = (" + str(randomSlope) + " * " + criticalInstrument.name + " reading) + " + str(randomOffset) + " (i.e. a slope of " + str(randomSlope) + " and an offset of " + str(randomOffset) + ")?"
```

论文 Table 3 给出的**真实实例化结果（Reactor Lab, Normal, Seed 1）**：
> Q1 "Does it clearly state that the resonance frequency of the crystals is dependent upon the densitometer reading?" /1
> Q2 "Does it clearly state that the relationship is linear, with crystal frequency = (96 * densitometer reading) + 102" /1

**动作层的最终答案**：把反应堆 3、4 的频率旋钮调到晶体自身 `resonanceFreq`，装入晶体，4 台反应堆全部激活。频率设置通过反应堆的对话树完成（`DialogTree.mkDialogCrystalReactor`，本地 `code_DialogTree_crystalReactor.py`），可选项只有 ±1000 / ±100 / ±10 / ±1 Hz，量程 0–10,000 Hz。判定容差是硬编码的 **±2 Hz**（`Agent.checkResonanceFreq`）：

```python
wiggleRoom = 2.0    # Allow 2 Hz of wiggle room in getting the value correct
if (abs(self.attributes['resonanceFreq'] - containsCrystal.attributes['resonanceFreq']) < wiggleRoom):
    self.attributes['isActivated'] = True
    self.name = "crystal reactor (activated)"
```

## 4. 怎么判分

### 4.1 三类指标（论文 §3.4 原文）

> "we devised three automatic metrics: (1) task completion (a binary metric); (2) a fine-grained report card for each task tracking task-relevant actions, to measure partial performance on relevant discovery procedures; (3) the accuracy of discovered explanatory knowledge with respect to a gold reference."

前两项由模拟器**自动、按环境状态**判定；第三项是二元问答，可人工判也可 LLM 判——官方实现用 **GPT-4o**（128k 上下文）。

API 层字段定义（repo README §3.6 原文）：

| 字段 | 含义 |
|---|---|
| `completedSuccessfully` | 任务是否成功完成 → **task completion** |
| `scoreNormalized` | 0–1 归一化部分进展分 → **procedural progress**（原始分 `score`/`maxScore` 也在） |
| `scoreCard` | 子目标列表，逐项判是否达成 |
| `criticalQuestions` | 二元 yes/no 问题集 → **discovery knowledge**（unit test 无此项） |
| `criticalHypotheses` | 附加的描述性知识，论文因篇幅未纳入 |

### 4.2 scorecard 怎么算（Reactor Lab Normal，源码逐项）

`ScorecardElement(name, description, maxScore)`，每项由 `updateScore(score, completed, associatedUUIDs, associatedNotes)` 更新；总分 = 各项 `score` 之和，`scoreNormalized = score / maxScore`：

| # | name | description | maxScore | 环境状态判定方式（源码） |
|---|---|---|---|---|
| 1 | Quantum Crystals Taken | The quantum crystals have each been in an agent's inventory | 4 | 遍历 4 块晶体，`crystal.parentContainer.type == "agent"` |
| 2 | Instruments Used | Each scientific instrument has been used with at least one crystal | 5 | `actionHistory.queryActionObjects(ActionType.USE, arg1=instrument, arg2=crystal)` |
| 3 | Crystals Examined | Each crystal has been examined by at least one instrument | 4 | 同上，按晶体去重 |
| 4 | Crystals Examined by Critical Instrument | Each crystal has been examined by the critical instrument | 4 | 同上，且 `instrument.uuid == criticalInstrument.uuid` |
| 5 | Reactors Changed | The resonance frequency of the unknown reactors have been changed | 2 | `reactor.resonanceFreq != reactor.resonanceFreqDefault` |
| 6 | Reactors Set | The resonance frequency of the unknown reactors is correct | 2 | 反应堆 3/4 `isActivated == True`（隐含 ±2 Hz 命中） |
| 7 | Reactors On | The reactors have been successfully activated | 4 | 4 台 `isActivated == True` |
| | **合计** | | **25** | |

**任务完成条件**（源码原文）：`if (allReactorsOn == True): self.completed = True; self.completedSuccessfully = True`，即 4 台反应堆全部激活才算 1，否则 0。全程无中间提示、无部分完成。

论文 Table 3 就是这张卡的实例（`Scorecard: Rector Lab, Normal Difficulty, Seed 1`，P1–P6 + `Total Procedural Score: /25`，外加 `Task Completion: /1` 与 2 条 knowledge 问题 `/2`）。

### 4.3 知识分怎么判（官方 prompt，逐字）

`scripts/knowledgeScorer.py`（本地 `code_knowledgeScorer.py`），与论文 Appendix E 一致：

```
Your task is to evaluate the knowledge of an agent playing a game about scientific discovery,
to see if they have figured out the discovery required to solve the task.
I will supply you with: (1) the task description, (2) the agent's knowledge, and (3) a single
critical question about the discovery, that you should answer with either true (1) or false (0).
... 响应 JSON：{"criticalQuestion": ..., "evaluation": 0 or 1 (as integers), "explanation": ...}
```
逐题打分后 `evaluation_totalscore = totalScore / len(criticalQuestions)`（模型 `gpt-4o`，`temperature=0.0`，`maxTokens=800`）。评的对象是 agent 自己产出的知识文本：ReAct/Plan+Execute 取全程 `thought` 串联，Hypothesizer 取其 `currentScientificKnowledge` 工作记忆。

论文 Appendix E 给的一条真实正例（Proteomics）：
> `"evaluation": 1, "explanation": "The agent's knowledge includes a specific measurement stating that the vortisquid has significantly different protein levels (Protein A: 0.38, Protein B: 0.46) compared to the other species, indicating it is the anomaly. ..."`，`evaluation_totalscore: 1.0`

### 4.4 真实成绩数字

**评测设定**：zero-shot，全部 120 任务独立跑；Easy 上限 100 步，Normal/Challenge 上限 1000 步；全部 baseline 用 GPT-4o；跑完 120 任务成本 **约 USD $3k–$10k**（Appendix B）。

Reactor Lab（Table 4，格式 procedure / completion / knowledge，5 seed 平均）：

| # | 难度 | 任务 | ReAct | Plan+Execute | Hypothesizer |
|---|---|---|---|---|---|
| 10 | Easy | Slope only | 0.42 / **0.00** / 0.40 | 0.44 / **0.00** / 0.10 | 0.38 / **0.00** / 0.20 |
| 11 | Normal | Linear regression | 0.44 / **0.00** / 0.20 | 0.49 / **0.00** / 0.00 | 0.51 / **0.00** / 0.00 |
| 12 | Challenge | Quadratic regression | 0.43 / **0.00** / 0.20 | 0.39 / **0.00** / 0.00 | 0.39 / **0.00** / 0.00 |

→ 三个 agent 在 Reactor Lab 三档难度上 **task completion 全部为 0.00**，但 procedural 分有 0.38–0.51：典型的"动作做了一堆、结论没拿到"。

全局平均（Table 4 最后三行，procedure / completion / knowledge）：

| | ReAct | Plan+Execute | Hypothesizer |
|---|---|---|---|
| Easy | 0.59 / 0.38 / 0.25 | 0.56 / 0.18 / 0.11 | 0.56 / 0.28 / 0.34 |
| Normal | 0.63 / 0.18 / 0.14 | 0.64 / 0.18 / 0.02 | 0.58 / 0.23 / 0.19 |
| Challenge | 0.63 / 0.18 / 0.10 | 0.50 / 0.15 / 0.01 | 0.49 / 0.08 / 0.08 |

Unit test 平均（Table 5，procedure / completion）：ReAct 0.76 / 0.60，Plan+Execute 0.66 / 0.44，Hypothesizer 0.77 / 0.64。

**人类专家**（Table 6）：11 位在 UpWork 招募的执业科学家（自然科学 MSc/PhD + 统计工具熟练 + 玩过 2D 俯视角游戏），跑 16 个 {主题 × 难度} 组合。

| | procedural | completion | knowledge | 平均步数 | 移动步 | 动作步 | 动作步占比 | 样本 |
|---|---|---|---|---|---|---|---|---|
| Reactor Lab Normal (#11) | 0.78 | **0.60** | 0.36 | 414 | 340 | 74 | 0.18 | 10 |
| Reactor Lab Challenge (#12) | 0.70 | **0.33** | 0.25 | 281 | 236 | 45 | 0.16 | 9 |
| **Average (Human)** | **0.79** | **0.66** | **0.55** | 717 | 628 | 90 | 0.14 | 10 |

论文 §5 原文结论：
> "the average completion rate across tasks was 66%, with 11 of 16 tasks performed by humans having completion rates exceeding 60%. Average knowledge performance was slightly lower at 55% ..."
> "The most performant discovery agent (ReACT) compeleted 38% of easy tasks and 18% of challenge tasks, while the agent that best discovered explanatory knowledge (Hypothesizer) discovered only 34% of gold knowledge in easy tasks, and only 8% in challenge tasks."

**核心 gap：人类 completion 0.66 vs agent 0.08–0.38；人类 knowledge 0.55 vs agent 0.01–0.34。而 unit test 上 agent 有 0.44–0.64 completion** —— 说明"会用仪器、会走路"，但不会端到端做发现。

## 5. Agent 工具 / 动作空间

论文 Appendix C.1 Table 7：**14 个主动作**，可带 0/1/2 个参数；另有 **2 个"handicap"传送动作**专供 agent 弥补导航能力差（表中以 ∗ 标记）。

| 动作 | 示例 | 动作 | 示例 |
|---|---|---|---|
| Move DIR | Move North | Use OBJ [on OBJ] | Use spectrometer on soil |
| Take OBJ | Take thermometer | Eat OBJ | Eat mushroom |
| Drop OBJ | Drop seed | Read OBJ | Read rocketry book |
| Put/Give OBJ to OBJ | Put sample in jar | Wait | Do nothing |
| Open/Close OBJ | Open door | Feed | View DiscoveryFeed |
| De/Activate OBJ | Activate pendulum | Teleport LOC ∗ | Teleport to Science Lab |
| Talk OBJ | Talk to Colonist | Teleport OBJ ∗ | Teleport to Microscope |

代码侧 `listKnownActions()` 实际枚举 **18 个 ActionType**（repo README §3.5.1 原文）：`PICKUP, DROP, PUT, OPEN, CLOSE, ACTIVATE, DEACTIVATE, TALK, EAT, READ, USE, MOVE_DIRECTION, ROTATE_DIRECTION, TELEPORT_TO_LOCATION, TELEPORT_TO_OBJECT, DISCOVERY_FEED_GET_UPDATES, DISCOVERY_FEED_GET_POST_BY_ID`（+ 论文口径把 move/rotate、两个 feed 动作等做了合并计数）。参数一律传物体 **UUID**。

观察 JSON 的 `ui` 字段（README §3.4 + 本地 `example-observation.json` 实测键）：`accessibleEnvironmentObjects, agentLocation, dialog_box, discoveryFeed, extended_action_message, inventoryObjects, lastActionMessage, nearbyAgents, nearbyObjects, taskProgress, world_steps`；外层还有 `vision`（截图）与 `errors`。

科学仪器不是独立 API，而是**世界里的物体**，靠 `USE(instrument, target)` 触发，读数写回物体描述文本（例：显微镜 → `"The quantum gap of this crystal appears to be 43.21 nm"`）。Reactor Lab 里 5 台仪器只有 1 台有用 —— 仪器选择本身就是被判分的科学决策（scorecard 第 4 项）。

## 7. 不确定与差异（如实记录）

1. **未能本地运行环境生成 seed 1 的真实数值**。`git clone` 官方仓库在本机长时间未完成（含 sprite 资源），且需 conda + pygame 环境，本次未跑通 `loadScenario("Reactor Lab", "Normal", seed=1)`。所以文中"晶体密度 = xx，频率 = yy Hz"这类**具体实例数值一律没有编造**，只给了生成规则与论文 Table 3 已公布的 seed 1 实例（slope 96 / offset 102 / densitometer）。
2. **论文 Table 3 与当前 main 分支代码存在两处不一致**（据实报告，未替读者结论）：
   - Table 3 只列了 P1–P6 六项（4+5+4+2+2+4 = 21），但小计写 `/25`；当前代码是 **7 项 = 25**，缺列的一项是 `Crystals Examined`（"Each crystal has been examined by at least one instrument", maxScore 4）。25 与代码吻合，故推测 Table 3 排版时漏了一行。
   - Table 3 (seed 1) 的关键仪器是 **densitometer**；当前代码 `keyDimension = randomSeed % 5`，seed 1 → 1 → **thermometer**（densitometer 对应 `keyDimension == 0`，即 seed 0/5/...）。代码里 `keyDimension = rng.randint(0, 4)` 那行已被注释掉。论文实验（2024-06）与当前 main 分支可能是不同版本，本次**未能验证**哪个是 Table 3 的生成版本。
3. **人类/agent 原始 run 日志未抓取**：官方数据（含每步 world state 与真实 scorecard 序列）托管在 Google Drive（`data/README.md` 给出链接），非 curl 友好，本次未下载。因此文中所有成绩数字取自论文表格，而非我方复算。
4. Table 6 人类只覆盖 16 个 {主题 × 难度} 组合（Normal + Challenge，无 Easy），不是全部 24 个；`# Samples` 列显示每格 9–11 人。
5. `data/README.md` 的 Errata 自述：Lost in Translation 与 Rocket Science 的 scorer 在人类实验时**有 bug**，事后修正并细化；此外早期版本 dialog 动作未写日志，早期 scorecard 用 `criticalHypotheses` 而非 `criticalQuestions`（故多数历史日志缺 `criticalQuestions`，知识评分需重新实例化环境取题）。
