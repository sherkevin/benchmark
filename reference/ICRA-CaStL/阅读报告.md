## 0. 一句话

把自然语言里的**约束**（不只是目标）翻译成 PDDL + Python 脚本，交给一个基于 SMT 的 PDDL 求解器求解，并配上错误、语法、语义三重检查；在三个 PDDL 域上显著提升了从自然语言到长程任务与运动规划（TAMP）的约束处理能力与成功率。

## 1. 数据量

**不是 benchmark 论文，无新数据集。** 实验规模：**3 个 PDDL 域**，报的是约束处理能力与规划成功率的提升。8 页会议短文，规模符合 ICRA 的常规体量。

## 2. 方法形态

- **输入**：自然语言任务描述（含目标 + 约束，且常常是**部分指定、含歧义**的）；
- **中间表示**：`部分指定的 PDDL problem` + 一组附加约束（编码进 SMT-based PDDL 求解器）；
- **三重检查**：error / syntax / semantic checking——用来拦住 LLM 翻译出的不合法规范；
- **输出**：可执行的长程任务与运动规划。

它扩展的是 "LLM-as-a-Translator" 框架：LLM 不直接规划，只负责把 NL 翻成形式语言，规划交给专业求解器。

## 3. "长"体现在哪

**ICRA 意义上的 long-horizon = TAMP 的层级深度**：
- 一个操作任务要分解为一串符号级动作（PDDL plan），每个符号动作还要落到运动规划（motion planning）；
- 约束跨越整条计划（例："橙色积木不能放在蓝色上"这类全局约束），因此不能贪心逐步决策。

**注意：这里的"长"完全没有交互轮数或上下文长度的含义**，也不涉及信息搜寻。

## 4. 判分粒度

**规划成功率 + 约束满足率**（由求解器与仿真判定，确定性）。无过程 checkpoint。

## 5. 对我方：可借 / 可打点

**可借（一条，但很重要）**

**"把自然语言约束翻译成可求解的形式规范 + 三重检查"这个模式，正是我们答卷契约（`answer_contract`）的对偶**：
- CaStL：NL → 形式约束（入口侧形式化）；
- 我们：agent 自由输出 → JSON schema strict 答卷（出口侧形式化）。

它给了我们一个 ICRA/机器人社区的先例来支持"**必须有一层形式化中介，否则判分无从下手**"这个主张。同时它的**三重检查（error/syntax/semantic）**可以直接映射为我们答卷校验的三层：格式合法 → 字段完整 → 语义自洽（如 `pool ⊆ universe`）。

**为什么不是我们的路**
- CaStL 的求解器路线意味着"存在一个正确解且可被求解器找到"，适用于封闭符号世界；我们的分子发现空间不是 PDDL 可表达的封闭域；
- 它的贡献在"翻译 + 求解"，不在"评测"，与我们的定位无重叠。

## 6. ICRA 调性判读

CaStL 与同批 ICRA 长程论文（FLTRNN 2024、ISR-LLM 2024、LaMMA-P 2025、Guiding Long-Horizon TAMP with VLMs 2025）构成一个清晰画像：

> **ICRA 的 long-horizon 论文 = "LLM/VLM 作为高层规划器或翻译器 + 经典 TAMP 求解器 + 仿真/真机验证"，8 页，方法论文为主，benchmark 类几乎都是感知数据集。**

**对我们的结论：ICRA 不投。** 除非我们把项目改造成"自驱动实验室（self-driving lab）的机器人实验编排"，那是另一个项目。
