# RetroAgent · 逆合成 agent 的结构化记忆（COLM 2026）

> **原文**：RetroAgent: Harnessing LLMs to Search Over Structured Memory for Agentic Retrosynthesis Planning
> **出处**：arXiv:2607.14512，2026-07-16（v2 07-21），**COLM 2026**
> **阅读方式**：基于完整摘要与元数据

## 0. 一句话
**它的关键设计是让 agent 看到"完整搜索状态"**——已探索的路线、可用的替代方案、中间体的性质——从而基于**全局进展**而非孤立打分做决策。

## 1. 关键数字
| 项 | 内容 |
|---|---|
| 任务 | 多步逆合成规划：把目标分子拆解为市售原料 |
| 它批评的旧法 | 树搜索 + 离线训练的价值网络，**孤立地给候选打分，不对完整多步路线做推理** |
| 它批评的新法 | 近期 LLM 工作**接口过于简单**，限制了对完整搜索空间的探索 |
| 核心组件 | harness + **结构化记忆** + 化学工具 |
| 评测 | 分布内与**分布外**基准均测 |

## 2. 机制与判分
路线级判定（能否收敛到市售原料 + 泛化性）。**判定是硬的**（可执行的原料可得性检查）。

## 3. 对我方
**可借（一条与我们直接相关的观察）**：

**"让 agent 观察完整搜索状态"与我们的候选池设计相关。** 我们目前的检索工具默认只返回 `k=10` 个候选（待办第 1 项），这实际上**限制了 agent 能看到的搜索状态**——与 RetroAgent 批评的"接口过于简单"是同一个问题。

**这为待办第 1 项（k 默认值）提供了外部依据**：不是我们想让 agent 轻松，而是**接口过窄会系统性地限制 agent 的规划能力，使评测结论偏向"接口限制"而非"模型能力"**。

**可打点**：任务是生成合成路线（开放空间），无法做答案隔离。归入"同域 agent 系统"类。
