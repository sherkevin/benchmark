# CiteCheck · 引用幻觉检测（受控污染做题）

> **原文**：CiteCheck: Retrieval-Grounded Detection of LLM Citation Hallucinations in Scientific Text
> **作者**：Khashayar Khajavi, Shaghayegh Sadeghi, Rise Adhikari, Alexander Tessier
> **出处**：arXiv:2605.27700，2026-05-26，cs.DL / cs.AI
> **阅读方式**：基于完整摘要与元数据

---

## 0. 一句话

它做的是**查引用是不是编的**：既查这条引用对应的学术成果**是否真实存在**，也查其**元数据是否忠实于那份成果**。

---

## 1. 数据量与成绩

| 项 | 数值 |
|---|---|
| 自建基准 | **982 条**物理学引用 |
| 题目构造 | **受控污染（controlled corruptions）** —— 既含**细微的元数据漂移**，也含**完全编造的引用** |
| 判定标签 | 三级：**Exact / Minor / Major** |
| 成绩（held-out 测试集） | macro-F1 **88.7**，准确率 **88.9%** |
| 对照 | 优于 GPT / Claude / Gemini 基线，含带网络搜索与 few-shot 的变体 |

---

## 2. 它的方法（三件套）

1. 从**外部学术源**检索候选文献；
2. 用**结构化的 LLM 校验器**把引用与检索到的候选做比对；
3. 把校验分**映射到三级标签**（校准过的决策规则）。

结论：可靠的引用核验需要**学术检索 + 结构化 LLM 比对 + 校准决策规则**三者结合。

---

## 3. 对我方：可借 / 可打点

**可借（一条方法论）**：

**"受控污染"这个出题手法我们可以用来做判分器的定标集。**

具体做法：拿我们的金标准轨迹，**人为注入已知错误**（比如把某个 ID 换成没查过的、把 cp3 的某次查询删掉、把 cp5 排序颠倒），然后看判分器是否准确识别。这比"金标准全过 + 非解不全过"两条粗检验精细得多，能算出判分器的 F1。

**这实际上补齐了 `BenchmarkingBenchmarks` 指出的缺口**（我们没有判分器的人工对照集）—— 受控注入错误比人工标注便宜得多，且真值已知。

**可打点**：它的判定用 LLM 校验器（软判定），且任务是文献元数据核验，与我们的化学任务无重叠。归入"取证方法"类引用。
