## 0. 一句话

给出一个模块化解耦（环境 / agent / 训练三层分离）的多轮交互 RL 框架，不依赖 SFT 就能从零训 LLM agent；并提出 **ScalingInter-RL**——训练早期限制交互轮数（偏 exploitation），逐步放开 horizon（转向 exploration），从而避免长 horizon 下的策略崩塌；在 27 个任务上匹配或超越商业模型。

## 1. 数据量

它是**框架 + 方法**论文，"数据量"体现为环境覆盖：

| 项 | 内容 |
|---|---|
| 场景数 | **5 类**：web navigation / deep search / digital games / embodied / scientific |
| 具体环境 | WebArena（含在线购物、论坛、协作开发、内容管理四个域）、RAG-based Deep Search、TextCraft、BabyAI、**SciWorld** |
| 任务数 | 论文口径 **27 个任务**上匹配或超过商业模型 |
| 骨干模型 | Qwen-2.5-3B / 7B 为主；对照 Gemini 2.5 Pro、o3、GPT-4o、DeepSeek-R1、Qwen-2.5-72B、Llama-3.1-8B/70B |
| 关键结果 | WebArena 上超过 10% 的绝对提升 |

## 2. 数据集形态（框架形态）

- **三模块解耦**：environment（HTTP 服务化，可并行）/ agent / training。论文花了很大篇幅讲工程改造：把 WebArena 默认的"单进程单浏览器"改成子进程架构以支持并行；给 SciWorld 重做初始化与 reset；修 TextCraft 的内存管理、修 SciWorld 内部时钟的内存泄漏；给 WebArena 加"每 episode 后把 web server 恢复初态"的 reset 接口。
- **交互协议**：`for i in range(max_rounds)` 的标准多轮 loop——agent 输出思考路径 T + 动作 a，环境返回观测 o 与奖励。
- **奖励**：环境原生奖励（稀疏，主要是终态成功），**没有过程级 verifiable reward**。

## 3. "长"体现在哪

1. **交互轮数是显式的一等旋钮**：`max_rounds` 就是 horizon；ScalingInter-RL 的全部内容就是**按训练阶段调度这个 horizon**（早期小、后期大）。
2. **崩塌是长程特有的失败模式**：论文明确指出，直接在大 horizon 上训会导致"策略崩塌 / 行为多样性丧失"，必须分阶段放开。
3. 环境本身是多轮的（WebArena 网页操作、SciWorld 科学实验循环）。

## 4. 判分粒度

**终态/环境原生稀疏奖励**。这是它的明确空白：它把 horizon 当旋钮调，但**没有任何中间 checkpoint 信号**，只能靠"限制 horizon"这种课程手段间接缓解长程 credit assignment。

## 5. 对我方：可借 / 可打点

**可借**

1. **ScalingInter-RL 的思路可以直接复用到我们的 checkpoint DAG 上，而且会更自然**：他们只能按"轮数"切课程；我们可以按 **DAG 深度**切课程——第一阶段只要求走到 cp2，第二阶段 cp4，最后全程。这叫 **checkpoint-curriculum RL**，是一个干净的、我们独有的方法学增量。
2. **"框架 + 方法"打包投稿的形态**：Abstract 的结构是"社区缺一个统一框架 → 我们给框架 → 我们再给一个训练方法 → 27 任务实验"。**我们的完整版可以照此结构：社区缺过程可判的长程科学 benchmark → 我们给 benchmark → 我们给 checkpoint-reward RL → 实验。**
3. **工程可复现细节值得抄进附录**：环境重置接口、并行化、内存泄漏修复这类"苦活"在 ICLR 是加分项（体现真实可用），不是废话。

**可打点**

| 维度 | AgentGym-RL | 我们 |
|---|---|---|
| 奖励 | 环境原生稀疏 | checkpoint 级稠密 verifiable |
| 课程维度 | 交互轮数 | **DAG 深度 / checkpoint 前缀** |
| 领域 | 通用（web/game/embodied）+ SciWorld（玩具科学） | 真实材料/药物数据库 |
| 长程 credit assignment | 未解决（靠限制 horizon 绕开） | checkpoint 直接给中间信号 |
