# CrystalGraphAutoLoop · agent 自主超过 17 个专家设计的模型

> **原文**：Optimizing Expert-Designed Crystal Graph Networks for Band-Gap Prediction with an Autonomous LLM Research Loop
> **出处**：arXiv:2606.29717，2026-06-29，cond-mat.mtrl-sci
> **阅读方式**：基于完整摘要与元数据

## 0. 一句话
**一个通用 coding agent 在 MatBench 带隙任务上自主构建出了「无外部预训练条件下最准确的模型」，超过全部 17 个已报告的专家设计模型**——但作者随后指出：它是靠**实现已知方法**做到的，不是靠创新。

## 1. 关键数字
| 项 | 内容 |
|---|---|
| 任务 | MatBench 带隙预测（**> 100k 晶体**） |
| 对照 | **17 个**专家设计的已报告模型 |
| 结果 | agent 自主构建的模型在"无外部预训练"类中**最准确** |
| **归因分析** | 靠的是**已在晶体神经网络中标准化的方法**，或**从机器学习其他领域借来的方法** |
| 具体贡献项 | 每条消息传递边上的**元素对特征** + **晶体空间群嵌入** |

## 2. 机制与判分
固定指标（MatBench 带隙 MAE）+ 已有基线排行榜。**判定完全硬**（数值指标）。

## 3. 对我方
**可借（一条重要的方法学启示）**：

**它做了"归因分析"——不只报"agent 赢了"，还查清"赢在哪、是不是真创新"。** 这个动作我们应该在矩阵结果分析时照做：某模型分高，要查清是**真走对了流程**还是**碰巧命中**。

**我们其实有更好的工具做这件事**：cp1–cp6 的分解本身就是归因。若某模型 task_score 高但 cp3 低，说明它没查证就答对了 —— 这正是"赢在运气"的信号。**建议把这类归因写成矩阵结果报告的固定一节。**

**可打点**：①它是"固定指标 + 现成排行榜"的任务（判终态），我们是判过程；②它说明**agent 在有明确指标的优化任务上已经很强** —— 这从侧面支持我们的选题：我们考的不是"优化一个指标"，而是"按科学流程走对"，后者尚未饱和。
