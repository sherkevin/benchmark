## 白话词典(本案术语)

| 词 | 白话 |
|---|---|
| **逆合成** | 倒着想:从目标分子往回推"它能由什么更简单的东西反应出来",一层层退到能买到的原料。 |
| **起始原料 / building block** | 化学货架上能直接买到的简单分子(路线的终点)。 |
| **反应先例 / 模板** | 这类反应别人真做过、数据库里有记录;凭空发明的反应不算数。 |
| **合成树 / 路线** | 拆解过程画成一棵树;一条从目标到原料的通路 = 一条合成路线。 |
| **SMILES** | 用一串字符表示一个分子结构的写法。 |

---

## L0 指令

> "给你一个目标药物分子(SMILES),规划一条可行的全合成路线:一步步把它拆解到可以买到的起始原料,每一步给出反应类型和它在已知反应里的先例依据。"

## 为什么是长程(6 性质)

链长(递归多层拆解)✓ · 强依赖(每层拆解的产物正是上一层的反应物,断一环全断)✓ · 状态累积(整棵拆解树/路径要一路带着)✓ · 误差放大(某步拆错 → 下游全无效)✓ · 奖励延迟(到叶子才知道原料买不买得到、整条路通不通)✓ · 自主决策(选哪条拆解分支、何时判定到头停)✓ → **6/6 ✓**。

> **独特形状 = 树搜索**。signature 桩点 = **路径连通(每步产物=下一步反应物)** + **叶可达(终点是真能买的原料)**——这是 case1 漏斗 / caseD 闭环 / case2 门控都没有的"树结构"校验。

## 金标准 trace(6 阶段 + 埋桩点 ⬛)

```
Stage 1 · 策略       → 解析目标骨架,定逆合成策略(找可断键/官能团互变)
  ⬛ ckpt-1(策略)
Stage 2 · 首层拆解   → 提出目标的直接前体 + 反应类型
  ⬛ ckpt-2(反应步合法)  ⬛ ckpt-6(反应有先例)
Stage 3 · 递归拆解   → 对每个前体继续拆,直到可购原料
  ⬛ ckpt-3(路径连通·杀手桩点)  ⬛ ckpt-5(无退化环)
Stage 4 · 终止判定   → 所有叶子都是可购原料则停
  ⬛ ckpt-4(叶可达)  ⬛ ckpt-7(深度合理)
Stage 5 · 提交路线   → 完整步骤序列 + 每步条件
  ⬛ ckpt-8(命中已知路线)
Stage 6 · 报告       → 标注哪步有先例 / 哪步是新提议
  ⬛ ckpt-9(报告诚实)
```

## 桩点链(9 cp,Tier 1 = 7/9 = 78% ✓)

每个讲清:**① 测什么 ② 标准答案(GT)从哪来 ③ 怎么判**。括号 = 阶段 · 谁判 · 抓哪种走偏 · GT 类型。

**桩点 1 · 策略靠不靠谱**(策略 · AI判T2 · D1 · 人编细则)
- 测什么:有没有说清"倒推拆解 → 拆到可购原料 → 每步要有先例"这套打法。
- 标准答案哪来:没有客观值,我们手写检查清单。
- 怎么判:AI 对清单打分。

**桩点 2 · 每步反应合不合法**(拆解 · 机器判T1 · D5 瞎编 · 规则)
- 测什么:每一步"产物 ← 反应物"在化学上成不成立。
- 标准答案哪来:**不需要外部答案**——交给 RDKit 反应解析 + 反应模板库校验。
- 怎么判:每步能否被反应模板匹配/RDKit 解析;解析不通 = 编了个不存在的反应。

**桩点 3 · 路径接不接得上**(递归 · 机器判T1 · D4 断链 · 结构/内部一致)【**杀手桩点**】
- 测什么:拆解树里每一步的产物,是不是正好是上一步的反应物——一环扣一环没断。
- 标准答案哪来:标准就是它自己的树(内部一致性,不是外部真值)。
- 怎么判:把路线画成图查连通;中间冒出对不上的中间体(这步产物 ≠ 上步反应物)= 断链。**case1/D/2 没有这条树连通校验。**

**桩点 4 · 叶子真能买到吗**(终止 · 机器判T1 · D4 · 集合)
- 测什么:路线终点的起始原料,是不是真在"可购货架"上。
- 标准答案哪来:公开可购原料库(eMolecules/ZINC,开放)。
- 怎么判:每个叶子原料 ∈ 可购库?有买不到的 = 路线落不了地(纸上谈兵)。

**桩点 5 · 有没有绕圈/退化**(递归 · 机器判T1 · D7 · 结构)
- 测什么:拆解有没有 A→B→A 这种死循环,或原地打转。
- 标准答案哪来:规则(合成树不能有环)。
- 怎么判:查树有无环/重复节点。

**桩点 6 · 反应类型有没有先例**(拆解 · 机器判T1 · D5 · 集合)
- 测什么:它用的每种反应,在已知反应库里有没有人真做过这类。
- 标准答案哪来:公开反应库 USPTO-50k / ORD(开放)的反应模板。
- 怎么判:反应类型 ∈ 已知模板库?凭空发明的"魔法反应" = 幻觉。

**桩点 7 · 路线长短合理吗**(终止 · 机器判T1 · D2 · 数值)
- 测什么:总步数有没有冗长绕路(或短到不可能)。
- 标准答案哪来:同类目标已知路线的步数量级(文献,⬜ 待锚)。
- 怎么判:步数落在合理区间算过。

**桩点 8 · 关键中间体命中已知路线吗**(提交 · 机器判T1 · D2/D4 · 集合)
- 测什么:若该分子有已发表合成,它的关键中间体跟真实路线对不对得上。
- 标准答案哪来:已发表合成路线(文献,⬜ 待锚)。
- 怎么判:中间体 ∩ 真实路线,命中率够高算过。

**桩点 9 · 报告诚实吗**(报告 · AI判T2 · D6 · trace+人编)
- 测什么:有没有如实标"这步有先例 / 这步是我新提的"。
- 标准答案哪来:看录像每步有没有对应先例 + 手写诚实清单。
- 怎么判:AI 逐步交叉验证;把新提的说成"标准反应" = 扣分。

## 走偏演示

会走偏的 agent:Stage 3 第 2 步产物写成 X,但第 3 步反应物却用了 Y(≠X);某个叶子是个买不到的复杂分子;还用了一个化学上不存在的"魔法反应"。

桩点亮红:
- **ckpt-3 红**:第 3 步反应物 Y ≠ 第 2 步产物 X → **D4 断链**
- **ckpt-4 红**:叶子 ∉ 可购库 → **D4**(路线落不了地)
- **ckpt-6 红**:反应类型无先例 → **D5 瞎编**

→ 杀手锏 **ckpt-3(树连通)+ ckpt-4(叶可达)**:一条路线"看起来步骤齐全",但只要中间断一环、或终点买不到,把它变成图 + 查货架立刻露馅——这是纯读文字看不出、必须靠结构校验才抓得到的偏。
