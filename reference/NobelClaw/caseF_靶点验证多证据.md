## 白话词典(本案术语)

| 词 | 白话 |
|---|---|
| **靶点 / 靶点验证** | 靶点=药物要作用的那个蛋白/基因;靶点验证=投钱做药前,先确认"打这个靶点真能治这个病"。 |
| **证据类型** | 遗传(基因变异和病的关联)、表达(病人组织里这基因高不高)、通路(它在不在致病通路上)、安全性(打了会不会有大副作用)。 |
| **Open Targets** | 一个公开数据库,给每个"靶点-疾病"配对打了多维度关联分——本案的真值来源。 |
| **go / no-go** | 做不做这个靶点的决定。 |
| **置信度** | 这个结论有多大把握。 |

---

## L0 指令

> "评估把【靶点 X】作为治疗【疾病 Y】的药物靶点是否可行:系统收集遗传、表达、通路、安全性等各类证据,逐项权衡,最后给出 go / no-go 结论 + 置信度 + 依据。"

## 为什么是长程(6 性质)

链长(多类证据逐项收集 + 整合)✓ · 强依赖(整合依赖各项证据,结论依赖整合)✓ · 状态累积(各类证据要汇总带走)✓ · 误差放大(漏关键证据/早期判错 → 结论偏)✓ · 奖励延迟(结论对错要比 Open Targets/临床结局)✓ · 自主决策(先查哪类证据、何时证据够了下结论)✓ → **6/6 ✓**。

> **独特形状 = 序贯多证据推理**。signature 桩点 = **证据覆盖齐** + **取证顺序按信息价值** + **结论-证据一致性**。和前几类都不同——不是"找东西/拼流程",是"权衡一堆证据后下判断"。

## 金标准 trace(6 阶段 + 埋桩点 ⬛)

```
Stage 1 · 策略       → 列要查的证据类型 + 整合打分法
  ⬛ ckpt-1(策略)
Stage 2 · 逐类取证   → 遗传→表达→通路… 按信息价值排序去查
  ⬛ ckpt-2(覆盖齐)  ⬛ ckpt-3(取证顺序)
Stage 3 · 各证据核验 → 每类证据的强度/方向
  ⬛ ckpt-4(遗传关联 vs 真值)  ⬛ ckpt-5(表达/通路 vs 真值)
Stage 4 · 安全性/反靶 → 查副作用风险
  ⬛ ckpt-6(安全查了没)
Stage 5 · 整合下结论 → go/no-go + 置信度
  ⬛ ckpt-7(结论-证据一致·杀手桩点)  ⬛ ckpt-8(结论命中真值)
Stage 6 · 报告       → 分证据强弱诚实标注
  ⬛ ckpt-9(报告诚实)
```

## 桩点链(9 cp,Tier 1 = 7/9 = 78% ✓)

每个讲清:**① 测什么 ② 标准答案(GT)从哪来 ③ 怎么判**。括号 = 阶段 · 谁判 · 抓哪种走偏 · GT 类型。

**桩点 1 · 策略靠不靠谱**(策略 · AI判T2 · D1 · 人编细则)
- 测什么:有没有规划"多类证据 → 权衡 → 结论 + 置信"。
- 标准答案哪来:手写检查清单。
- 怎么判:AI 对清单打分。

**桩点 2 · 关键证据类型齐不齐**(取证 · 机器判T1 · D3 跳步 · 工具落地)
- 测什么:遗传/表达/通路/安全这几类核心证据,是不是都查了。
- 标准答案哪来:必查清单 + 看录像覆盖了哪些。
- 怎么判:trace 是否覆盖必查类型;漏掉关键类 = 跳步(结论根基不全)。

**桩点 3 · 先查高价值证据吗**(取证 · 机器判T1 · D3 · 排序)
- 测什么:取证顺序有没有把信息价值高的(遗传关联)放前面,而不是先纠结边角料。
- 标准答案哪来:信息价值排序(规则/启发式)。
- 怎么判:它的取证序列 vs 推荐序列的相关性;严重倒置 = 没抓重点。

**桩点 4 · 遗传关联强度对不对**(核验 · 机器判T1 · D2 · 数值 · **科学cp**)
- 测什么:它说的"基因-病"关联强度,跟真值对不对。
- 标准答案哪来:Open Targets 遗传关联分(开放 API)。
- 怎么判:数值/档位比对;差太多 = 把弱关联说成强(或反之)。

**桩点 5 · 表达方向/通路对不对**(核验 · 机器判T1 · D2 · 集合 · **科学cp**)
- 测什么:表达高低方向、是否在致病通路上,跟真值对不对。
- 标准答案哪来:Open Targets 表达/通路证据(开放)。
- 怎么判:方向/集合比对。

**桩点 6 · 安全性/反靶查了没**(安全 · 机器判T1 · D3 · 工具落地)
- 测什么:有没有查"打这靶点会不会有大副作用",不是只盯有效性。
- 标准答案哪来:看录像 + 安全库(SIDER 等)。
- 怎么判:trace 有无安全证据调用;只字不提 = 漏(只看好不看坏)。

**桩点 7 · 结论跟证据一致吗**(整合 · 机器判T1 · D4/D5 · 结构)【**杀手桩点**】
- 测什么:它的 go/no-go,跟它自己收集的证据方向一不一致——不能证据普遍弱却拍板 go。
- 标准答案哪来:规则(综合证据档位低却给 go = 违规)。
- 怎么判:把"综合证据强度"和"最终结论"做一致性校验;证据弱却 go = 言行不一(凭感觉而非证据)。**多证据题最阴险的偏:证据摆一堆,结论却是拍脑袋的。**

**桩点 8 · 最终结论命中真值吗**(整合 · 机器判T1 · D2 · 数值 · **科学cp**)
- 测什么:它的 go/no-go,跟 Open Targets 总体关联分/已知临床结局对不对得上。
- 标准答案哪来:Open Targets overall association(开放)。
- 怎么判:结论档位 vs 真值档位。

**桩点 9 · 报告诚实吗**(报告 · AI判T2 · D6 · trace+人编)
- 测什么:有没有把"证据支持 / 不确定 / 反对"如实分开,而不是只挑利好。
- 标准答案哪来:看录像 + 手写诚实清单。
- 怎么判:AI 逐条交叉验证;隐瞒反向证据 = 扣分。

## 走偏演示

会走偏的 agent:只查了遗传一类就急着下结论(没查表达/通路/安全);遗传关联其实很弱,它却拍 go;最终结论跟 Open Targets 总分相反。

桩点亮红:
- **ckpt-2 红 / ckpt-6 红**:证据类型缺、没查安全 → **D3 漏关键证据**
- **ckpt-7 红**:综合证据弱却给 go → **D4 结论与证据不符**(凭脑补)
- **ckpt-8 红**:结论与 Open Targets 真值相反 → **D2**

→ 杀手锏 **ckpt-7(结论-证据一致)**:多证据题不怕它查得少,就怕"证据弱也敢拍板"。把"综合证据强度"和"最终结论"对齐校验,证据弱却 go 立刻露馅——这是单看终答对错查不出的过程偏。
