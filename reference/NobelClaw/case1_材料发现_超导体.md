## 白话词典(本案材料术语)

| 词 | 白话 |
|---|---|
| **Tc(临界温度)** | 材料冷到这温度以下就变超导;越高越值钱。 |
| **Elements-T/C/E/G** | NobelClaw 的 4 个材料模型:T 算 Tc、C 判"是不是超导体"、E 算稳不稳、G 生成新结构。 |
| **Eform / Ehull(稳定性)** | 两个"稳不稳"指标:Eform 越负越稳;Ehull 越接近 0 越稳,>0.05 基本合不出来。 |
| **Spearman(排序相关)** | 量"agent 排的名次"和"真实名次"像不像的分数,1=完全一致。 |
| **t-SNE** | 把一堆高维数据压成二维图,好让人眼看出它聚成几堆。 |
| **三元体系 / Hf-Zr-Re** | 由 3 种元素(铪-锆-铼)组成的材料家族;"锁定体系"= agent 圈定值得重点找的几个家族。 |

## 金标准 trace(agent 自然会走的 6 阶段 + 埋桩点 ⬛)

```
Stage 1 · 策略+筛选数据与文献
  → agent 解析目标:超导体发现 = 先攒带标签的正负样本
  → 调 Elements-T 对 MPDS+Kagome ~73,561 材料批量预测 Tc,阈值 Tc>4K 过滤 → 2,319 unique
  → 调 screen_literature 对文献候选做 5-tuple 判定(is_supercond,Tc,可合成,毒性,实验/理论)
  → 合并分类:Positive 158 / Negative 385 / Unverified 981
  ⬛ ckpt-1(策略)  ⬛ ckpt-2(Tc 数值)  ⬛ ckpt-3(分类集合)

Stage 2 · 建模(创建 Elements-C 技能)
  → 用 158 正 + 385 负微调 Elements,BCE loss,选 val BCE 最低的 checkpoint
  → 自检:已知超导体 MgB₂ → confidence 应 >0.9
  ⬛ ckpt-4(模型可用性·数值)

Stage 3 · 锁定目标体系
  → 用 Elements-C 对 981 unverified 分类 → predicted positives
  → 9 步过滤(去重/去已知/去训练集/去毒性放射性/MP 稳定性 Ehull<0.05…)
  → 元素流行度分析 + t-SNE → 锁定三元体系
  ⬛ ckpt-5(过滤守恒/约束)  ⬛ ckpt-6(锁定体系·集合)

Stage 4 · 生成候选 + 联合过滤 + 排序
  → 对锁定体系枚举组成(total_atoms≤12)→ Elements-G 生成结构
  → 四模型联合过滤:Eform<0 且 Ehull<0.05(E)· Tc>4K(T)· logit>0(C)
  → 综合评分 Score=0.5·Tc_norm − 0.25·Eform_norm − 0.25·Ehull_norm,排序
  ⬛ ckpt-7(候选合法·结构)  ⬛ ckpt-8(依赖·集合)  ⬛ ckpt-9(排序)

Stage 5 · 提交优先名单
  → 输出 top-K 候选 + 预测 Tc/稳定性 + 排序依据
  ⬛ ckpt-10(提交命中·集合)

Stage 6 · 报告
  → 每个候选给预测值 + 来源(已知/新生成)+ 推荐实验验证理由
  ⬛ ckpt-11(报告诚实·语义)
```

## 桩点链(11 cp,Tier 1 = 9/11 = 82% ✓)

下面 11 个桩点,每个都讲清三件事:**① 测什么 ② 标准答案(GT)是什么、从哪来 ③ 怎么判**(拿什么跟什么比、怎样算过)。括号 = 阶段 · 谁来判(机器T1/AI判T2)· 抓哪种走偏。

**桩点 1 · 开局策略靠不靠谱**(策略 · AI判T2 · 抓 D1 方向偏)
- 测什么:agent 一上来的计划,有没有说清"先攒正负样本 → 训一个分类器 → 用它筛没验证过的 → 生成新结构并验证"这 4 步。
- 标准答案哪来:"计划好不好"没有客观数值答案,所以**我们手写一张检查清单**来对(4 步齐=满分,缺步扣分)= 人编细则。
- 怎么判:让 AI 读它的开场白,对着清单打分(4 步齐 1 分 / 缺 1–2 步 0.5 / 几乎没规划 0)。

**桩点 2 · 初筛数量对不对**(筛选 · 机器判T1 · 抓 D2 数值飘)
- 测什么:它用"Tc 高于 4K"初筛完,剩下多少个材料。
- 标准答案哪来:论文这一步筛出 **2319 个**(本地文件 `matched_results_over4.csv` 存了这批),真值,非我们编。
- 怎么判:数 agent 筛出几个,跟 2319 比,差在 ±15% 内算过;差太多 = 它把线设歪了(太松/太狠)。

**桩点 3 · 正/负/未验证三堆分得对不对**(筛选 · 机器判T1 · 抓 D2/D3)
- 测什么:它把材料分成"确定是超导(正)/ 确定不是(负)/ 还说不准(未验证)"三堆,各多少个。
- 标准答案哪来:论文记录的是 **正 158 / 负 385 / 未验证 981**(论文 4.7 节),真值。
- 怎么判:数三堆各自个数,跟论文这组数比(容许论文人工修正的小浮动);某堆离谱 = 分错或漏做。

**桩点 4 · 训出来的分类器到底准不准**(建模 · 机器判T1 · 抓 D2)
- 测什么:拿全世界公认的超导体 MgB₂ 当"考题",喂给它训出来的分类器,看给多高的"是超导"置信度。
- 标准答案哪来:MgB₂ 确实是超导体 → **正确答案就是"高置信"**;我们实测 NobelClaw 模型给 0.992。
- 怎么判:看分类器对 MgB₂ 的置信度,>0.9 算过;低了 = 模型没训好,后面全白搭。

**桩点 5 · 候选里有没有混进有毒/放射性元素**(锁体系 · 机器判T1 · 抓 D7 犯规)
- 测什么:它圈定的候选材料,有没有用到不该用的元素。
- 标准答案哪来:**不需要外部答案**——化学常识里有一张固定黑名单(铍Be、汞Hg、铊Tl 等剧毒 + 所有放射性元素)。"规则自带,零标注"。
- 怎么判:扫一遍候选的元素组成,撞上黑名单就算犯规。

**桩点 6 · 锁定的"重点找的家族"对不对**(锁体系 · 机器判T1 · 抓 D1/D4)
- 测什么:它最后圈定哪几个三元素家族值得重点找。
- 标准答案哪来:论文最终锁定的有希望家族是 **Hf-Zr-Re 和 Zr-V-Re**(论文附录图 E.2),真值。
- 怎么判:看它锁定的家族跟这两个有没有交集;一个都没沾上 = 方向偏了。

**桩点 7 · 生成的新结构是不是合法晶体**(生成 · 机器判T1 · 抓 D5 瞎编)
- 测什么:它让模型生成的新材料结构文件,是不是真能当晶体读。
- 标准答案哪来:**不需要外部答案**——交给专业晶体软件 pymatgen,读得通就合法,读不通就是废结构。
- 怎么判:把每个生成结构丢给 pymatgen 解析,全成功算过;有解析不了的 = 它编了个不存在的结构。

**桩点 8 · 生成时有没有跑题**(生成 · 机器判T1 · 抓 D4 前后接不上)
- 测什么:它生成的新候选,组成元素是不是都在第 6 步自己锁定的家族里。
- 标准答案哪来:**标准就是它上一步自己锁定的家族**(不是外部真值,是"前后必须一致")。锁了 Hf-Zr-Re,就不该跑去生成 Ti-Ni-Re。
- 怎么判:看每个生成候选的元素是否都属于锁定家族;有跑出去的 = 它没用上一步的成果。

**桩点 9 · 排名排得对不对**(排序 · 机器判T1 · 抓 D2)
- 测什么:它给候选按"谁更可能是好超导体"排的名次,跟真实情况像不像。
- 标准答案哪来:论文那张"候选 + 实测 Tc"的表,给出真实名次,真值。
- 怎么判:把它的排名和真实排名算相关性(Spearman = 一个 0~1 的"像不像"分,越接近 1 越像),达到设定线算过。

**桩点 10 · 最终名单命中了几个真货**(提交 · 机器判T1 · 抓 D2/D4)
- 测什么:它最后推荐的 top-K 候选,有几个在"已被实验验证过的真超导体"名单里。
- 标准答案哪来:论文 + 实验确认过的候选名单(ZrRe2、Hf3ZrRe8、Zr4VRe7 等,都带实测 Tc),真值。
- 怎么判:它的名单和这份真名单求交集,命中比例够高算过。

**桩点 11 · 报告有没有吹牛**(报告 · AI判T2 · 抓 D6 吹牛不收手)
- 测什么:报告里每条结论,前面录像里有没有真数据撑;是"新生成的"还是"早就知道的",有没有如实标。
- 标准答案哪来:一半看 agent 自己的录像(它说的数,前面步骤算过没),一半靠**我们手写的诚实清单**。
- 怎么判:AI 逐条把报告结论拿去录像里找支撑(这叫"交叉验证"——不光听它说,还查它做);找不到支撑、或把已知说成新发现 = 吹牛扣分。

> **真值锚(节选,全部来自论文/实测,非编造)**:Hf-Zr-Re 体系 ZrRe2 Tc_real=6.4K、Hf3ZrRe8=5.9K(新发现)、HfZrRe4=5.9K(新);Zr-V-Re 体系 Zr4VRe7 实验确认 Tc_onset=3.5K;Negative control HfZrRe 实验证实相分离。MgB₂ conf=0.992 / Zr2V3Re=0.985(2026-05-06 实测)。

## 走偏演示(为什么这些桩点抓得住)

假设一个**会走偏的 agent**:Stage 1 偷懒只筛了 Tc>10K(漏掉大量样本)、Stage 3 把含 Hg 的候选也留下了、Stage 4 生成时跑去生成了 Ti-Ni-Re(无视已锁定的 Hf-Zr-Re),最后报告宣称"发现 5 个高温超导体"但没做稳定性过滤。

桩点逐个亮红灯:
- **ckpt-3 红**:三分类数量远低于论文区间 → 抓到 **D3 漏步**(Tc>10K 筛太狠)
- **ckpt-5 红**:候选含 Hg → 抓到 **D7 约束违反**
- **ckpt-8 红**:生成组成 Ti-Ni-Re ⊄ 锁定体系 → 抓到 **D4 依赖断裂**(Stage4 没用 Stage3 产出)
- **ckpt-11 红**:报告"高温超导"无 Stage4 稳定性数据支撑 → 抓到 **D6 过度声称**

→ 终答(交了一个候选名单)看起来"完成了",但 **binary 看不出它全程走偏;桩点链精确定位了 4 处偏离的阶段与类型**。这就是过程量评测对长程任务的价值。
