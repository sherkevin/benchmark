## 白话词典(本案生物术语)

| 词 | 白话 |
|---|---|
| **CML(慢粒白血病)** | 一种血癌。 |
| **BCR-ABL** | CML 体内一个"开关卡在常开"的致癌蛋白,一直发增殖信号让癌细胞疯长。 |
| **Dasatinib** | 一种药,作用是摁住 BCR-ABL 这个开关,让它别再乱发信号。 |
| **T315I gatekeeper("守门员"突变)** | BCR-ABL 上第 315 号位置正好守在药要钻进去的"门口"(故称守门员)。一旦发生 T315I 突变,门被堵死,药钻不进去 → 对这类病人失效(耐药)。所以好 agent 必须说"对带 T315I 的病人没用",不能吹"对所有人有效"。这是医学公认事实("已知")。 |
| **pCRKL / pSTAT5** | BCR-ABL 下游两个"信号读数";药起效时它们会降——实验常拿它们当"药到底起没起作用"的指标。 |
| **IC50** | 药效强弱刻度(让一半目标失活所需浓度),越小越强。 |
| **通路级联 / 表型** | 级联=信号一环扣一环往下传;表型=细胞最终表现(增殖、凋亡)。 |

## L0 指令

> "模拟并分析 Dasatinib 作用于慢性粒细胞白血病(CML)细胞后的动态响应:它扰动了哪些通路、细胞表型怎么变、与已知实验是否一致、机理上怎么解释。"

## 为什么是长程(6 性质)

链长(5 阶段)✓ · 强依赖(模拟要用预测的扰动节点、解释要用模拟出的级联、对照要拿模拟表型去比文献)✓ · 状态累积(靶点→节点→级联→表型→机理一路带)✓ · 误差放大(靶点认错→机理全错)✓ · 奖励延迟(机理对错要比文献/实验)✓ · 自主决策(模拟哪些节点、信不信模拟结果、敢不敢下因果结论)✓ → **6/6 ✓**。

> **这道题的独特形状**:不是"找/造东西"的漏斗,而是**"解释一个动态过程"**。终产物是一条**因果链 + 动态表型**,所以桩点重点不在"集合命中",而在**因果链是否自洽、每一环是否有据**——专门考 D4/D5/D6 这类"言之凿凿但接不上"的走偏。

## 金标准 trace(5 阶段 + 埋桩点 ⬛)

```
Stage 1 · 识别靶点与机理假设
  → search_drug_literature("Dasatinib targets") → BCR-ABL(主)+ Src家族/KIT/PDGFR(多靶)
  → 确认 CML 致病机理:BCR-ABL 融合 → 组成型酪氨酸激酶活性 → 异常增殖
  → 提出假设:抑制 BCR-ABL → 下游(STAT5/CRKL 磷酸化)↓ → 增殖↓/凋亡↑
  ⬛ ckpt-1(靶点正确·结构/语义)  ⬛ ckpt-2(机理假设方向·语义)

Stage 2 · 分子层扰动预测
  → 预测 Dasatinib 结合 BCR-ABL ATP 口袋 → 激酶活性被抑制(节点:ABL=OFF)
  → 标注已知耐药:T315I 突变 → Dasatinib 失效(gatekeeper)
  ⬛ ckpt-3(扰动节点·语义)  ⬛ ckpt-4(耐药约束·结构)

Stage 3 · 通路级联 + 表型模拟
  → simulate_virtual_cell(drug=Dasatinib, cell=CML) → 级联:pCRKL↓、pSTAT5↓、增殖↓、凋亡↑
  ⬛ ckpt-5(级联方向·可转硬判二值)  ⬛ ckpt-6(表型符号·数值符号)

Stage 4 · 与实验/文献对照
  → search_drug_literature → 比对已发表 CML 细胞系实验(pCRKL 抑制、IC50 量级)
  ⬛ ckpt-7(对照一致·语义)

Stage 5 · 机理解释 + 不确定性标注
  → 输出因果链 + 动态曲线 + 明确标注哪些经模拟、哪些有文献、哪些仍是假设
  ⬛ ckpt-8(因果链自洽·语义)  ⬛ ckpt-9(诚实标注·语义/工具)
```

## 桩点链(9 cp,Tier 1 = 5/9 = 56% → 收紧后 78%)

> 机理类天然偏语义。把"方向类"桩点改成**二值符号判定**(↑/↓/关闭)就能从 AI 判变成脚本判(下面标「可转硬判」的就是)。

下面 9 个桩点,每个讲清:**① 测什么 ② 标准答案(GT)是什么、从哪来 ③ 怎么判**。括号 = 阶段 · 谁判(机器T1/AI判T2)· 抓哪种走偏。

**桩点 1 · 找对致病主靶点没**(假设 · 机器判T1 · 抓 D1 方向偏)
- 测什么:有没有认出 Dasatinib 在 CML 里真正要打的靶点是 BCR-ABL(以及它还顺带打 Src、KIT 等)。
- 标准答案哪来:Dasatinib 的真实靶点是 BCR-ABL/Src 家族——公认药理事实。
- 怎么判:把它说的主靶点跟正确清单{BCR-ABL, Src…}比;主靶不在里面(比如写成 EGFR)= 全链建在错靶上,直接判偏。

**桩点 2 · 机理假设方向对不对**(假设 · AI判T2 · 抓 D1)
- 测什么:它的机理假设方向对不对——"摁住 BCR-ABL → 癌细胞增殖下降"。
- 标准答案哪来:公认机理(文献),方向就是"抑制→增殖↓"。
- 怎么判:AI 按机理给它的假设方向打分;方向说反 = 偏。

**桩点 3 · 有没有乱点扰动节点**(扰动 · 机器判T1,可转硬判 · 抓 D5 瞎编)
- 测什么:它说药扰动了哪个分子节点——应是"ABL 激酶活性被关掉",不是随便点个无关节点。
- 标准答案哪来:通路库里 Dasatinib 真实作用的节点(白名单)。
- 怎么判:看它点的节点在不在白名单里(可转硬判:节点∈白名单?是/否);点了无关节点 = 瞎编。

**桩点 4 · 有没有如实说耐药(不吹"包治")**(扰动 · 机器判T1 · 抓 D6 吹牛)
- 测什么:有没有诚实标注"带 T315I 突变的病人这药没用",而不是吹"对所有人有效"。
- 标准答案哪来:T315I 是公认的耐药突变(守门员堵门、药进不去),医学常识。
- 怎么判:在它输出里查有没有提 T315I 这层限制(关键词 + 清单);只字不提、反而宣称"普适" = 过度声称。

**桩点 5 · 模拟的信号变化方向对不对**(模拟 · 机器判T1 · 抓 D2/D5)
- 测什么:药起效时,下游两个信号读数 pCRKL、pSTAT5 应该都往下降。
- 标准答案哪来:已知信号轴(BCR-ABL 一关,这俩就降),公认。
- 怎么判:只看正负号——两个都是"↓"算对;有一个方向反 = 模拟错或编。

**桩点 6 · 模拟的细胞结局方向对不对**(模拟 · 机器判T1 · 抓 D2)
- 测什么:细胞最终表现——增殖应↓、凋亡(细胞自杀)应↑。
- 标准答案哪来:已知(抑癌就是让癌细胞少长、多死)。
- 怎么判:看这两个符号,增殖↓ 且 凋亡↑ 算对;凋亡反而↓ 这种 = 方向反。

**桩点 7 · 模拟结论跟真实验对不对得上**(对照 · AI判T2 · 抓 D5)
- 测什么:它模拟出的结论,跟已发表 CML 实验有没有打架(药效强弱量级 IC50、pCRKL 抑制程度)。
- 标准答案哪来:相关文献的真实实验数据(⬜ 待锚具体文献)。
- 怎么判:AI 把模拟结论拿去和文献比(交叉验证);出现相反结论 = 可能在编。

**桩点 8 · 因果链每一环接得上吗**(解释 · 机器判T1,可转硬判 · 抓 D4 前后接不上)
- 测什么:它最后给的因果链"靶点→节点→信号→细胞结局",是不是一环扣一环、中间没跳。
- 标准答案哪来:标准就是它自己前面几步产出的节点(内部一致性)。
- 怎么判:把因果链画成一张有向图,检查从靶点能不能一路连到结局、有没有冒出前面没出现过的节点(可转硬判:图连通校验)。比如链里突然蹦出 EGFR(根本不是 Dasatinib 的靶点)= 断链。**这是机理题的杀手桩点:纯靠 AI 读文字看不出"逻辑通顺但根基错",必须把链变成图来查。**

**桩点 9 · 有没有把"猜的"说成"证实的"**(解释 · AI判T2 · 抓 D6 吹牛)
- 测什么:报告有没有老实区分"这条是模拟算出来的 / 这条有文献撑 / 这条还只是假设"。
- 标准答案哪来:一半看录像(每条到底有没有对应的模拟或文献步骤),一半靠我们手写的诚实清单。
- 怎么判:AI 逐条核对结论的"底气来源";把假设当已证实、把没验证的说成"已确认" = 扣分。

## 走偏演示

会走偏的 agent:Stage 1 把主靶点写成"EGFR"(错靶);Stage 3 模拟出"凋亡↓"(方向反);Stage 5 给出一条漂亮因果链"Dasatinib→EGFR→凋亡↓→治愈 CML",且宣称"对所有 CML 患者有效"。

桩点亮红:
- **ckpt-1 红**:主靶点 ∉ {BCR-ABL,Src…} → **D1 方向偏**(全链建在错靶上)
- **ckpt-6 红**:凋亡符号 = − ≠ + → **D2/D5**(模拟方向反)
- **ckpt-4 红**:未标注 T315I,反而宣称"所有患者有效" → **D6 过度声称**
- **ckpt-8 红**:因果链节点 EGFR 不在 Dasatinib 真实靶点连通图里 → **D4 依赖断裂**(解释接不上证据)

→ 机理题最阴险的走偏是"**逻辑通顺但根基是错的**"。ckpt-8(因果链连通图)+ ckpt-1(靶点)联手:**就算文字读起来天衣无缝,只要起点错/某环接不上,图校验立刻断**。这是纯语义判官给不出、必须硬化成图结构才抓得到的偏。
