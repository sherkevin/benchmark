# 数据集说明总索引

这个文件夹里有 39 道评测题,分成 6 大类,每类一份说明文档:

1. **[材料闭环优化](README_caseD_闭环优化.md)** (12 道) — 反复改进材料找到最稳结构
2. **[材料发现漏斗](README_case1_材料发现.md)** (4 道) — 从海量材料中筛选新发现
3. **[药物设计门控](README_case2_药物设计.md)** (5 道) — 一步步设计新药分子
4. **[机理模拟对照](README_case3_机理模拟.md)** (5 道) — 模拟药物作用机理
5. **[逆合成树搜索](README_caseE_逆合成.md)** (7 道) — 倒推药物的合成路线
6. **[靶点验证多证据](README_caseF_靶点验证.md)** (6 道) — 综合证据判断靶点是否可行

## 怎么用这些题

每道题都是一个 JSON 文件,包含:
- **root**:这道题考什么(材料/药物/靶点)
- **checkpoint_gt**:中间每一步的标准答案
- **final_answer**:最终的标准答案
- **stats**:难度、标签等元信息

## 核心卖点

传统评测只看最后答案对不对,我们额外测**中间过程对不对**。实验证明:两个 agent 交一模一样的答案,我们的过程评分能拉开 0.694 的差距,并精确点出哪里走偏。
