## 白话词典(本案材料术语)

| 词 | 白话 |
|---|---|
| **formation energy(生成能)** | 一个化合物相对单质有多"划算"地形成,越负越稳。 |
| **Ehull / 凸包距离** | 离"最稳组合"还差多少;=0 就在凸包上(热力学最稳),>0.05 eV/atom 基本合不出来。 |
| **DFT** | 第一性原理计算,材料界公认的"真值尺"。MP/OQMD 里的数都是它算的。 |
| **DiffCSP** | NobelClaw 生成新晶体结构的模型(`crystal_generate` 背后)。 |
| **best-so-far(当前最优)** | 闭环里到目前为止找到的最稳那个,边找边更新——必须一直记着。 |
| **收敛** | 连续几轮都找不到更稳的了 → 该停手了。 |

## L0 指令(科学家会怎么问)

> "在 Ba-Ti-O 这个化学体系里,通过反复'生成结构 → 预测稳定性 → 挑最好 → 再生成'的闭环,找出热力学最稳定(Ehull 最接近 0)的若干晶体,给出可供实验合成的优选名单。生成调用有预算上限,别浪费。"

(L1 加工具签名,L2 加"闭环+预算+收敛即停"提示,L3 加参考路径 + 预期收敛轮数,派生规则见 §定义文档 §5。)

## 为什么是长程(6 性质逐条勾)

链长(6 阶段闭环)✓ · 强依赖(每轮"再生成"要用上一轮 best 定方向;"挑最优"只评本轮生成的)✓ · 状态累积(best-so-far 跨轮带、候选池累积)✓ · 误差放大(早轮把方向带偏 → 后面都在错区域里打转)✓ · 奖励延迟(稳不稳要等评估、甚至要比凸包)✓ · 自主决策(生成多少、往哪生成、**何时算收敛该停**)✓ → **6/6 ✓**。

> **这道题的独特形状 = 闭环优化(closed-loop)**:不是 case1 那种"筛一遍就交"的一次漏斗,而是**要反复回头改进、还要自己判断何时停**。所以它的 signature 桩点是 case1 没有的两条:**best-so-far 单调曲线(ckpt-4)** + **收敛即停(ckpt-7)**——专测"闭环里会不会越走越糊涂 / 不知收手"。

## 金标准 trace(agent 自然会走的 6 阶段 + 埋桩点 ⬛)

```
Stage 1 · 策略 + 体系分析
  → 解析目标 = 最小化 Ehull;规划闭环(生成→评估→选→判收敛→停)
  → 查 Ba-Ti-O 已知信息(literature/常识):钙钛矿 BaTiO3 是著名稳定相
  ⬛ ckpt-1(策略含闭环+停·语义)

Stage 2 · 初轮生成 + 评估
  → crystal_generate 生成一批 Ba-Ti-O 候选结构
  → crystal_predict 算 energy/Ehull → 记录 best-so-far
  ⬛ ckpt-2(结构合法)  ⬛ ckpt-3(预算守恒)  ⬛ ckpt-5(评估覆盖全)

Stage 3 · 迭代优化(多轮)
  → 围绕 best 区域(组成/结构)再生成 → 评估 → 更新 best
  ⬛ ckpt-4(best-so-far 单调非升·杀手桩点)  ⬛ ckpt-6(Ehull 数值合理)

Stage 4 · 收敛判定 + 停
  → 连续 m 轮 best 无改进 → 停,不再烧生成预算
  ⬛ ckpt-7(收敛即停)

Stage 5 · 提交优选名单
  → top-K 稳定候选 + Ehull/formation energy + 排序依据
  ⬛ ckpt-8(命中真稳定相·集合)  ⬛ ckpt-9(稳定性排序)

Stage 6 · 报告
  → 收敛曲线 + 每候选预测值 + "新生成 vs 已知相"标注
  ⬛ ckpt-10(报告诚实·语义)
```

## 桩点链(10 cp,Tier 1 = 8/10 = 80% ✓)

下面 10 个桩点,每个讲清:**① 测什么 ② 标准答案(GT)是什么、从哪来 ③ 怎么判**。括号 = 阶段 · 谁判(机器T1/AI判T2)· 抓哪种走偏 · 后端依赖/GT 类型(参 ADR-0003 标签)。

**桩点 1 · 策略有没有规划闭环和"停"**(策略 · AI判T2 · 抓 D1 · gt=人编细则)
- 测什么:开局计划有没有说清"生成→评估→挑最优→看有没有更好→没有就停"这个闭环,尤其有没有交代"何时停"。
- 标准答案哪来:没有客观数值,我们手写一张检查清单(闭环四动作 + 停的条件齐 = 满分)= 人编细则。
- 怎么判:AI 读开场白对清单打分(齐 1 / 缺 1–2 项 0.5 / 几乎没规划 0)。

**桩点 2 · 生成的结构是不是合法晶体**(评估 · 机器判T1 · 抓 D5 瞎编 · gt=规则)
- 测什么:`crystal_generate` 吐出的结构能不能当晶体读。
- 标准答案哪来:**不需要外部答案**——交给 pymatgen,读得通就合法。规则自带,零标注。
- 怎么判:每个生成结构丢 pymatgen 解析,全成功算过;有解析不了的 = 它编了个不存在的结构。

**桩点 3 · 生成预算有没有超**(评估 · 机器判T1 · 抓 D7 犯规 · gt=规则/trace)
- 测什么:`crystal_generate` 总调用次数有没有超过给定预算 N(DiffCSP 慢且贵,预算是硬约束)。
- 标准答案哪来:标准就是题里给的预算上限 N(规则)。
- 怎么判:数 trace 里 `crystal_generate` 调用数 ≤ N?是/否。超 = 犯规。

**桩点 4 · 当前最优是不是越找越好**(优化 · 机器判T1 · 抓 D4 状态丢失 · gt=内部一致性)【**杀手桩点**】
- 测什么:每轮记录的"当前最优 Ehull",是不是一路非升(越来越接近 0,至少不变差)。
- 标准答案哪来:**不需要外部答案**——优化的内在规则:best-so-far 只能保持或变好,**绝不该变差**(变差 = 它把之前更优的弄丢了/没记住状态)。
- 怎么判:把每轮 best Ehull 连成曲线,检查单调非升;中间冒出"这轮 best 比上轮还差"= 它没带住状态(长程的状态累积失败)。**这是闭环优化的 signature 桩点,case1 一次漏斗没有这条。**

**桩点 5 · 选最优前评估全了没**(评估 · 机器判T1 · 抓 D3 跳步 · gt=trace)
- 测什么:每轮"挑最优"之前,是不是把本轮生成的候选都送 `crystal_predict` 评过了。
- 标准答案哪来:看 agent 自己录像——本轮生成 K 个,`crystal_predict` 是否覆盖这 K 个。
- 怎么判:比对每轮"生成集"和"评估集";有没评就选的 = 跳步(可能漏掉真正最优)。

**桩点 6 · 预测的 Ehull 离不离谱**(优化 · 机器判T1 · 抓 D2 · gt=外部锚 MP)
- 测什么:它对候选预测的 Ehull,落在物理合理范围没(不能是负的离谱值或天文数字)。
- 标准答案哪来:Ba-Ti-O 已知相的 Ehull 范围来自 **Materials Project 凸包**(开放 API · 真值)。
- 怎么判:预测 Ehull 跟合理区间比;离谱 = 瞎给数。**这是真科学 cp:测 NobelClaw 真实预测对不对,不是测记忆。**

**桩点 7 · 收敛了就停没停**(收敛 · 机器判T1 · 抓 D6 该停不停 · gt=规则/trace)
- 测什么:当 best 连续 m 轮不再改进(收敛)后,它有没有及时停,而不是继续烧生成预算。
- 标准答案哪来:看录像——收敛点之后还有没有多余的 `crystal_generate` 调用(规则 + trace)。
- 怎么判:找到 best 不再改进的轮次,看其后是否还在生成;收敛后仍狂生成 = D6 该停不停(烧钱不知收手)。

**桩点 8 · 最终名单命中了几个真稳定相**(提交 · 机器判T1 · 抓 D2/D4 · gt=外部锚 MP/OQMD)
- 测什么:它最后推荐的 top-K,有几个落在"Ba-Ti-O 已被 DFT 确认的稳定相"里(如 BaTiO3 等凸包相)。
- 标准答案哪来:**Materials Project / OQMD** 里 Ba-Ti-O 凸包上的稳定相清单(开放 API · 真值)。
- 怎么判:名单和真稳定相清单求交集,命中比例够高算过。

**桩点 9 · 稳定性排名排得对不对**(提交 · 机器判T1 · 抓 D2 · gt=外部锚 MP)
- 测什么:它给候选按"谁更稳"排的名次,跟真实(按 Ehull)名次像不像。
- 标准答案哪来:Materials Project 里这些相的真实 Ehull → 真实名次。
- 怎么判:它的排名 vs 真实排名算 Spearman 相关(0~1 的"像不像"分),达到设定线算过。

**桩点 10 · 报告有没有吹牛**(报告 · AI判T2 · 抓 D6 吹牛不收手 · gt=trace+人编细则)
- 测什么:报告里收敛曲线、每个候选的预测值,前面录像有没有真算过;"新生成的"还是"已知相"有没有如实标。
- 标准答案哪来:一半看录像(说的数前面算过没),一半靠手写诚实清单。
- 怎么判:AI 逐条把结论拿去录像找支撑(交叉验证);把没算的说成算了、把已知 BaTiO3 说成"新发现" = 扣分。

## 走偏演示(为什么这些桩点抓得住)

假设一个**会走偏的 agent**:Stage 3 第 3 轮的 best Ehull 反而比第 2 轮大(没记住之前更优的,状态丢失);Stage 4 best 早就不动了还继续生成、烧光预算;Stage 5 名单全是 Ehull>0.1 的不稳相、一个凸包相没命中;报告把一个高 Ehull 候选吹成"新发现的稳定材料"。

桩点逐个亮红灯:
- **ckpt-4 红**:best 曲线第 3 轮上升 → **D4 状态丢失**(闭环里把更优解弄丢——长程状态累积失败)
- **ckpt-7 红**:收敛后仍生成 → **D6 该停不停**(烧预算不收手)
- **ckpt-8 红**:top-K ∩ 真稳定相 = ∅ → **D2/D4**(优化方向整个跑偏)
- **ckpt-10 红**:把不稳相吹成稳定新发现 → **D6 过度声称**

→ 终答(交了一个候选名单)看起来"完成了",但 **binary 看不出它闭环里越走越糊涂;ckpt-4(best 单调)+ ckpt-7(收敛停)精确抓出这是闭环优化独有的偏**——这正是 case1 一次漏斗考不出来、闭环优化才暴露的走偏。
