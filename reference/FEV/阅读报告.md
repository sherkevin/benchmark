## 0. 一句话

**它是一篇综述，且它的核心主张就是我们的核心主张**：

> `we argue that agentic bioinformatics should be assessed through workflow correctness rather than final-answer correctness alone.`

## 2. FEV 三分框架

| 维度 | 含义 |
|---|---|
| **Function（功能）** | 已展示的**工作流操作**（做了哪些事） |
| **Evidence（证据）** | 对动作与结论的**可追溯支撑** |
| **Validation（验证）** | **针对具体用例**的验证 |

**它的核心诊断**：跨领域来看，**规划与工具介导的执行进展远快于**——可重放性（replayability）、溯源（provenance）、稳健的科学评估、外部验证、前瞻性实证测试。

**翻成人话**：agent 越来越会"做"，但"能不能查、能不能复现、能不能被独立验证"这些跟不上。

---

## 3. 对我方：可借 / 可打点

**可借（这是本篇最大价值）**：

**它是我们立论的最强外部支撑**，因为：①它是综述（覆盖 128 篇），代表领域视角而非单篇主张；②它的主张与我们的设计**逐条对应**：

| FEV 维度 | 我们的对应机制 |
|---|---|
| Function | cp1–cp6 记录做了哪些操作 |
| **Evidence** | **真值从 tool call 反查；声称未查证的 ID 在 cp3 记 0** |
| Validation | 23 条质量门 + 金标准/非解轨迹双检验 |
| **replayability（可重放）** | 我们的判分器同轨迹重判结果一致 |

**可打点**：它是综述不含题集，引用时归入"方法论主张"类，不进 benchmark 对照表。
