## 一条完整 case（长什么样）

任务来自 ALFWorld（如「把两个钥匙链放进保险箱」）；奖励 = 稀疏终态 + 四个元推理标签(planning/explore/reflection/monitor)的规则化过程奖励

## 数据格式

ReAct 轨迹 + XML 元推理标签；过程奖励规则可验证（如 explore 分 = 动作是否指向新物体/位置）。用现成环境，非新数据集

## 对我方的意义

过程级 verifiable reward 的先例；但其「可验证」比我方 checkpoint 断言弱（标签由 agent 自声明）
