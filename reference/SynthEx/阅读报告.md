# SynthEx · 天然产物合成规划（专家盲评认可其关键步骤）

> **原文**：Strategy-first synthesis planning for complex natural products
> **出处**：arXiv:2608.07454，2026-08-07，cs.MA / cs.AI
> **阅读方式**：基于完整摘要与元数据

## 0. 一句话
**它最值得注意的是评价方式**：在**盲评**中，专家化学家判定其关键步骤**可与已发表的人类合成路线相比**，并把它们当作**真正的合成方案**来对待——这是算法路线预测此前未做到的。

## 1. 关键数字
| 项 | 内容 |
|---|---|
| 产物 | **SynthAtlas** —— 一千余个天然产物的合成路线，开放交互式数据库 |
| 对象 | 复杂天然产物（密集官能化、多环骨架），传统设计算法难以覆盖 |
| 机制 | agentic 框架：**提出竞争性策略 → 把常规步骤与关键步骤组装成连贯路线 → 自我批评并改进** |
| 特征 | 其偏好的化学**更收敛（convergent）**，覆盖了目录型工具无法企及的反应空间区域 |
| 评价 | **盲评**：专家判定关键步骤可比于已发表人类合成 |

## 2. 机制与判分
**专家盲评**（人工判定，软），非自动判分。但"盲评 + 与人类路线对比"的设计严谨。

## 3. 对我方
**可借（一条重要的方法学）**：

**盲评设计值得我们参考**。它没有用 LLM 裁判，也没有用自动指标，而是让专家在**不知道路线来源**的情况下判断质量。这规避了"评测者偏向已知答案"的问题。

**对应到我们**：owner 已定"case 必须工程师手写"。若将来要论证我们的题目质量，**盲评（让化学专家在不知道题目来源的情况下判断题目是否合理）比我们自己声明 23 条质量门更有说服力**。

**可打点**：①它指出一个尖锐问题——现有逆合成工具"**在同源基准上报告接近完美，因为工具本身是照着那些基准塑形的**"（shaped to fit benchmarked chemistry）。**这是对基准与方法共同进化的批评，我们必须自省**：我们的 23 条质量门是否也在把题目塑形成"我们的判分器好判的样子"？②它是方法非评测，归入"同域系统"类。
