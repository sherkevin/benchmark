# ABC-Bench · 生物安全相关的 agent 能力评测（ICML 2026）

> **原文**：ABC-Bench: An Agentic Bio-Capabilities Benchmark for Biosecurity
> **出处**：arXiv:2606.11150，2026-06-09，**ICML 2026**
> **阅读方式**：基于完整摘要与元数据

## 0. 一句话
**它的三项任务全部由湿实验验证过**，且**所有被测 agent 在三项任务上都超过了人类专家基线的中位数**——这是"agent 已在部分科学任务上超人"的一条硬证据。

## 1. 关键数字
| 项 | 内容 |
|---|---|
| 任务 | 3 项：给液体处理机器人写代码 · 为体外组装设计 DNA 片段 · **规避 DNA 合成筛查** |
| 对照 | 人类专家 baseliner 的中位数 |
| 结果 | **全部被测 agent 在全部三项上超过人类中位数** |
| 弱项 | 需要**新颖生信推理**的任务表现较弱（已发表知识与成熟协议的任务表现好） |
| **湿实验验证** | 3 次；o4-mini-high 产出的脚本在 OpenTrons 液体处理机器人上**成功组装出预期序列的 DNA** |

## 2. 机制与判分
能力对比型评测（agent vs 人类专家），判定靠实际执行结果（部分经湿实验）。**判定是硬的**（DNA 序列比对、机器人执行成功与否）。

## 3. 对我方
**可借**：①**"已发表知识/成熟协议做得好、新颖推理做得差"**这个二分与 AutonomousScienceRoadmap 的"封闭式接近专家、开放式只完成一小部分"完全一致，**两篇独立佐证同一结论**，可用于支撑我们区分 fixed 与 open 两类题；②它有真实的人类专家基线，我们目前**没有人类基线**——这是我们对外发布时会被问到的问题，应提前准备说法（我们的题是从库里选，人类做同样任务也需要查库，基线可比性需论证）。

**可打点**：它含 dual-use 风险内容（DNA 合成筛查规避），我们的 benchmark 无此维度。归入"科学域能力评测"类。
