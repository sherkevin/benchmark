## 0. 一句话

**它是我们"顺序/依赖判定"这一维度最直接的同类**——摘要明写 **DAG-grounded trajectory synthesis**，且环境里编译了 **hidden evidence graphs（隐藏证据图）** 与 verifiers，使得"**分析进展可以在交互过程中被检查**"。

**但它的 DAG 是用来训练的，我们的 DAG 是用来判分的**（详见 §3）。

---

## 1. 三个组件的分工

| 组件 | 做什么 |
|---|---|
| **SciThèque** | 把**假设 · 数据集 · 隐藏证据图 · 验证器**编译成任务环境，使分析进展**可在交互中被检查** |
| **DAG-grounded trajectory synthesis** | 用这些环境构造**经验证器过滤的**多轮示范轨迹 |
| **DiscoPO** | 把环境本身当训练信号来源，对"产生可验证分析证据的动作"赋 **turn-level credit** |

**成绩**：SciDisco-14B 在假设驱动的科学数据分析基准上达到 SOTA。

## 2. 它解决的问题（与我们同源）

> `Long-horizon scientific analysis remains constrained by the lack of process supervised environments over real-world scientific data.`
>
> （长程科学分析仍受制于**缺少针对真实科学数据的过程监督环境**。）

---

## 3. 与我们的准确差异（三重）

| | SciDisco | 我们 |
|---|---|---|
| **DAG 的用途** | **训练**：合成示范轨迹 + 赋 turn-level credit | **评测**：判实际轨迹是否满足偏序约束 |
| **证据图的位置** | **隐藏**（hidden evidence graph），用于验证器判定 | 我们的对应物是 per-case 视图 + B 侧隔离 |
| **产物** | 一个被训练出来的模型（SciDisco-14B） | 一套题集 + 判分器 |

**核心区别一句话**：**它用 DAG 教 agent 怎么走，我们用 DAG 判 agent 走对没有。**

**一个值得注意的呼应**：它的"隐藏证据图"与我们的"答案隔离在 B 侧"思路一致——**都把判定所需的真值放在 agent 看不到的地方**。这是独立得出的相同设计选择，可作为该设计合理性的佐证。

---

## 4. 对我方：可借 / 可打点

**可借**：①`process supervised environment`（过程监督环境）这个提法比"过程级 benchmark"更准确地描述我们做的东西；②它的"verifier-filtered 示范轨迹"与我们的"金标准轨迹回放全过"是同一机制的两种用途。

**可打点**：①它是 RL 训练框架，判定服务于赋 credit，**不构成 benchmark 对照**，在对比表中应单列"训练用 DAG"一类；②它的领域是科学数据分析（统计断言），不是化学/材料的分子筛选。
