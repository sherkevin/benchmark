# CriticExperienceBank · 行动执行前的步级置信度

> **原文**：Critic Experience Bank: Self-Evolving Step-Level Confidence Estimation for LLM Agents
> **作者**：Yaopei Zeng, Congchao Wang, JianHang Chen, Nan Wang, Yurui Chang, Lu Lin
> **出处**：arXiv:2607.12397，2026-07-14，cs.AI
> **阅读方式**：基于完整摘要与元数据

---

## 0. 一句话

**它要的是"这一步动作值不值得做"的事前概率**——在动作**执行之前**就给出一个校准过的概率，判断该动作是否会推进任务。

**与我们的根本区别**：我们是**事后判**（动作做完了，看卡点达成没有），它是**事前判**（动作还没做，预测它有没有用）。

---

## 1. 它的问题陈述（与我们的立项动机同源）

> `LLM agents act in external environments where each action changes the state that later decisions condition on, and where a single wrong step can waste interaction budget or trigger irreversible side effects long before the final failure is observed.`
>
> （agent 在外部环境中行动，**每个动作都会改变后续决策所依赖的状态**，而**一个错误步骤可能在最终失败被观察到之前很久，就已经浪费了交互预算或触发了不可逆的副作用**。）

**这段话是"为什么必须判过程"最凝练的表述之一**：错误在终态之前很久就发生了，只看终态等于放弃了归因。可直接引用。

---

## 2. 机制与成绩

| 项 | 内容 |
|---|---|
| 核心结构 | 自演化的 critic：LLM 裁判**累积自己过去判断及其实际后果**作为证据 |
| 伪标签来源 | 每条轨迹跑完后，一个**能看到完整执行反馈的 hindsight LLM** 投票判定每一步是否"有成效" |
| 记忆库 | 伪标签填充记忆库；遇到相似步骤时检索相关的"有成效/无成效"经验注入裁判提示 |
| 训练需求 | **无需训练、无需真值步级标签** |
| 成绩 | 三个 agent benchmark × 三个裁判骨干，**校准（ECE、Brier）与排序（AUC）全部最优**；ECE 相对最强免训练基线**降低最多 54%** |

## 3. 对我方：可借 / 可打点

**可借（一条概念，一条警示）**：

1. **hindsight（事后回看）标注法**：跑完整条轨迹后，用能看到全局的模型回头标注每一步。**我们其实有更强的版本** —— 我们不需要 LLM 投票，因为我们有确定性的卡点判据。但这个思路可用于**分析**：跑完矩阵后回看轨迹，统计"哪一步开始走偏"，这是我们目前没做的诊断。

2. **它的伪标签是 LLM 投的，因此是软标签**。这提醒我们在对比文档里要区分：**步级判定 ≠ 硬判定**。市面上很多"step-level"工作的步级标签本身是 LLM 或人工给的，我们的是断言算出来的。

**可打点**：它是方法（提升 agent 可靠性），不是 benchmark。归入"步级评估方法"类。
