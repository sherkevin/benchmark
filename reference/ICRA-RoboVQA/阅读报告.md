## 0. 一句话

用"众包自顶向下拆解长程任务"的方式高效采数据：先给人一个长程任务，让他拆成中程步骤并录视频，从而同时拿到**中程步骤**与**长程连贯序列**；得到 829,502 个 (video, text) 对、29,520 条唯一指令，训出的 video-conditioned 模型（RoboVQA-VideoCoCa）能引导真实机器人完成长程任务。

## 1. 数据量

| 量纲 | 数值 |
|---|---|
| (video, text) 对 | **829,502** |
| 唯一指令数 | **29,520** |
| 任务层级 | long-horizon 任务 → 拆成 medium-horizon 步骤 |
| 附加分析 | 论文专门算了**采集成本经济学**：在固定采集预算下，这种自顶向下众包方式比其他方案更划算 |

**读数**：这是本批里数据量最大的一篇（10⁵ 量级），因为它是**训练数据集**而非评测集。**ICRA 的"数据集+benchmark"论文往往是感知/训练数据集，量级大但判分浅。**

## 2. 数据集形态

一条样本 = **（一段视频，一个文本问答对）**，问答类型多样（例："what just happened?"、"下一步该做什么"、"任务完成了吗"）。

- **采集手法（本文最值得学的一点）**：**自顶向下的众包拆解**——不是让人一条条录中程动作，而是给一个长程任务让人自己拆，于是"长程连贯性"是免费附带的。论文明确论证：即便只关心中程步骤，用这种方式采也更划算。
- 数据同时支持多种下游任务（VQA、规划、成功判定、可执行性判断等），所以一份数据能撑起一个多任务 benchmark。

## 3. "长"体现在哪

**物理执行的长程 + 视觉时序的长程**：

1. 一个长程任务（如"清理桌面"）含多个中程步骤，每个中程步骤含多个动作；
2. 判断"接下来做什么"必须依赖**视频**（即历史观测），而不是单帧——这是它强调 video-conditioning 的原因；
3. 真机验证：模型能引导真实机器人走完长程任务。

## 4. 判分粒度

以 VQA 式指标为主（答案匹配/BLEU 类），并有真机成功率。**没有过程 checkpoint 判分**；"过程"在这里是被拆成一堆独立 QA 样本，而不是被当作一条需要保序的轨迹来判。

## 5. 对我方：可借 / 可打点

**可借**
1. **"自顶向下拆解 + 长程连贯性免费附带"这个采集哲学非常值钱**。映射到我们：**不要一条条造 checkpoint，而是先造一条完整的专家级发现流程，再从中切出 checkpoint**——长程依赖结构就自动来了。这与我们 GT-first 反查的第 3 步方向一致，但 RoboVQA 明确给出了"这样更省钱"的经济学论证，可以引用。
2. **一份数据支撑多类任务**：我们的一条 case（分子 + 性质 + 流程）也可以同时支撑"找分子"、"判断某候选是否合格"、"下一步该查什么"、"任务是否已可交卷"多种题型。这能显著提高数据的复用率与论文的丰满度。
3. **成本经济学分析**：审稿人会问"造这个 benchmark 要多少人力"。像 RoboVQA 一样把成本算清楚是加分项。

**可打点 / 差异**

| 维度 | RoboVQA | 我们 |
|---|---|---|
| 长程来源 | 物理动作序列 + 视频时序 | 信息依赖链 + 数值约束推理 |
| 判分 | VQA 匹配 + 真机成功率 | checkpoint 断言 + 路径闸门 |
| 定位 | 训练数据集（10⁵） | 评测集（10²）+ 可生成训练实例 |

## 6. ICRA 调性判读（本报告的核心用途）

从 DBLP 对 `conf/icra` 的检索（2022–2025，见 `../../task/task9/目标会议长程benchmark横评.md`）可见 ICRA 的 "long-horizon" 几乎全部是：
- **long-horizon manipulation / TAMP**（任务与运动规划）；
- **long-horizon navigation / loco-manipulation**；
- **LLM 作为 PDDL 翻译器或高层规划器**（FLTRNN、ISR-LLM、CaStL、LaMMA-P）。

而 ICRA 的 "dataset & benchmark" 论文几乎全是**感知类数据集**（LiDAR 位置识别、越野可行区、水果形状补全、导盲机器人指令、V2V 感知）。

**结论：ICRA 不是我们的目标会议。** 我们的题目没有物理本体、没有运动规划、没有传感器数据；投过去审稿人会问"机器人在哪里"。它的价值仅在于：① 借用它的长程分层思想（长程→中程→原子）；② 在 Related Work 里用一句话说明"具身长程"与"信息型长程"是两条独立脉络。
