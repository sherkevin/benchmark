# ToolMATH · 长程工具链的三轴诊断（含 Tool Connectivity）

> **原文**：ToolMATH: A Diagnostic Benchmark for Long-Horizon Tool Use under Systematic Tool-Catalog Constraints
> **作者**：Hyeonje Choi, Jeongsoo Lee, Hyojun Lee, Jay-Yoon Lee
> **出处**：arXiv:2602.21265，2026-02-24（v2 2026-05-18），投 NeurIPS Evaluation & Dataset Track
> **阅读方式**：基于完整摘要与元数据

---

## 0. 一句话

**它的第三条评测轴 Tool Connectivity 与我们的顺序判定关切同一件事**——衡量模型**在长的已执行工具调用链上能否保持正确**。

---

## 1. 构造机制

把 MATH 数据集的**逐步解题过程转成可复用的 Python 工具**（带自然语言描述与类型化 schema），每道题配一个工具环境，要求：**顺序使用工具 · 复用中间输出 · 形成逻辑相连的工具调用链**。

**难度控制手法（值得借）**：构造**金工具（gold tools）** 与**分级干扰项（graded distractors）**，干扰项与金工具的相似度可调。

---

## 2. 三条评测轴

| 轴 | 定义 | 对应我们 |
|---|---|---|
| **Adaptability（适应性）** | 当金工具**被干扰项完全替换**时，还能保留多少 Gold-only 成功率 | 我们无对应项（工具集固定） |
| **Robustness（鲁棒性）** | 加入干扰项作为噪声后的稳定性 | 我们无对应项 |
| **Tool Connectivity（工具连通性）** | **在长的已执行工具调用链上能否保持正确** | **对应我们的 cp 链 + 偏序判定** |

另有 **behavior-conditioned metrics**（行为条件化指标）与 **trace-level failure analyses**（轨迹级失效分析），使评测超越终态准确率。

---

## 3. 它区分出的四种模型画像

摘要称这些诊断揭示了不同的模型剖面：**可靠的工具使用 · 工具回避（tool avoidance）· 适应性替换 · 不可靠工具目录的影响**。

**"工具回避"这一项与 OpenBioRQ 的 agentic collapse 呼应** —— 两篇独立工作都观察到 agent 会在困难处放弃使用工具。**这已经构成一个可引用的共识现象**，而我们的 cp1/cp3 正好能量化它。

---

## 4. 对我方：可借 / 可打点

**可借**：
1. **`Tool Connectivity` 这个指标名比 `no_path_violation` 好懂**，可作为对外表述的备选。
2. **"分级干扰项"这个手法可用于我们的强化版出题**：在候选池里塞入"看起来满足约束但实际差一点"的近邻实体，考验 agent 是否真去查证而非凭相似度猜。**这是提升区分度的一条具体路径。**

**可打点**：它是数学域、工具由解题步骤合成（非真实科学 oracle），不满足我们"工具需覆盖真实科学接口"这条边界。引用时归入"工具调用评测"类。
