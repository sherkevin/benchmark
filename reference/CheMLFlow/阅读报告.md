# CheMLFlow · 化学与材料信息学的工作流平台

> **原文**：CheMLFlow: An Open-Source Platform for Cheminformatics and Materials Informatics Applications
> **出处**：arXiv:2608.04942，2026-08-05
> **阅读方式**：基于完整摘要与元数据

## 0. 一句话
**它是平台不是评测**，但它把科学 ML 的完整管线（取数→清洗→表示→训练→验证→筛选→解释→报告）模块化，且明确面向"coding agent 辅助实验"设计。

## 1. 关键数字
| 项 | 内容 |
|---|---|
| 定位 | 开源平台，构建端到端、高通量、**agentic** 工作流 |
| 解决的痛点 | 研究者即使只贡献一个环节，也得把全套管线拼起来 |
| 组件 | 模块化工作流组件 · 可直接跑的参考管线 · **标准化产物** · 评测输出 |
| 工程特性 | 可插拔表示与模型 · **确定性划分**（deterministic splits）· 显式运行产物 · 批量执行 · 报告生成 |
| 基准覆盖 | 量子力学、物理化学、生物活性性质预测达到文献水平；另有时间序列用例 |

## 2. 机制与判分
不适用（平台，非评测）。但其**确定性划分**与**显式运行产物**两条工程特性与我们的可复现要求同向。

## 3. 对我方
**可借**：①**"配置驱动的工作流 + 结构化输出为 coding agent 提供了实用接口"**这个观察值得注意——它说明科学软件正在主动为 agent 适配，这与我们用 MCP 统一暴露工具是同一趋势；②**确定性划分**这个提法可用于描述我们的快照库（同一快照下任何人跑出的真值相同）。

**可打点**：平台非 benchmark，无题集无判分。仅作为"领域基础设施"引用，不进对照表。
