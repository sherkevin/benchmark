## 一条完整 case（长什么样）

端到端发现子集 E2E-Bench：给一个研究问题，agent 从头做完小型研究（提方法→写代码→跑实验→给结论），在统一 Asta 环境（8 个 MCP 检索工具 + 有状态 Jupyter + 语料日期截止）内完成

## 数据格式

2400+ 题 / 11 子集 / 4 类（文献理解/代码执行/数据分析/端到端发现）；端到端子集仅 40+40 题。评 57 agents / 22 类

「benchmark 严谨性」五条 checklist 的出处（工具出厂/控成本/防污染/baseline）
