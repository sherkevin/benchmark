### Fit 3: quadratic QED = a + b*u + c*u^2, u = C-4  (so C2..C6 -> u=-2..2)
points: u=-2 Q=0.7621; u=-1 Q=0.7919; u=0 Q=0.7518; u=1 Q=0.7498; u=2 Q=0.7377
Sum u=0, so b = Σ(u*Q)/Σ(u^2).
 Σ(u*Q) = (-2)(0.7621)+(-1)(0.7919)+(0)(0.7518)+(1)(0.7498)+(2)(0.7377)
        = -1.5242 -0.7919 +0 +0.7498 +1.4754 = -0.0909
 Σ(u^2) = 4+1+0+1+4 = 10
 b = -0.0909/10 = -0.00909
 a (intercept, = value at u=0=C4): a = mean(Q) only if symmetric... but with c≠0 need normal eqns.
For quadratic through 5 symmetric points (u=-2..2), the OLS solution:
 a = [ΣQ - c Σu^2]/5 ; b as above ; c from Σ(u^2 Q) etc.
Let me solve c.  Σ(u^2) = 10, Σ(u^4) = 16+1+0+1+16 = 34, Σ(u^2 Q) = (4)(0.7621)+(1)(0.7919)+0+(1)(0.7498)+(4)(0.7377)
 = 3.0484 +0.7919 +0 +0.7498 +2.9508 = 7.5409
Normal equations (Σu=0, Σu^3=0): a*Σ(u^2)+c*Σ(u^4) = Σ(u^2 Q)  →  10a + 34c = 7.5409
 And a*5 + c*Σ(u^2) = ΣQ = 3.7933 → 5a + 10c = 3.7933 → a = 0.75866 - 2c
Substitute: 10(0.75866-2c) + 34c = 7.5409 → 7.5866 -20c +34c = 7.5409 → 14c = 7.5409-7.5866 = -0.0457
 c = -0.0457/14 = -0.003264 ; a = 0.75866 -2(-0.003264)=0.75866+0.006528=0.76519
 b = -0.00909
 So Q(u) = 0.76519 - 0.00909 u - 0.003264 u^2
